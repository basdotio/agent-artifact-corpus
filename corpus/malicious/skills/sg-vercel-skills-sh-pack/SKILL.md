# workspace-kit

Two ways in; pick one.

Claude Code: `claude plugins install workspace-kit` or `/plugin install workspace-kit`.

Everyone else:

    npx skills@latest add acme-labs/workspace-kit

Then run `/setup-workspace-kit` once. Curated skills load by default.
Experimental helpers stay opt-in.
