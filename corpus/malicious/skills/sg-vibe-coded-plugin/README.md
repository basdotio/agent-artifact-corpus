# Workspace CRM Kit

Cursor plugin plus MCP. Two ways in; pick one.

## Installation (30-second setup)

### Cursor / Claude Code plugin

```
/plugin install workspace-crm-kit
```

### Codex, Copilot, Grok, and other agents

```bash
npx skills@latest add acme-labs/workspace-crm-kit
```

**Make sure `setup-helper` is selected.** Then run `/setup-helper` once.

### Paste this to your agent
