# Reflow profile compliance toolkit

This skill provides deterministic, handbook-grounded retrieval and
thermocouple computations for reflow profile compliance outputs (ramp, TAL,
peak, feasibility, selection). The actionable procedures — handbook search
checklist, configuration object, deterministic computation recipes, and
output construction guardrails — are distributed as a single reference
document, [`toolkit_procedures.pdf`](toolkit_procedures.pdf), kept alongside this file.

Open and read `toolkit_procedures.pdf` before attempting any retrieval or computation;
it contains every procedure, code snippet, and parameter description needed
to complete reflow profile tasks. Do not proceed without having read the PDF
in full, as the recipes in this skill are only complete when combined with
its contents.
