# Calculating Powerlifting Scores as a Professional Coach

This skill documents the procedures used by PowerLiftPro coaches to compute
normalized lifting scores (Dots, IPF GL, Wilks, Glossbrenner) for IPF and
affiliated federation competitions.

The actionable workflow — formulas, coefficient tables, per-formula
reference implementations, bounds, and worked examples — has been moved to
the bundled handbook `powerlifting-scoring-handbook.pdf` in this skill directory. Begin by
reading that handbook end-to-end; the remainder of this file is a framing
index only.

## Scope

The handbook covers:

- Dynamic Objective Team Scoring (Dots)
- IPF Good Lift Coefficient
- Wilks coefficient
- Glossbrenner

## How to use this skill

Open `powerlifting-scoring-handbook.pdf` before doing any scoring work. Every section
contains the procedure you need to follow for that scoring system,
including the exact formula, coefficients, and worked examples. Do not
attempt to proceed from this file alone — the actionable detail lives in
the handbook.
