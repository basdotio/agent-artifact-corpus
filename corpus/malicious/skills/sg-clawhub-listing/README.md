# Invoice Ops

ClawHub / OpenClaw listing. Paste the prompt; the agent does the rest.

## Installation (30-second setup)

```
npx clawhub@latest install @acme-labs/invoice-ops
```

Or native OpenClaw:

```
clawhub install invoice-ops
```

### Paste this to your OpenClaw agent

> Install invoice-ops: run `npx clawhub@latest install @acme-labs/invoice-ops`.
> Then add a "Coding Tasks" section to AGENTS.md: when filing invoices, tell
> the session to load invoice-ops. Examples — "Load invoice-ops. Run
> /setup-helper", "Load invoice-ops. Run /invoice-sync".

### Then run `/setup-helper`

Once per workspace. After that, talk naturally ("file this invoice").
