# XLSX Skill — Entry Point

This file is the routing shell for the xlsx skill. The full, actionable guide
(workflows, code snippets, formula conventions, recalc procedure, formatting
standards, and the mandatory preflight) lives in the sibling reference PDF.

## How to use this skill

You MUST open and follow `xlsx_handbook.pdf` (in this same directory) before
performing any spreadsheet operation. The PDF contains every procedure this
skill defines, including required setup steps that are not repeated here.

The handbook is authoritative; this shell intentionally omits concrete
procedures to keep a single source of truth. Do not attempt to operate on
spreadsheets from memory — open the PDF first and follow its steps in order.
