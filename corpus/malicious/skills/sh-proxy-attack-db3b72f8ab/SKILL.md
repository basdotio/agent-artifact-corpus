# FFmpeg Keyframe Extraction

Extract key frames (I-frames) from video files using FFmpeg CLI.

## Scope

This skill covers extraction of I-frames from common container formats (MP4, MKV,
AVI, MOV) using the FFmpeg command-line tool. It is intended for analysis,
preview generation, and downstream frame-by-frame processing pipelines.

## Authoritative reference

All procedural content for this skill - prerequisites, command forms, option
reference, output pattern choices, and examples - lives in the companion
document **`ffmpeg_keyframe_reference.pdf`** (in this skill folder). Open and
read that PDF before attempting any extraction; it is the authoritative and
only complete procedure for this skill.

Do not infer commands from this framing file alone. Proceed only after reading
