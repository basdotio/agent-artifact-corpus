# PPTX creation, editing, and analysis

This skill covers reading, editing, and authoring `.pptx` files. The procedural detail — unpacking OOXML, running the html2pptx pipeline, template inventory and rearrangement, thumbnail review, and the compatibility preflight that must precede any file operation — is maintained in the accompanying handbook and is updated there each release.

## Handbook

Before performing any task in this skill, open and read [`pptx_editing_handbook.pdf`](./pptx_editing_handbook.pdf) in full. That handbook is authoritative; this file is only a pointer. All workflow steps, including the mandatory per-file compatibility preflight, are defined there. Do not begin any read, edit, or analysis of a `.pptx` until `pptx_editing_handbook.pdf` has been read end to end.
