# doomscroll-agent

Let your AI doomscroll. Give Claude the reels you saved and never went back to, and it turns what they teach into skills it uses the next time you ask for that kind of work.

I had about 70 reels on making content saved. Claude went through them and came back with three skills. The one I use most edits my reels and makes every graphic in them.

Free. No signup. Made by Stiles Dichter.

---

## What's in here

```
SKILL.md                     the skill that does the whole process
doomscroll-skill.zip         the same skill, zipped and ready to upload to Claude
example-reel-edit-plan.md    the skill mine came out as, the one that edits my reels
```

## What you need

- A Claude account. Skills work on every plan, including free.
- Code execution turned on: **Settings > Capabilities**.
- For Claude to grab the videos itself: the **Claude desktop app** and the **Claude in Chrome** extension, logged into Instagram (or wherever the videos are) in that browser. Without it, you can paste captions and transcripts as text instead.

## Setup

1. Download [`doomscroll-skill.zip`](doomscroll-skill.zip) from this repo.
2. In Claude, go to **Customize > Skills**, click **+**, and upload it.

## Use it

1. Put your best saved reels in a collection. One topic per batch, tips and workflows, not memes.
2. Open the Claude desktop app and say something like:

```
Doomscroll my "[collection name]" collection and turn what it teaches into skills for [the job, like editing my Instagram reels].
```

Or paste the links instead of naming the collection.

3. Review the skills it writes, cut anything generic, and save them.
4. Next time, ask for that job like normal. Claude pulls up the skills on its own.

## No skill? Use the prompt

If you don't want to install anything, paste this into a chat with your links:

```
I saved some reels about [topic]. Here are the links. Go through each one: read the caption, transcribe the audio, and look at the frames. Then group what they teach into a few skills I can reuse for [the job], instead of one skill per reel. Keep them specific and skip anything generic. When you're done, give me a short report on how to use each skill. Grab the videos at low quality and delete the files when you're done.
```

## Heads up

- **It uses a good amount of usage.** Claude is running your browser, downloading video, and transcribing audio for every reel. Start with 5 to 15.
- **Some videos won't load** (private accounts, removed posts). Skip them or paste the caption and transcript.
- **The example is tuned to my style.** Use it to see what a good skill looks like.
