# 直播输出模板（`contributes.live.template`）参考

> 唯一权威：`SPEC.md` §5.8。本页是**速查 + 自检**，冲突时以规范为准。
> 级别：**L2 声明式**（`kind:"asset"`、`permissions` **必须为空**、**无 `main`**）。骨架：`assets/plugin.live-template.json`。

## 1. 一句话

你的插件**不跑代码**，**也不发任何网络请求**：只声明「每行格式串」，由宿主把**已经解析好的直播频道**导出成文本文件。

```
宿主已解析的频道（LiveGroup[]）  →  按你的模板格式化  →  TXT / M3U 文件
             ↑ 解析是宿主引擎的事（你碰不到、也不需要碰）
```

## 2. 它在什么位置生效

- 出口在 **直播页顶栏**（导出「当前线路」）与 **配置 → 直播线路**（每行「导出」按钮）。
- 用户点「导出」→ 选择模板 → 宿主弹保存对话框 → 写**新文件**（绝不改动任何原始文件）。
- ★ **无插件时也照常可用**：宿主自带 2 个内置模板（`builtin:txt` / `builtin:m3u`）；你的模板会**追加**在它们之后。

## 3. 结构

```jsonc
{
  "type": "live.template",
  "id": "my-live-txt",          // [a-z0-9-]{3,40}；同一插件可声明**多个**模板（各自独立 id）
  "label": "标准 TXT",           // 导出面板里的选项名
  "format": "txt",              // txt | m3u（决定语义与**默认扩展名**）
  "group": "{group},#genre#",   // 可选：分组行模板（**不得含 {url}**，须单行）
  "header": ["#EXTM3U"],        // 可选：文件头，**逐行**（每项须单行）
  "line": "{name},{url}",       // ★ 必填：频道行模板（**必须含 {url}**；允许 \n 表达多行）
  "ext": "txt"                  // 可选：扩展名（不带点，[a-z0-9]{1,8}）；缺省按 format
}
```

- **`format:"txt"`** —— TVBox 惯用文本：分组行 + `名称,地址`（内置 `builtin:txt` 就是这套）。
- **`format:"m3u"`** —— 播放列表：文件头 `#EXTM3U`，每个频道两行（`#EXTINF…` + 地址）。
  m3u 的 `line` 里写 `\n` 就能让「EXTINF」与「地址」分两行（见骨架）。
- 一个插件可以给**多套**模板（如「标准 TXT」+「带 tvg 的 M3U」），用户导出时自己挑。

## 4. 占位符

| 占位符 | 取值 |
|---|---|
| `{group}` | 分组名 |
| `{name}` | 频道名 |
| `{url}` | 该行的线路地址（**一个频道多线路 → 每线路各输出一行**） |
| `{logo}` | 频道台标地址 |
| `{tvgId}` / `{tvgName}` / `{tvgChno}` | 频道 EPG id / 名 / 频道号 |
| `{index}` | 频道序号（1 起；**同一频道多线路共用同一序号**） |

- 值**原值替换**（不 `%` 编码）—— 导出的是给人 / 外部播放器读的文本。
- **越界占位符（如 `{foo}`）→ 拒装**；`group` 里**不得**用 `{url}`。

## 5. 渲染规则（宿主怎么拼）

1. 先输出 `header` 各项（若有）。
2. 逐分组：**无频道的分组整组不输出**；有 `group` 模板时先输出分组行。
3. 组内逐频道：**无地址的频道不输出**；对**每条地址**渲染一次 `line`。
4. 行连接符 `\r\n`，末尾补一个。空内容 → 空文件（m3u 至少剩 `#EXTM3U`）。

## 6. 自检（发布前逐条）

- [ ] `kind:"asset"`、`permissions: []`、**无 `main`**（本贡献类型**不发请求**，不要写 `url`/`headers`）
- [ ] `id` 匹配 `[a-z0-9-]{3,40}`；同插件内不重复；`label` 非空
- [ ] `format` 是 `txt` 或 `m3u`
- [ ] **`line` 含 `{url}`**；`line`/`group`/`header` 无 `\r`、无空行；`group` 与 `header` 是单行
- [ ] 占位符都在 §4 表内（**越界即拒装**）
- [ ] `ext`（若写）只含小写字母数字、不带点
- [ ] **真机两步**：装 → 「配置 → 直播线路」某行点「导出」能选到你的模板并写出文件
      → 停用插件后该模板消失（内置 2 个模板不受影响）

## 7. 打包（与其它声明式 contribute 一样：**没有 `files/`**）

```powershell
Compress-Archive -Path plugin.json, LICENSE -DestinationPath out.zip
Rename-Item out.zip my-live-template.winbox
```

## 8. 对照拒装原因码

`LIVE_TEMPLATE_INVALID`（结构 / 字段 / `format` / 占位符越界 / `group` 含 `{url}` / `header` / `ext`）·
`BAD_LIVE_TEMPLATE_LINE`（`line` 为空、缺 `{url}`、含空行）。

## 9. 常见坑

- **以为要写接口地址**：本类型**不发请求** —— 写 `url`/`headers`/`list`/`map` 一律拒装（那是 R2~R4 那几个 provider 的字段）。
- **`line` 忘了 `{url}`**：直接拒装（导出的行没有地址就没意义）。
- **m3u 只写一行**：`#EXTINF…` 与地址必须分两行 —— 在 `line` 里用 `\n` 分隔。
- **想反过来「解析」别人的直播订阅**：那是宿主引擎的行为（1:1 复刻），插件**不做**也不允许做。
- **想改导出到哪 / 怎么命名**：由宿主决定（保存对话框 + 新文件），插件只说「格式」。
