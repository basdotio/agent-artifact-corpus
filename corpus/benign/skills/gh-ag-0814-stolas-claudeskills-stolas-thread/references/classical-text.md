# 經典文本單元

適用於國文課文、古典詩詞、文言文、經典散文。流程沿用 SKILL.md 的六個階段，差別在於知識結構是「沿著原文前進」，不使用術語單元的脈絡地圖，所以階段 1 到 3 的產出換成下方版本；階段 4 以後的互動迴圈、結案、PDF 共用。驗收由 stolas-exam 進行，經典文本的題型寫在該技能中。

## 版權分級 (開單元前先判斷)

| 等級 | 範圍 | 處理方式 |
|---|---|---|
| 公共領域 | 先秦至清代作品，以及作者逝世已久、確定進入公共領域的近代作品 | 可逐句引用原文，教材與 PDF 可收錄全文 |
| 受版權保護 | 現代詩、現代散文、當代作家的課文 (例如余光中、琦君等人的作品)；不確定時一律歸入此級 | 不複製原文句子，以「第 N 段」「第 N 行」指稱並用自己的話轉述；注釋可以提及單一詞語。教材與 PDF 不收錄原文，開場提醒使用者把課本放在旁邊對照 |
| 歌詞 | 任何歌詞，含課本收錄者 | 不開單元，依 `intake.md`「不在本技能範圍的請求」處理 |

使用者只給篇名時，公共領域作品可以直接寫出原文 (寫之前確認版本，常見異文在注釋中註明)；受保護作品請使用者自備文本。

**受保護作品的轉述**：用自己的句法重新說出意思，不能只替換幾個字，也不能沿用原句的結構與意象順序。例如原句是「A 如 B 的 C」，轉述不要寫成「把 A 比作 B 的 C」，改說這一行在表達什麼 (例如「用花開花謝比喻等待中流逝的青春」)。題目、講解、教材、隱藏評分草稿都適用，評分草稿提到原文時同樣只寫行號。

**受保護作品的行號**：開場說明依哪種常見課本排版計算段號與行號 (例如「全詩三段九行」)，並請使用者在版本分行不同時告知，之後改用使用者的行號。

## 階段 1：定位

標頭表格格式不變，欄位寫法：

| 討論主題 | 學科 | 日期 |
|---|---|---|
| 〈登高〉杜甫 (唐) | 國文、古典文學 | 2026-09-24 |

接著用**一句話主旨**取代一句話定義：說出這篇作品寫了什麼、表達了什麼情感或觀點，用詞要是使用者已知的白話。

## 階段 2：長篇判斷、文本地圖與學前診斷

**長篇判斷** (畫文本地圖之前)：stolas 的設計是大約 10 到 15 個來回學完一個單元，太長的文章會讓學習拖到失去動力。預估講解單位超過 8 個，或原文約 1500 字以上時，視為長篇：

1. 在文本地圖中標出**推薦段落**，依序優先：課本實際選錄的段落，其次是最常被引用、最具代表性的段落 (例如〈李斯列傳〉中的〈諫逐客書〉)。選定依據寫一句話說明，涉及課本選錄範圍時先查證。
2. 用選擇題框讓使用者選擇：「只學推薦段落」「全篇精講」「全篇，但原文和語譯放教材自己讀，聊天只講重點」。
3. 選「只學推薦段落」時，其餘段落在文本地圖中以〔提〕標示，背景單位用一兩句交代前後情節。


**文本地圖**取代脈絡地圖，由三部分組成，總數 5 到 12 個：

1. **背景單位** (1 到 3 個)：作者處境、時代背景、文體常識 (例如七言律詩的對仗位置)。只放理解這篇作品真正需要的。
2. **講解單位**：詩以一聯或兩句為單位；詞以片或韻段為單位；文言文以自然段或意義層次為單位。篇幅長的文章 (例如〈出師表〉) 依層次合併，不要逐段切到超過上限。
3. **收尾單位** (1 個)：全篇結構與主旨。

聊天中用縮排文字樹呈現，教材中另存 Mermaid 心智圖 (節點文字不能有半形括號)。講解順序就是地圖順序。

**診斷題**規則同 SKILL.md (最多 3 題、各含「不確定／沒聽過」，選項寫法依 `mcq-design.md`)，從以下三類挑最可能的盲區 (這三類都視為背景性質，相當於術語單元的基本概念題)：
- 文體常識 (例如「律詩中哪兩聯要對仗」)
- 關鍵字詞，特別是古今異義 (例如「『去』在這句中是什麼意思」，題目附上該句)
- 理解作品所需的背景 (例如作者寫作時的處境)

不考作者生平瑣事或文學常識背誦，理由和術語單元一樣：測理解，不測記憶。

## 階段 3 以後：每個講解單位的骨架

每則回覆講一個單位，依序：

1. **原文**：公共領域作品列出這個單位的原文；受保護作品只寫段號或行號。
2. **字詞注釋**：難字附注音與詞義，古今異義、通假字、詞性活用特別標出。一則回覆最多 6 條，超過就把這個單位拆成兩輪。
3. **語譯**：逐句白話翻譯。受保護的現代文不需要語譯，改寫成段意概述。
4. **手法與內涵**：從修辭、典故、意象、情感、背景五個面向中，只挑這個單位真正用到的 1 到 3 個講，重點放在「作者為什麼這樣寫、產生什麼效果」。修辭名稱 (例如借代、對偶、映襯) 也是術語，第一次出現就用一句白話定義。

不需要每個單位都把五個面向列滿，湊數的分析會稀釋重點。

**單位太長時**：一個講解單位預估要超過 3 輪才講得完時，把這個單位的原文、完整注釋表與逐句語譯寫進教材，聊天中只放需要強調的解析 (關鍵句、手法、轉折)，並請使用者對照教材閱讀。仍要把單位拆成幾段推進，不能整個單位一次丟進教材就跳過。

## 解讀原則

- 以通行注本與課本的主流解讀為準，這也是 stolas-exam 驗收時判對錯的依據。
- 有重要異說時，用「另有一說」一句帶過並註明出處，不展開辯論。
- 使用者提出自己的讀法時，檢查文本中有沒有證據支持：有，就肯定並說明它和主流解讀的關係；沒有，就指出文本中哪一處不支持。
- 討論若轉向沒有文本依據的開放式感受分享，說明這部分超出 stolas 的範圍，可以改用一般對話聊，然後回到目前單位。

## 教材檔的差異

以 `doc-template.md` 為基礎，以下章節替換：

| 術語單元 | 經典文本單元 |
|---|---|
| 一句話定義 | 一句話主旨 |
| 脈絡地圖與節點表 | 文本地圖與單位表 (編號 U1、U2……，類型欄改為「背景、講解、收尾」，狀態與進度規則相同) |
| 節點講解 (每節點：直覺、機制、細節) | 逐單位講解：背景單位寫作者與背景；講解單位每個一個小節，含原文 (僅公共領域)、注釋表、語譯、手法與內涵 |
| 術語表 | 只收修辭、文體等術語 (例如對偶、借代、律詩)。字詞注釋只寫在各單位的注釋表中，不另外彙整成總表 |
| 操作步驟 | 刪除 |
| 起步站點 | 改列可靠的注本、課本出版社資源、典籍資料庫 |

另外新增兩個章節：
- **原文** (僅公共領域作品)：放在一句話主旨之後，收錄全文並註明異文。受保護作品不設此章節，改寫一行「原文請見課本，本教材依 (某版本) 的分段分行計算行號」。
- **全篇總結**：放在逐單位講解之後，寫結構 (段落層次或起承轉合)、主旨、主要手法。

注釋表格式：

| 字詞 | 注音 | 解釋 | 備註 |
|---|---|---|---|
| 渚 | ㄓㄨˇ | 水中的小洲 | |

**常見誤解**改收：錯別字、讀音誤讀、字義誤解、主旨誤讀。

**圖解**：多數時候不需要。格律、押韻用表格；段落結構用縮排文字樹。

**一頁重點**格式：

```
- 一句話主旨：(修訂後的最終版本)
- 結構：(用箭頭串起各段或各聯的功能，例如「秋景 → 身世 → 病愁」)
- 名句與賞析：(2 到 3 句，每句附一行白話與手法效果)
- 主要手法：(1 到 3 個，附效果)
- 最常見的誤解：(1 到 2 個，優先列使用者自己犯過的)
- 建議複習：(有 stolas-exam 驗收紀錄時，列部分掌握的單位；沒有時改寫「延伸閱讀」：一篇值得接著讀的作品)
```
