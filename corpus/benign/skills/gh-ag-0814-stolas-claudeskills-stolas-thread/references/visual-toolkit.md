# 圖解：表徵選擇、繪圖規格與工具

## 第一步：判斷這段內容適合哪種表徵

SKILL.md「圖解」列出優先畫圖的五類內容。判斷時看內容的形狀。文字幾乎什麼都能描述，但讀者要在腦中自行拼出空間關係或多步因果時，負擔會落在讀者身上，這時就該畫。

| 內容的形狀 | 表徵 |
|---|---|
| 單一定義、兩三項的簡單對照 | 文字、Markdown 表格 |
| 公式、化學式、簡單計算 | LaTeX (`$...$`、`$$...$$`) |
| 分類、層級 | 縮排文字樹 |
| 少量數據的趨勢或比較 | 內建簡易圖表工具 (若有) |
| 空間或結構、多步因果與流程、多對象全景、隨時間變化、結構對照 | 示意圖 (內嵌視覺化工具或手寫 SVG) |
| 必須轉動 3D 或拖曳參數才能理解 | HTML 互動教具 (three.js 等)，使用者同意後才做 |

**頻率的參考**：一般單元每 2 到 3 個節點至少 1 張示意圖；以機制、結構、流程為主的學科 (生理、化學、物理、氣象、地球科學、經濟學圖形分析、工程) 通常更多。使用者說沒聽懂時一定畫。整個單元講完只有 0 到 1 張圖時，回頭檢查是否有本體機制節點漏畫。

**限制**：

- 每則回覆原則上 1 張，使用者主動要求時除外。
- 同一個概念已經畫過，回頭引用舊圖 (「見圖 3」)，需要新增元素時在舊圖規格上擴充重畫。
- 每張圖只講一件事，配一句看圖重點。

## 第二步：學習中只畫一次，教材只記規格

最終交付物是 PDF，圖片在結案後由 stolas-print 依規格重繪併入，所以學習過程中：

- **有內嵌視覺化工具**：在對話中內嵌顯示，不另存檔案。
- **沒有內嵌視覺化工具**：存成一個 SVG 檔並呈現，在圖解表格的內容欄註明檔名，stolas-print 會直接沿用。
- **內嵌工具呼叫失敗**：改存 SVG 檔，不重試同一個呼叫。
- **沒有檔案工具**：改用 ASCII 示意或文字描述。

不論哪一種，教材「圖解」章節都要寫下這張圖的**繪圖規格**，內容要足以讓 stolas-print 不看對話也能重畫出同一張圖：

- 圖的類型與佈局 (例如「上下兩排比較」「中央一個訊號源，向四個器官放射」「單條鋸齒碳鏈」)
- 每個元素與標籤 (例如「上排 4 個碳，各接 2 個氫；下排中間兩碳以雙鍵相連，各接 1 個氫，下方以虛線圈標出 2 個空位」)
- 強調方式 (例如「雙鍵用紅色」「被改造的位置用琥珀色」)
- 圖說文字

範例：

| 圖 | 所屬節點 | 內容 | 繪圖規格 | 看圖重點 |
|---|---|---|---|---|
| 圖 2 | N2 | 飽和與不飽和的 4 碳片段 | 上下兩排原子結構式。上排：4 個碳以單鍵相連，每個碳上下各接 1 個氫，兩端虛線表示碳鏈延續，下方註「4 個碳，8 個氫」。下排：中間兩碳以紅色雙鍵相連，兩碳各只在上方接 1 個氫、下方以虛線圈標出空位，下方註「4 個碳，6 個氫」 | 每個碳都剛好 4 條鍵；下排少 2 個氫 |

## 介面渲染的保守預設

模型看不到畫面，以下無法直接偵測：

- LaTeX：預設會在聊天中渲染。
- Mermaid：不假設會在聊天中渲染，所以聊天中的脈絡地圖用縮排文字樹，Mermaid 心智圖只寫進教材檔。心智圖的節點文字不能有半形括號 `()` `[]` `{}`，會被解析成節點形狀。

## 手寫 SVG 規範

- 使用 `viewBox`，寬度 680 左右，不寫死像素寬高。
- 另存成檔案時，最底層放白色背景矩形，並用內嵌 `<style>` 定義顏色，確保深色模式下也看得見。
- 中文標籤字級至少 12。
- 顏色之外，同時用線型或文字標籤區分重要元素。
- 另存檔案前用 Python 或 `xmllint` 檢查是否為合法 XML。

## 各工具注意事項

- **RDKit** (分子結構)：`pip install rdkit --break-system-packages` 失敗即改手寫 SVG，不重試。
- **matplotlib**：沙盒中常缺中文字型，圖內標籤優先用英文。
- **選擇題框** (例如 `ask_user_input_v0`)：呼叫後本輪結束，所以它必須是回覆的最後一個動作，文字與進度列都寫完才呼叫。只用在學前診斷、多義詞釋疑、沒聽懂時定位卡點、長篇段落選擇。沒有此工具時改用文字選項。
