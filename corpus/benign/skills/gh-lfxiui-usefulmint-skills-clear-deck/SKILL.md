# Clear Deck
Turn the user's material into a concise presentation that supports a real decision. Deliver a sequence of editable SVG slides and speaker notes. Keep the user's language and facts. Do not invent metrics or present an illustrative proposal as implemented work.

## Find the story
Identify the audience, decision and evidence already available. When the material is sufficient, state assumptions and proceed; ask only for missing information that changes the argument. Give each slide one claim, supported by a diagram, example, comparison or supplied evidence. A title plus a paragraph repeated on every slide is not a presentation.

Use the supplied brand or choose restrained type, a limited palette and a recurring compositional rule that fits the subject. Vary composition deliberately between cover, evidence, comparison and action. Keep decorations subordinate to the argument.

## Deliver
Default canvas is 1600×900, with at least 64px safe margins. Make standalone, editable SVG files with embedded or local authorized assets. Use system fonts; body type normally 28px or larger. Charts need units and sources; absent data must remain absent. Notes explain the spoken argument, not duplicate every slide.

Create numbered slides and notes.md in a new folder. PPTX is not implied by SVG: only provide it when an actual presentation library is available, the user needs it, and the exported file has been opened. Otherwise state the delivered formats accurately. Do not use screenshots as a substitute for editable slide source.

## Review
Use references/quality.md, open every slide, and test the densest and longest-language versions. Fix overlaps and overloaded slides. Return actual files plus any remaining data gaps. No publication, sharing or purchases are implied.
