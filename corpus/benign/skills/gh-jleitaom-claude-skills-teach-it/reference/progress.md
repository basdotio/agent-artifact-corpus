# PROGRESS.md template

Keep it short. Update it at the end of every part so the user (or a new session)
can resume.

```markdown
# Learning <Topic> (theory)

Settings: mode=…, level=…, depth=…, quizzes=…
Folder: <path> (symlinked from ~/learning/<topic_slug>: yes/no)
Lab: <TOPIC>_ESSENTIALS_LAB.html

## Done
- [x] Part 1 — The big picture — <date>

## Next
- [ ] Part 2 — <title>

## Notes
- <topics they asked to zoom into, questions left open, quiz weak spots>
```

If `teach-it-with-projects` later runs in this folder, it reads this file and
continues with projects.
