# Голос автора: шаблон карточки

Скопируйте этот файл в `references/voice.md` и заполните для одного автора. Карточка нужна, когда тексты собираются из диктовки или сообщений конкретного человека (подрежим «сборка» в SKILL.md). Без неё скилл работает по общим правилам.

Карточка — фильтр и скелет, а не генератор голоса. Текст собирается из слов самого автора. Ничего не добавлять от его имени: ни мнений, ни эмоций, ни опыта, ни «для живости».

Источник карточки — его настоящие тексты или расшифровки диктовок, не меньше 2–3 тысяч слов. Каждое правило подкрепляйте примером из его речи.

## 1. Чистка диктовки

Что удалять из расшифровки голоса, а что оставлять. Удаляются автоматизмы устной речи (паузы, перезапуски, метакомментарии), а не логика и оценки автора.

| Тип | Примеры у этого автора | Что делать |
|---|---|---|
| Хезитации | … | удалить всегда |
| Слова-паразиты на границе фраз | … | удалить; частицы внутри смысловой фразы оставить |
| Перезапуски («то есть» в начале) | … | удалить, если дальше нет настоящего пояснения |
| Метакомментарии («скажем так», «смотри») | … | удалить |
| Усилители, которые он повторяет | … | не больше одного на текст |
| Самоисправления | … | оставить итоговый вариант |
| Ошибки распознавания речи | названия моделей и сервисов, которые распознаватель путает | словарь замен; невосстановимое не угадывать, а переспросить |

## 2. Карточка голоса

1. **Только его содержание.** Мнения, оговорки, оценки и опыт — из его слов. Нет мнения — текст фактовый.
2. **Как он начинает.** Типичный зачин (повод, ситуация читателя, вопрос) — с примером.
3. **Как он строит аргумент.** Типичный порядок мыслей — с примером. Это его привычка, а не шаблон: если в конкретной диктовке порядок другой, идти за ним.
4. **Его оговорки** («по-моему», «похоже», «как будто») — только там, где он сам сомневался.
5. **Его слова и обороты,** которые нельзя «нормализовать».
6. **Чего у него не бывает** (восклицательные знаки, эмодзи, хештеги, обращения) — чтобы не добавить.
7. **Как он заканчивает** — вывод, вопрос, личный пример или ничего.

## 3. Сборка из слов автора

- Порядок — его, формулировки — его, правка минимальная.
- Каждая строка его заметок должна найтись в тексте или быть названа в заметке «не вошло».
- Связки модели короткие и без оценок.

## 4. Образец

Короткая диктовка автора → готовый текст по этой карточке. Один пример полезнее десяти правил.
