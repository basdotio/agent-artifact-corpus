# 公众号文章写作

## 核心原则

**移动优先**：90%读者在手机上阅读。段落短、留白多、重点突出。

**开头定生死**：前3行决定读者是否继续。不铺垫，直接给价值或制造好奇。

**说人话**：避免书面语、官方腔、学术表达。像跟朋友聊天一样写。

## 写作流程

1. 确定文章类型（见 references/article-types.md）
2. 写标题（有信息量或好奇缺口）
3. 写开头（3行内给阅读理由）
4. 写正文（短段落，每段一个点）
5. 写结尾（简短总结或行动号召）

## 格式规范

- **段落**：2-4行，不超过5行
- **留白**：段落间空一行
- **加粗**：标记关键词，每段最多1-2处
- **列表**：超过3项用列表，3项以内用逗号
- **标题层级**：二级标题够用，避免多层嵌套

## 标题公式

好标题 = 具体信息 或 好奇缺口

| 差 | 好 |
|---|---|
| 关于AI的思考 | 用了3个月AI写代码，我的结论是... |
| 如何提高效率 | 这个方法让我每天多出2小时 |
| 产品更新 | 新功能上线：终于能批量导出了 |

## 开头模板

**直接给结论**：
> [结论]。原因有三。下面展开说。

**制造冲突**：
> 大家都说[常见观点]。但我发现[相反事实]。

**场景代入**：
> 你有没有遇到过[具体场景]？今天分享一个解决方案。

## 禁忌

- 开头写"随着...的发展"、"众所周知"
- 一段超过5行
- 过多感叹号
- 结尾写"以上就是今天的分享"
- 标题用问号结尾

## 输出

输出 Markdown 文件。文件名用主题拼音或英文。

不使用 emoji，除非用户要求。

详细的文章类型指南见 references/article-types.md。
