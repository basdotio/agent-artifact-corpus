# Word salad surgery

A status ping with nothing to report is a chance for a smile. Answer it with ONE made-up word: funny,
pronounceable, and never built from the same parts twice in a row. Good ones sound like words a
cartoon sidekick might blurt (Hobnoggle, Quindlebarf, Blargissimo), and people end up adopting them.

## When to use it
- A scheduled check (mail, messages, a CI run, a review queue) finds nothing new.
- A background task pings while it's still working.
- Any status update whose honest content is "no change".

## Example
**A cron check:** "Check the build queue. If nothing changed, reply with one made-up word."

**Output:** `Blargissimo`

Later the same day, the same check: `Crumpetfendle`, then `Zorpelette`, never the same parts twice.

## How to build one
1. Pick 2 (sometimes 3) parts from DIFFERENT families below, or invent new ones.
2. Now and then (not every time), operate on them:
   - **Swap syllables or halves:** Snoobwaddle → Woobsnaddle.
   - **Clip:** use just "wob", "fiz", "quin", "plim".
   - **Shift a vowel:** snoodle → snaddle, plumb → plimb.
   - **Borrow:** a Latin, Italian, Spanish, French, German, or Japanese-flavored piece
     (-ibus, -issimo, -ucho, -erie, -schnitz, -kazu, -ette, -orum).
3. Theme it to the moment when it's easy (what the task is about, the weather, the hour).
4. Check the words you've already used today (scroll up): never reuse a part the same day.
   Habits creep in, especially after a long session; deliberately reach for a family you
   haven't used lately.

## Families (rotate; add your own)
- **Burbles:** blarg-, gorp-, zorp-, quib-, frump-, snork-, thwip-
- **Diminutives:** -kin, -let, -ette, -icle, -ling, -ino, -chen
- **Clatter:** -clank, -thrump, -kerplunk, -bonk, -crumpet
- **Soft:** -fendle, -mivver, -wiffle, -throp, -nuggin, -quinx
- **Latinate:** -ibus, -orum, -atio, -issimo, -ulent, -escent
- **Kitchen:** strudel-, pudding-, gravy-, crouton-, noodle-

## Retired
Keep a short list of parts your user has tired of, and skip them. (Ours: wobble, wump, whistle,
nozzle.)

## Format
Just the word, capitalized, nothing else, unless the ping's own instructions say otherwise.
