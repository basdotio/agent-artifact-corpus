# Ask Kimi - Kimiに意見を聞くスキル

このスキルはKimi Code CLIを使って、別のAIの意見を取得します。

## 使い方

### 基本的な質問の仕方

```bash
kimi -p "質問内容" --print
```

自動承認（ファイル変更・コマンド実行を許可）する場合：
```bash
kimi -p "質問内容" --print --yolo
```

### コードレビューの場合

1. 対象のコードをReadツールで読み取る
2. 以下の形式でKimiに質問する：

```bash
kimi -p "以下のコードをレビューしてください。改善点、バグの可能性、ベストプラクティスの観点からコメントをお願いします。

[コードをここに貼り付け]" --print
```

### 設計・アーキテクチャ相談の場合

```bash
kimi -p "以下の設計について意見をください。

[設計の説明や要件]

考慮すべき点：
- スケーラビリティ
- 保守性
- パフォーマンス" --print
```

### ファイルを指定して質問する場合

```bash
kimi -p "このファイルの問題を分析してください" --print [ファイルパス]
```

### 複数ファイルをまとめてレビュー

```bash
kimi -p "以下の複数ファイルの関連性と設計をレビューしてください。

=== file1.js ===
[内容]

=== file2.js ===
[内容]
" --print
```

## 実行手順

1. ユーザーが質問したい内容を確認する
2. 必要に応じてコードや設計情報を収集する（Read、Glob、Grepツールを使用）
3. 適切なプロンプトを構築してKimi CLIを実行する
   - 必ず `--print` オプションを付けて非インタラクティブモードで実行
   - ファイル変更が必要な場合は `--yolo` も付ける
4. Kimiの回答をユーザーに伝える
5. 必要に応じてClaudeとしての補足意見を追加する

## 注意事項

- Kimi CLIは `--print` モードで実行し、インタラクティブモードにならないようにする
- `--yolo` を付けるとファイル変更やコマンド実行が自動承認されるので注意
- 長いコードや複雑な質問の場合、適切に要約してからKimiに渡す
- Kimiの回答とClaudeの意見が異なる場合、両方の視点をユーザーに提示する
- 作業ディレクトリが異なる場合は `--work-dir` オプションで指定する
