# Figure Interpretation Protocol

Deep-read PHASE 2 的图表解读规范。目标：理解图表**内容**并与正文结论**对照验证**，不是裁剪搬运图片。

## 核心原则

1. **看图而非搬图**：不裁剪/提取图片文件到 assets/。利用 Claude 阅读 PDF 页面时的 vision 能力直接"看"图并产出文字解读。
2. **三源对照**：每个图表对比 (a) 视觉显示内容 (b) 图注声明 (c) 正文描述。三者不一致 = 差异标记。
3. **诚实标注不确定性**：分辨率不足、标注模糊、图表类型复杂时，标 `[LOW]` 并明确说明限制。

## 工作流

### Step 1: 识别所有图表

通读全文后，从图注和正文引用中提取完整图表清单：

```
Fig. 1 (p.3) — "Schematic of the experimental design"
Fig. 2 (p.5) — "Growth curves of mutant strains"
Fig. 3 (p.7) — "Western blot analysis of protein expression"
...
Table 1 (p.4) — "Strains and plasmids used in this study"
Supplementary Fig. S1 (p.12) — ...
```

### Step 2: 逐图解读

对每个图表，用 Read 工具重新读取其所在页面（利用 vision 能力观察图表），然后按以下格式产出解读：

```markdown
<a id="FINT-001"></a>
### Fig. 1 图表解读

**图表身份**
- 图表编号: Fig. 1
- 所在页码: p.3
- 图表类型: [柱状图 / 折线图 / 凝胶电泳图 / 显微照片 / 热图 / 示意图 / 表格 / 流程图 / 其他]
- 原始图注: "..."

**视觉内容描述**
- 面板数量: [单面板 / A-B-C 三面板]
- 各面板描述:
  - A: [描述视觉所见 — 例如 "Western blot 条带，4条泳道从左至右：Marker、WT、Δgene、Δgene+complement。Δgene 泳道条带强度明显弱于 WT，complement 组恢复至接近 WT 水平"]
  - B: [描述]
- 坐标轴/标注（如适用）:
  - X轴: [内容]
  - Y轴: [内容 + 单位]
  - 图例: [内容]
  - 显著性标注: [视觉可见的统计标注 — 星号、字母、p值等]
  - 误差棒: [有/无，类型 — SEM/SD]
- 关键趋势/模式:
  - [视觉上最显著的趋势或模式]

**文本对照**
- 正文描述: [引用作者在正文中对该图的描述 — 原文段落 + 位置]
- 图注声明: [图注是否有额外声明]
- 一致性: ✅ 一致 / ⚠️ 部分一致 / ❌ 不一致
- 差异项（如存在）:
  - [DISCREPANCY-MAJOR] [具体差异]
  - [DISCREPANCY-MINOR] [具体差异]

**置信度**: [HIGH / MEDIUM / LOW]
- 理由: [HIGH=图类型常见、标注清晰完整 | MEDIUM=部分标注模糊但可推断 | LOW=分辨率不足、标注缺失、或图像类型复杂]
```

### Step 3: 图表一致性汇总

全部图表解读完成后，生成汇总表：

```markdown
### 图表-文本一致性汇总

| 图表 | 类型 | 一致性 | 差异 |
|------|------|--------|------|
| Fig. 1 | 示意图 | ✅ 一致 | — |
| Fig. 2A | 生长曲线 | ⚠️ 部分一致 | 图注写 n=3 但图上仅2条曲线 [MINOR] |
| Fig. 3B | 柱状图 | ❌ 不一致 | 正文声称"显著差异"但误差棒重叠 [MAJOR] |
| Table 1 | 表格 | ✅ 一致 | — |
```

## 图表类型特定指南

### 凝胶电泳 / Western Blot
- 识别每条泳道对应的样品
- 评估条带强度的视觉差异
- 注意：不进行密度定量（除非图上已有标注）——描述视觉强度时声明"基于视觉判断，非密度定量"
- 检查是否有 loading control

### 柱状图 / 条形图
- 读取 X/Y 轴标签和单位
- 识别处理组和对照组
- 观察误差棒长度和重叠情况
- 检查显著性标注（星号/字母标记）是否与视觉趋势一致
- 检查 Y 轴是否从 0 开始（非零起点可能夸大差异）

### 生长曲线 / 折线图
- 识别各条曲线对应的条件/菌株
- 观察趋势：增长/下降/平台期
- 检查时间点密度是否足够
- 注意对数坐标 vs 线性坐标

### 显微照片 / 荧光图像
- 描述可见结构/信号
- 注意比例尺（如可见）
- 声明图像分析限制（"未做定量分析"）
- 不同通道/染色用文字区分

### 示意图 / 模型图
- 描述图中展示的机制/流程
- 区分"作者提出的模型"和"已建立的背景"
- 检查模型的每个环节是否有数据支持（与后续维度联动）

## 差异严重度判定

| 级别 | 判定标准 | 示例 |
|------|---------|------|
| `[DISCREPANCY-MAJOR]` | 影响对结论的理解或论文可信度 | 正文声称"完全敲除"但图中仍有明显条带；正文声称 n=3 独立重复但误差棒模式暗示技术重复 |
| `[DISCREPANCY-MINOR]` | 呈现细节不一致但不影响核心解读 | 图注写 n=3 正文写 n=4（仅数字不一致）；颜色标注与图注描述不完全匹配 |

## 红线

- ❌ 不要裁剪或提取图片文件——这是解读，不是搬运
- ❌ 不要在分辨率不足时猜测——标 `[LOW]` 并说明不确定性
- ❌ 不要在未声明限制的情况下解读凝胶条带强度——声明"基于视觉判断，非密度定量"
- ❌ 不要跳过补充材料中的图表——同等严谨处理，但标记 `[Supplementary]`
- ❌ 不要只描述不对照——每个图必须与正文描述做一致性检查
