# Methodological Rigor Checklist

Deep-read Dimension 3「方法严谨性」的系统化检查清单。替代原自由文本评价，借鉴 nature-reviewer 的 concern taxonomy 模式，适配个人读者视角（不是审稿人的 gate-keeping 视角）。

## 使用方式

对以下 6 个检查项逐个评估：
1. 先判定适用性（`[applicable]` / `[not applicable]` / `[not assessable]`）
2. 若适用，给出评价并标注严重度
3. 每个 `[MAJOR]` 项附带解决方案测试

全部检查完成后，在维度末尾给出**总体方法质量判断**。

## 检查清单

### 3.1 对照设计

```
适用性: [applicable / not applicable / not assessable]

检查内容:
- 阳性对照: 是否设置了预期产生效果的对照？（如已知抑制剂、已验证的阳性菌株）
- 阴性对照: 是否设置了预期无效果的对照？（如空载体、溶剂对照、未处理组）
- 遗传学对照: 对于基因操作实验，是否有回补实验或独立 sgRNA/RNAi 验证？
- 条件对照: 不同条件间的比较是否控制了单一变量？

评价格式:
[HIGH/MEDIUM/LOW] [无严重问题 / MINOR / MAJOR]
具体发现: [引用原文位置]
如何解决（仅 MAJOR）: [具体方案]
```

### 3.2 重复与样本量

```
适用性: [applicable / not applicable / not assessable]

检查内容:
- 生物学重复: 是否明确区分了生物学重复（独立样品/独立培养/独立动物）vs 技术重复（同一样品多次测量）？
- 重复数量: 关键实验的 n 数是否足够支撑统计推断？（一般 ≥3）
- 独立实验次数: 核心结论是否被多次独立实验验证？
- 报告完整性: 每个实验的 n 数和重复类型是否在方法或图注中明确报告？

评价格式: 同上

特别注意:
- 发酵罐实验：n 指独立批次还是同一批次多次取样？
- 组学实验：生物学重复数（通常是独立培养/独立个体）
- 动物实验：个体数 vs 笼数（笼是实验单位时需注意 pseudo-replication）
```

### 3.3 统计方法

```
适用性: [applicable / not applicable / not assessable]

检查内容:
- 检验方法: 使用的统计检验是否适合数据类型？（连续变量→t-test/ANOVA；非正态→非参数检验；分类→卡方/Fisher）
- 假设检验: 是否检查了统计检验的前提假设？（正态性、方差齐性）
- 多重比较: 多组比较时是否进行了多重比较校正？（Bonferroni/Tukey/Dunnett/BH）
- 效应量: 是否报告了效应量而不只是 p 值？
- 统计软件: 是否说明了使用的统计软件和版本？
- 显著性阈值: 是否预先声明了 α 水平？

评价格式: 同上

统计方法检测到后，按 SKILL.md 规则主动询问：
"需要我用 nature-statistics 对该论文的统计方法做深度审计吗？"
```

### 3.4 菌株/试剂信息

```
适用性: [applicable / not applicable / not assessable]

检查内容:
- 菌株: 是否提供了基因型、构建方法、保藏信息？
- 质粒: 是否提供了质粒图谱、构建策略、关键元件？是否提交到 Addgene？
- 引物: 关键引物序列是否在 Supplementary Table 中列出？
- 抗体/试剂: 是否提供了供应商和货号？
- 关键化学品/底物: 纯度和来源是否说明？

评价格式: 同上
```

### 3.5 数据可获取性

```
适用性: [applicable / not applicable / not assessable]

检查内容:
- 原始数据: 是否声明了数据存储位置？（GEO/SRA/ProteomeXchange/MetaboLights/figshare）
- Accession 号: 是否提供了有效的 accession number？
- 数据可获得: access 是否为 public（而非"available upon request"）？
- 代码: 自定义分析代码是否开源且有版本记录？（GitHub + DOI/Zenodo）
- 补充材料: 是否包含了足够的补充数据支撑正文结论？

评价格式: 同上
```

### 3.6 实验方法细节

```
适用性: [applicable / not applicable / not assessable]

检查内容:
- 关键步骤: 最影响结论的实验步骤是否有足够细节？
- 条件参数: 温度、pH、培养基配方、诱导条件等是否完整？
- 仪器: 关键仪器型号和参数是否说明？
- 分析流程: 数据分析的具体流程和参数是否可追溯？
- 批次效应: 多批次实验是否考虑了批次效应的控制？

评价格式: 同上
```

## 维度总结格式

在逐项检查后，给出总体判断：

```markdown
### 3. 方法严谨性总评

总体置信度: [HIGH/MEDIUM/LOW]

MAJOR 发现: [N 项]
- [列表]

MINOR 发现: [N 项]
- [列表]

总体方法质量: [严谨 — 方法设计合理、信息完整、结论可靠 /
              基本可靠 — 存在可改进但不影响核心结论的缺陷 /
              存在重大缺陷 — 核心结论的可信度因方法问题而打折扣 /
              无法判断 — 关键方法信息缺失过多]

如果结论中最关键的 1-2 个实验存在方法缺陷，须在此明确警示并引用严重度标记。
```
