# Field: visual design · UI · web pages

If research already answered an item, don't ask it — note "confirmed by research" in the summary.
[Recommended defaults] are the first-option candidates.

- **Purpose and audience**: what the screen must make people do or understand first
- **References**: sites, screenshots or brands to look like — and ones to avoid
- **Existing system**: design tokens, component library, brand colors and fonts to follow [Recommended: follow existing]
- **Devices**: desktop / mobile / both; minimum width; dark mode
- **Content**: real copy and images available, or placeholders?
- **Review method**: screenshots at which sizes, live preview, side-by-side with the reference
- **Accessibility**: contrast, keyboard use, reduced motion
- [Don't candidates] generic template look, excess animation, new fonts or colors outside the system, lorem ipsum left in, changing copy without asking
