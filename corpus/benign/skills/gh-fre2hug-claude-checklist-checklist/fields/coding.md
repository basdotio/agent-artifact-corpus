# Field: coding · apps · tools

If research already answered an item, don't ask it — note "confirmed by research" in the summary.
[Recommended defaults] are the first-option candidates.

- **Runtime environment**: OS, language and runtime versions, can things be installed (admin rights, disk space)
- **Form**: CLI / desktop app / web / widget / single script; how it ships (exe, installer, repo, package)
- **Tech choices**: reuse existing code or repos? [Recommended: reuse] Libraries or services that must not be used
- **Data**: where input comes from, where results go, does any data leave the machine
- **Verification**: tests needed? How "it works" is proven (screenshot, run log, numbers)
- **Repository**: new or existing, public or private, may I commit / push myself
- **Compatibility**: existing users, config or data formats that must keep working
- [Don't candidates] over-abstraction, unneeded dependencies, unrequested features, changing global settings, auto-commits, rewriting working code
