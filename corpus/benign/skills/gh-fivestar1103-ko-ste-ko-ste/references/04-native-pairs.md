# 사람이 고친 전후 쌍

> 이 파일의 '보기'와 '권장 표현' 인용은 국립국어원 「쉬운 공문서 쓰기 길잡이」(2022)의 것이며 공공누리 제3유형(출처표시·변경금지)을 따른다. MIT 자료가 아니다. 이 파일을 재배포할 때는 [인용 고지](../NIKL-NOTICE.md)를 함께 보존한다. 인용문은 다듬거나 변형하지 않는다. 관련 규칙, 메모, 제외 이유는 ko-ste의 해설이며 MIT로 제공한다.

이 파일은 실제로 고치는 방식의 본보기다. 규칙을 설명하려고 LLM이 만든 예문은 [02-examples.md](02-examples.md)에 따로 둔다.

같은 유형의 문장을 고칠 때는 다음 순서로 참고한다.

1. 사용자 수정 쌍(U-)
2. 본보기로 채택한 공식 자료 쌍(NP-)
3. 02-examples.md의 설명용 예문

제외 쌍(X-)은 의미 보존의 본보기로 쓰지 않는다. 공식 권장 표현이라도 원문의 조건이나 강도를 바꾸는지 확인한다.

## 목차

1. 출처와 이용 조건
2. 채택한 쌍 (NP-01 ~ NP-55)
3. 본보기에서 뺀 쌍 (X-01 ~ X-20)
4. 사용자 수정 쌍 (U-)

## 1. 출처와 이용 조건

- 자료: 국립국어원, 「쉬운 공문서 쓰기 길잡이」, 2022. 발간등록번호 11-1371028-000915-01.
- 파일: `쉬운 공문서 쓰기 길잡이(2022)-웹용_수정2.pdf`. SHA-256 `50fe05a794ba375ce12773e8f4a11aa664d1e8fa321fb2db0d1f810dc4845fe4`.
- 내려받은 곳: https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=&etc_seq=700&pageIndex=1. 조회일은 2026-10-07이다.
- 이용 조건: 공공누리 제3유형(출처표시, 변경금지, 상업적 이용 가능).
- 쪽수는 책에 인쇄된 쪽 번호다. 이 PDF에서는 PDF 쪽 번호와 같다.
- 옮기는 방식:
  - '보기'와 '권장 표현'('수정')은 원문 그대로 옮겼다. 띄어쓰기, 문장부호, 빗금(/)으로 나눈 대안, ○○ 자리표시도 그대로 두었다.
  - 원문의 밑줄 강조는 옮기지 않았다.
  - 대부분의 쪽은 PDF에 글자 층이 없다. 그래서 쪽 이미지를 190–220dpi로 읽어 옮겼다.
  - 28–32쪽은 PDF 글자 층과 이미지를 대조했다.
- 이 파일의 '관련 규칙'과 '메모'는 ko-ste 작성자의 해석이다. 국립국어원의 견해가 아니다.

공공누리 제3유형은 변형을 금지한다. 그래서 아래 인용문을 고치거나 다듬지 않는다. 이 파일을 고칠 때도 인용문은 원문 PDF와 대조해서만 바꾼다.

## 3. 본보기에서 뺀 쌍

## 4. 사용자 수정 쌍 (U-)

사용자가 직접 고친 쌍을 여기에 쌓는다. 같은 유형을 고칠 때 NP- 쌍보다 먼저 참고한다.

기록 규칙:

- 사용자가 직접 쓴 수정만 기록한다. LLM에게 다시 고쳐 달라고 해서 나온 문장은 기록하지 않는다. 사용자가 그 문장을 받아들였더라도 마찬가지다.
- 사용자가 LLM 출력을 일부만 고쳤다면 사용자가 바꾼 부분만 기록한다.
- 원문에 회사 정보나 개인 정보가 있으면 기록하지 않는다. 아니면 사용자가 직접 지운 형태로만 기록한다.
- 날짜, 관련 규칙 ID, 사용자가 밝힌 이유를 함께 적는다. 이유를 밝히지 않았으면 비워 둔다.
- 공개 저장소에 제공할 쌍은 작성자가 MIT로 제공할 권한이 있는 문장이어야 한다. 사용자의 동의를 받아 기록한다.

현재 등록된 쌍은 없다.
