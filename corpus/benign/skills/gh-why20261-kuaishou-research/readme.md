# 🚀 快手数据分析与市场调研

> ✨ **一句话价值**：一条命令拿到快手公开的视频/作者/评论数据，直接输出结构化JSON——做数据分析、市场调研、对标账号监控、评论舆情分析、热点追踪，不用再手动刷快手。

## 1. 技能概述

这是一款专注于**快手数据挖掘**的工具。它能够穿透快手的公开数据层，为你提供深度的**竞品监控**、**趋势预测**和**KOL 筛选**服务。无论你是内容创作者、品牌营销人员还是市场分析师，都能通过此工具获取决策支持。

**🔥核心优势**

> - 安全: 无需登录你的快手账号，不担心风控风险 / 封号问题
> - 强大: 一次可获取最多1W条数据
> - 全面: 各功能出参数据全面，可见及有价值数据都会返回
> - 灵活: 支持多维度筛选
> - 轻量: 无需部署服务，Node.js 一键运行
> - 实用: 日志自动归档，适配营销报告 / 内容策划场景

**🎯 核心能力**

| 使用场景        | 具体价值                                                      |
| --------------- | ------------------------------------------------------------- |
| 🔍 内容创作选题 | 输入关键词，筛选「最多点赞」视频，快速找到爆款选题方向        |
| 🕵️ 品牌竞品监控 | 输入竞品账号链接，分析其互动数据、内容风格，制定差异化策略    |
| 👥 KOL筛选      | 解析KOL视频的真实互动率（点赞/评论/收藏），避免数据造假的博主 |
| 💬 评论分析     | 获取快手评论详情，分析舆情方向                                |
| 📈 市场趋势分析 | 定时监控关键词「最新发布」，捕捉快手热点风向，提前布局内容    |

**✨ 适用人群**

✅ 快手内容创作者/运营 | ✅ 品牌营销/市场人员 | ✅ 数据分析师 | ✅ MCN机构/经纪人

## 2. 🚀 快速使用

> **Note:** 请先访问[快手数据分析与市场调研技能](https://www.guaikei.com)开通TOKEN，配置环境变量 `GUAIKEI_API_TOKEN` 后才能正常运行。

### 2.1 快手关键词搜索

```bash
node scripts/kuaishou/search-cli.js --keyword "AI"
```

### 2.2 快手博主作品监控

```bash
node scripts/kuaishou/post-cli.js --url "https://www.kuaishou.com/profile/3xxx" --limit 20
```

### 2.3 快手视频评论分析

```bash
node scripts/kuaishou/comment-cli.js --url "https://www.kuaishou.com/short-video/3xxx" --limit 100
```

**💡 详细选项说明**， 可参阅 [完整选项说明](references/options.md)

## 3. 📌 使用场景

- 需要做内容选题 → 关键词搜索 + 最多点赞排序
- 需要模仿爆款视频 → 查看高赞视频详情
- 需要监控竞品账号 → 批量抓取对方作品
- 需要分析评论区情绪 → 查看视频的评论内容及互动数据
- 需要快速追热点 → 实时获取快手热门视频

## 4. ⚠️ 重要限制

- 仅抓取快手公开数据，不支持私密 / 隐藏内容
- 需要配置 GUAIKEI_API_TOKEN 才能正常运行
- 数据仅限个人 / 团队内部使用，禁止违规分发
- 本工具无需登录快手账号，不涉及用户隐私数据的获取

## 5. ❓ 技术说明

### 5.1 运行环境兼容说明

- 系统兼容：Windows/Linux/MacOS（无需额外依赖，仅需Node.js）
- Node.js版本：推荐16.14.0+
- 网络要求：需能正常访问网络，国内服务器无需代理
- 权限要求：无需管理员权限，普通用户即可运行

### 5.2 日志说明

- 启动时会打印工具Banner，方便确认是否正确执行；
- 过程中会输出彩色日志，用于反馈技能执行情况，过程中无需用户交互；
- 所有任务结果会自动保存到 `logs/` 目录（按时间+关键词/链接命名）。
