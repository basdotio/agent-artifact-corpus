# configuration.md

아래는 TOML 설정 예. 실제 형식과 코드의 설정 우선순위로 교체

````text
# 설정

## 우선순위

1. 명령 옵션
2. 환경 변수
3. 프로젝트 설정 파일 `{경로}`
4. 사용자 설정 파일 `{경로}`
5. 기본값

## 항목

### `[{표 이름}]`

| 키 | 타입 | 기본값 | 환경 변수 | 뜻 |
|---|---|---|---|---|
| `{키}` | `{타입}` | `{기본값}` | `{환경 변수}` | {뜻} |

## 전체 예

```toml
{기본값을 모두 적은 설정 파일}
```
````

- 영어 작업 언어의 절 이름: `설정` → `Configuration`, `우선순위` → `Precedence`, `항목` → `Settings`, `전체 예` → `Full example`
- 우선순위: 실제 코드의 적용 순서 대조. 해당하지 않는 단계 삭제, 순서 수정 후 번호 재부여
- 표 이름 순서: 설정 파일에 나오는 순서. 키: 알파벳순
- 환경 변수가 없으면 `없음`
- 전체 예: 기본값과 같은 값만
