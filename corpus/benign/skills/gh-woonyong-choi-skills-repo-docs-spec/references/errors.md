```text
# 오류

프로세스 종료 코드는 [명령](cli.md)에 있다.

## 오류 코드

| 코드 | 이름 | 메시지 | 원인 | 대응 |
|---|---|---|---|---|
| `{코드}` | `{이름}` | `{메시지}` | {원인} | {대응} |
```

- 영어 작업 언어의 절 이름: `오류` → `Errors`, `오류 코드` → `Error codes`
- 종료 코드 문장: `cli.md`가 있을 때만
- 코드 오름차순
- 메시지: 코드의 메시지 문자열 그대로
- 문장 열: `원인`, `대응`
- 없앤 코드: 행 삭제 대신 `이름`을 `폐기`로 변경. 없앤 코드 재사용 금지
