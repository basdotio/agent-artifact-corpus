- 영어 작업 언어의 절 이름: `프로토콜` → `Protocol`, `전송` → `Transport`, `연결 수명` → `Connection lifecycle`, `요청` → `Requests`, `매개변수` → `Parameters`, `결과` → `Result`, `오류` → `Errors`, `예` → `Example`, `알림` → `Notifications`, `호환성` → `Compatibility`
