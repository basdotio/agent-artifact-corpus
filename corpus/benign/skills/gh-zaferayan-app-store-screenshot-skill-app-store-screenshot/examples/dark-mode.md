# Dark Mode Examples

Use these patterns for apps with dark interfaces or screenshots captured in dark mode.

## Prompt: Dark Premium Composition

```text
Use the app-store-screenshot skill.
Create a premium store screenshot from the attached dark-mode mobile app screen.
Preserve the app UI exactly.
Use a realistic device frame, a dark branded background with enough contrast around the phone, and a short readable headline.
Do not brighten or recolor the UI inside the screenshot.
```

## Headline Ideas

- "Focus, without noise."
- "Everything in view."
- "Work after dark."
- "Built for deep focus."
- "Clear, even at night."
- "Your dashboard, refined."

## Visual Direction

Dark-mode screenshots usually benefit from:

- Subtle edge lighting around the device
- Controlled contrast
- One or two brand color accents
- Clean shadows that separate the phone from the background
- Large, high-contrast headline type

Avoid:

- Low-contrast gray-on-gray layouts
- Heavy bloom effects
- Bright backgrounds that make the dark UI feel pasted on
- Recoloring the screenshot to match the background

## Multi-Screen Set

Suggested sequence:

1. Hero dashboard or main value
2. Detail view
3. Search, command, or workflow
4. Insight, timeline, or analytics
5. Settings, customization, or summary

Keep the set cohesive by repeating the same lighting position and device scale.
