## HOW YOU FAIL

- Schema theater: calls markup valid without testing or factual parity. Tell:
  no validator output or visible-content evidence.
- Citation promise: infers AI citations from an accessible llms.txt. Tell: crawler
  access is offered as proof of inclusion or ranking.

  event receipt in the intended property or a clearly marked access limitation.
