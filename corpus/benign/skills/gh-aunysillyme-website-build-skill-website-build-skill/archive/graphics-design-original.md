Deep Research prompt to make your Claude Code an expert at Graphics Design:

I want you to become genuinely good at graphics design - specifically at creating
brand-specific graphics that respect a brand kit and its messaging. Run deep research
using web search, then save everything so future sessions can use it.

STANDARDS
- Search the web for every dated claim (tool capabilities, pricing, licensing, trends,
  platform specs). Never answer those from training memory.
- Every claim gets a source URL and a date. Open every output file with
  "Research as of <today's date>".
- Where sources disagree, record the disagreement - never average it.
- Mark anything you could not verify as UNVERIFIED.

RESEARCH THESE 13 AREAS
1. Fundamentals - typography (pairing, type scales, hierarchy), color theory + WCAG
   contrast rules, grids, whitespace, gestalt principles.
2. Brand systems - what a modern brand kit contains (logo lockups, clear space, color
   tokens, type ramp, motion rules) and how the best teams make guidelines enforceable
   instead of a PDF nobody reads.
3. Award-winning work - D&AD, Cannes Design Lions, ADC, Type Directors Club, Brand New
   reviews: what patterns actually win, 2023-2026.
4. Current trends and anti-trends (2025-26), and when brand consistency should
   override a trend.
5. AI design tools - Firefly, Ideogram, Recraft, Midjourney, Flux, Canva, Figma AI:
   verified capabilities, pricing, and COMMERCIAL RIGHTS per tier. Map each tool to
   the job it is best at.
6. Brief interpretation - documented frameworks for turning words like "bold" or
   "premium" into concrete visual decisions (type choice, palette, density, imagery).
   This is where AI design fails most - go deepest here.
7. Evaluation and taste - critique frameworks, design QA checklists, how agencies
   review work before it ships. Go deep here too.
8. Copy-visual interplay - message hierarchy, headline/image relationships, CTA
   design, how much text each format tolerates.
9. Formats and production - current social sizes and safe zones, print vs digital
   (CMYK, bleed, DPI), vector vs raster, export hygiene.
10. Brand-kit extraction - how to audit an existing brand's site/materials into
    machine-readable rules (colors, fonts, spacing) so "on-brand" becomes checkable.
    Third deep-dive area.
11. Design psychology - color connotations across cultures, attention patterns,
    persuasion vs decoration. Evidence-backed sources only.
12. Systems over one-offs - templates, design tokens, making the 10th asset a
    parameter change instead of a new design.
13. Legal (keep light) - font licensing, stock licensing, commercial rights on
    AI-generated images, trademark risk.

SAVE THE RESULTS - two places, both required:
A. Markdown files in a new folder ~/Desktop/design-research/ :
   - one file per group of related areas (4-5 files is fine)
   - README - an index with the headline findings
   - design-qa-checklist - a step-by-step gate you will apply to EVERY graphic you
     make for me from now on: blockers first (message clear? brand rules followed?
     contrast computed, not eyeballed? licenses ok?), then quality scoring
   - how-to-read-a-brand-kit - a procedure: brand kit in, design decisions out
B. Your memory: commit the durable rules to memory so every future session applies
   them automatically - at minimum: "every graphic passes the design QA checklist
   before it's shown", "contrast gets computed against WCAG, never eyeballed",
   "commercial rights are per-tier per-tool, re-verify before relying", and where
   the research folder lives.

When done, give me a short summary of the most surprising findings and ask me for my
brand's colors, fonts, and logo so we can encode MY brand kit as the first real test.
