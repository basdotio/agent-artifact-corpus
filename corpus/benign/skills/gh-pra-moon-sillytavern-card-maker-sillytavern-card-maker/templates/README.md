# templates 使用说明

| 文件 | 用途 |
|---|---|
| `card.json` | 角色卡本体骨架（占位文本填完即用） |
| `worldbook.json` | 世界书骨架（含 4 个变量条目与示例内容条目） |
| `变量结构.js` / `变量结构-健壮版.js` | 变量结构脚本（普通版 / 带错误上报的发布版） |
| `变量列表.txt` | 变量列表条目内容（直接抄进条目） |
| `变量更新规则.yaml` / `变量输出格式.yaml` | 两个变量提示词条目内容 |
| `变量输出格式强调.yaml` / `强制结尾输出.yaml` | AI 不肯输出更新块时的强化条目（二选一或叠加） |
| `initvar.yaml` | 初始变量值示例 |
| `regex-基础.json` | 正则四件套：去除变量更新 / 折叠×2 / 不发送界面占位符 |
| `regex-界面.json` | 界面状态栏正则（**无闸门**方案，匹配 `Impl|READY`） |
| `regex-闸门.json` | 闸门校验组（**有闸门**方案）：校验放行 + 未更新警告 |
| `statusbar.html` | 交互式状态栏模板（自包含，可内联进正则） |
| `创角表单骨架.html` | 创角/开局表单骨架（含提交逻辑） |
| `readme-template.md` | 玩家安装/游玩说明 |
| `维护检查清单.md` | **改卡**用四段 checklist：动工前 / 写补丁 / 校验 / 收尾（对应 SKILL.md「修改与维护现有卡」章） |

## 组合规则（重要）

- **默认（无闸门）**：`regex-基础.json` + `regex-界面.json`。界面正则匹配 `Impl|READY`，两种占位符都能渲染。
- **启用闸门**（要"没更新变量时给出警告"）：`regex-基础.json` + `regex-闸门.json`，并把界面正则的 findRegex 改为
  `/…` 只匹配 `<StatusPlaceHolderREADY/>`（去掉 Impl 分支）。数组顺序：**闸门在前，界面在后**。
- 多套模板合并进一个 `regex.json`；跨卡复制时给每条换新 UUID。
- 状态栏变体（PC/手机/多主题）：复制多条同 findRegex 的正则，只启用一条，其余 `disabled: true`。
