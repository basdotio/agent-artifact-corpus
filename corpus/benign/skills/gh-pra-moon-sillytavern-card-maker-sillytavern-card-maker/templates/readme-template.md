# 【卡名】游玩说明

> 本卡是**MVU 变量卡**：角色的状态（好感度/物品/时间……）会被实时记录并影响剧情。

## 安装要求

游玩本卡需要安装两个开源扩展（缺一不可）：

1. **酒馆助手（TavernHelper）**
   - 安装：酒馆 → 扩展 → 安装扩展 → 填入 `https://github.com/N0VI028/JS-Slash-Runner`
   - 安装后请开启：扩展设置 → 酒馆助手 → **渲染**（否则状态栏不显示）
2. **提示词模板（ST-Prompt-Template）**
   - 安装：同上位置，填入 `https://codeberg.org/zonde306/ST-Prompt-Template`

本卡已自带：世界书、变量规则、正则脚本、酒馆助手脚本（导入角色卡即可，无需手动导入其他文件）。

## 使用步骤

1. 导入角色卡 PNG/JSON。
2. 首次进入时酒馆会弹窗询问是否启用**角色卡自带的正则脚本**，请选择**允许**。
3. **新开聊天**（变量在开局时初始化；中途导入不生效）。
4. 开始游玩。

## 故障排查

| 现象 | 处理 |
|---|---|
| 状态栏不显示 | 检查酒馆助手的「渲染」开关是否开启；检查正则是否被拒绝（扩展 → 正则） |
| 变量不更新 | 确认两个扩展都已安装且启用；到「酒馆助手 → 日志查看器」看 `【脚本|MVU】` 报错 |
| 想重置进度 | 新开聊天即可（变量按聊天记录保存） |
| 想看变量数值 | 输入框左侧魔棒 → 变量管理器 |
