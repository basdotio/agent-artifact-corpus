# 改卡维护检查清单（每轮照抄）

> 配合 SKILL.md「修改与维护现有卡」一章使用。新建卡不需要本清单。

## 一、动工前

- [ ] 明确本轮改动主题，建备份：`备份-<主题>前/`
  - ~~拷入将动的文件：`card.json`、`worldbook.json`、`说明.md`、相关 `scripts/`、`界面/`、`tools/`~~
  - ~~拷入 `输出/` 的成品（json 与 png）~~
- [ ] 从文件 dump 原文核对每条锚点（防全角/半角冒号、等号数量、转义差异）

## 二、写补丁

- [ ] 写 `tools/patch_<主题>.py`（幂等补丁脚本），不直接手改大 JSON
  - 每条替换先 assert 锚点恰好出现 1 次，全部通过再落盘
  - 脚本开头做幂等检查（已打过 → 跳过并退出）
  - worldbook：JSON 感知替换（load → 改 content → dump，保持 CRLF）
  - card.json：保形字符串替换（保持原格式与结尾换行）
  - 动过 `界面/*.html`：改完重跑 `tools/assemble_regex.py`

## 三、校验（顺序固定）

- [ ] `python scripts/check_card.py <工程>`
- [ ] `python scripts/build_card.py <工程> --image 底图.png`
- [ ] `python scripts/check_card.py 输出/<卡名>.json`
- [ ] `python tools/audit_consistency.py`（新增机制 → 先往关键词表追加）

## 四、收尾

- [ ] 版本号 +0.1
- [ ] `说明.md` / creator_notes 同步新功能
- [ ] 新机制关键词加入 `tools/audit_consistency.py` 的 KEYWORDS（防回归）
- [ ] 成品内容抽查（关键新句/删除句在成品 JSON 与 PNG 里各查一遍）
