# 常备件模块库：把每次投标的 70% 变成取件，而不是写件

## 为什么要做这件事

法律服务投标的材料，按"要不要重做"分两类：

| 类别 | 占比 | 特征 |
|---|---|---|
| **常备件** | 约 70% | 每个标都要交，内容几乎不变——执业许可证、律师名册、完税证明、社保、业绩合同、制度文件 |
| **本次专有件** | 约 30% | 只有这个标才有——服务方案、团队配置、报价、针对性的承诺函 |

**现在的做法是每次从零找一遍那 70%：** 翻上个项目的文件夹复制，
日期没改、版本是旧的、完税证明还是三个月前的。
**这不是"投标能力"问题，是"文件管理"问题——而文件管理可以一次性做掉。**

模块化的目标只有一个：**新标来了，先取件，再写件。**
取件是十分钟的事，写件才是要投入的地方。

## 一、常备件清单（按更新频率分五档）

「更新频率」这一列是这套方法的核心——**决定一件材料什么时候会过期，
比决定它放在哪个文件夹重要得多。**

### A 档 · 按次（每次投标都要重新取，因为时效由招标文件规定）

| 材料 | 常见时效要求 | 谁办 | 常见坑 |
|---|---|---|---|
| **"信用中国"查询截图** | 查询日期距投标截止日 **不超过 7 日**（也有要求 15 日、30 日的，以招标文件为准） | 行政 | 提前一周查的截图会被判不合格；截图要能看清查询日期和查询结果 |
| **投标保证金缴纳凭证** | 投标截止时间前**到账**（不是"汇出"） | 财务 | "已汇出"≠"已到账"，跨行尤其慢；留足 3 个工作日 |
| **授权委托书** | 本次投标专用 | 行政 | 授权范围、期限要与本次项目对应，不要套用旧项目 |
| **投标函 / 报价表** | 本次专用 | 合伙人核定 | 见下方「模板默认值」一节 |
| **无重大违法记录声明 / 承诺函** | 按招标文件指定的措辞出具 | 合伙人 | **格式一字不改**，包括标点和落款位置 |

### B 档 · 按月（时效性强，建议每月固定一天更新）

| 材料 | 常见时效要求 | 谁办 | 常见坑 |
|---|---|---|---|
| **完税证明 / 纳税证明** | 招标文件多要求"近 3 个月"或"近 6 个月" | 财务 | 电子税务局能直接导出，别用去年的扫描件 |
| **社会保险缴纳证明** | 多为"近 3 个月" | 财务 | 需体现参保人数——有的标会拿它对律师名册核人数 |
| **律师执业证复印件** | 年检结论页必须是最新的 | 行政 | 只复印首页、漏掉年检页，是最常见的低级失分 |

### C 档 · 按季 / 按年（跟着机构的自然节奏走）

| 材料 | 更新节奏 | 谁办 | 常见坑 |
|---|---|---|---|
| **律师事务所执业许可证** | 年度检查考核后更新副本复印件 | 行政 | 副本的年检页要复印进去 |
| **营业执照 / 事业单位法人证书** | 年度报告公示后更新 | 行政 | — |
| **财务审计报告 / 财务报表** | 每年审计完成后（多在 4—6 月） | 财务 | 上半年投标时，交上上年度的；别把两年前的当最新的 |
| **律师名册（含执业证号、执业年限）** | 人数变动即更新，至少每季核对 | 行政 | **名册人数必须与执业证复印件、社保参保人数对得上**——三份材料互相矛盾是硬伤 |
| **荣誉证书** | 获得即归档 | 行政 | 按"省级/全国级""律所/个人"分好，评分表按级别给分 |
| **行业排名 / 评级材料** | 榜单发布后 | 合伙人 | 标注发布机构和年份，评分时评委要看这个 |

### D 档 · 事件驱动（发生了才更新，但必须及时）

| 材料 | 触发事件 | 谁办 |
|---|---|---|
| **法定代表人身份证明** | 负责人变更 | 行政 |
| **律所地址、联系方式变更说明** | 迁址 / 换号 | 行政 |
| **新增业绩合同关键页** | 每办结一个可用于投标的项目 | 承办律师 |
| **合伙人 / 律师变动情况** | 入伙、退伙、转入、转出 | 行政 + 合伙人 |

### E 档 · 制度类（长期有效，但每年必须复核一次）

| 材料 | 复核要点 |
|---|---|
| 保密管理制度 | 是否覆盖"案卷不落个人设备""离职交接"这类具体动作 |
| 档案管理制度 | 归档时限、保存期限、销毁流程是否写清 |
| 利益冲突审查制度 | 审查流程和回避机制是否具体可执行 |
| 收费管理制度 | 与现行收费标准是否一致 |
| 应急预案 / 投诉处理机制 | **多数律所最弱的一项，也常常是别人不重视的一项——值得单独做好** |

> **制度类材料有一个特点：几乎是"抄"来的，但抄来的东西经不起追问。**
> 银行、国企类客户会追问"这个制度怎么执行、谁负责、留什么痕"。
> 与其写十页，不如写三页但每一句都能说出"我们实际是这么做的"。

## 二、目录结构（建议照这个建，别自己发明）

```
投标常备件/
├─ 01_主体资格/          执业许可证、营业执照、法人身份证明
├─ 02_人员/              律师名册、执业证复印件、社保、简历库
├─ 03_业绩/              合同关键页、中标通知、结案证明
│   └─ 业绩索引.csv      ← 关键：一份可检索的业绩台账，见下
├─ 04_财务税务/          审计报告、财务报表、完税证明、社保
├─ 05_荣誉评级/          证书扫描件、榜单、评级
├─ 06_制度文件/          保密、档案、冲突审查、收费、应急
├─ 07_模板承诺函/        各类声明函、承诺函的空白模板
├─ 08_本次投标_<项目名>/  ← 每个项目一个，用完归档
└─ README.md             ← 每件材料什么时候更新的说明
```

**四条命名与存放规则：**

1. **文件名带日期**：`完税证明_2026-09.pdf`，不带日期的文件三个月后就是谜。
2. **按"取用场景"分目录，不按"文件类型"分。** 投标时要的是"人员相关的一套"，
   不是"所有的 pdf"。
3. **每次投标新建 `08_本次投标_<项目名>/`，只放本次专有件和从各处取来的副本。**
   取件用复制，不改源文件——改了源文件，下一个标就拿到被改过的版本。
4. **`README.md` 里写清每件的更新时间和下次更新时间。** 目录会自己说话。

### 业绩索引.csv —— 这一份台账的价值最高

没有索引，业绩就是一堆散落的合同扫描件，每次投标靠回忆去找。有索引，
就可以按"客户类型 / 业务类型 / 时间 / 金额 / 能否脱敏"筛：

| 字段 | 说明 |
|---|---|
| 序号 | — |
| 委托人 | 客户名称 |
| 客户类型 | 银行 / 国企 / 政府 / 民企 / 个人 |
| 业务类型 | 金融借款 / 执行 / 劳动争议 / 知识产权 / 常年顾问 … |
| 承办律师 | 谁办的——**评分表常按"拟派律师本人的业绩"给分，这个字段决定业绩能不能算数** |
| 委托时间 | 合同签订日 |
| 标的额 | — |
| 是否可脱敏提供 | 有的客户不同意对外提供合同，提前标出来 |
| 合同关键页路径 | 存哪儿了 |
| 可用于投标 | 是 / 否（含保密限制的标"否"） |

**备注栏建议记一句这个案子值得说的点**，比如"从一审办到执行回款，全额收回"。
述标时用得上——**评委记不住案件明细，但记得住这类一句话结论。**

## 四、自动化的边界：哪些能脚本做，哪些不能

**你在招标文件里看到"自动化"三个字时，先问清楚自动化的是哪一段。**
投标这件事上，能自动化和不能自动化的地方界线很清楚：

| 能做（脚本） | 不能做（必须人做） |
|---|---|
| 读招标文件，抽出资格条件、评分表、时间节点、废标条款 | **判断"我们够不够格"**——这要对人、对证件、对未来排期，脚本看不见 |
| 扫描常备件目录，报"哪件过期了 / 哪件快到期了" | **填写任何一份材料的内容**——声明函、承诺函、报价表的措辞，一个字错就是废标 |
| 按招标文件要求生成"本次要交哪些材料"的取件清单 | **决定报价**——那是商业判断，得由能担责的人定 |
| 核对命名规范、编号连续性 | **签字盖章**，以及判断盖章位置对不对 |
| 把已填好的文件归档、生成台账 | **读评标办法之外的东西**：招标文件里没写进评分表的要求，往往才是真要求 |

**这条界线不是技术限制，是责任限制。** 投标文件签的是律所的名字，
承担后果的是律所——所以**任何一份对外提交的材料，最终都必须有人逐字看过。**

本 skill 配套的两个脚本都严守这条线：

- `scripts/read_tender.py` —— **只读**招标文件，产出导航用的四份材料，不改任何东西
- `scripts/check_standing.py` —— **只读**常备件目录，报每件材料的状态，不生成、不改写

## 五、新标来了，十分钟走完取件流程

1. `python3 scripts/read_tender.py <招标文件>` —— 拿到资格条件、评分表、时间节点
2. `python3 scripts/check_standing.py <常备件目录>` —— 看哪件过期了、哪件要重取
3. **对照招标文件里"投标文件的组成"一节，逐条核对常备件够不够** ——
   招标文件说要什么，就以什么为准；本清单只是提醒你"别忘了有这个"
4. **本次专有件（服务方案、团队、报价）才是真正要投入时间的地方**
5. 装订前过一遍《投标文件自检表》（见 `02-模板与填写说明.md`）

**第 3 步不能省。** 常备件库是你自己的存货清单，
**招标文件要什么是它说了算**——两者的差集才是本次要补的东西。
