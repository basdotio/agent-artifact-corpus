# 法律服务投标 Skill

## 使用方式

```
/legal-bidding 帮我读这份招标文件，判断要不要投
/legal-bidding 这份磋商文件要求现场述标，帮我准备述标稿
/legal-bidding 投标文件做完了，帮我过一遍废标风险
/legal-bidding 这次没中标，带我复盘
```

也可以直接说"有个法律服务的标要投"，我会自动启动。

**手上有一份招标文件时，先跑脚本再看流程：**

```bash
python3 scripts/read_tender.py <招标文件>       # 抽出该看的地方
python3 scripts/check_standing.py <常备件目录>   # 看哪件材料该重取了
```

**第一次用这套东西，先读 `examples/02_全流程演示_九步走一遍.md`** ——
它用一个虚构的银行标把九步走了一遍，比读流程表快。

---

## 〇、动手之前：三条铁律

**1. 资质与废标条款优先于一切。**
拿到招标文件的第一件事不是读需求，是读**资格条件**和**废标条款**。资质不满足或触发废标条件，后面所有工作都是白做。

**2. 招标文件的要求永远压过本 skill 的默认值。**
本 skill 里的排版、装订、命名规范都是"招标文件没规定时"的兜底。招标文件有规定的，一律从其规定。

**3. 法条引用必须带时点。**
见下方「法条时效」一节。这是本 skill 最容易过期的地方。

## 一、九步流程

框架出处：毕宝胜、陈正刚、白静《法律服务投标"三篇九步法"》（北京德恒律师事务所），
威科先行 2022-06-14 发布。本文引用其结构，内容按本所实务与现行法规重写。

| 篇 | 步 | 做什么 | 产出物 |
|---|---|---|---|
| **知彼** | 1 熟悉文件、定位需求 | 读资质条件、废标条款、招标范围；估准备时间 | 《项目基本信息清单》＋投/不投的判断 |
| | 2 对照标准、锚定得分 | 把评分标准当靶心；模拟打分，标出基础分／差距分／胜负分 | 《评分标准梳理表》 |
| | 3 及时沟通、避免偏差 | 有歧义按程序要澄清；内部有分歧集体讨论 | 澄清函（必要时） |
| **解己** | 4 分工协作、重点突出 | 按模块拆解分派；资深把关法律意见，合伙人核定 | 《分工计划表》 |
| | 5 读者友好、换位思考 | 评委在短时间阅多份上百页文件——做成"读者友好型" | 《评分导读表》随文件附上 |
| | 6 逐项检查、交叉复核 | 清单式管理 ＋ 同事交叉复核 | 《投标文件自检表》完成 |
| **制胜** | 7 装订密封、准时响应 | 胶装不活页；签字盖章骑缝；报价函单独放；按开标时间倒推 | 密封完成的投标文件 |
| | 8 模拟演练、精准述标 | 准备 5 分钟与 15 分钟两版；顺手记同行报价 | 述标稿 |
| | 9 投后复盘、成长提升 | 不论中没中都复盘 | 《投标复盘表》 |

**三步里最容易省、也最不该省的：第 3、8、9 步。** 这三步不产生交付物，所以最常被跳过——
而它们恰恰是"下一次投得更好"的唯一来源。

## 二、一票否决：废标风险清单

**投标前对每一项打勾。任一项不满足，先停下来解决，不要往下走。**

### A. 资格类（★ 项一票否决）

- [ ] 营业执照经营范围覆盖本次服务
- [ ] 执业许可、资质证书在**有效期内**、等级达标、通过年检
- [ ] 招标文件中标 "★" 的指标**全部满足**——"★"是实质性要求，不满足即废标
- [ ] 联合体投标的：已附联合体协议书；联合体各方**未再单独参加**或与其他供应商另外组成联合体
      参加同一合同项下的采购活动（依据：《政府采购法实施条例》第二十二条，条文见第六节）
- [ ] 不存在"单位负责人为同一人**或**存在直接控股、管理关系"的其他供应商同时投本标
      （依据：《政府采购法实施条例》第十八条，条文见第六节）

### B. 响应类

- [ ] 工期／服务期限响应招标要求
- [ ] 数量、人员安排逐项核对无遗漏
- [ ] 投标有效期**达到**招标文件要求的期限（常见坑：误以为越短越好，写成 30 天而要求 90 天）
- [ ] 未擅自修改招标文件规定的格式——授权书、声明函、响应函、报价表的格式一字不改
- [ ] 报价未超最高投标限价／预算

### C. 形式类

- [ ] 法定代表人授权书已签章；由委托代理人签字的，已附授权委托书
- [ ] 服务方案、磋商响应函、承诺函等要求签章处**逐处**签章到位
- [ ] 公章盖在指定位置、清晰；骑缝章覆盖每一页
- [ ] 只有一个有效报价（招标文件允许备选方案的除外）
- [ ] 纸质版、电子版、上传系统的报价三者一致
- [ ] 正副本份数、正副本标记符合要求

**注**：废标最常见的原因不是资质真不过关，是**疏忽**。以上清单的价值就在于把疏忽变成打勾。

## 三、报价环节的特殊约束

**政府采购项目中，不得以赠品作为优惠条件。**

- 依据：《政府采购货物和服务招标投标管理办法》（财政部令第 87 号，2017-07-11 颁布，
  2017-10-01 施行，**现行有效**）第六条第二款：
  > 采购人不得向供应商索要或者接受其给予的赠品、回扣或者与采购无关的其他商品、服务。

**⚠️ 表述边界**：该条约束的是**采购人不得索要或接受**，
**并未直接规定"供应商提供赠品即视为无效"**。引用时不要超出条文射程。
实务建议是：不设赠品条款，改以服务内容本身的增量（如增加服务频次、扩大服务范围）体现优惠。

**价格分计算**：政府采购服务类项目多采用**低价优先法**——
满足要求的最低价为基准价得满分，其余按公式折算。
故报价策略的核心不是"报最低"，而是**在预算内报一个不会被质疑、又能守住利润的价格**。

## 四、文件编制规范（招标文件无规定时的默认值）

| 项 | 默认规范 |
|---|---|
| 纸张 | 正文 A4／80g 白；封面封底胶装 A4 |
| 打印 | 双面、彩色；左侧装订线；不出现倒装页 |
| 版面 | 上 26mm／下 22mm／左 25mm／右 25mm；装订线左侧 3mm |
| 页眉页脚 | 小五号；页眉距 20mm、页脚距 15mm；页码居中；行距 1.5；首行缩进 2 字符 |
| 字体 | 文章标题三号黑体；节标题小三号黑体；正文小四号宋体；全黑；英文 Arial |
| 序数 | 章用"一、二、三、"；节用"1""1.1""1.1.1" |
| 目录 | Word 自动生成，不手工添加 |
| 表格 | 表题五号宋体；表内小四或五号宋体 |
| 插图 | 不超页边距；证书类一律扫描为图片插入 |
| 装订 | **胶装，一律不用活页**（穿孔式、文件夹式均不可）；正副本内容排版一致 |

**装订环节的两个易漏点**：
1. **报价函单独放**（通常在招标文件里明示，但极易漏）
2. **密封条**用法定代表人印章 ＋ 单位公章，写明"××年××月××日封／开标前不得启封"

## 五、电子文档命名

`文件名称-项目名称-日期版本序号-版本作者`

例：`承诺函-某某投标项目-20260927V1-某某律师`

- 日期用八位年月日
- 当日第一版不加版本号，之后从 V2 起
- 跨日修改接续此前版本号，不重新编号
- 定稿加中文"定稿"，不加版本号
- 项目名称在同一项目全程保持一致

## 六、法条时效（**本 skill 最需要维护的一节**）

| 法规 | 状态（截至 2026-09-27） |
|---|---|
| 《政府采购法》 | 🔴 **修订中**。2026-06-26 十四届全国人大常委会第二十三次会议审议修订草案并公开征求意见（30 日，已截止），**尚未通过**。现行仍为 2002 年制定、2014 年修正版本 |
| 财政部令第 87 号《政府采购货物和服务招标投标管理办法》 | ✅ **已核**。颁布 2017-07-11，施行 2017-10-01，现行有效。第六条第二款已逐字核对（见第三节） |
| 《政府采购法实施条例》（国务院令第 658 号） | ✅ **条文内容已核**（2026-09-27 核对官方文本）。第十八条、第二十二条全文见下方。**施行日期未独立核实**，引用时请自行补上 |

**第十八条**（关联供应商、为采购项目提供过服务的供应商）：

> 单位负责人为同一人或者存在直接控股、管理关系的不同供应商，不得参加同一合同项下的政府采购活动。
> 除单一来源采购项目外，为采购项目提供整体设计、规范编制或者项目管理、监理、检测等服务的供应商，不得再参加该采购项目的其他采购活动。

**第二十二条**（联合体）：

> 联合体中有同类资质的供应商按照联合体分工承担相同工作的，应当按照资质等级较低的供应商确定资质等级。
> 以联合体形式参加政府采购活动的，联合体各方不得再单独参加或者与其他供应商另外组成联合体参加同一合同项下的政府采购活动。

| 《招标投标法》及其实施条例 | ⚠️ 未核实 |

**使用规则**：引用任何法条前**先核当前效力**，引用时标"截至××××年××月××日有效"。
《政府采购法》修订通过后，本 skill 第二、三、六节需整体复核。

**关于"二手来源"这个标记**：它不是"内容有问题"的意思，是"我还没看到官方原文"的意思。
这两种情况必须分开——**前者要改内容，后者只是还没核。** 把两者混为一谈，
要么会让可信的内容被无谓地推翻，要么会让没核过的内容被当成核过的用。

> ⚠️ **待办**：核《政府采购法实施条例》的**施行日期**（条文内容已核）。
> 国家法律法规数据库（flk.npc.gov.cn）在部分网络环境下取不到正文（只返回前端空壳）。

## 七、配套材料

### 脚本（只读，不生成也不改写任何投标材料）

| 脚本 | 作用 | 关键输出 |
|---|---|---|
| `scripts/read_tender.py` | 读招标文件，抽出该看的地方 | `01_原文.txt` / `02_项目基本信息.md` / `03_评分标准.md` / `04_风险提示.md` |
| `scripts/check_standing.py` | 体检常备件目录 | 哪件过期、哪件没找到、哪件一年没动 |

```bash
python3 scripts/read_tender.py <招标文件.pdf|.docx|.doc>
python3 scripts/check_standing.py <常备件目录> --asof 2026-11-16
```

**两个脚本都遵守同一条规矩：不做静默失败。** 抽不到就报"未抽到"，
并且区分「未成章节，散见 N 行」和「全文无此字眼」——
**报"没找到"不等于文件里没有，只等于脚本没认出它。**

⚠️ **脚本的输出只作导航。** 资格条件、评标办法、报价上限三项，必须回原文逐字核对。
