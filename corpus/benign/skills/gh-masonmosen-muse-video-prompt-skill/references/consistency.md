# 人物一致性实战策略

> 诚实线：没有任何提示词技巧能强制平台锁脸。一致性是"纪律 + 概率"，不是保证。

## 有效手段（按实测有效性排序）
1. **人物描述逐字复用**：同一段人物描述原样粘贴进每个分段 prompt，改写是变脸第一诱因。
2. **参考图（弱）**：内置视频参考图对锁脸帮助有限（2026-10-05 以晴实验：强锁脸指令仍不像本人）。可用，但别指望。
3. **强锁脸指令**（聊胜于无，附在提示词开头）：
   ```
   视频中的人物必须是参考图中的同一人。脸型、五官、眉眼间距、鼻唇比例、
   脸部轮廓与参考图严格一致，全程不得漂移、不得变成另一张脸、不得网红脸化。
   以参考图的人脸身份为最高优先级。
   ```
4. **参考图范围声明**：只参考声明的部分（"只参考面部特征，不参考服装配饰发型背景"），减少模型乱抄。
5. **snapshot 接续**：多段长片用 `resume_from_snapshot_id` 链式生成（麻将 30 秒实测：三段人物连贯）。
6. **否定式锚定**：`不要面部漂移、不要身体比例变化、不要衣服变形、不要手指畸形` 列入限制清单。

## 升级路径（本 skill 不做，告知用户）
- 严肃锁脸需求 → Seedance 2.0 omni-reference / 第三方视频模型（用户已有资产）。
- 长期角色 → LoRA / FaceID（重型方案，另行评估）。

## 话术模板（动手前说）
> 内置视频的人物一致性是弱项：跨段可能换脸，参考图可能不像。我会用逐字复用 + snapshot 接续 + 强锁脸指令尽量稳，但不承诺 100%。要锁脸的话走 Seedance。
