# 六段式提示词模板

> 思想借鉴 LuoJiangYong/muse-video-skill 的 six-part prompt，字段按本工作流重写。
> 写完后给用户定稿，定稿原样传入 `media.generate_video`。

## 通用模板

```
[时长/画幅] [一句话场景]
人物：年龄 / 性别 / 外貌特征 / 服装 / 发型（精确到颜色款式）
场景：地点 / 时间 / 光线 / 氛围
剧情/节拍（带时间轴）：
  0-2秒：...
  2-5秒：...
镜头语言：机位 / 运镜 / 景别 / 手持或稳定 / 禁止的运镜
声音：环境音 / 拟音 / 台词（注明）
对白语言：（默认台湾腔国语，见 dialogue.md；无对白则删）
参考图说明：（只参考人物/服装/场景中的哪部分；文件名须为 ASCII）
限制：不要……（逐条列出禁止项：穿模、变形、磨皮、特定内容等）
```

## 变体模板

### POV 生活流
- 开头声明：`全程严格第一人称：镜头就是（男友/朋友）的眼睛，本人绝不入镜，只允许手或前臂偶尔出现在画面边缘。`
- 如需"本人禁入镜"，写成强约束并单独成段，弱约束会被模型忽略（2026-10-05 天台实验：弱约束下男友肩膀大面积入镜）。

### 口播 talking-head
- 人物正对镜头、视线看镜头；注明"非自拍，画面中不出现相机/手机"。
- 台词用引号标出，注明语气、尾音、口型同步要求。

### 多段长片（>10 秒）
- 每段一个独立提示词，段首声明：`本段为 30 秒短片的第 N 段（X-Y 秒），延续上一段的同一人物/场景/光线/质感，人物服装发型面容严格保持一致。`
- 每段只写本段的 2-3 个镜头，不写全片。
- 生成时用上一段的 `resume_from_snapshot_id` 接续。

## 写作纪律
- 人物描述在全片各段**逐字复用**，改写是变脸第一诱因。
- 时间轴按 10 秒一段写，不要写 15/30 秒的长轴（模型会压缩）。
- 限制清单宁多勿少；失败过的项（穿模、入镜、磨皮）显式列入。
