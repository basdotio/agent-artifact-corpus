# 内置 Muse Video 能力边界（2026-10-05 实测）

## 硬限制
- 单条约 10 秒，时长不可控。用户要 15/30 秒 → 必须分段生成再拼接。
- 纯文本或图文序列输入；**不接受音频输入**。"用这首歌""配这段音"做不到。
- 自带合成音效；可用文字描述氛围（"天台风声""安静的空调底噪"），模型会配。
- 画幅：在提示词里声明 16:9 / 9:16，模型大致遵守（地铁 9:16 ✓，麻将 16:9 ✓）。

## 参考图
- 传图前先确认文件存在；`/tmp` 是临时的，可能被清理，传图前重建。
- **文件名必须 ASCII**：中文文件名会被上游以 400 拒绝上传（2026-10-05 实测：同一张图改英文名后通过）。
- prompt 里用 `{kind: image}` + `{kind: text}` 有序传入；图在前、文在后。

## 一致性
- `resume_from_snapshot_id` 可接续同一生成上下文，用于多段长片保连贯。
- 内置视频人物锁脸弱：即使加显式强锁脸指令，参考图人物仍可能不像（以晴实验）。
- 需要锁脸 → 走 Seedance 第三方，本 skill 不承诺。

## 我的盲区（必须告知用户）
- 我看不见成片，只能抽帧自查；听不见音频，台词/口音/音效必须用户终验。
- 动态连贯性（动作跳帧、剑身变形这类）抽帧只能部分发现，最终靠用户看片。
