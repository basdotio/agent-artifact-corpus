# v0.1.2 — 表格渲染完整性与脚注核验修复

发布日期：2026-10-17。面向 Codex 的兼容补丁；旧标签与 Release 不变。

## 修复

- 普通论文也默认保留 HTML 合并表格，不再绑定 `--scan-book`。新增可选 `--table-format auto|html|markdown`；旧命令仍可使用，显式 markdown 保留原网格选择，旧 CLI 的 auto 回退会提示。
- 同时检查 Markdown 列数、HTML 合并范围/重叠/截断；增加表格处理前后、证据到渲染的数值出现次数核对，可用时检查单元格位置。修复“证据中有数值、网格渲染静默丢值但报告不报警”的检测缺口。
- 脚注/图注比较保留自动链接，归一化内联链接、HTML 实体与转义；OCR 换行 URL 不再被当作 HTML 标签删除。完整注释比较也能发现保留开头但尾部漏文的情况。
- 区分缓存锁等待超时、权限不足、引擎缺失和其他失败；新增运行阶段旁文件和实时阶段提示。锁观测不改变获取/释放语义，不删除其他任务的锁或终止其进程。
- 增加标题层级不一致、列表重复编号候选提示。核验状态绑定源/输出哈希，正文、表格、公式、结构与印刷页码相互独立。
- 最终 MD 发布前验证图片路径整理及页标添加没有改变逐页正文；raw 与严格分页校验继续保留。

原 CLI 选项、退出码及旧 JSON/CSV 字段保留；新报告字段为附加字段。没有依赖或模型升级，不包含运行库、模型或用户文献。

## 验证

- 本地 Python 3.13：44 项 unittest 全部通过，包含原有 19 项与新增 25 项；编译检查、skill-creator 验证及 Git 空白检查通过。测试内容为自行编写的微型 PDF/HTML/Markdown，不包含论文全文。
- Marker 2.0.0 / Surya 0.22.1：匿名真实论文的 6 个代表页和 22 页全篇转换验收；严格页面对应与独立页码映射通过。最终源码另外回放核对全篇逐页正文完整性。
- 隔离同一表格 HTML：上游网格渲染丢失末列 `0.008`，HTML 渲染保留该值；新检测能报数值不足和位置差异。真实异常续表与多级表头的列数风险得到提示。
- 完整链接脚注不再误报；人工注入真正缺注后仍报警。独立锁占用试验中，等待超时正确分类，持锁状态和锁文件均保留。

## 仍需人工核验

HTML 保留 OCR 预测，不能修复错误的 rowspan、错列、缺表头或错误识别的数值。数值齐全、列数一致也不能证明数据对应正确。真实试验中仍有两页表格结构异常，必须对照原图修订。

标题层级与参考文献重复编号仅提示；公式下标、表格数值不按推测自动修改。表注、跨页注释与特殊链接排版仍可能触发需要人工判断的候选提示。检测器无报警、命令成功或存在修订记录都不等于内容已核验。

首次使用或上游依赖版本改变后，仍先选代表页试验。详细方法见 [表格与渲染完整性](../../references/render-integrity.md)。
