# Обезличивание материалов дела

Цель: дать ИИ разобрать дело, не раскрывая лишних персональных данных клиента (152-ФЗ, адвокатская/профессиональная тайна).

## Что заменять
| Тип | Замена | Пример шаблона |
|---|---|---|
| ФИО | [Истец], [Ответчик], [Свидетель 1] | последовательно: один человек — одна метка |
| Паспорт РФ | [ПАСПОРТ] | 4 цифры + 6 цифр, часто «серия 22 11 № 123456» |
| СНИЛС | [СНИЛС] | 123-456-789 01 |
| ИНН физлица / юрлица | [ИНН] | 12 / 10 цифр |
| ОГРН / ОГРНИП | [ОГРН] | 13 / 15 цифр |
| Номер карты, счёта | [СЧЁТ] | 16 цифр карты, 20 цифр счёта |
| Телефон | [ТЕЛЕФОН] | +7 / 8 и 10 цифр |
| Эл. почта | [EMAIL] | |
| Адрес | [АДРЕС ИСТЦА], [ОБЪЕКТ] | город можно оставить, если важен для подсудности |
| Госномер ТС, VIN | [ГРЗ], [VIN] | для дел по гл. 12 КоАП |
| Дата рождения | [ДР] | оставить возраст, если важен |

## Что НЕ заменять
Даты событий, суммы, номера договоров и дел (если пользователь не просил), наименования судов и органов — они нужны для анализа.

## Порядок
1. Предложи пользователю обезличивание, если видишь ПДн, и он не сказал, что они нужны.
2. Сделай таблицу соответствий «метка → оригинал» и отдай её пользователю отдельно — сам в анализе используй только метки.
3. В готовом документе метки остаются — пользователь подставит сам.

Скрипт `scripts/anonymize.py` делает черновую автозамену по шаблонам выше (ФИО не ловит — их размечать вручную или по списку `--names`).
