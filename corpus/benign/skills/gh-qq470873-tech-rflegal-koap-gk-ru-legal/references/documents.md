# Структуры процессуальных документов

Плейсхолдеры в квадратных скобках — никогда не заполнять выдуманными данными.

## Шапка (для всех документов в суд)
```
В [наименование суда]
[адрес суда]

Истец / Заявитель: [ФИО или наименование], [дата и место рождения + один из идентификаторов — для граждан по ГПК; ИНН, ОГРН — для организаций], адрес: [...], тел.: [...], эл. почта: [...]
Представитель: [ФИО], доверенность от [дата] № [...], адрес для корреспонденции: [...]
Ответчик: [...]
Третье лицо: [если есть]

Дело № [если присвоено]
Цена иска: [сумма] руб.
Госпошлина: [сумма] руб. [сверить с действующей редакцией НК]
```

## Исковое заявление (ГПК ст. 131–132 / АПК ст. 125–126)
1. Заголовок: «Исковое заявление о взыскании …» — предмет в заголовке.
2. Фабула: хронология фактов с датами и документами (договор № от …, акт № от …, платёжное поручение № от …).
3. Нарушение: что именно не исполнено.
4. Правовое обоснование: норма → применение к фактам.
5. Досудебный порядок: когда направлена претензия, как доставлена, ответ (обязательно для АПК по ч. 5 ст. 4).
6. Расчёт: сумма долга + неустойка/проценты (таблицей или отдельным приложением).
7. Просительная часть:
   ```
   На основании изложенного, руководствуясь ст. … ГК РФ, ст. … ГПК/АПК РФ,
   ПРОШУ:
   1. Взыскать с [ответчик] в пользу [истец] основной долг в размере … (…) руб.
   2. Взыскать неустойку за период с … по … в размере … руб.
   3. Взыскать неустойку/проценты с … по день фактического исполнения обязательства.
   4. Взыскать расходы по уплате госпошлины в размере … руб.
   ```
8. Приложения (нумерованный список): доказательства направления копий, квитанция о пошлине, доверенность, документы по фабуле, претензия с доказательствами отправки, выписка ЕГРЮЛ (АПК).
9. Дата, подпись.

## Отзыв / возражения на иск (АПК ст. 131; ГПК ст. 149)
1. «Отзыв на исковое заявление [истец] о … (дело № …)».
2. Позиция одной фразой: «Ответчик с иском не согласен по следующим основаниям» / «согласен частично».
3. Процессуальные возражения — первыми: подсудность, досудебный порядок, полномочия, **заявление о пропуске исковой давности (ст. 199 ГК) — отдельным пунктом и прямым текстом**.
4. По существу — ответ на каждый довод истца, в той же последовательности.
5. Контррасчёт, если сумма спорная.
6. Заявление о снижении неустойки по ст. 333 ГК — отдельным пунктом, с доводами о несоразмерности (для коммерсантов обязательно).
7. Просительная часть: «в удовлетворении исковых требований отказать полностью / частично в части …».
8. Приложения, в т. ч. доказательство направления отзыва истцу.

## Апелляционная жалоба (ГПК ст. 322 / АПК ст. 260)
1. Подаётся через суд первой инстанции.
2. Какое решение обжалуется: суд, дата, номер дела, дата изготовления в окончательной форме.
3. Основания отмены по кодексу (ГПК ст. 330 / АПК ст. 270): неполное выяснение обстоятельств, недоказанность, несоответствие выводов обстоятельствам, неправильное применение норм.
4. Каждый довод: что решил суд → почему неверно → какая норма / доказательство.
5. Новые доказательства — только с обоснованием, почему не представлены в первой инстанции.
6. Просительная часть: отменить полностью/в части и принять новый судебный акт (…).
7. Если срок пропущен — ходатайство о восстановлении.
8. Приложения: квитанция о пошлине, доказательства направления копий, доверенность.

## Досудебная претензия
1. Кому, от кого, дата.
2. Основание (договор, акт), нарушение.
3. Требование с суммой и сроком исполнения (не менее срока из закона/договора; по АПК — учитывать 30 дней).
4. Реквизиты для оплаты.
5. Последствия: обращение в суд с взысканием неустойки, процентов, расходов.
6. Способ направления, позволяющий доказать получение (ст. 165.1 ГК): ценное письмо с описью, курьер, ЭДО, эл. почта — если предусмотрено договором.

## Ходатайства (общая форма)
«Ходатайство о [предмет]» → обстоятельства → норма (ГПК ст. 35 / АПК ст. 41 и специальная норма) → просьба одной фразой → приложения. Частые: об истребовании доказательств, о назначении экспертизы (вопросы эксперту, кандидатуры, депозит), об отложении, о рассмотрении в отсутствие, об участии по ВКС/веб-конференции, о приобщении документов.

## Пояснения / письменные объяснения
Короткие, адресные: на какой вопрос суда отвечаем или какое обстоятельство уточняем. Без повторения всего иска.
