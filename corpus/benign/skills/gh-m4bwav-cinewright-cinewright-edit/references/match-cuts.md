# Match cuts

## Rules

- A match cut repeats one element across the cut: shape (graphic match), motion (direction and speed), position in frame, color, or sound.
- Plan it in the cards: both cards name the same shape at the same frame position and size ("the round lamp lens fills the center of frame" / "the full moon fills the center of frame"). A model will not produce a match unless both prompts ask for it.
- Use the last frame of the first take as the first-frame reference of the second when the model accepts a start frame (`takes lastframe`, cinewright-genvideo); that makes position and scale match.
- Cut on the frame where the two elements overlap best; scrub 3-6 frames either side, not more.
- A motion match keeps direction: an object leaving frame right enters the next shot from frame left (screen direction).
- One match cut per sequence carries meaning; several in a row read as a gimmick.

## Vocabulary

- graphic match, match on action, sound match (a sound bridges two places), smash cut (the opposite: an abrupt mismatch).

## Pitfalls

- Matching on an element the model renders loosely (hands, text, crowds): the match wobbles; match on big simple shapes.
- A match cut across the axis flips direction and breaks the rhyme.

## Verify

- Both cards name the matched element with the same frame position words; the cut list marks the cut as a match with the frame used.
