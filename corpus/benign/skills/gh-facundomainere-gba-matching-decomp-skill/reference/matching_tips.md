# agbcc matching tips (collected from decompiling this ROM)

Read before starting a function. Each tip has an ID; report the IDs you tried and the ones that are in your
final matching code (`tips_tried` / `tips_helped`). Usage is tallied in `tools/tip_stats.json` and tips that
never help get purged (`tools/tip_stats.py`).

## Workflow
- [T40] Bodies dumped as .4byte in asm/*.s: `arm-none-eabi-objdump -D -b binary -marm -Mforce-thumb --adjust-vma=0x08000000 --start-address=.. baserom.gba`; a claimed range often hides several functions (new starts after each `bx`); every `bl` target must exist as a sub_ label (grep asm/ src/ ld_script.ld) or the link fails despite check_func MATCH; a pool function pointer with no sub_ label: integer address cast (thumb bit set), report the missed start; a function over ~2KB uses `bl` as an internal far jump, so the splitter invents fake sub_ labels there (pool word + `movs r0,r0` after the bl) and check_func never MATCHes: confirm a real prologue/pop+bx before trusting a claimed end. A thumb function address with no sub_ label used only as data (pool word with bit 0 set) can also be declared `extern gUnk_<addr|1>` (syms.py defines it at that address). (merges T60, T92, T122, T188, T190, T191, T320)
- [T90] Many functions are near-clones of matched siblings with other globals/offsets: grep src/ for a distinctive constant or callee and adapt the matched body first.
- [T131] check_func MATCH but add_funcs/integrate fails: add_funcs rejects any `\basm\b` text, comments included ("verified 0/1"); a new-agbcc-only function following an old_agbcc file gets appended to it, so re-match with the neighbour's exact extern prototypes (e.g. __divsi3 `__attribute__((const))`) or force a standalone file with a deliberately conflicting extern/prototype or struct redefinition (e.g. a different struct Oam); or reuse the neighbour's struct tag with a different layout. (merges T132, T134, T187, and T125's integrate note, T257)
- [T242] A leaf with branches but no push {lr} that still has new-agbcc code (`movs rX,#0; ldrsb rX,[rY,rX]`) is new agbcc with -fprologue-bugfix, not old_agbcc: test with a CC1 wrapper adding the flag. The build has no per-file flag yet, so such a function matches but cannot be integrated until splits.txt/Makefile support a 'bugfix' marker. (merges T276)
- [T277] A function that saves r9 at entry (`mov r3,r9; push {r3}` plus `mov r1,r9; str r1,[sp]`) and whose caller does `mov r9,sp` before each bl is a GCC nested function (r9 = static chain): define it inside the caller's body (emitted just before the outer function). Both compile into one object, so they must be integrated as a pair. (merges T280)
- [T306] Library code (EEPROM routines near 0805533C) was built with -O1, not -O2. The tell: loop invariants are never hoisted and while-loops keep a duplicated top test whose address is CSE'd from a previous store (adds rX,#2). Test with a CC1 wrapper script that appends -O1; it needs per-file build support. (merges T309)
- [T308] Callee-saved copies of r0/r1 with no matching use of r2 can mean a third argument passed straight through in r2: check the callers' argument count before fighting register allocation.
- [T317] Library code at 0x08055768-0x08056164 (timer/flash routines) is -O1: if -O2 is close but structurally off, run OPT=-O1 python3 tools/check_func.py first, then integrate with OPT=-O1 tools/integrate_one.sh.
- [T323] Library code built without -mthumb-interwork (leaf/func ends with pop {..,pc} instead of pop {r1}; bx r1): test with OPT=-mno-thumb-interwork; needs per-file flag support in splits/Makefile. (merges T325, T326)
- [T330] A claimed range whose only mismatch is a lone 0x4770 (bx lr) after the literal pool hides an empty function: add `void sub_XXXXXXXX(void) {}` after the main one in the same file.

## Types and extension
- [T05] Division/modulo calls libgcc: `sub_080561A0` __divsi3, `sub_08056238` __modsi3, `sub_08056308` __udivsi3, `sub_08056380` __umodsi3. Call them explicitly (`/` gives "undefined symbol __divsi3") and declare them `__attribute__((const))`; for a constant first argument put it in a local (`s32 n = 0x10000; __divsi3(n, a)`) to load it before extending the argument. (merges T27, T46, T132)
- [T01] `lsl #24; lsr #24` = zero-extend u8, `lsl #24; asr #24` = sign-extend s8 (same for 16); declare params/locals `s8`/`s16`/`u8` (not int) to get entry extensions. The callee prototype decides the caller's load: s16 field to a u16 param gives ldrh, s16 param ldrsh; an otherwise-dead ldrh into r3 before a bl is a 4th argument; a u8 result tested as `lsls r0,#24; cmp r0,#0` with no lsr, or a u16 result extended only after a later call: declare the callee u32 and cast at the use; byte table values combined in a RMW (`(r & a) | b`) with an extra mov ip: declare the temps int/u32, not u8. (merges T02, T59, T93, T153, T195, T256)
- [T03] A value re-truncated before a later compare is a narrow typed copy (`u8 j = m;`), one per block if tested in two blocks; a byte incremented and stored back untruncated is `t = p->f + 1; u8 n = t; ... p->f = t;` (int t); a byte counter compare that gives bhi instead of bgt (`(++b & 31) < 20`) needs s8; a byte index sign-extended at uses but zero-extended at its bound check is s8 with `if ((u8)++j > 11) j = 0;`; a u16 counter n-1 as subs+lsl/lsr instead of a 0xFFFF add: `u16 c = n; n = c - 1; if (c != 0)`. (merges T51, T116, T117, T118, T181)
- [T66] Signedness shows in the code: extra `& 0xFFFF` after ++ = s16 field; `x &= ~12` as `movs #13; negs` = s8; `+= tbl - 4` as `subs #4` = s8 table; ldrsh in compares + ldrh in args = u16 table with (s16) casts; agbcc keeps s16 vars zero-extended in registers and sign-extends at each use, so `lsls #16; adds 0x80000; lsrs` for x += 8 or compares against `432<<16`-style constants mean declare s16, not u16 with (s16) casts; two separate sign-extends of one s16 (one lsl/asr from the zero-extended copy, one bare asrs reusing the def's lsl) come from a copy `s16 c = a;` used in one expression and `a` in the other. (merges T72, T73, T81, T226, T246)
- [T135] gcc narrows int arithmetic passed to an s16 param, dropping inner (s16) sign-extensions: put the sum in an int temp before masking (`(a+b)&mask` turns asr into lsr), `s32 y = 192; y -= (s16)b;` instead of `(s16)(192 - (s16)b)`, or a comma assignment `(sa = a, sa)` to an s16 local (COMPOUND_EXPR blocks narrowing; reusing sa makes CSE share/spill it); keep a per-use asrs #16 in a loop with compound statements (`y = t[0] + xo[j]; y += (s16)a;`) so loop.c cannot hoist it; an element whose address comes early but whose ldrsh sits at the call argument: `int y = ys[idx];` in a statement before the call; a u16 bitfield `+=` of an s16 element that must stay ldrsh: `p->w = p->w + (t = arr[k]);` with s32 t (a separate statement keeps ldrsh but swaps registers); a reload copy `mov rLo,rHi` after ldrh needs an HImode pseudo: let the s16-param conversion narrow to the u16 load with `<< 3` (MULT does not narrow), sign-extended operands as `- (t = (s16)a)` with s32 t. An (s16) cast that must stay sign-extended inside a loop (narrowed away when passed to an s16 param): assign the sum to an int temp inside the argument, `f(.., (s16)(t = (s16)x + dx), ..)`; the MODIFY_EXPR stops narrowing. (merges T169, T189, T192, T224, T230, T239, T263, T338)
- [T313] A byte value the ROM re-zero-extends (lsl #24, lsr #24) from a high-register copy long after an ldrb, while the other copy is used unextended: keep it in a packed 1-byte struct local (`struct B { u8 v; } __attribute__((packed)) b;`). That gives a QImode pseudo whose nonzero bits combine cannot see. Copy it from a second such struct temp (`t.v = load; v = t.v; b.v = t.v;`) to get the shared load register and both copies.
- [T341] When a `y -= K` in-place subs lands before an unrelated constant load that the ROM emits first, make y an s16 variable (not u32/int). The HImode set changes the insn order, and the later (s16) uses need no extra extension. (from sub_0804CFE0)

## Constants and zero
- [T06] A zero kept live across stores: a local `u8 z = 0;` (`int v = 1;` for 1-bit fields) or `a = b = 0` chains; a stack CpuSet zero source (`mov r1,sp; movs r0,#0; strh`) is `volatile u16 z = 0;`; a stored 1 reused as an `ands` mask after calls is a u32 local `g[off] = one = 1; ... one &= keys;`; a zero used as stack CpuSet source and as a register zero: two locals, `zero = 0; buf = zero; f(&buf, ...)`; two constants stored with swapped registers (want movs r0,#0; movs r1,#K; strb r1; strb r0): K in a variable shared with a sibling block, 0 in a block-local `u8 z = 0;` declared before it; a const-0 that CSE merges with an earlier zero (make_regs_eqv, even across loop notes): write a value only combine folds to 0 (`z = t >> 16`, t a u16 call result); `x >= 1` on an s8 flag avoids the eq-jump equivalence that replaces later zeros with x. (merges T07, T44, T122, T170, T207, T249) (keep: pattern used in 47 matched files; under-credited)
- [T291] A constant 0 that CSE reuses from an earlier zero store in the same extended block (mov r0,r9; strb r3 where the original has a fresh movs r0,#0): store a value that only combine folds to 0 and that is already loaded in that block, e.g. `p->unk4 >> 8` for a u8 field tested just before. A dmg_ >> 16 param shift or a loop counter also folds, but it adds a spill or changes registers. (keep: inverse of T06, helped 2 matches in run 35)
- [T08] Stop gcc folding base + offset into one literal: keep the base in a local (`u16 id = 46;`), cast through an integer, or address through the real containing symbol (`&T[14]`, the struct at the lower symbol, `((u16 *)0x05000000) + idx*16 + b`); `ldr rX,=sym; adds rX,#32` reused across calls is `&sym[N]` of an extern struct array; VRAM as `(u16 *)0x06000000 + (x + y*32) + bg*0x400` in asm term order (byte casts fold the constant; `(a<<11)+(b<<11)` merges otherwise); a read at (i*W+K)*2+base: integer address `(u16 *)(0x0600A000 + (i*38 + 32) * 2)`; sym+const built as ldr/movs/lsls/adds is an int offset local set in an earlier block (`k = 344; if (...) {...} f(sym + k)`); adds going right to left need right-nested parens (`A + (B + (C + D))`); a constant added to the bg term before tile: separate u32 temps in that order (`t = tile*32; b = bg*0x4000 + 0x06000000;`); inner-loop local order decides hoisted invariant order; a constant added to the pointer after the index shift (`ldr base; lsls idx; adds base,#K; adds base,idx`): temps in that order `g = (u32)ptr; sh = idx << 1; k = K; q = (T *)((g + k) + sh);` (a literal K always folds next to the shift); a 3-term sum like idx*792 + (j*8 + T8) needs a block-local `t2 = &T[0].rec[j+1]; q = (P)(idx*792 + (u32)t2)`. (merges T70, T79, T83, T87, T123, T129, T160, T171, T173, T176, T193, T252, and T248's 3-term note)
- [T20] `w << 1` vs `w * 2` and unsigned (`88u`, `& 0xFFu) % 32` -> &31) vs signed constants change the code; `<< 3` instead of `* 8` drops a stray `mov rN, r8`; `adds rX, rY` with a 0x0000FFE0-style literal (not subs #32) is a truncated offset `a + (u16)(g - 32)`. (merges T56, T112, T136)
- [T142] A constant loaded early or kept as movs(+negs)+muls instead of shift/add comes from a local holding it: `m = 6; v * m`, `s32 ty = -16; (ty - 64) * d`, a stack arg at the very top `s32 x = 96;`, `y = 69; f(); g(.., y, ..)`; a `movs #1` into a callee-saved reg then muls is a function-top `s32 one = 1;` used as `(r = one, x * r)`. A constant call argument hoisted into a callee-saved reg before a loop (movs r0,#80; mov r9,r0) is a local set before the loop (`s32 y = 80; ... f(.., x, y, ..)`), not a literal in the call. (merges T151, T157, T163, T205, T294)
- [T278] `base + (idx + K)` where gcc keeps reassociating to `(base + K) + idx`: declare a zero-length `u8 data[0]` member at offset K and write `&s->data[idx]`; this reproduces `adds rI,#K; adds rB,rI`.
- [T344] A zero (or other constant) that the ROM sets once in a callee-saved reg at an odd spot and reuses for later byte stores, where agbcc instead reuses the HImode RMW-store zero of a later u16 field store: declare `struct H { s16 v; } __attribute__((packed, aligned(2))) z;` and set `z.v = 0;` at the ROM's position. That gives a non-promoted HImode pseudo, so CSE shares it with the HI RMW zero. Plain packed puts it on the stack (align 1), and an unpacked struct is SImode and adds a mask. (from sub_08020F8C) Variants: (T354) to keep a u16 global's stored constant in a register without CSE folding a later `g | K` into one constant, `g = K1; z.v = g; v = z.v; ... g = v | K2;` with v u32/int (a u16 v swaps the orrs operands; reading g straight into v keeps an ldrh); (T355) for a constant set the ROM schedules between a u16 global's ldrh and its `adds #1` post-increment, load the old value into the struct first: `z.v = g; done = 0; g++; t = z.v;`. (merges T354, T355)
- [T346] An HImode constant like 0x8000 stored or ORed into a u16 loads as an `ldr =0xFFFF8000` pool word when the operand is s16 or HImode. The ROM's `movs #128; lsls #8; adds rX,rY,#0` form comes from the SImode positive constant: cast the other operand, `(u16)v | 0x8000`. (from sub_08053944)

## Control flow
- [T10] Shared-looking tails (same call/stores in both arms, or registers swapped at a shared `b`): write the full statement in each branch with only the differing part changed; agbcc cross-jumps them back together; `if (a && b) x = 1; else x = 0;` whose else stores a just-tested-zero reg (strb r6): nested ifs with duplicated else arms (`if (a) { if (b) x = 1; else x = 0; } else x = 0;`), also when a ldrb is copied to two regs (read the field inline each time). (merges T41, T48, T52, T269, T271)
- [T53] `cmp A; beq; cmp B; beq` then an inline body = `switch` with explicit `default:`; `cmp X; beq far` with X's body last = `if (v != X) { others } else { X }`; a compare tree starting `subs rX,#K` is `switch (v - K)`; a signed range check on a zero-extended byte (`cmp #2; bgt; cmp #0; blt`) is `switch (b) { case 0: case 1: case 2: ...; break; }`; a 3-case tree pivoting on the lowest case: add a dummy lower case sharing default (`default: case 0x00: break;`) so balance_case_nodes pivots on the 2nd. (merges T74, T89, and T147's switch note, T254, T255)
- [T67] Extra zeroes/ldrs right after the counter's `movs #0` go in the for-init (`for (i = 0, n = 0, tb = tbl; ...)`, declared at function scope); comma order in the increment (`p++, i++`) sets the latch add order and registers. (merges T86, T184)
- [T12] Block layout: `if (x) {...}` vs `continue`, `return` vs `goto end`, a store inside/after an if all reorder blocks; a loop entered by `b test` with its condition at the body end is `t = first; goto test; do { ...; t = next; test:; } while (!t);`; a flag set just before a break into its test (`ok = 0; break;`) gets jump-threaded away: use it when the asm keeps a leftover `movs r0,#1; cmp r0,#0; beq` or `bne check; b doit`; a switch case `return x` moved out of the loop by loop.c (bne + shared return): wrap the case in `do { ... } while (0);`; a loop entered by `b test` whose counter store is crossjumped (`movs r0,#0; b L`, L: mov r9,r0; cmp; bcs exit) is a hand-written goto loop `i = 0; goto test; loop: {...; i++;} test: if (i < n) goto loop;` (a do-while gets rotated by jump.c). To stop loop.c hoisting constants or symbol addresses the ROM rebuilds each iteration, write a label + `if (++i <= N) goto loop;` with strength reduction by hand (offset += 12, p++). (merges T58, T64, T152, T211, T234, T244, T305)
- [T09] Two adjacent byte `== 0` tests merged into one word compare: split them into nested ifs.
- [T143] Ternaries: an offset picked between two constants (movs #A after the flag load, movs #B under bne) is `c ? B : A` (`x = A; if (c) x = B;` hoists movs #A); two of three arms sharing one truncation tail: `if (i) x = (i == 1) ? x+10 : x+12; else x = x+14;`; a clamp comparing the sign-extended load but keeping the u16 value: `s16 n = (s16)v > 10 ? 10 : v;`. (merges T148, T159, T212)
- [T144] Epilogue `pop {r1}; bx r1`: non-void; if r0 holds an earlier call's result, save and return it; if nothing writes r0, declare u32 with no return. (merges T149)
- [T166] Palette fades with a second `movs #31` in a high reg: declare the colour s16 so all three masks share one constant; one fresh `movs #31; ands` with the others sharing: `r = 31; r &= c;`; reuse the colour variable for the multiplier (`c = 16 - gTimer;`), int c with `(u32)c >> 5` keeps lsr. (merges T175)
- [T295] An if/else-if chain that picks one of two bodies, where the last case tests a byte (`a<b -> X; b<a -> Y; else BC ? Y : X`), with a fresh field address or reload at the join: write it as a direction variable `if (..) dir = 0; else if (..) dir = 1; else dir = p->f; if (dir == 0) X else Y;`. Jump threading deletes the constant arms but leaves a label that blocks CSE and reload inheritance.
- [T342] When a loop's entry copy of its exit test should cross-jump with the in-loop test (entry loads into callee-saved regs, then `b mid`), put a dead assignment of the test's user variable before the loop (`v = 0;`). jump.c's duplicate_loop_exit_test gives the copy a new pseudo for any reg whose first set and last use both fall inside the exit test; the earlier set keeps the copy and the loop on the same pseudo, so their tails cross-jump. (from sub_080142BC)
- [T353] Two equality tests against adjacent constants (ldr K; cmp; beq; adds r0,#1; cmp) come from a switch with those two cases. An if/else-if chain loads each constant from the pool, or hoists them into registers. (from sub_08046D8C)

Reuse one short-lived, ref-heavy user variable for an unrelated earlier value (e.g. `i = p->h & tbl[k]; p->h = i;` before the loops that use i as the counter) to push its refs past a rival that would otherwise take the register first. Also, regs_used_so_far starts with only r0-r5 here, so pass 0 never picks r6 or r7 first. (from sub_08025498)
- [T421] agbcc u16 var 'r |= g << 5' keeps a lsl16/lsr16 zero-extend (the shift is done in int and combine cannot prove r|t fits 16 bits), while 'g <<= 5; r |= g' with u16 vars has none; a single-expression '*dst = r | (g<<5) | (b<<10)' drops the zext but regmove then folds r/g/b into block-local pseudos. (from sub_08050948)
- [T422] When agbcc emits `ldr rK,=C; and rD,rS` (constant loaded straight into the dest) but the target has `ldr r1,=C; adds rD,rS,#0; ands rD,r1`, regmove's backward pass tied the constant pseudo to the dest. Wrapping the and in `do { w = r & m; } while (0);` with `u32 m = C;` set just before it puts a LOOP_BEG note between them, which stops the tie and leaves the constant as a local pseudo. (from sub_08051D8C)
- [T423] A pseudo set once from a constant or symbol (e.g. p = &gGlobal) gets REG_EQUIV in update_equiv_regs, which doubles its REG_LIVE_LENGTH and so lowers its global-alloc priority (log2(refs)*refs/len). To win a register race, make the same variable also hold a later unrelated value (casts allowed), so it gets more refs, or lengthen the rival's life with a code-free self-copy like `c2 = c2;`. Compare the (refs, live_length) pairs in agbcc -dg's .greg 'sorted order' list. (from sub_08025498)
- [T424] To debug reload-register choices, copy the debug agbcc build (scratchpad/fn/a1/gccdbg) and add an fprintf in reload1.c allocate_reload_reg after 'last_spill_reg = i;' that prints the insn UID, the chosen reg and the spill_regs order. - [T425] A reload trace (fprintf in allocate_reload_reg) shows the spill regs (often r0-r2) handed out round-robin across the whole function; if the target's reload regs are your version's shifted by one slot, look for the reload that sets the phase. Reordering a statement so an earlier reload finds r0 busy (e.g. `i = 0;` before a store through a high-reg pointer) moves every later reload reg by one. (from sub_08051D8C)
- [T426] agbcc combine drops the zero-extend of a u16 'r |= x' only when x is a variable shifted in place (x <<= 5); a fresh temp (t = g << 5, local or global, u16 or int) keeps lsl16/lsr16, which combine then merges with the next OR (lsl #26 / lsr #16 pattern). 'x = g; x <<= 5' drops the zext but regmove coalesces x into g. (from sub_08050948)
- [T427] A u16 '& 31' with a loop-hoisted HImode mask register (paradoxical subreg) hides the value's nonzero bits from combine, so a later 'x = v << 5; r |= x' keeps its lsl16/lsr16. Writing the mask and the shift in one expression, g = ((g*f>>4)&31) << 5, drops the zero-extend and still gives the shift its own pseudo. (from sub_08050948)
- [T428] If reload registers after some point are shifted one slot from the ROM and the trace shows no visible reload that could account for it, the ROM probably had a loop-entry copy of the exit test (jump.c duplicate_loop_exit_test). The copy used up a spill reg, then jump2 cross-jumped it into the bottom test after reload, so no code remains. Replace a hand-written 'goto test' loop with a plain while loop. (from sub_08051D8C)
- [T429] regmove's forward pass (fixup_match_1) renames a 2-address insn's dest pseudo into its dying source (e.g. 'g = m & asr_tmp' becomes asr_tmp) when the next insn mentioning g is the one where g dies.
