## Запуск

Для локальной разработки и ручных тестов. Настройки живут в `config/local.env` — подключать через `source`, не запуском.

```bash
source config/local.env
docker compose up -d
```

Любая правка в `config/` уедет в коммит, поэтому секреты храните в `.env.secret`. Флаг `--force` перезаписывает базу без вопросов.
