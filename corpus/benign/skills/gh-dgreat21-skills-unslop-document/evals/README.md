# Проверки unslop-document

Синтетические тексты разных жанров с эталонным разбором: что исправить, что оставить как есть (голос автора, цитаты, юридические формулы, код, формат площадки), какие цифры и имена должны пройти без изменений, о каких ярлыках нужно спросить автора.

- `build_synth.py` — тексты и эталоны. Запуск пишет `synth/*.md` и `evals_synth.json`.
- `grade_synth.py <папка_прогона>` — применяет предложенные правки к исходнику, сверяет с эталоном и пишет `grading.json` и `details.json`.

Прогон ожидает структуру `<папка>/eval-<id>-<name>/<with_skill|without_skill>/run-<n>/outputs/` с файлами `result.md` (ответ пользователю), `edits.json` (`{"edits":[{"before","after"}],"optional":[...]}`) и `input/<файл>` (копия исходника; скрипт проверяет, что его не изменили).

| id | Текст | Что проверяет |
|---|---|---|
| 1 | пост в блоге | штампы, «не просто X, а Y», вывод ни о чём; авторский повтор не трогать |
| 2 | описание товара | пустые усилители, тире-раскрытие; характеристики не трогать |
| 3 | письмо клиенту | кальки («адресует», «на ежедневной основе»), канцелярит; обращение не трогать |
| 4 | сопроводительное письмо | рамки, «питает»; факты и цифры не трогать |
| 5 | пост в соцсети | рамки; эмодзи-анонс — формат площадки, не трогать |
| 6 | объявление для сотрудников | отглагольные цепочки, слипшееся предложение |
| 7 | договор подряда | канцелярит; юридические формулы и термины с заглавной не трогать |
| 8 | README | кальки разработчиков, обрывок; код и идентификаторы не трогать |
| 9 | авторское эссе | почти ничего не трогать |
| 10 | письмо о проекте | термины-призраки; определённый термин не называть непонятным |
| 11 | статья с цитатами | канцелярит вне цитат; цитаты не трогать |

Скрипт смотрит только на «исправлено / не тронуто / спрошено». Оформление ответа и качество формулировок он не оценивает.
