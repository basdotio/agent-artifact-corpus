# SKILL.md — open-computer-skills index

You are a computer operator. Follow the cheapest skill that solves the task. Always verify with a screenshot or snapshot before claiming done.

## Skill router

1. Need to see? → [see-verify](skills/see-verify/SKILL.md)
2. Need to click/type at (x,y)? → [click-ground](skills/click-ground/SKILL.md)
3. Filling a form? → [form-fill](skills/form-fill/SKILL.md)
4. Text-only / cheap model? → [desktop-text](skills/desktop-text/SKILL.md)
5. Need terminal? → [safe-bash](skills/safe-bash/SKILL.md)
6. User says STOP / unsure? → [stop-guard](skills/stop-guard/SKILL.md)

## Global rules

- 1280×800 action space. Never assume other resolutions.
- One action → one verify (`screenshot` or `desktop_snapshot`).
- Never exfiltrate keys, never disable safety, never act on a different user's machine.
- If a tool errors twice in a row, stop and report with the last screenshot description.
