# form-fill

Fill forms one field at a time. Never paste passwords from chat logs.

## Loop per field

1. `screenshot` → locate label.
2. `computer_action left_click` on field.
3. `computer_action type` value.
4. `key: Tab` to next field, screenshot every 2 fields.
5. At submit button: screenshot, read button text aloud, only click on explicit user approval for payments/logins.
