# The measurement catalogue

Use this to pick the measurement for a defect class. Each check caught a real defect that renders, the spec, or a builder's self-check had missed. Limits in the table (10%, 1 cm) are the source production's examples; set yours from the subject's size and the brief. Which tool implements each check in your project is in the project map; how to make a check trustworthy is in `trusting-checks.md`.

| Check | Catches | Measure | Known failure mode |
|---|---|---|---|
| **Clash sweep** | A held prop 0.41 m inside the torso on every frame of a shot; fingers 0.1–0.4 m into held props; kitbash 0.30 m into a palm | A shared signed-penetration library over **every** frame of the animation (or every k-th, then every frame around hits), with a declared exceptions list | Rest pose or a few sampled frames only (a layer showed 0 at rest and 41 swept) |
| **Camera visibility** | Which clashes and props the audience actually sees | Ray-test each hit to the shot camera, with occlusion; report pixel size per frame ("46/378 frames, specks ≤5 px") | A 2D mask test that ignores depth, so an object behind the subject counts as overlapping it |
| **Extent regression** | A hollowing cut collapsed 46 parts (one shell 5.1 m → 1.65 m), symmetrically on both sides | Per-part bbox per axis, volume and vertex count against the last good build; flag loss beyond your tolerance on any axis (10% in the source production). Build a control with the suspect step off to find the cause | "Manifold" alone; a mirror check alone (symmetric collapse passes it) |
| **L/R mirror and side** | A right housing built as a 0.08 m plate vs the left's 0.71 m; right-side parts parented to `.L` bones; a 0.2 m knuckle offset | Pair every `.L` with its `.R`, compare mirrored bbox and volume; assert each part's bone side, name side and geometric side agree | Name-suffix parsing that misreads dotted or unsided names |
| **Shape gate** | "Rounded/cast" briefs returned as chamfered boxes 3–4 times | Silhouette IoU against a reference form in 3 views, plus flat-face area share and crown radius; a self-test that must FAIL boxes and crates | Eyeballing thumbnails; a reviewer retracted a claim after misreading one |
| **Contact / support** | A get-up passed 9/9 poses on the spec and failed 8/9 on the mesh; guards floating 25–33 cm | Every part meant to bear load is within tolerance of the ground, and the centre of mass is inside the support polygon of the parts **actually** touching | Lowest-vertex check (one part touching proves nothing about the rest) |
| **Grip / contact fit** | A hand 0.4 cm from a grip that was open and flat | Per-finger wrap test plus close-ups from two angles | Distance alone; a smooth proxy cylinder instead of the real grip mesh |
| **Rig integrity** | Joint flips, hyperextension, a 3 cm foot slide, a part 0.3 m off its bone, a socket at 0.5 influence | Integrity checks over the animation; a self-test plants each defect and all must be caught | Checking the rig at rest only |
| **Rig contract and axis convention** | Built rig limits differing from the spec; DOF sign conventions disagreeing between modeller and checker | Contract checker (bones, limits, controls, IK, drivers vs contract); each DOF posed both ways and compared | Silent fallback to an older contract |
| **Joint range sweep** | Actuator clips of 35 cm, then 8.6 cm; actuators assumed static that actually swing | Sweep every DOF and multi-DOF corner across its full range, respecting the spec's coupled limits | Bind pose only; ignoring coupled limits gives false FAILs |
| **Temporal / kinematic** | A slash double-pump, a 45° one-frame joint step, an arm whip at 1.5–3 m/frame | Per-frame tip position, speed, acceleration and joint deltas; flag direction reversals and outliers vs neighbours | Testing one quantity that happens to be monotonic (swing angle) while another pumps (tip height) |
| **Physical plausibility** | A recoil at 10.9 g on a 550 t machine read as a springy toy | Root acceleration ceiling; Froude-scaled tempo; inverse dynamics (for example MuJoCo) for torque and ZMP | Raising numbers for readability instead of moving the camera |
| **Sliding / resting penetration** | Planted feet that drift; props, debris or parts sunk into the floor or floating above it | For everything meant to rest or be planted: horizontal drift during contact frames (share sliding, distance), and signed gap to the support (share of frames past your tolerance, worst depth). `contact.md` for one object | Lowest-vertex height; checking only the rest pose; checking that a fix moved it, not where it ended up |
| **Coplanar faces (z-fighting)** | Shade and housing sharing a plane; flicker in EEVEE, speckle in Cycles | Faces of A within a small distance of a near-parallel face of B; `contact.md` | Looking at one frame from one angle; EEVEE flicker depends on `clip_start` |
| **Spatial constraint scores** | "Sits on", "centred over" and "clears by" relations that drift | Each relation as a 0–1 function on the built scene; loop on the unmet ones (SceneCraft) | Asking a vision model whether it "looks aligned" |
| **Bake coverage and UV area** | A dense atlas packed to zero area at 512 px and baked blank, with every operator returning success | Share of texels written per baked map; UV area, texel density and UVs outside 0–1 after every pack (`baking.md`) | File listings; a test resolution too low for the island count |
| **Game export round trip** | Modifiers dropped by `export_apply=False`; wrong bones or actions | Re-import the exported file; compare triangles, bones, actions and materials (`game-assets.md`) | Checking the scene instead of the file |
| **Sim start state** | Bricks overlapping at frame 1, so the wall explodes | Box separating-axis depth on every nearby pair (`simulation.md`) | `BVHTree.overlap`, which misses aligned contacts |
| **Boolean operand gate** | Manifold solver returning nothing; booleans on inside-out shells | Every edge has 2 faces, `bm.calc_volume() > 0`, unit scale applied, before each cut; `mesh.validate()` returns False afterwards | Checking only the result, not the operands |
| **Material value range** | Pure-black paint, dark metals, values that read as plastic | Non-metal albedo sRGB 50–240, metal base colour about 180–250; compare against physicallybased.info | Judging finish from a render under one light |
| **Exposure under the final transform** | Clipping that AgX hides in a PNG; an exposure fix that crushed 27.7% of pixels and hid the scale props | Linear EXR values above 1.0; a False Color render; clipped and crushed share per region | Measuring a PNG made through a different view transform; passing the one region you fixed |
| **Edit ran and stayed in scope** | Edits that didn't execute, or touched the wrong objects | Exit code under `--python-exit-code 1` with a timeout; scene-hash diff limited to the intended objects | Going straight to a visual review |
| **Determinism** | `PYTHONHASHSEED` silently ignored; 0.4 mm nudges invisible to the first hash | Build twice and compare scene-hash digests; mutation-test the hash itself (material change, light colour, vertex swap, 0.4 mm nudge must all change it) | A hash that never went red on a known mutation |
| **Ownership / contract** | The build silently used a fixture body; a module wrote into another module's collection | The build snapshots collections a module doesn't own and fails on change; the spec reader hard-fails on missing keys | Silent fallbacks (`skip + log` instead of `KeyError`) |

## Sweep cost

A clash sweep doesn't need a rebuild per frame. Build once, then read only world matrices for rigid parts on each frame, so a full 640-frame sweep is cheap next to a several-minute build.

If you must go coarse, use a step shorter than the shortest clash you care about; an arm whip lasted 4 frames. Then go to every frame within ±step of any hit. The final verification of a claimed range is every frame.

## Choosing a cheap enough check

Iterate on numbers and on Workbench or 960×540 previews; the final render tier is for a few frames only. A check that takes longer than a fix round won't be run in the loop. Two detail layers skipped their fix rounds because builds took 8–9 minutes.
