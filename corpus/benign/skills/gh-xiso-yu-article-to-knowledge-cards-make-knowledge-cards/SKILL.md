# Make Knowledge Cards

## Overview

把一篇文章压缩成一组便于复习的知识卡片：只保留真正重要的知识点，一卡一点，忠于原文。目标数量为 5～8 张，但**数量服从内容**。

## 支持与不支持

**支持的输入**

- 用户直接粘贴的文章文本
- 本地 `.md` / `.markdown` / `.txt` 文件（用文件工具完整读取）

**不支持（收到时明确说明，并给出替代做法）**

- 网页 URL / 网页抓取：请用户把网页正文粘贴为文本
- PDF：请用户转换为 `.md` / `.txt`，或直接粘贴文字
- Anki 牌组（.apkg 等）导出
- 图形界面、卡片图片渲染

## Workflow

1. **获取全文**
   - 粘贴文本：直接使用。
   - 本地文件：完整读取；路径无效或读不到时请用户确认路径，不要猜测内容。
2. **提取知识点**
   - 标记可复用的知识：定义、原理与机制、方法与步骤、关键区别、规则、重要事实与因果关系。
   - 合并重复或近义表述，把从属小点归入同一个知识点。
   - 删除铺垫、寒暄、过渡句、引入性表述、重复强调和不含可复用知识的细节。
3. **筛选与排序**
   - 按重要性筛选，目标 5～8 个；按学习顺序排列（基础概念在前，或沿用原文结构）。
   - 超过 8 个：保留最重要的 8 个，可备注被省略的数量。
   - 不足 5 个：有几个做几个，并说明原文只支持该数量，**禁止凑数**。
4. **按卡片格式起草**（见 Card Format）。
5. **交付前核查**（逐条过）：
   - 每条陈述都能在原文找到依据；没有原文之外的事实、数据、例子或推论。
   - 每张卡片只讲一个点；卡片之间无重复；标题互不相同且具体。
   - 自测问题仅凭本卡内容即可回答。
6. **交付**
   - 默认在对话中以 Markdown 输出。
   - 用户要求存档时，写入一个 `.md` 文件。
   - 开头用一行注明来源（“用户粘贴文本”或文件名）与卡片数量；不足 5 张时说明原因。
   - 不输出图片、GUI 或 Anki 文件。

## Card Format

严格使用以下结构（例子与自测二选一，也可都给）：

```markdown
### 卡片 N：<具体标题>
- **核心知识**：<一句话陈述定义 / 结论 / 原理，可独立成立>
- **简明解释**：<2～4 句，讲清机制、原因或适用条件，只用原文信息>
- **例子 / 自测**：<取自原文的例子；或一个答案就在本卡内的自测问题>
```

字段要求：

- **标题**：具体点明知识点，禁用“概述”“简介”“相关知识”等空泛标题。
- **核心知识**：一句话，脱离上下文也能读懂。
- **简明解释**：保留原文术语；不引入原文没有的内容。若原文对该点说明不足，可写明其前提、适用范围或原文未提供的信息，不用空话凑字数。
- **例子 / 自测**：优先用原文例子；自测题答案必须能在本卡找到，不考卡片之外的内容。

## Hard Rules

- **不编造**：原文没有的信息（包括例子、背景、数据、推论）一律不写；宁可卡片少。
- **一卡一点**：一个知识点一张卡；不同的点拆成多张卡。
- **去重**：同一含义只出现一次，即使原文反复强调。
- **不凑数**：5～8 是目标而非配额；信息不足时按实际数量输出并说明原因。
- **抓重点**：优先保留定义、原理、方法、关键区别与因果；舍弃装饰性内容。
- **同语言**：卡片语言与原文 / 用户语言保持一致，表述简洁。

## Edge Cases

- **文章很短或几乎没有知识点**：如实说明，给出实际能做的 1～4 张（或 0 张），不硬凑。
- **单个知识点的信息也很少**（如产品参数、公告条目）：核心知识给出事实，简明解释说明该事实的前提或原文信息边界，不补充外部知识。
- **故事、随笔、观点文**：只提炼其中可复用的观点、方法或道理；没有可复用知识就如实告知。
- **操作指南 / 教程**：每个独立步骤或原则可成一张卡；连续步骤只有合在一起才可理解时，合并为一张“如何做 X”的卡。
- **用户给 URL、PDF 或要求 Anki / 图片**：按“不支持”清单说明，并请其改用支持的输入形式。

## Mini Example

输入片段：

> “复利是指收益计入本金后继续产生收益，因此长期增长呈指数曲线而非线性。例如年化 10% 时，本金约 7.2 年翻一倍（72 法则）。”

输出：

### 卡片 1：什么是复利

- **核心知识**：复利是把已获得的收益并入本金、继续产生收益的增长方式。
- **简明解释**：由于每一期的本金都在增加，收益也随之增长，长期表现为指数曲线，而不是简单的线性增长。
- **例子 / 自测**：按 72 法则，年化收益 10% 时本金约 7.2 年翻一倍。自测：为什么复利的长期增长是指数曲线？
