# 降去AI痕迹润色人味（AI 智能体技能）

**去AI味、去AI痕迹必备技能**——把AI生成的中文文本改写成真人笔触。适用于小说、自媒体文章、文案、ai输出的文字内容。

✅ **开箱即用**：安装后直接免费用，无需注册、无需任何配置。

## 核心能力

1. **微处理（flash）**——打破AI骨架结构 
2. **中处理（pro）**——琢字琢句对症下药
3. **重处理（pro_plus）**——超级处理，耗时长，最有效去AI味

三档自由选、可配合尝试，选择自己合适的结合。插件一直更新中。

"保住内容的根"：不改观点不塞词，三档可分离可结合，处理完和你原文的质量还在一个层次。

## 隐私与数据说明

- 数据说明：你提交的文本仅用于本次实时处理——由腾讯云函数无状态运行，处理完立即返回结果并丢弃，不存储原文、不保留任何上下文。为保险起见，请勿提交敏感个人信息。
- 默认使用公共共享密钥，你绑定的个人密钥保存在你自己电脑的本地配置文件中（不会上传给任何第三方，也不会被其他人获取），随时可以清除。


## 大量润色痛点（对号入座）

1. 经常删除或扭曲原意，需要人工大量复核
2. 强行塞同义词、乱换句式，读起来生硬别扭
3. 大改，和原文的质量完全不在一个层次
4. 内容效果看运气，多次重复去调用
5. 处理方法模板化，导致大家的结构内容都一样

## 我的优势

1. 内容的根不会删减改变——你的观点、判断、意思不会删减扭曲
2. 不会强行塞入各种表述用词，不会为了强行人味导致内容降智或成外星人
3. 润色处理中途可以停——润色和排版可分离，润色完看结果再排版，也可结合一次性输出
4. AI 智能识别内容领域，无需手动选类型
5. 处理出来的内容随机应变，不会模板化
6. 处理出来的内容质量和原文还在一个层次

## 三个核心应用

### ✅ 微处理（flash）
打破AI骨架结构，最大程度保留原文，100% 保留原文核心情节、观点、细节，不删减不扭曲（微处理打破结构会出现无标点，需自己手动加一下或者在用中处理处理更佳）。

### ✅ 中处理（pro）
琢字琢句对症下药——**本作者一般用的最多**

### ✅ 重处理（pro_plus）
超级处理，耗时长，最有效去AI味——微/中处理后的内容属于疑是人味，用重处理后就很出人味了，一步到位直接能发。
三个档位是最新的处理，三个档位可以配合组合使用，比如先用未处理再用一次中处理效果更佳。（本人写自媒体文章一般都这样操作）
## 在 AI 智能体里怎么用

支持任何能安装技能的智能体（WorkBuddy、Claude Code、OpenClaw 、以及自己智能体、软件、网站等。openAI格式-接入简极方便），说法通用：

**轻度**：直接说 →「帮我微处理这篇文章：……」（粘贴 300 字以上原文）

**中度（AI味不重推荐）**：直接说 →「帮我中处理这篇文章：……」

**重度一步到位（推荐）**：直接说 →「帮我重处理这篇文章：……」或「最有效去AI味」

- 三档可以配合尝试，选择自己合适的结合
- 重处理耗时较长，耐心等待即可
- 三种处理方式都可以配合尝试，选择自己合适的结合。插件一直更新中。

> 字数要求：至少 300 字，1000 字左右效果最佳；太长的超过3000字的内容可分段处理。

## 使用方法：
1，重度ai内容直接用重处理（pro_plus）一步到位，或先微处理再重处理配合使用。
2.轻度ai内容直接用中处理（pro）
3.中处理是最热门的处理。

> 存储说明：密钥在你确认保存后才会写入本机配置文件（默认 `~/.workbuddy/wenzi-runse-config.json`，也可以让 AI 自定义存储位置；明文，仅限本人设备），随时可说「清除润色密钥」删除。未确认前只作当次临时使用，不会落盘。

其他说法：

- 查看当前密钥：说「查看润色密钥」
- 退回公共密钥：说「清除润色密钥」

**开发者提示**：本服务同时提供 OpenAI 兼容接口（/v1），有开发能力的用户可以用自己的密钥，在任意支持 OpenAI 格式的工具（各类客户端、工作流、自建应用等）中直接对接，接口地址见 `scripts/runse.py`。
