CautionDo not send public with data for one user. A shared cache can give that data to a different user.

Find the row for your content. Send the header in the Send column. When the content changes, give it a new URL or a new ETag. Each cache then gets the new version.

To find the time left for a copy:
  1. Read max-age in the Cache-Control header.
  2. Read the Age header. If there is no Age header, use 0.
  3. Subtract Age from max-age. A result of 0 or less means that the copy is stale.
NoteThe Age header counts the seconds since the origin made or checked the response. Each cache on the path adds the time that it kept the copy.
