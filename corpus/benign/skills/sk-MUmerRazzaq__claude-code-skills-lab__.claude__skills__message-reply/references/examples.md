
**User said:** "make it natural and humanized"

**Good Reply:**
```
Hey there!

I can help you set up a clean and reliable workflow in n8n that connects your Google Sheets, runs prompts through ChatGPT or DeepSeek, and automatically sends out a formatted PDF email twice a week.

Here's the plan:
I'll connect your Google Sheets and set it to trigger either on a schedule (like twice a week) or whenever new data is added. Then the relevant data gets passed to the AI for processing, and the output is formatted and converted to PDF. Finally, it's sent via Gmail automatically.

I've built similar workflows with Google Sheets, AI APIs, and automated reporting. Happy to discuss the specifics!
```

## Methodology Questions (When Relevant)

### Client Asks About Process

**Received (Fiverr/Upwork):**
```
What's your development approach? How do you ensure the automation works reliably?
```

**Good Reply:**
```
I follow spec-driven development:

1. Document requirements first (you approve before I start coding)
2. Write tests that define expected behavior
3. Implement against specs and tests
4. Deliver working code + specs + tests + docs in the repo

You get verified, documented code — not just "it works on my machine."
```
