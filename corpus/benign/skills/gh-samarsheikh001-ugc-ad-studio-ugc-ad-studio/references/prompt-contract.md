# UGC generation prompt contract

Create an original, product-specific prompt using the approved research, selected reference mechanics and authorized product images. Do not pass a competitor video to a generator unless the user specifically authorizes that use and the chosen tool supports it.

## Required prompt sections

1. **Goal and format:** platform, aspect ratio, target duration, UGC format (talking head, unboxing, handheld demo, street-style Q&A, etc.) and output count.
2. **Product identity:** exact official asset(s) and what each governs: bottle/package shape, label text, color, materials, accessories or visible result. Keep unverified areas out of frame rather than inventing them.
3. **Creator and setting:** original fictional adult performer when synthetic; wardrobe, position, phone framing, background objects, light and recording texture. Never claim the person is a customer.
4. **Hook and timed beats:** dialogue/action per beat; gesture, camera, product contact, reveal timing and expression. Keep actions physically possible and non-contradictory.
5. **Dialogue and audio:** exact words, speaking language, audio mode requested, room sound, music/SFX if actually supported, and whether speech is native or a separate generated track. Preserve approved text exactly.
6. **Continuity:** repeat appearance, wardrobe, room, product position, voice and last-frame pose across extensions. Specify the boundary action and dialogue to avoid repeating.
7. **Exclusions:** inaccurate labels, unsupported product/health/performance claims, unintended text/subtitles/watermarks/brand marks, extra hands/fingers, product morphing and undesired cuts. Only ask for elements the selected model can honor.
8. **Review criteria:** required product visibility and dialogue, final frame/CTA, and checks for claims, label, hands, audio, duration and continuity.

## Claim handling

Keep sourced product statements in exact, plain language. Creative metaphors are allowed when clearly experiential and not presented as measured results. Avoid fabricated first-person usage histories, customer quotes, ratings, scarcity, discounts, efficacy, scent performance, guaranteed outcomes and comparative claims.

## NinjaChat execution adaptation

The media prompt contains content direction; model selection, aspect ratio, duration, reference images, quality and budget belong in the matching NinjaChat tool arguments. Read live schemas before execution. Preserve a single chosen prompt version and attach only the intended, authorized product images. Prompt text alone does not establish native audio, lip-sync, editing or extension capability.
