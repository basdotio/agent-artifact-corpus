# Miko tutorial and source-kit mapping

The source video demonstrates Codex + GPT-6 Astra Medium, a Higgsfield plugin, the Miko video-ad-stack kit, Hawthorne Canary Diamond research, three fragrance references and Seedance 2.5 generation. This adaptation retains its staged handoff and substitutes Opus 5.5 + NinjaChat MCP for this project.

## Source-to-adaptation map

| Miko stage | Opus 5.5 + NinjaChat version |
|---|---|
| Start the video ad stack | Invoke `/ugc-ad-studio` or use the starter prompt in `SKILL.md`. |
| Give brand homepage and product URL | Give product site plus official product page and available product photos. Claude researches and cites claim sources. |
| Choose a TikTok UGC reference, download and attach the MP4 | Provide authorized reference media. Claude inspects the actual footage and documents its format mechanics; do not copy creator identity or claims. |
| Higgsfield visual/audio video analyzer | Use measured ffmpeg/frame evidence plus the current Claude client's actual vision/audio capabilities. Mark any unavailable audio inspection. Do not imply NinjaChat performs this analysis. |
| “Adapt this concept to our own perfume at the same target length, show me the full script and shot plan and very detailed generation prompt before generating.” | Keep the requested concept/timing adaptation, but create original product claims, dialogue, shot plan, product-image map and a NinjaChat-compatible prompt. Show and approve the entire preview. |
| Seedance/Higgsfield generation with 30s + 30s + 8s extension chain | Query NinjaChat's current model catalog, quote actual compatible operations and use only supported durations, references and continuity controls. Do not preserve that split unless the chosen NinjaChat model requires it. |
| Review outputs and request revisions | Review the actual NinjaChat result; quote/approve additional paid edits or extensions before submission. Track IDs, spend, output links and review findings. |

This package contains the adapted skill only, not Miko's source files. Installing the skill does not select Claude's model or connect NinjaChat MCP for you. A perfume tutorial using this workflow was produced separately; generation results and current tool availability still need checking for each new product.
