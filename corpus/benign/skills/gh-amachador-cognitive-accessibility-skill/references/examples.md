# Precedent catalog

Real products observed in the research. Naming the analogue turns a recommendation into
a shipped precedent — "this is the Workday density problem" lands harder than an opinion.

Products change; these describe what was observed. Cite them as patterns, not as current
claims about the product.

✅ do this · ❌ avoid this

---

## H1. Purposeful sensory stimulus

| | Product | Pattern |
|---|---|---|
| ✅ | **Brave** | Autoplay of video and sound off by default; native ad blocking. *The quiet default.* |
| ✅ | **Notion** | UI elements appear on interaction; they hide once typing starts. *Chrome on demand.* |
| ✅ | **Chrome / OS settings** | Option to reduce or disable animation; a pause button on the download-page animation. *In-context pause, not only a buried setting.* |
| ❌ | **Dirección General de Registros** | Every element animated, varying intensity, no defined purpose, no way to disable. |
| ❌ | **Windows 11 + Excel** | Incomplete dark mode — flashes of white from legacy interfaces, overloading partly *because* they surprise. |
| ❌ | **SAP SuccessFactors** | Large shortcut buttons in arbitrarily saturated colors following no convention. *High contrast ≠ low sensory load.* |
| ❌ | **Mercado Libre, Blacksmith, Fablet & Bertoni** | Saturated color as background or highlight — overstimulating, complicates navigation, worst on a landing page. |

## H2. Clarity and straightforwardness

| | Product | Pattern |
|---|---|---|
| ✅ | **MATLAB** | CTA states it's a trial *and* how long it lasts. Avoids "OK" / "Learn more". |
| ✅ | **macOS Finder** | Optional **visible** text labels under toolbar icons — rendered on screen, not a tooltip or an accessible name. *Recognition over recall.* |
| ❌ | **Windows 10 setup** | To decline, you must choose "Limited experience" — a loss-framed decline that's hard to identify as "no". |
| ❌ | **TocToc Viajes, Microsoft Edge** | Emotional tactics and manipulation to drive downloads, subscriptions and upgrades. |

## H3. Assistance

| | Product | Pattern |
|---|---|---|
| ✅ | **Notion, Word** | Templates and use cases at document creation — capabilities shown by example. |
| ✅ | **Grammarly** | Explains the mistake as well as correcting it. *Errors as teaching.* |
| ✅ | **Perplexity** | Follow-up questions after an answer — bounds an open space into choosable actions. |
| ✅ | **Microsoft To Do** | "My Day" aggregates what's scheduled and surfaces it at the start of that day. |
| ✅ | **Gmail** | Predictive writing removes the load of deciding tone. *Relieves masking and communication.* |
| ✅ | **Notion formulas** | Graphical picker, worked examples, error location, and what's needed to fix it; natural language to generate a formula from the intended result. |
| ❌ | **Excel formulas** | Requires recalling the formula, its syntax, semantics and language variants. |
| ❌ | **Dia** and generative-AI apps | A bare text field as the only entry point — no context, so capabilities stay undiscovered. |

## H4. Progressive discovery

| | Product | Pattern |
|---|---|---|
| ✅ | **Hey.com "The Screener"** | Emails presented one at a time to separate urgent from deferrable. |
| ✅ | **Facebook, Figma** | Redesigns shipped with a way back to the old UI and docs on what moved where. |
| ❌ | **Workday** and similar dashboards | Widgets, charts and tables at maximum density simultaneously — impedes comprehension, overwhelms. |
| ❌ | **DGI Servicios en Línea** | Subprograms with no clear hierarchy and unfamiliar naming; seasonal tools (tax declaration) permanently visible, saturating the scan. |

## H5. Control and customization

| | Product | Pattern |
|---|---|---|
| ✅ | **Superlist** | Visual personalization (header images) to grasp a list at a glance; preserved across devices. |
| ✅ | **Outlook, Gmail** | Granular control over which mail is important and seen first. |
| ✅ | **Arc** | Profiles and spaces compartmentalize different areas of life — also mitigates errors. Steep learning curve. |
| ✅ | **Obsidian** | Multiple views of the same notes; the graph view reveals connections at a glance. |
| ❌ | **Zendesk** | Tickets in one table grouped by priority — no regrouping, no other view, no filters. |
| ❌ | **IBM Support** | ~52,000 results across 100+ pages with no filters or refinement. |

## H6. Cohesion

| | Product | Pattern |
|---|---|---|
| ✅ | **Uruguayan State portal** | Agencies adopted a shared style guide — common hierarchy, order and interaction model. |
| ✅ | **Microsoft Teams** | Notes, calendar, contacts and calls unified into one surface for an organization's operations. |
| ❌ | **SAP** | Modules of the same application with diametrically different interaction models and visual languages. |

## H7. Consistency and standards

| | Product | Pattern |
|---|---|---|
| ✅ | **Nanoscope + MATLAB** | Different vendors, different goals — shared interaction patterns and UI elements let familiarity transfer between them. |
| ❌ | **Zureo Facturación** | "Grabar" (record) as the button to issue an invoice. Biller uses "Emitir" (issue) — the verb people actually use. |
| ❌ | **Microsoft Teams** | Call controls at top right, against the standard set by Zoom, Meet, Webex and Skype (bottom). Not repositionable. |

## H8. Resilience and error tolerance

| | Product | Pattern |
|---|---|---|
| ✅ | **Slack, WhatsApp, Instagram** | Edit and delete after sending — mitigates errors and can prevent a crisis in a challenging moment. |
| ✅ | **Outlook** | "Replace message" and "Recall email". |
| ✅ | **Gmail** | Send delay for a final review; warns before sending when the text mentions an attachment and none is attached. *Proactive help.* |
| ✅ | **Slack** | Confirms before mentioning many people, especially outside configured office hours. *Guards actions that notify third parties.* |
| ❌ | **macOS update** | A timer that initially can't be postponed; force-quitting apps can lose work. |

## H9. Focus management

| | Product | Pattern |
|---|---|---|
| ✅ | **Windows 11 Focus Sessions** | Cognitive accessibility feature in the Clock app: focus timers plus white noise and calming sound. |
| ✅ | **Notion Calendar** | Visible countdown of the current event and upcoming events without switching context. |
| ✅ | **iA Writer** | Hides UI and highlights the passage being written or read — focus managed by priority. |
| ✅ | **macOS Focus** | Granular by place, schedule and event criticality. |
| ❌ | **Windows 10 Focus Assist** | All-or-nothing: turns off every interruption, which enables hyperfocus and loss of time awareness. |
