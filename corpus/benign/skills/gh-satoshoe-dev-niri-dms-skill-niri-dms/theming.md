# Theming: colors, wallpapers, app themes

Read this before changing the theme, wallpaper, light/dark mode, accent
colors, or colors of GTK, Qt, terminal, browser or editor apps.

Upstream: https://danklinux.com/docs/dankmaterialshell/custom-themes and
https://danklinux.com/docs/dankmaterialshell/application-themes

## Where colors come from

DMS has one active theme, set by `currentThemeName` in settings.json:

| Value | Meaning |
|-------|---------|
| `dynamic` | Material You colors generated by matugen from the current wallpaper |
| a stock name: `blue`, `purple` (default), `green`, `orange`, `red`, `cyan`, `pink`, `amber`, `coral`, `monochrome` | Built-in palettes |
| `custom` | Colors from the JSON file in `customThemeFile` |
| a registry theme | Installed under `~/.config/DankMaterialShell/themes/<id>/`, picked in the theme browser |

The Theme & Colors page (`dms ipc call settings openWith theme`) covers all
of these. Related scalar keys can be set over IPC:

```bash
dms ipc call settings set currentThemeName dynamic
dms ipc call settings set matugenScheme scheme-expressive   # scheme-tonal-spot (default), -content, -expressive,
                                                             # -fidelity, -fruit-salad, -monochrome, -neutral, -rainbow
dms ipc call settings set matugenContrast 0.2
```

Whatever the source, DMS then runs matugen to write color files for apps (see
below). That includes `~/.config/niri/dms/colors.kdl`, which sets niri's focus
ring, border, shadow and tab indicator colors.

## Light and dark

```bash
dms ipc call theme getMode
dms ipc call theme dark
dms ipc call theme light
dms ipc call theme toggle
```

The mode is stored as `isLightMode` in session.json. Automatic switching by
time or location is on the Theme & Colors page (`themeModeAuto*` keys in
session.json).

## Wallpaper

DMS draws the wallpaper itself (layer namespace `quickshell`, background layer).

```bash
dms ipc call wallpaper get
dms ipc call wallpaper set /absolute/path/image.jpg
dms ipc call wallpaper setFor DP-1 /absolute/path/image.jpg   # per monitor, names from `niri msg outputs`
dms ipc call wallpaper next                                   # next image; in per-monitor mode use nextFor <output>
```

Use absolute paths. With the `dynamic` theme, every wallpaper change
regenerates all colors, including niri's and the apps'. Per-monitor
wallpapers, separate light/dark wallpapers, cycling and transitions are in
session.json and on the Wallpaper page (`settings openWith wallpaper`).
`matugenTargetMonitor` picks which monitor's wallpaper drives the colors.

For a wallpaper that stays still while switching workspaces and shows in the
overview, see "Workspaces, overview and the wallpaper" in [niri.md](niri.md).

## Custom theme file

A custom theme is a JSON file anywhere on disk (keep it with your dotfiles):

```json
{
  "dark": {
    "name": "My Theme Dark",
    "primary": "#7aa2f7",
    "primaryText": "#0b0f19",
    "primaryContainer": "#2b3a5c",
    "secondary": "#bb9af7",
    "surfaceTint": "#7aa2f7",
    "surface": "#15161e",
    "surfaceText": "#c0caf5",
    "surfaceVariant": "#1f2335",
    "surfaceVariantText": "#a9b1d6",
    "surfaceContainerLowest": "#0f1017",
    "surfaceContainerLow": "#14151d",
    "surfaceContainer": "#1a1b26",
    "surfaceContainerHigh": "#222436",
    "surfaceContainerHighest": "#2a2d42",
    "background": "#0f1017",
    "backgroundText": "#c0caf5",
    "outline": "#565f89",
    "error": "#f7768e",
    "warning": "#e0af68",
    "info": "#7dcfff",
    "matugen_type": "scheme-tonal-spot"
  },
  "light": { "...": "same keys with light values" }
}
```

A file without `dark`/`light` uses the same colors in both modes. Activate it:

```bash
dms ipc call settings set customThemeFile /absolute/path/my-theme.json
dms ipc call settings set currentThemeName custom
```

While it is active, saving the JSON file updates the shell live. Check
contrast of `surfaceText` on `surface` and `primaryText` on `primary`.

## App colors through matugen

DMS needs the `matugen` binary for this (`dms doctor` reports it). Each app
has a toggle on the Theme & Colors page, stored as `matugenTemplate<App>`
keys (`matugenTemplateGtk`, `matugenTemplateQt6ct`, `matugenTemplateKitty`,
`matugenTemplateNiri`, ...). See which apps DMS detects:

```bash
dms matugen check
```

Generated files are rewritten on every theme or wallpaper color change. Never
edit them; edit the app config that includes them.

| App | Generated file | What you add once |
|-----|----------------|-------------------|
| GTK 3/4 | `~/.config/gtk-3.0/dank-colors.css`, `~/.config/gtk-4.0/dank-colors.css` | Install adw-gtk3 and enable "Apply GTK Themes" in Theme & Colors |
| Qt (qt5ct/qt6ct) | `~/.config/qt5ct/colors/matugen.conf`, `~/.config/qt6ct/colors/matugen.conf` | `QT_QPA_PLATFORMTHEME=qt6ct` (or `gtk3`, or `qtengine`), pick the color scheme in qt6ct |
| kitty | `~/.config/kitty/dank-theme.conf`, `dank-tabs.conf` | `include dank-theme.conf` and `include dank-tabs.conf` in kitty.conf |
| ghostty | `dankcolors` theme | `theme = dankcolors` in the ghostty config |
| foot | `~/.config/foot/dank-colors.ini` | `include=/home/<user>/.config/foot/dank-colors.ini` (absolute path) |
| alacritty | `~/.config/alacritty/dank-theme.toml` | add it to `import` in alacritty.toml |
| niri | `~/.config/niri/dms/colors.kdl` | `include "dms/colors.kdl"` in config.kdl |

Firefox, Zen, VS Code and Neovim need extra steps; follow the
application-themes page above. GTK4 apps usually pick up new colors on their
next launch. Qt environment changes need a new login.

To keep niri's colors your own while DMS themes everything else, either turn
off `matugenTemplateNiri` or set `focus-ring`/`border` colors in a `layout {}`
block placed after `include "dms/colors.kdl"`.

## Your own matugen templates

DMS also runs templates you define in `~/.config/matugen/config.toml`
(when `runUserMatugenTemplates` is true, the default). Paths must be absolute
and templates must sit under `[config]`:

```toml
[config]

[templates.myapp]
input_path = '/home/<user>/.config/matugen/templates/myapp.conf'
output_path = '/home/<user>/.config/myapp/colors.conf'
```

Templates can use the matugen color keywords (`{{colors.primary.default.hex}}`)
and DMS's 16-color terminal palette (`{{dank16.color4.default.hex}}`, with
`.dark` and `.light` variants). `dms dank16 <hex>` prints a palette for a given
color, useful for testing.

To stop DMS from running matugen at all, set `DMS_DISABLE_MATUGEN=1` in its
environment (see [dms.md](dms.md)).
