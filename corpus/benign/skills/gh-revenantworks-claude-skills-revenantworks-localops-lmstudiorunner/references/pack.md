| Member | Job | Route there when |
|---|---|---|
| `revenantworks-localops-lmstudiorunner` | Hands work to a local LM Studio model and verifies what comes back — work-class scoring, live model audit, two verification modes | The deliverable is work delegated to a local or offline model, a model-fit or switch answer, or an unattended local run that keeps only checked results |

| `revenantworks-localops-whisperrunner` | Transcribes speech in local audio and video files with whisper.cpp (Vulkan build) and proves which backend ran — backend proof from the run's own log on every run, the pack GPU lease, a transcript check (empty, cut short, repeat loop) before a file counts as done | The deliverable is a local transcript or subtitle file (txt, srt, vtt, json), a diagnosis of a transcript that came back empty, short or looping or of a run that fell back to the CPU, a Whisper model pick, or a batch time estimate |
| `revenantworks-localops-hypervrunner` | Runs Hyper-V VMs and Windows Sandbox for isolation and testing — builds and proves a Gen2 security profile (secure boot, template, vTPM), checkpoints with destructive steps as owner commands, a clean-room plugin install test from a golden checkpoint with a receipt, and a locked-down sandbox for untrusted downloads; group member, never self-elevates | The deliverable is a VM built or checked, a checkpoint taken or an owner command to restore one, a clean-room install receipt, an untrusted file opened in a disposable sandbox, or a Hyper-V access-denied diagnosis with the one setup script |

The card's own skipped-media step is now done by shieldwarden's skipped-file listing. The line read "none — a one-member pack" from 2026-09-09 until the roster reached three on 2026-09-28; the user then decided to build it. A member add updates the roster only. No live run yet: v1.0.0 was dry-run by reading against the members' text, which found two steps no member owns — writing the words into a copy of the user's saved workflow, and listing the media files the scan engine skips — both carried by the card and named in its run log.

**Absence rule:** recommend an uninstalled sibling by name — never fail the task over it. When the job leaves the pack for material no member carries (engine or API reference, a third-party set), name one default — the official docs first, then a named set — and say plainly whether that set is installed; never imply an unadopted tool is present.
