# 图文视频的强钩子与完播引擎

## 这条对标视频的结构性观察

样本是一条 35 张图组成的财经/心理科普图文视频，主题是“贫穷是不是因为懒”。它没有把解释一次性说完，而是让观众沿着一条不断升级的问题链前进：

1. 用几个违反直觉的日常问题开场：为什么贫困者会买电视、拒绝免费消毒剂、做最廉价的工作？
2. 先承认观众的道德直觉，再把“懒/蠢/活该”改写成自控力、压力、注意力和信息成本问题。
3. 每个心理机制都落到一个可见的生活场景：饼干与胡萝卜实验、打水、旧手机、网贷、机场调度、短视频。
4. 中段把外部观察推回观众自己：我们也会在疲惫时刷短视频、延迟学习、选择最省力的方案。
5. 在观众已经接受总解释后，再给出三个“坑”：容错率归零、信息差、贫穷标签/惩罚机制。
6. 最后回到开头的电视问题，用“唯一可触摸的快乐、体面和尊严”重新解释原行为，并给出三条防线：改造环境、给大脑留空白、警惕诱人机会。

它的关键不是信息量大，而是每一次回答都改变了前一个问题的含义，同时打开下一个问题。

## 可复用的留人机制

### 问题链，而不是单个钩子

为每个故事维护一个问题账本：

| 节点 | 必须完成的动作 |
|---|---|
| 开头 | 提出一个具体、反直觉、带道德压力的问题 |
| 早段 | 给出一个看似合理但不完整的解释 |
| 中段 | 用实验、数字、人物选择或场景证明解释仍不够 |
| 后段 | 把机制映射到观众自己的生活 |
| 结尾 | 回答原问题，并兑现一个可执行的防线 |

每个 5–15 秒单元至少要完成一项：回答旧问题、打开新问题、提高代价、改变解释、补充证据或给出视觉隐喻。不能只有换背景、换形容词或重复结论。

### 四级升级

优先使用这条升级链：

`反常行为 → 道德误判 → 底层机制 → 观众自我牵连 → 可执行防线`

如果主题是商业陷阱，可替换为：

`看似占便宜 → 谁在承担风险 → 现金流/信息差如何运作 → 我为什么也会接住它 → 如何设置退出条件`

### 回环与重释

开头的物件、动作或一句话至少回到两次：第一次代表欲望，第二次代表代价，最后一次代表新的解释或解决方案。回到开头时必须改变含义，不能只是重复台词。

### 三层张力

同时维持三条线：

- **人物线**：他现在想得到什么、害怕失去什么？
- **机制线**：钱、注意力、信息和风险究竟怎样移动？
- **观众线**：我什么时候也做过同样的选择？

只有人物线会变成普通剧情，只有机制线会变成干燥知识，只有观众线会变成空泛说教。三线交叉才会形成持续观看动力。

## 图文型视频的画面语法

- 每张图包含一个有意义的场景、一个主要判断、一个具体道具和一个未解决的问题。
- 顶部可放短命题，底部可放后果或追问；文字应服务画面，不做脱离场景的空白知识卡。
- 用颜色标记叙事阶段：疑问/风险/机制/行动可以有稳定的色彩变化，但角色、画风和世界观保持一致。
- 抽象数字必须落到电量条、硬币、账单、门槛、时钟、背包、手机发热等可见物件上。
- 复杂机制优先拆成 2–4 张递进图，而不是一张图塞满所有结论。

## 结尾兑现与互动

结尾不要只说“点赞收藏”。先完成三步：

1. 用一句话重新解释开头的反常行为；
2. 给出 2–3 条明天就能执行的检查或防线；
3. 留下一句适合转发的自我保护提醒。

点赞来自“被说中”，收藏来自“以后用得上”，转发来自“我想提醒某个人”。三者要分别设计，不能用一个泛 CTA 代替。

## 事实与伦理提醒

样本中的“自控力耗竭”、贫穷与行为的因果关系属于科普叙事，不能直接当作完整定论。使用类似机制时，应区分已验证事实、研究争议、创作类比和作者推论；不能把贫困、负债或成瘾归结成个人品格，也不能用羞辱观众制造互动。
