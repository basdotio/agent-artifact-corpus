Pick a style

The same look is available for explainer videos, mockups / prototypes and animated READMEs. Every tile below is a live sample of one style: same scene, drawn the way that style would draw it. Click a tile to pick it, then tell the assistant its name (the bar at the bottom has the line to copy).

Samples are CSS approximations for choosing by eye. In a real video the same style is drawn frame by frame on a canvas, and in a mockup it becomes the page's CSS variables and component rules. Palettes and motion carry over; fine detail can differ.

Selected: Paste that line to the assistant. Not sure? Say "surprise me" and it will recommend one for your topic.
