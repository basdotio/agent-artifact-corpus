# Runtime API — `runtime/video-gaga.js`

A single, zero-dependency script that exposes `window.CV`. A composition is one HTML file:

```html
<!doctype html><html><head><meta charset="utf-8">
<link href="https://fonts.googleapis.com/css2?family=Geist:wght@400;800&display=block" rel="stylesheet">
</head><body>
<script src="build/narration.js"></script>     <!-- optional: generated by TTS -->
<script src="video-gaga.js"></script>        <!-- the runtime -->
<script>
const { ease, fx, draw } = CV;
CV.create({
  width: 1920, height: 1080, fps: 30, background: '#0b0b0f', lang: 'en-US',
  scenes: [
    { id: 'hook', draw(ctx, s) { /* pure function of s.t */ } },
    { id: 'next', transition: { type: 'push', direction: 'left', duration: 0.6 }, draw(ctx, s) { … } },
  ],
});
</script></body></html>
```

Open the file in a browser to get a **preview player**: Space plays or pauses, ←/→ steps one frame, Shift+←/→ steps one second, click the bar to scrub, and `#12.5` in the URL jumps to 12.5 s. Narration audio plays in sync if it has been generated. The renderer loads the same file with `?render=1`.

## The determinism contract

- `draw(ctx, s)` must be a **pure function of time**: same `s.t`, same pixels.
- Don't use `Date.now()`, `performance.now()`, `Math.random()`, `setTimeout`, CSS animations or DOM elements for visuals.
- Don't mutate state across frames. Precompute data at load time (seeded with `CV.rand(seed)`). Caches that are pure are fine, for example a pre-rendered texture.
- The renderer may render frames out of order and in parallel pages. Any hidden state will flicker.

## `CV.create(config)`

| Key | Default | Meaning |
|---|---|---|
| `width`, `height` | 1920×1080 | Design size in px (the coordinates you draw in). Must be even. |
| `fps` | 30 | Frame rate (24/25/30/60). |
| `background` | `#000` | Fill painted before each scene (scene `background` overrides it). |
| `lang` | from narration, else `en` | Drives caption rules (CJK vs Latin). |
| `fonts` | `[]` | Extra font specs to preload. Fonts actually drawn are detected automatically. |
| `scenes` | — | Array of scenes (below). |
| `transition` | cut | Default transition *into* every scene after the first. |
| `voiceDelay` | `overlap/2 + 0.25` | Seconds from scene start to the first spoken word. |
| `tail` | `0.55` | Seconds held after the voice ends. |
| `subtitles` | — | `{ burn, maxChars, minChars, punctuation: 'strip'\|'keep', style: {...} }` |
| `overlay(ctx, g)` | — | Drawn on top of every frame (chrome, grain, progress bar). `g = {T, frame, W, H, u, duration, p, scenes}` |
| `music` | — | The soundtrack and the **beat grid**: `{ bpm, beatsPerBar: 4, offset: 0, snap: 'beat', voiceOnBeat: true, volume: 1, duck: -12, sfx: true, ending: 'resolve' }` plus the score for this video: `key, mode, script: 'score.mjs'`, a module next to `video.html` that writes the piece against the timeline (see [music-and-sound.md](music-and-sound.md) §2), or the older pattern spec `progression, sevenths, chordBars, layers, lead, seed, fills, parts` ([music-spec.md](music-spec.md)). There are no preset styles, and `style` is an error. `layers: []` keeps only sound effects; `file: 'bed.mp3'` (or the old `music: 'bed.mp3'` string) uses a licensed track instead. |
| `setup(api)` | — | Async hook awaited before the warm-up pass (load data, build three.js scenes, pre-render textures). Declared `fonts` are already loaded. |
| `pixelRatio` | 1 | Supersampling factor (`--scale` on the CLI overrides it). |

### Scenes

```js
{
  id: 'specs',                 // also the narration segment id
  duration: 4,                 // fixed length (s) — or omit and let the voice decide
  minDuration: 3, maxDuration: 8,
  narration: 'specs' | false,  // which narration segment (defaults to id)
  captions: true | 'file' | false, // burn + export (default) · export to .srt/.vtt only · no cue
  say: 'text',                 // inline narration text (estimated timing until TTS runs)
  voiceDelay: 0.3, tail: 1.2,  // per-scene overrides
  beats: 6, bars: 1,           // music-only length on the beat grid (needs music.bpm)
  energy: 0.6,                 // 0..1: how full the score is under this scene
  part: 'bridge',              // music.parts: this scene starts a chapter of the score (holds until the next part; the cut lands on a bar)
  snap: false | 'bar',         // per-scene override of music.snap for the cut into it
  voiceOnBeat: false,          // opt out of starting the voice on an eighth note
  sfx: [{ at: 1.2 | 'spoken words' | (s) => s.onBeat(2), type: 'tick', gain: 1, dur }],
  background: '#fff',
  captionStyle: { highlight: '#E62E2D' }, // per-scene override of subtitles.style (contrast with this scene's field)
  transition: { type: 'wipe', duration: 0.6, ease: CV.ease.swift, angle: 20, lineColor: '#f33', sfx: 'whoosh' | false },
  draw(ctx, s) { … },
}
```

Timeline resolution: `scene.duration = duration ?? beats/bars ?? max(minDuration, voiceDelay + speech + tail)`, where `speech` runs to the **end of the last spoken word** plus 0.25 s for its final syllable to decay (`CV.speech.end`). It is not the clip length, because TTS clips end with up to a second of silence. Consecutive scenes overlap by the transition's duration. With a music `bpm`:
- **cuts land on the grid**: the middle of each transition is moved to the next beat (`snap: 'beat' | 'half' | 'bar'`); the previous scene holds a little longer to get there,
- **the voice starts on an eighth note**: `voiceDelay` is nudged so the first syllable lands on the grid,
- **the video ends on a beat**, so the score's final chord and the last frame agree.

**One take** (`narration.track`, written by `gaga voicetrack`): a run of scenes whose lines were cut from one recording follows it instead. Each such scene starts its slice at the middle of its transition (`voiceDelay` = half the overlap) and lasts until the next slice's cut, so the slices play back to back; their cuts and voices are not snapped to the grid, and only the last slice of the run keeps its `tail` ([narration-and-subtitles.md](narration-and-subtitles.md) §7).

**Pacing — leave room.** A video doesn't need wall-to-wall narration. Use a long `voiceDelay` for a music-only pre-roll, a `narration: false` scene with `beats: 4–8` to let a result sink in, and a longer `tail` on the end card. The score fills those moments (its melody only plays where nobody speaks).

### The scene info object `s`

| Field | Meaning |
|---|---|
| `s.t` | local time in seconds (0 at scene start, including the incoming transition) |
| `s.dur`, `s.p` | scene duration, and `t/dur` clamped to 0..1 |
| `s.T`, `s.frame`, `s.fps` | global time, frame index, fps |
| `s.W`, `s.H`, `s.u` | design size. `u` = short side / 1080 (use it to scale for other aspect ratios) |
| `s.enter`, `s.exit` | 0→1 progress of the incoming and outgoing transitions |
| `s.at(start, dur, ease?)` | eased 0→1 progress of a local window. The workhorse. |
| `s.when('phrase', fallback)` | **local time at which the phrase is spoken** (from TTS word boundaries). Use it for sync. An exact word or run of words wins over a substring, so `s.when('S')` finds the word "S", not "Press". |
| `s.voiceStart`, `s.voiceEnd` | when the narration starts, and when its last word has ended and decayed (local; last word end + 0.25 s) |
| `s.voice` | `{text, duration, words:[{text,start,end}]}` or null |
| `s.out(d = 0.5, ease = exit, lead = 0)` | 0→1 over the scene's last `d` seconds (ending `lead` s before the end). Drive **exit choreography** with it so cuts happen on action. |
| `s.syncTimes(units)` | local start time per on-screen unit, matched to the spoken words (what `fx.wordReveal({ sync: s })` uses) |
| `s.beat`, `s.bar`, `s.beatLen` | global beat / bar position (float) and beat length — `NaN`/`0` without a music bpm |
| `s.onBeat(i, unit = 'beat')` | local time of the i-th beat (or `'half'`/`'bar'`) at or after the scene start; `i` may be fractional (`1.5` = the and of 2) — schedule music-only moves with it |
| `s.nextBeat(lt, unit)` | local time of the next grid point at or after `lt` (e.g. land a sign-off on the beat after the voice ends) |
| `s.pulse(decay = 0.16, unit)` | 1 on every beat, decaying exponentially — for *subtle* beat accents (a dot, a glow), never whole layouts |
| `s.isRender` | true inside the renderer |

The `overlay(ctx, g)` object also has `g.beat`, `g.beatLen` (seconds; NaN without music), `g.bar` and `g.pulse(decay)`.

### An object that lives across scenes

Scenes draw independently, but what the viewer has learned can stay on screen and change ([motion-design.md](motion-design.md) §3, *Objects live across scenes*). Two ways:

- **Hand it over at the cut.** One draw function and one pose shared by both scenes: the outgoing scene ends with the object at the pose, and the incoming one starts from it, so a hard cut doesn't move it.

  ```js
  const DOT = { x: 300, y: 700, r: 10 }, NODE = { x: 760, y: 540, r: 18 }; // the dot ends where the node begins
  const lerpPose = (a, b, k) => ({ x: CV.lerp(a.x, b.x, k), y: CV.lerp(a.y, b.y, k), r: CV.lerp(a.r, b.r, k) });
  const node = (ctx, { x, y, r }, label = 0) => { /* the one drawing of it */ };
  // scene 'dot':   node(ctx, lerpPose(DOT, NODE, s.at(1.2, 0.8, ease.outCubic)))
  // scene 'graph': node(ctx, NODE, s.at(0.2, 0.6)) — then the edges grow out of it
  ```

- **Draw it above the scenes.** `overlay(ctx, g)` draws over every frame, untouched by transitions. Key the object to the scenes it lives through with `g.scenes` (each has `id`, `start`, `dur`), since their times come from the voice:

  ```js
  overlay(ctx, g) {
    const at = (id) => g.scenes.find((s) => s.id === id).start;
    if (g.T < at('dot') || g.T >= at('payoff')) return;
    const k = CV.clamp((g.T - at('graph')) / 0.8);  // the dot becomes a node as 'graph' begins
    node(ctx, lerpPose(DOT, NODE, ease.inOutCubic(k)));
  }
  ```


## Transitions

| Type | Options | Natural sound | Reads as |
|---|---|---|---|
| `cut` | — | — | the default; on the beat |
| `fade`, `dip` | `color` | — | time passes / chapter break |
| `push`, `slide` | `direction`: left, right, up, down | whoosh | next step in a sequence |
| `whip` | `direction`, `blur` (0.16), `samples` | whoosh | a fast, energetic "next" (motion-blurred push) |
| `wipe` | `angle`, `softness`, `lineColor`, `lineWidth` | swish | editorial graphic change |
| `stripes` | `colors: […]`, `count`, `direction`, `stagger` | swish | brand-coloured bands sweep the frame (social, pop) |
| `blinds` | `count`, `direction`: vertical / horizontal, `stagger` | swish | structured, typographic reveal |
| `split` | `direction`: horizontal / vertical, `zoom` | whoosh | the old frame opens like doors onto a reveal |
| `clock` | `x`, `y`, `reverse` | swish | time / process ("a year later") |
| `iris` | `x`, `y` (0..1) | swish | focus: a point grows into the next scene |
| `ink` | `x`, `y`, `seed`, `softness`, `edgeColor` | swell | organic spread from a point (ideas, culture) |
| `dissolve` | `seed`, `softness` | swell | memory, soft change (noise threshold) |
| `zoom`, `zoomBlur` | `strength`, `samples` | whoosh | going *into* something |
| `cube`, `flip` | `direction`, `color` | whoosh / swish | rotate to the next face / card (3D-ish) |
| `flash` | `color`, `strength` | shimmer | warm light leak across a cross-fade |
| `pixelate` | `size` | glitch | digital resolve |
| `blur`, `glitch` | `tint`, `seed` | glitch | digital/cyber only |

Custom: `type: (ctx, A, B, p, opts) => {…}`, where A and B are canvases of the outgoing and incoming scenes and `p` is eased 0→1. With music enabled each transition plays its natural sound at its midpoint; override with `sfx: 'whoosh' | false` and `sfxGain`.

## Easing & motion

- `CV.ease.*` — `linear, inQuad, outQuad, inOutQuad, inCubic, outCubic, inOutCubic, outQuart, inOutQuart, outQuint, inOutQuint, inExpo, outExpo, inOutExpo, outCirc, inOutSine, outBack(p, s)`. Intent names: `standard, enter, exit, swift, gentle`. Custom curves: `bezier(x1,y1,x2,y2)` (same as CSS).
- `CV.spring({stiffness, damping, mass, velocity})` or `CV.spring({ratio, hz})` → `(t) => 0..1` (closed form). `ratio` is the damping ratio (1 no bounce, 0.7–0.85 premium, 0.4–0.6 playful), `hz` the natural frequency (default 2). Presets: `CV.spring.presets.smooth` (ratio 1.0) `| snappy` (0.87) `| bouncy` (0.47) `| heavy` (0.88, slow).
- `CV.progress(t, start, dur, ease)` → eased 0..1 over a window.
- `CV.tween(t, [[t0, v0], [t1, v1, ease], …])` → keyframes (numbers or arrays).
- `CV.springTrack(t, [[t0, v0], [t1, v1], …], springOpts)` → a spring-animated value re-targeted over time.
- `CV.clamp, lerp, invLerp, remap(v, a, b, c, d, ease), stagger(i, each, start)`.
- `CV.rand(seed)` → a seeded PRNG function. `CV.noise(x, seed)` → smooth value noise in −1..1.

## Motion primitives — `CV.fx`

- `fx.lineReveal(ctx, lines, x, y, t, {lineHeight, stagger, dur, ease, align, rise, exit})` — lines rise out of masks.
- `fx.charReveal(ctx, str, x, y, t, {stagger, dur, rise, blur, align, maxWidth, exit})` — per-glyph fade, rise and unblur. Returns the glyph layout.
- `fx.wordReveal(ctx, str, x, y, t, {sync: s | times | stagger, dur, rise, blur, ghost, exit, colorFor(unit, i, p), align, maxWidth})` — word by word (CJK: per character). **`sync: s` lands every word exactly when the voice says it**; shown-but-said-differently units ("30" / "三十") follow the next spoken one.
- `fx.countUp(p, from, to, {decimals, sep, prefix, suffix})` → formatted string.
- `fx.roll(ctx, str, x, y, p, {spins, dur, align, ease})` — odometer: digits roll into place in their own masks. For short codes and counters, not for numbers whose *growth* is the story (use `countUp`).
- `fx.scramble(str, p, {chars, seed, rate})` → decode effect (resolved left→right).
- `fx.typewriter(str, p, {caret, t})` → a substring (grapheme-safe).
- `fx.highlight(ctx, x, y, w, h, p, {color, radius, skew, blend})` — marker swipe behind a term.
- `fx.along(pts, p)` → `{x, y, angle}` on a polyline (motion paths, a dot riding a line).
- `fx.stagger(t, i, {each, dur, start, ease})` → eased progress of item i in a group.
- `fx.shake(t, start, amount, {decay, freq, seed})` → `{x, y, r}` decaying jitter — literal impacts only.
- `fx.mask(ctx, x, y, w, h, fn)` — clip drawing to a rectangle.
- `fx.onTwos(t, fps, n)` — quantised time for hand-made, animate-on-twos motion.

## Text — `CV.text`

- `text.wrap(ctx, str, maxWidth)` → lines. CJK-aware with kinsoku (no `，。！？）` at line start, no `（《“` at line end). Latin words and numbers stay whole.
- `text.fitSize(ctx, str, '900 {size}px "Font"', maxWidth, max, min)` → the largest size that fits (and sets `ctx.font`).
- `text.glyphs(ctx, str, x, y, {maxWidth, lineHeight, align})` → `[{ch, x, y, w, i, line}]` for per-glyph animation.
- `text.words(…)` → word or CJK-character units with positions.

## Drawing — `CV.draw`, `CV.color`

- `draw.roundRect, drawOn(ctx, pts, p)` (progressive stroke), `arrow(ctx, x1, y1, x2, y2, p, {bend, head, width})` (draws on, head arrives last), `arc(ctx, cx, cy, r, a0, a1, p)`, `sketchLine(x1,y1,x2,y2,{seed, roughness})`, `sketchCircle(cx,cy,r,{seed, roughness, steps})`, `grain(ctx, frame, amount, {blend})`, `vignette(ctx, W, H, amount, color)`, `camera(ctx, W, H, {zoom, x, y, rotate, focusX, focusY, depth}, fn)` (`depth` 1 is the subject plane; far layers below 1 move less, near layers above 1 move more), `cameraAt(t, [[t0, {zoom, x, y, …}], [t1, {…}, ease], …])` → a keyed camera for `camera()`, with zoom interpolated in log space so pushes move evenly.
- `CV.noise2(x, y, seed)` — 2D value noise in −1..1.
- `color.rgba(c, a)`, `color.mix(a, b, p)`, `color.parse(c)`.
- `CV.image(src)` preloads an image (the renderer waits for it). `CV.drawCover(ctx, img, x, y, w, h, fx, fy)` draws it cover-fit.
- WebGL: create your own `<canvas>` or `OffscreenCanvas` with a `webgl2` context, render your shader for `s.t`, then `ctx.drawImage(glCanvas, 0, 0)`. Call `gl.finish()` before drawing it. SwiftShader is available headless.
- Helper 2D canvases (blur buffers, pre-rendered textures): create them with `getContext('2d', { willReadFrequently: true })`, like the runtime's own, so Chromium keeps them on the CPU rasteriser and every frame rasterises the same way. Frosted glass has no backdrop-filter in canvas. Draw what's behind the pane into a half-size buffer, blur it once per frame with `ctx.filter = 'blur(…)'`, and paint it inside the pane's clip.

## three.js — `CV.three(THREE, {width, height, shadows, exposure, toneMapping, antialias})`

`toneMapping`: `'aces'` (default, filmic: darkens and shifts saturated colours), `'neutral'` (keeps product and brand colours true), `'agx'`, or `false`.

Import three as an ES module (pinned CDN, works from `file://` and in the renderer) and hand it to the bridge. See [three-d.md](three-d.md) for the full pattern.

```html
<script type="importmap">{"imports":{"three":"https://cdn.jsdelivr.net/npm/three@0.186.1/build/three.module.min.js"}}</script>
<script type="module">
import * as THREE from 'three';
const gl = CV.three(THREE, { width: 1920, height: 1080, shadows: true });
const scene = new THREE.Scene(), cam = new THREE.PerspectiveCamera(35, 16 / 9, 0.1, 100);
// … build meshes once …
CV.create({ /* … */ scenes: [{ id: 'hero', draw(ctx, s) {
  mesh.rotation.y = s.t * 0.6;            // set every property from s.t (pure)
  gl.render(ctx, scene, cam);             // composite onto the 2D frame (transparent background)
  /* 2D type on top */
} }] });
</script>
```

- `gl.render(ctx, scene, camera, rect?)` — renders and draws onto the frame; `rect = [x, y, w, h]` renders into a region.
- `gl.texture(key, w, h, (g, w, h) => {…})` — a `CanvasTexture` painted with the 2D API (labels, type in 3D), repainted once webfonts are ready.
- `gl.map(src, { color = true, repeat, flipY })` — an image file as a texture (sRGB for colour, `color: false` for data maps), cached; the renderer waits for it.
- `gl.pbr(dir, { repeat, normalScale, metalness, ao })` — `albedo/normal/roughness/ao(.jpg)` from one folder (as `gaga asset` and `gaga texture` write it), returned as material props to spread: `new THREE.MeshPhysicalMaterial({ ...gl.pbr('assets/oak', { repeat: 2 }) })`.
- `gl.hdri(src)` — an equirectangular `.hdr` as a PMREM environment. The first call starts the download and returns `null`; assign it where the world is posed (`world.environment = gl.hdri(src)`), by the first frame it is the cached texture.
- `gl.model(src, { shadows })` — a glTF/GLB inside a Group returned at once; filled before the first frame. Clips: `group.userData.animations`, played with `mixer.setTime(s.t)`.
- A map, HDRI or model that fails to load stops `gaga still`/`render` with its path. Load files only through these: three's own loaders `fetch()`, which can't read `file://`.
- `gl.studio({ sky, ground, panels: [{ az, el, w, h, intensity, color, tilt }], size, key })` — a studio built in code for reflections you direct: a dome and panels (softboxes, strips, black flags) placed in degrees (`az` 0 camera side, 90 right, 180 behind; `el` 0 horizon, 90 overhead; `w × h` in degrees, exact at any size: each panel is a patch of a sphere, and one that reaches the zenith becomes a round cap). Returns a PMREM texture for `scene.environment` or a material's `envMap`, cached per `key`; called with a changed spec under the same key it rebuilds (about 0.3 s per 1080p frame), so a glint strip can sweep as a function of `s.t`.
- `gl.mirror(normal, camera, point?)` → `{ az, el }`: where a studio panel must sit for a surface with that world normal to reflect it into the camera (aim a glint).
- `gl.project(x, y, z, camera)` → `[x, y]` in design px: 2D labels that ride a 3D point, match cuts between a 3D object and its flat shape.
- One renderer is shared by all scenes, so transitions between two 3D scenes work and the WebGL context limit is never hit.

## Isometric figures — `CV.iso({ paper, ink, lit, weight, mode, tones })`

Paints the geometry of the [anatomy](https://github.com/wheresryan22/anatomy) kit (imported by the composition from a pinned CDN) onto the frame with `Path2D`, in the kit's order and tones. See [iso-figures.md](iso-figures.md) for when and how.

```js
import * as k from 'https://cdn.jsdelivr.net/gh/wheresryan22/anatomy@dbf697a527bbf7d358668e1557cb1e35ff725d46/kit/iso-kit.mjs';
const iso = CV.iso({ paper: T.bg, ink: T.ink, lit: T.accent, weight: 1.4 });
iso.solid(ctx, k.slabOf(plan, 0, 12, P, 8, 1.2), { tone: 'mid' });
```

- Tones come from `paper` and `ink` (`mode` 'dark' or 'light' is read from the paper): `hi`, `mid`, `lo`, `faint` for lines, `paper`, `face`, `top`, `shades[0..3]`, `litTop`, `litShade` and `halo` for fills, and `lit` (the film's accent: the one part to watch). `tones: { … }` overrides any of them.
- `weight` is the line width in design px of the frame (default 1.5). Lines keep it at any camera zoom, like the kit's non-scaling strokes.
- `iso.solid(ctx, paths, { tone: 'hi', crease: 'faint', halo, lit, flat, alpha, inner })` — a kit solid (`slabOf`, `cylinder`, `extrude`, `lathe`…): halo, paper fill, four side shades, top, crease, bevel, `inner(ctx)`, outline.
- `iso.line(ctx, d, { tone: 'lo', dotted, dashed, width, alpha })` — any kit line path. A tone name or a colour.
- `iso.dots(ctx, points, { size: 0.5, tone: 'mid' })` — screws and rivets: screen points `[x, y, alpha?]` from `k.iso`/`k.pointsAt`, `size` in figure units.
- `iso.wire(ctx, from, to, { via, tone, ends: 'both', size })` — a connector with terminal dots.
- `iso.halo(ctx, d, { blur: 9, dy: 3 })` — the soft shadow under a base (`k.haloOf`), blur and offset in figure units, so it grows with the object under a push.
- `iso.faded(ctx, [[d, alpha], …], style)` — `ribsOf`/`dotsOf` results with `fade`. `iso.tube(ctx, piece, { tone })` — a piece from `tubePieces`.
- `iso.tones`, `iso.unit(ctx)` (user units per design px under the current transform), `iso.path(d)` (the cached `Path2D`).

## Captions — `CV.subtitles`

- `subtitles.build(text, words, {maxChars, minChars, lang, punctuation, offset})` → cues `[{start, end, text, words}]`.
- `subtitles.draw(ctx, cues, t, style)`. Style keys: `font, color, highlight` (karaoke colour), `box` (background colour or null), `stroke, strokeWidth, y` (baseline as a fraction of H), `maxWidth, padX, padY, radius, lineHeight, fadeIn`.
- `subtitles.estimate(text, lang)` → an estimated `{duration, words}` before TTS exists.
- `CV.speech.end(segment)` → when speech ends: the last word's end + 0.25 s of decay, capped at the clip length. `CV.speech.find(words, phrase)` → a phrase's start time, or `null` (what `s.when` uses).
- `minChars` counts spoken characters, so punctuation doesn't make a clause long enough to break on.

The renderer burns captions with `--subs burn` (the same cues become `.srt` and `.vtt`).

## Renderer hooks (for tools)

`window.__CV` exposes `renderFrame(frame, subframe)` (async: draws, and redraws once any webfont download it triggered has finished; renderers should use it), `drawFrame(frame, subframe)`, `drawAt(t)`, `ready()`, `info()` (the resolved timeline, voice clips, cues, missing fonts) and `capture(type, quality)`, and `textBoxes(frame)` (renders the frame and returns each string drawn on it: its box in design pixels and its solid colour, which `gaga still` uses for the edge, caption-band, phone-size and contrast checks).
