# 大学工科与计算机专业核心课程实验报告写作指南 (Course Guidelines)

## 1. 《网络协议分析》/《计算机网络》
- **核心工具**：Cisco Packet Tracer, Wireshark, GNS3, eNSP
- **图表规范**：
  - 必须有拓扑搭建截图（带设备端口标签，如 Fa0/0）
  - 必须有 Wireshark 抓包的分组树与十六进制/字段展开图
  - 必须有网络节点 IP 地址分配规划表（5列格式）
  - 必须有 Cisco 路由器/交换机核心 CLI 配置脚本代码框

## 2. 《操作系统》
- **核心工具**：Ubuntu Linux, GCC, GDB, VS Code, VMware Workstation
- **图表规范**：
  - 必须有终端编译和执行命令截图（`gcc -o test test.c && ./test`）
  - 进程控制（fork, wait, exit）必须画出进程树父子关系图
  - 信号量与临界区必须包含测试时序输出与互斥/同步日志
  - 虚拟内存命中率/置换算法需包含模拟运行对比表

## 3. 《数据结构与算法》
- **核心工具**：C/C++ 编译器, Clion, Dev-C++, Python
- **图表规范**：
  - 核心算法核心实现必须使用等宽紧凑代码框
  - 树（二叉树/哈夫曼树）和图的遍历必须给出逻辑节点图或矩阵表
  - 思考题必须附带大 O 渐进时空复杂度严格分析（如 $O(n)$、$O(n \log n)$）

## 4. 《数据库系统原理》
- **核心工具**：MySQL, Navicat, SQL Server, PowerDesigner
- **图表规范**：
  - 必须包含数据库概念结构设计（E-R 图）
  - 关系模式必须写明主键与外键约束
  - 复杂查询必须给出带有 SQL 关键字高亮的建表与查询代码
  - 必须附带 EXPLAIN 执行计划分析截图与查询性能比对
