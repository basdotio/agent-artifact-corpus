## 📝 正文文案

宝子们！！谁懂啊！！😭  
作为工科/计算机生，每次期末或者平时写实验报告（计网、操作系统、数据结构、数据库、数电模电），真的要被 Word 折磨疯了：
- 分栏排版表格只占上半截，下半截大片尴尬留白！
- 稍微多加一行代码，整页表格全乱套！
- 截图糊成一坨，被老师退回要求重写！
- 课后思考题完全不知道怎么编，抓耳挠腮憋不出字！

实在受不了了，我和同学一起肝了一个专门给大学生用的开源神器：
👉 **Universal-College-Lab-Report（大学通用实验报告生成器 Skill）**

✨ **它到底有多神？**
1️⃣ **独创实体大框全高容器**：OpenXML 底层算法强制外框贴齐页脚，彻底消除半截悬空留白，视觉极度治愈！
2️⃣ **100% 锐利高保真终端截图**：纯代码直接画 Cisco Packet Tracer、Windows CMD、Linux 终端截图，字迹锐利如刀，绝无马赛克！
3️⃣ **B4 6页双面印刷折页独立页码**：完美契合高校工科官方装订标准，正反面对得严丝合缝！
4️⃣ **深度课后思考题全解**：多层次技术论证与分析，条理清晰、层次分明。
5️⃣ **完全保护隐私**：没有写死任何个人信息，首次使用自动向你提问，信息只保存在本地电脑！

💻 **怎么用？**
直接在 GitHub 搜索：`Universal-College-Lab-Report`  
支持接入 Claude、Cursor、Antigravity，也可以本地一行 Python 命令直接跑出 Word 和 PDF！
