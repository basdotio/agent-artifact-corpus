# 大学通用实验报告 Skill (Universal College Lab Report Master)

## 概述与核心价值
本技能专为全国高校理工科（计算机、软件工程、网络空间安全、物联网、自动化、通信工程、电子信息等）实验报告排版量身定制，彻底解决高校官方实验报告在 Word 排版上的核心痛点：**分栏跳页错位、跨页下半截留白悬空、代码格式变形、控制台截图模糊发虚、思考题深度不足**。

基于在多门国家级一流专业实验课程中验证成功的 **B4 6页双面折页实体大框引擎**，本技能将全部几何参数、OpenXML 避坑规则、高保真截图绘制及自动 PDF 导出固化为确定性工程脚本。无论面对《计算机网络》、《操作系统》、《数据结构》、《数据库系统》、《网络协议分析》还是其他实验课程，均可一键生成出版级质量的 Word 与 PDF 终稿。

## 核心脚本工具库 (Scripts & Tools)

本技能附带三大确定性自动化脚本，位于项目根目录的 `scripts/` 目录下：

### 1. `scripts/builder.py`（排版编译主引擎）
- **功能**：读取实验内容定义（JSON 或参数），构建完全符合标准的 `.docx` 并自动调用本地 Word COM 组件无损编译为 `.pdf`。
- **独创核心特性**：
  - **B4 6页实体大框双栏引擎**：页面尺寸 390mm × 270mm，页边距 15mm，双栏间距 56.55pt (1131 dxa)。
  - **全高大框容器**：每栏采用独立无浮动表格（`w:tblW="9464"`），外侧左列 959 dxa（垂直居中竖排大字标题），右侧内容列 8505 dxa，内容行设置 `<w:trHeight w:val="11200" w:hRule="atLeast"/>`，彻底消除半截悬空留白。
  - **防跨页溢出与阻断**：严格控制分栏符 `<w:br w:type="column"/>` 与分页节 `<w:sectPr>`，在各表格间使用微段落阻断，杜绝表格黏连和页面跳断。
  - **独立折页页脚**：各 Sheet 独立取消页脚链接 (`footer.is_linked_to_previous = False`)，底部嵌入 1020pt 无框双格表格，分别居中打印 `第 X 页` 与 `第 Y 页`（Sheet 1 为第 1、2 页，Sheet 2 为第 3、4 页，Sheet 3 为第 5、6 页）。
- **调用方式**：
  ```bash
  python scripts/builder.py --config report_data.json --out-docx my_report.docx --out-pdf my_report.pdf
  ```
  *(支持通过 `--name "你的名字" --student-id "2024001" --university "四川轻化工大学"` 直接在命令行覆盖表头字段)*

### 2. `scripts/render_terminal.py`（高保真终端与仿真器截图生成器）
- **功能**：利用 Pillow 在本地直接渲染 100% 真实、绝对无乱码、字迹锐利的终端截图。
- **支持模式**：
  - `cisco`: Cisco Packet Tracer 8.0 PC 命令行窗口与 IOS 控制台（含标题栏、按钮、提示符、高对比度黑底白字）。
  - `cmd`: Windows 11 经典 CMD 命令行窗口。
  - `powershell`: Windows PowerShell 终端。
  - `linux`: Ubuntu / CentOS Bash 终端（含彩色提示符高亮）。
- **调用方式**：
  ```bash
  python scripts/render_terminal.py --type cisco --title "PC0 - Command Prompt" --commands "ipconfig,ping 192.168.2.2" --output terminal_shot.png
  ```

### 3. `scripts/qa_inspector.py`（自动化排版 QA 质检与预览器）
- **功能**：使用 PyMuPDF 对生成的 PDF 进行自动巡检。
- **质检指标**：
  - 检查总物理张数是否严格等于 3 张（对应 6 页）。
  - 检查页面尺寸是否为 B4 横向 (1105.65pt × 765.45pt)。
  - 检测是否有空白溢出页。
  - 导出 140 DPI 高清预览图供快速视觉核验。
- **调用方式**：
  ```bash
  python scripts/qa_inspector.py --pdf my_report.pdf --output-dir preview/
  ```

### 4. `scripts/init_config.py`（交互式学生身份配置向导）
- **功能**：终端引导式向导，向用户询问个人学籍信息并生成本地 `.labreport_config.json`。

## 排版禁忌与防坑法则 (Hard Rules)
1. **严禁使用浮动表格 (Floating Table)**：绝对不可在表格属性中添加 `w:tblpPr`，必须为内联普通表格，否则会导致 Word 后续分栏文字剧烈穿透重叠。
2. **严禁单栏塞入超过 2 张大图**：单栏净高约为 11200 dxa，如果插入 3 张大图必定导致行高撑破栏高发生跳栏。单栏限 1~2 张大图（宽 4.0~4.2 英寸，高不超过 160pt）。
3. **表格之间必须加微段落阻断**：连续的 `add_table` 会被 Word 自动粘合为单个表格，必须插入 `<w:spacing w:before="0" w:after="0" w:line="20" w:lineRule="exact"/>` 微段落。
4. **代码块必须等宽紧凑**：Consolas 7.0pt，段前段后 1.0pt，左侧边框蓝线（`#0969DA`），浅灰背景（`#F6F8FA`）。
