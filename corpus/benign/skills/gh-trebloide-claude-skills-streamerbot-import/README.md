# streamerbot-import

A Claude Code skill that generates Streamer.bot import strings. It builds the JSON for actions, C# sub-actions and commands, then encodes it into the `U0JBRR…` text you paste or drag into Streamer.bot's **Import** dialog. It can also decode an existing import string.

See [SKILL.md](SKILL.md) for the format and the list of known sub-action types.

Part of [Tr3bl4/claude-skills](https://github.com/Tr3bl4/claude-skills).
