# 论文格式规范（《历史研究》/《史星》自检表）

本 skill 实现的格式标准。权威来源：用户提供的《史星》审稿自检表 = 《历史研究》关于引文注释的规定（官方原文适用于《中国社会科学》《中国社会科学内刊》《历史研究》；PDF: https://cddx.gov.cn/uploads/file/202208/111534019740.pdf）。**以用户当次提供的自检表/格式参考 docx 为第一准绳**；下表是该体系的已落实参数，期刊不同时以参考文件为准。

## 一、版面与字体（自检表参数）

| 项目 | 参数 |
|---|---|
| 页面 | A4，上下 2.54cm、左右 3.17cm（72/90 pt） |
| 标题 | 黑体三号（16pt）居中 |
| 摘要、关键词 | 楷体小四（12pt） |
| 正文 | 中文宋体小四；西文/数字 Times New Roman 小四 |
| 一级标题 | 黑体三号、居左、首行缩进 2 字符、1.5 倍行距、段前段后 0.5 行 |
| 二/三/四级标题 | 黑体小三 / 黑体四号 / 宋体加粗小四（同级缩进规则同上） |
| 行距 | 1.5 倍；段前段后均 0.5 行（6pt）；首行缩进 2 字符 |
| 注释 | 宋体小五（9pt） |
| 页码 | 页脚居中（自检表未要求，投稿惯例补上，可删） |

## 二、注释体例（官方规定原文要点）

1. **位置**：注释放置于当页下（脚注）。序号用①②③……**每页单独排序**（注意：不是全文连续编号）。正文中的注释序号统一置于包含引文的句子（有时候也可能是词或词组）或段落标点符号之后。
2. **著作**：责任者与责任方式/文献题名/出版地点/出版者/出版时间/页码。责任方式为"著"时可省略；引用翻译著作时，译者作为第二责任者置于文献题名之后。
3. **析出文献**：责任者/析出文献题名/文集责任者与责任方式/文集题名/出版地点/出版者/出版时间/页码（文集责任者相同可省）。
4. **期刊析出**：责任者/析出文献题名（英文引号）/期刊名（斜体）/卷册及出版时间/页码。官方示例：`Heath B. Chamberlain, "On the Search for Civil Society in China," Modern China, vol. 19, no. 2 (April 1993), pp. 199-215.`——**出版时间放在卷册后的括号里，示例含月份**。
5. **报纸**：责任者/篇名/报纸名称/出版年月日/版次。
6. **古籍**：刻本=责任者与责任方式/文献题名/卷次、篇名、部类（选项）/版本、页码；点校本/整理本/影印本在出版时间后注明；页码注明 a、b 面。地方志：明清以后不标注作者，书名前冠年号；民国方志冠"民国"。
7. **未刊文献**（学位论文等）：责任者/文献标题/论文性质/地点或学校/文献形成时间/页码。
8. **档案文献**：文献标题/文献形成时间/卷宗号或其他编号/藏所。
9. **转引文献**：须标明。责任者/原文献题名/原文献版本信息/原页码/转引文献责任者/转引文献题名/版本信息/页码；间接引文以"参见/详见"引领并注出起止页码。
10. **外文专著**：责任者/文献题名（斜体）/出版地点：出版者，出版时间，页码（出版地点后用英文冒号，其余英文逗点）。
11. **再次引证**：同一文献只需标注责任者、题名、页码，出版信息可省略（示例：`赵景深：《文坛忆旧》，第24页。`）。
12. **电子文献**：责任者/电子文献题名/更新或修改日期/获取和访问路径/引用日期。

## 三、规范未覆盖处的既有做法（体例外延，已与用户确认保留）

- **英国法条**（规定无法规类目）：法条名后括注年份+摄政年章号，版本页码走"据"句式。例：《为贫民设工与去游惰法》（1576年，18 Eliz. I, c. 3），据 The Statutes of the Realm, vol. IV, p. 611。首次出现给全（年份+章号），之后简化（仅章号+具体页）。
- **说明性注释**（词语解释、法条内容解说）不挂页码；需要时补"据 SoR vol. IV, pp. XXX-XXX"。
- **档案无形成时间**时按"标题/编号/藏所"注，缺项不编造。

## 四、内容层面的固定动作（每次都要做并回报）

1. 清除 Obsidian wikilink（`[[X]]`→X，`[[X|Y]]`→Y）。
2. 删除定义了但从未被引用的孤儿脚注。
3. 重复引证按第 11 条简化；同一文献两次以上时首次给全。
4. 外文文献题名/期刊名斜体（在 spec 的 italics 字段登记子串）。
5. 补全卷期页码的通道依次尝试：① 库内文献笔记 frontmatter（title/authors/year/发表于）② Zotero 本地 REST API `http://127.0.0.1:23119/api/users/<userID>/items/<key>`（Zotero 开着才可用）③ statutes 类去用户原始笔记按锚点块定位页码。补不到的列清单交用户补，**禁止编造页码**。
6. 错别字/笔误修复后必须在回复中逐条列明。
7. 摘要为空时代拟一版（严格据论文自身论点）并 flag 用户审；无作者信息不编造。
