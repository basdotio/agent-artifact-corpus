# 模板库（Templates）

模板是**脚手架，不是填空题**。按需取用，删掉不相关的行。

---

## T1 · 文本生图

````markdown
**正向 Prompt**

中文：<主体 + 关键特征>，<3—5 个视觉锚点>，<动作/姿态>，<场景环境>，<构图与镜头>，<光线>，<色彩关系>，<材质质感>，<空间层次>，<由具体元素构成的情绪>，<风格>，<后期与画质>

English: <subject and key traits>, <3–5 visual anchors>, <action/pose>, <setting>, <composition and camera>, <lighting>, <color relationship>, <materials>, <spatial layering>, <mood via concrete elements>, <style>, <post-processing and detail density>

**Negative Prompt**

<8—15 条，按当前风险定制>

**推荐参数**

比例 <1:1 / 16:9 / 9:16 / 4:3 / 3:2 / 21:9> ｜ 分辨率 <1K / 2K / 4K>
````

**极简版变体**（用户要简单时）：
```
<主体>，<核心风格>，<场景/构图>，<光影或氛围>，<质量收尾>
```

---

## T2 · 图生图 / 编辑

````markdown
使用上传图片作为基底。

只修改：<单一、明确的改动>。

保持完全一致：主体身份与五官、构图与裁切、姿态、光线方向与软硬、色彩关系、背景与空间结构、画面中的文字、整体风格与媒介。

不要添加任何新物体。不要改变画面中已有文字。

**推荐参数**：比例与原图一致 ｜ 强度 <如需>
````

**要点**：改一处，锁一片。改动越多，一致性越差。

## V4 · 路径控制视频（FSDV：FPV / 航拍 / 穿行）

**编号停靠模式（近景互动首选）**

````markdown
首帧图 prompt：
<场景描述>，地面或目标旁放置小号编号标记 1—N，按可达深度从近到远排列，
不画红色路线线、不画连接线、不画箭头。

视频 prompt：
使用上传图片作为首帧与编号停靠顺序参考，生成一段 <比例>、<时长> 秒、一镜到底的
<场景类型> <POV 身份> 视频。首帧中的编号只作为镜头停靠顺序参考，**不要出现在最终画面里**。

观众/摄像机是 <POV 身份>，从 <起点> 出发，严格按编号顺序移动：
<起点> → 1 <目标1> → 2 <目标2> → ... → <终点>。
本视频恰好包含 <N> 个主要目标：<列出>。不要增加或减少主目标。
角色脸、服装、位置、身份与参考图保持一致。

镜头运动必须符合 <POV 身份> 的物理限制：<低机位滑行 / 步行 / 飞行 / 车载>；
移动连续，有真实加速减速，不瞬移、不跳切、不穿越障碍物、不切换 POV。

时间轴：...
环境动态：...
回避：编号残留、路线/箭头/标注、换脸、同脸、身份漂移、主目标数量变化、
      穿模、跳切、瞬移、POV 错误、过度抖动、场景漂移、低质、畸形、水印

**推荐参数**：比例 16:9 ｜ 时长 15s
````

**红线路径模式（大尺度航拍 / 地图穿行）**

````markdown
路线图 prompt：
16:9 高分辨率航拍地形图/世界地图，一条清晰连续的红线从 <起点> 到 <终点>，
可带细箭头；路线沿可见通道（道路/山谷/河流/峡谷/屋顶/空域）延伸，
分为 4—6 个视觉可区分路段。

视频 prompt：
上传图片是**路线规划图，不是最终画面**。红线、箭头、标注**只是镜头路径控制，
必须在最终画面中完全消失**。

镜头严格沿图上路线几何从起点移动到终点。使用隐形 <无人机/鸟/灵体> 第一人称视角。
按地理分段推进：<路段1> → <路段2> → ... → <终点>。
持续前推，自然倾斜，近距离掠过，高度变化，前景视差，渐进加速，地平线稳定。

回避：地图视角、可见红线、箭头、标注、瞬移、倒放、跳切、可见飞行器、
      引导角色、平坦地形、地标变形、结构闪烁

**推荐参数**：比例 16:9 ｜ 时长 15s
````

## C1 · 角色工作表（Character Sheet）

````markdown
**角色工作表 Prompt**

输出：<写实身份表 / 电影写实 / 二次元 / 3D / 厚涂> 角色工作表（三视图 / 模型表）。

角色身份：<年龄段、性别呈现、族裔或肤色、体型、身高感>
面部锚点：<脸型、五官特征、瞳色、显著特征>
发型：<发型、发色、长度、质感>
服装与轮廓：<上衣、下装、鞋、外套、配饰，锁死轮廓>
道具：<随身物品>

分格：全身正面 ｜ 全身 3/4 视角 ｜ 侧脸 ｜ 背面
<可选：表情行、手部姿态、道具特写、面料细节标注>

跨分格一致性约束：同一角色，脸部结构、发型、体型、服装、配色在所有分格中完全一致；
<写实模式追加：保留面部不对称、真实皮肤纹理与年龄线索、自然姿态，soft neutral documentary lighting>

背景与呈现：<纯色背景 / 中性灰背景>，均匀布光，无环境干扰。

回避：<过度美颜、面部平均化、合成 3D 感、分格间服装或发型变化、多余文字与标识>

**推荐参数**：比例 16:9 或 3:2 ｜ 分辨率 2K
````

**下游用法**：工作表 → 场景静帧（引用工作表）→ 图生视频（引用静帧）。每步都显式声明「角色参照上传的角色工作表」。

## 通用尾巴

任何模板产出后都追加一句**可调项提示**，让用户知道下一步拧哪个旋钮：

```
可调项：光线软硬、色温倾向、镜头景别、节拍密度、时长。
```
