# 交付质检清单（Checklists）

**每次交付前必走。不通过就改，不要带着已知缺陷交付。**

---

## 一、通用（所有产出）

- [ ] **意图保真**：结果符合用户原始意图，没有把主题换掉
- [ ] **默认不出分析**：只给成品，没把推理过程倒给用户
- [ ] **成品可复制**：放在代码块里，单段自然语言，不是散落的碎片
- [ ] **双语**：中文用于理解、英文用于执行（用户没要求单语时）
- [ ] **语言一致**：用户用中文就中文，术语保留英文原名
- [ ] **只问了一个**真正必要的问题（或压根没问，直接给了默认合理的答案）

## 二、六层约束（全部通过才算合格）

- [ ] **L1 事实**：每个具体数字/专有名词都有依据，无编造
- [ ] **L2 媒介**：媒介明确，且排除了最易混淆的错误媒介
- [ ] **L3 结构**：3—5 个核心锚点在前 1/3，维度按序，不平均堆砌
- [ ] **L4 一致性**：需要稳定的元素已显式声明为不变量
- [ ] **L5 排除**：排除项具象、有针对性、分层组织
- [ ] **L6 参数**：模型名/时长/比例/分辨率已外置到「推荐参数」行

## 三、生图专项

- [ ] 主体类型的**专项**写到了（是人物就有面部/手部，是产品就有结构与卖点）
- [ ] **没写**与主体无关的专项（没有人就不写表情）
- [ ] 空间关系写清：主体在左/右/中，什么最靠近镜头，前景/背景各有什么
- [ ] 抽象词（高级感/电影感）都用具体元素解释了
- [ ] 负面词 8—15 条，且与正面描述**无冲突**
- [ ] 文字/Logo/水印已按需排除或声明为「预留文字区域」

## 四、视频专项

- [ ] 描述的是**运动与变化**，不是静态画面
- [ ] 动作节拍数与时长**匹配**，超容量时已建议缩短时长或拆镜头
- [ ] 明确了一镜到底还是多镜头，并排除了跳切/瞬移
- [ ] 图生视频时**没有**重复描述首帧内容
- [ ] POV 身份明确，且带**物理限制**（猫不上桌、无人机不走路、扫地机不爬楼梯）
- [ ] 运镜用了标准电影动词
- [ ] 音频部分：台词用引号、音效显式点名、或明确声明无声
- [ ] 多资产场景：每个参考资产**逐个声明了角色**
- [ ] 路径控制：编号停靠优先；用红线模式时已声明「标注必须消失」
- [ ] 时长/比例**没有**出现在提示词正文里（除非官方 schema 要求）

## 五、一致性专项

- [ ] 需要跨图/跨镜稳定的元素，已写进不变量声明
- [ ] 角色多镜头场景，已产出或引用了角色工作表
- [ ] 多主体场景，已写「恰好 N 个主要目标 + 不得增减」
- [ ] 没有用负面词去承担一致性的职责

## 六、模型适配专项

- [ ] 提示词形态匹配目标模型（自然语言 ↔ 标签）
- [ ] 负面词放在了该模型正确的位置（独立字段 vs 写进正文）
- [ ] 参数写法匹配目标模型语法
- [ ] 目标模型要求官方 schema 时（MiniMax / LTX / Seedance 多镜头），字段名与行序**未被擅自简化**

## 七、常见扣分项（高频翻车点）

| 扣分项 | 检查 |
|---|---|
| 写了「8K 超高清」还声称是原图参数 | ❌ 只能作为期望生成质量 |
| 提示词里混了 `--ar 16:9` 给非 MJ 模型 | ❌ 参数外置 |
| 负面词抄了一整套餐 | ❌ 按当前风险定制 |
| 一个镜头塞了 6 个动作 | ❌ 减节拍或加时长 |
| 图生视频把首帧描述了一遍 | ❌ 只写变化 |
| 说「电影感」就完了 | ❌ 用光比/色温/镜头关系解释 |
| 角色跨镜头没锁 | ❌ 补不变量 + 参考图 |
| 尺寸/时长写进正文 | ❌ 提到「推荐参数」行 |

## 八、交付格式

- [ ] 成品在代码块中，可直接复制
- [ ] 参数在独立「推荐参数」行
- [ ] 结尾有一句**可调项**提示（不要长篇解释）
- [ ] 没有多余的客套与总结
