# 一致性约束（Consistency）

跨图、跨镜、跨批次保持一致，靠的不是模型记性，是**你显式声明的不变量**。

---

## 一、三层锚点

| 层 | 要锁的东西 | 手段 |
|---|---|---|
| **角色** | 脸型、五官、发型发色、体型、肤色、服装、配饰、道具 | 角色参考图（character sheet）+ 显式不变量声明 |
| **场景** | 空间结构、家具位置、光线方向、色调、天气、时间 | 场景参考图 + 空间锚点描述 |
| **风格** | 媒介、渲染方式、色调、颗粒、笔触、后期 | 风格锚点词 + 参考图 |

**规则：能锁的尽量锁，只把真正要变的写成变量。** 变量越少，一致性越高。

---

## 二、Character Sheet 工作流（角色工作表）

**用途**：需要同一角色出现在多张图/多个镜头时，先产出一张可复用的参考表。

**推荐下游顺序：**

```
1. 生成角色工作表（character sheet）
        ↓
2. 用工作表作参考，生成首个场景静帧
        ↓
3. 从场景静帧生成图生视频镜头
```

### 先确认（只问缺失项）

1. 视觉风格：写实身份表 / 电影写实 / 二次元 / 3D / 厚涂 / 美漫
2. 角色基础：年龄段、性别呈现、族裔或肤色、体型、身高感
3. 发型与面部锚点：发型、发色、面部结构、瞳色、显著特征
4. 服装锚点：上衣、鞋、外套、配饰、道具
5. 表的内容范围：仅三视图 / 三视图 + 表情 / 完整制作表
6. 用途：通用参考 / 场景静帧生成 / 直接用于图生视频

**用户已有图时，把那张图当身份锚点，围绕它描述，不要重新发明角色。**

### 写作顺序

```
1. 声明输出是角色工作表 / 三视图 / 模型表
2. 用具体视觉语言定义角色身份
3. 锁定服装与轮廓（silhouette）
4. 指定需要的视图与分格
5. 指定跨分格保持同一性的渲染约束
6. 指定背景与呈现方式
```

**一表一角色。** 多角色各写各的 sheet。

### 默认分格

- 全身正面
- 全身 3/4 视角
- 侧脸
- 背面

可选：表情行、手部姿态、道具特写、面料/配饰细节标注。

### 写实身份表模式

用于真人、纪实风、演员连续性、或基于上传肖像建表。

优先级：
- **保留面部不对称**，不要把脸平均成通用美颜模
- 保留年龄线索、皮肤纹理、小瑕疵
- 姿态自然，不要死板对称
- 目标是「同一个人被反复拍摄」，不是「一个被重新设计的数字资产」

可用措辞：
```
real-world photographic identity sheet
the same person photographed across multiple angles
natural human asymmetry preserved
real skin texture and age cues
soft neutral documentary lighting
```
此模式**少用负面约束**，只在压制典型失败模式（合成 3D 感、过度风格化）时才用。

## 三、不变量声明模板（通用）

跨图/跨镜时，在提示词里显式写：

```
以下保持不变：主体脸部与五官、发型发色、体型、服装与配饰、构图/裁切、
光线方向与软硬、色调与饱和度、背景结构与元素、整体风格与媒介。

只改变：<明确列出的变量>。

不要添加或移除：<主目标/关键元素>。
```

---

## 四、多主体场景的计数约束

有 N 个主要人物/目标时：

- 资产、路线、时间轴、提示词**全部围绕这个准确数字**构建，不要默认回到 3 或 5。
- 必写两句：`恰好 [N] 个主要人物/目标` + `不要增加或减少主目标`。
- 超过 6 个目标时：用分组、手势、眼神、快速节拍代替逐人台词。
- 背景群众只在被要求时存在，且必须保持次要。

---

## 五、漂移诊断

| 漂移症状 | 原因 | 修法 |
|---|---|---|
| 第二张图脸不一样 | 只有文字描述，无参考图 | 补 character sheet + 引用 |
| 服装细节每张都变 | 服装描述太笼统 | 锁定轮廓与关键单品（领型、长度、材质、颜色） |
| 光线方向反了 | 光线未列入不变量 | 写死主光方向 + 光比 |
| 风格逐张偏移 | 风格锚点词不稳定 | 固定风格锚点词，加参考图 |
| 角色像「美颜模板」 | 缺不对称与瑕疵描述 | 补面部不对称、年龄线索、皮肤纹理 |
| 主目标数量变了 | 无计数约束 | 补「恰好 N 个 + 不得增减」 |
| 场景结构飘移 | 无空间锚点 | 写死前中后景的关键结构与相对位置 |
