# 六层约束模型（Core）

提示词失控，几乎总能归因到某一层约束缺失。写稿前在心里过一遍这六层，出稿后用它自检。

```
L1 事实  →  L2 媒介  →  L3 结构  →  L4 一致性  →  L5 排除  →  L6 参数
 不编造      定边界      排顺序      锁变量        划红线      剥离元数据
```

---

## L1 事实层 —— 不编造

**约束：只描述能看到、能推断、能负责的内容。**

- 焦距、光圈、快门、机身型号、镜头型号：**仅当**用户提供元数据或画面证据足够明确时才写。否则转写为视觉效果：
  | 不要写 | 改成 |
  |---|---|
  | `85mm f/1.4` | `中长焦人像压缩感，浅景深，背景柔和虚化` |
  | `Shot on Sony A7R V` | `高解析度相机质感，自然透视，皮肤纹理保留` |
  | `8K`（当作原图属性） | 作为**期望生成质量**写，不声称是原图分辨率 |
- 品牌 / IP / 角色名 / 地点：可以在内部分析时理解，但**默认输出不依赖具体名称**。转写为外形、配色、服装、轮廓、材质、设计语言。
- 看不到的物体、身份、文字内容：不补全。看不清就说「模糊标识」「简化图案」。
- 反推图片时，正确表述是「对画面的**实用重构**」，不是「还原原始隐藏参数」。

**自检**：提示词里每一个具体数字和专有名词，我能指出它的依据吗？指不出来的删掉。

---

## L2 媒介层 —— 定义边界

**约束：明确目标媒介，并显式排除最容易混淆的错误媒介。**

先判定媒介，再动笔：

| 媒介 | 典型特征 | 必须排除的混淆项 |
|---|---|---|
| 摄影 | 真实光学、皮肤纹理、自然缺陷 | 3D 渲染感、插画感、过度磨皮 |
| 写实 3D | CG 体积感、次表面散射、微瑕疵 | 真人摄影、二次元、厚涂 |
| 半写实 3D | 风格化比例 + 写实材质 | 纯二维插画 |
| 二次元插画 | 线条、赛璐璐/厚涂、平涂色块 | 写实摄影、复杂 3D 体积 |
| 厚涂插画 | 笔触可见、块面塑造 | 摄影、矢量扁平 |
| 扁平矢量 | 纯色块、无体积、几何 | 写实摄影、真实材质 |
| 产品渲染 | 影棚光、干净反射、无环境噪音 | 生活随拍、杂乱背景、低质反射 |
| UI / 平面设计 | 网格、层级、可读排版 | 摄影景深、无意义装饰 |
| 混合媒介 | 明确指出主导媒介 | 让模型自由发挥 |

**约束规则：**
- 混合媒介只有一种占主导，按主导者写 L2。
- 媒介判定不明时，选一个**最接近用户意图**的，并在交付时说明「按 X 处理」。

**自检**：把提示词给一个不知道上下文的人看，他能说出这是摄影还是插画吗？

---

## L3 结构层 —— 排顺序

**约束：锚点前置，维度有序，不平均堆砌。**

正向提示词的结构顺序（生图）：

```
[主体 + 关键特征] → [3—5 个视觉锚点] → [动作/姿态] → [场景/环境]
→ [构图 + 镜头/视角] → [光线] → [色彩] → [材质] → [空间层次]
→ [情绪（由具体元素构成）] → [风格] → [后期/画质]
```

**锚点优先级**（挑 3—5 个，放前 1/3）：

1. 独特构图 / 画面结构
2. 主体轮廓、姿态、比例
3. 特殊镜头关系（视角、透视、遮挡）
4. 标志性光线
5. 关键材质
6. 背景几何
7. 色彩关系
8. 空间层次
9. 由具体元素构成的情绪

**反模式**：把所有维度塞满、每条都写一点 → 模型注意力被稀释，命中率反而下降。**宁可五个维度写透，不要十二个维度写平。**

**自检**：前 1/3 是否包含最影响相似度的要素？删掉后半段，画面还成立吗？

---

## L4 一致性层 —— 锁变量

**约束：跨图、跨镜、跨批次要保持稳定的元素，必须显式声明为不变量。**

需要锁的东西：脸、发型、体型、服装、道具、场景结构、光线方向、色调、风格。

**手段：**
1. **声明式锁定**：显式写出「以下保持不变：主体脸部、发型、服装、构图、光线、色调、背景、整体风格」。
2. **角色参考图（character sheet）**：先出一张三视图/转身图，后续所有镜头引用它。见 [`consistency.md`](consistency.md)。
3. **参考资产映射**：多资产场景下，逐个声明每个资产负责什么（参考图 1 = 构图、图 2 = 角色、图 3 = 场景）。
4. **不变量 vs 变量分离**：改动只写变量，其余一律归入「保持不动」。

**自检**：第 2 张图/第 2 个镜头，模型凭什么知道要跟第 1 个一样？我有没有明说？

---

## L5 排除层 —— 划红线

**约束：排除项具象化、有针对性，不套模板。**

- **具象化**：不写抽象否定，写包含排除结果的场景描述。（详见 G6）
- **有针对性**：负面词来自**当前这张图/这个镜头**的真实风险，不是固定套餐。
- **分层组织**：

| 类别 | 典型排除项 |
|---|---|
| 错误媒介 | 与 L2 冲突的媒介特征 |
| 结构缺陷 | 畸形手、多指、脸部不对称崩坏、穿模、比例失调 |
| 内容多余/缺失 | 多余人物、多余文字、缺少主体 |
| 光影错误 | 过曝、欠曝、光源方向矛盾、无阴影 |
| 画质缺陷 | 低清、噪点、过度锐化、过度磨皮、伪影 |
| 材质错误 | 塑料感皮肤、错误反射、材质混淆 |
| 文字/标识 | 可读品牌 Logo、水印、乱码、错字 |
| 视频特有 | 跳切、瞬移、身份漂移、主目标数量变化、场景漂移、POV 错误 |

- **数量**：负面词 8—15 条，英文逗号分隔。**不要为了凑数堆砌无关项。**

详见 [`negative.md`](negative.md)。

---

## L6 参数层 —— 剥离元数据

**约束：生成控制参数与提示词正文分离。**

外置到「推荐参数」行：

```
推荐参数：比例 16:9 ｜ 时长 10s ｜ 分辨率 2K ｜ 9:16 竖版
```

正文里**不出现**：模型名、版本号、时长、比例、分辨率、CFG、seed、去噪强度、API 参数名。

**例外**：目标模型的官方提示词 schema 本身就要求这些字段时，按官方格式写（MiniMax H3 的对齐指令、Seedance 多镜头时间轴、LTX screenplay 格式）。

**自检**：把提示词直接粘进模型输入框，里面的每个词都是给**画面**的指令吗？如果有给**工具**的指令混在里面，剥离出来。

- [ ] **L2** 媒介明确，且排除了混淆媒介
- [ ] **L3** 前 1/3 是核心锚点，维度按序不堆砌
- [ ] **L4** 需要稳定的元素已声明为不变量
- [ ] **L5** 排除项具象、有针对性、分层
