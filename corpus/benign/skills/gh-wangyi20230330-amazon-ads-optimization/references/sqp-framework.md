> **来源说明**：目标文章《万字解读SQP品牌搜索和自然流量分析》（公众号「从宇宙大爆炸到PPC」，阿波罗）**正文被微信反爬拦截，未能获取**（同号另一篇 PD 复盘文章可正常读取，此篇返回验证页）。

## 一、为什么必须加这一层：广告报表答不了的问题

| 报表 | 能回答 | 答不了 |
|---|---|---|
| 广告搜索词报告 | 钱花在哪、出多少单、ACoS 多少 | 我在这个词上**占多少份额**、短板在漏斗哪一环、自然位有没有在起作用 |
| **SQP（搜索查询绩效）** | **份额构成 + 全链路漏斗 + 自然/广告同框** | 具体某次点击的出价与花费 |

**关键差异**：广告报表是「我的支出视角」，SQP 是「市场份额视角」。**只看广告报表，你会把「转化问题」误当成「出价问题」—— 于是不断加价，越加越亏。**

SQP 按搜索查询给出了**品牌与全站双侧的完整漏斗**：

```
全站：搜索量 → 全站曝光 → 全站点击 → 全站加购 → 全站购买
品牌：         品牌曝光 → 品牌点击 → 品牌加购 → 品牌购买
份额：         曝光份额   点击份额   加购份额   购买份额
```

**注意「加购」这一环** —— 广告报表里完全没有，而它恰好能把「不想要」和「想买但没下单」这两类问题分开。

前置条件：SQP 属品牌分析报表，**需品牌备案（Brand Registry）**；无备案的账号拿不到，此时只能退回广告报表做粗诊断，并明确告知用户缺这一层。

## 二、核心方法：份额断崖定位法

**做法**：把品牌四个份额按漏斗顺序排开，找**相邻两环节落差最大**的那一处 —— 那就是短板环节。

| 断崖位置 | 含义 | 真实病因 | **不要做什么** |
|---|---|---|---|
| 曝光份额本身就低 | 这个词上你根本没被看到 | 相关性弱 / 竞价不足 / 预算受限 / 类目权重低 | — |
| **点击份额 < 曝光份额** | 被看到，但没人点 | **主图、价格、评分、标题、变体** | ❌ 不要加价 —— 加价只是把更多钱烧在点不动的流量上 |
| **加购份额 < 点击份额** | 点进来了，但不想买 | 详情页、A+、卖点表达、图文不符、尺寸信息缺失 | ❌ 不要加预算扩量 |
| **购买份额 < 加购份额** | 加购了，但最终没下单 | **价格、运费、优惠券、库存、配送时效、竞品更便宜** | ❌ 不要怪广告 —— 这是转化链路末端问题 |
| 某环节份额反而高于全站 | 这是你的**优势环节** | 可能是主图强、或价格有竞争力 | 用于防守与放大 |

**判读口诀**：**份额落差在哪一环，钱就不该花在广告上，而该花在那一环。**

## 三、品牌 vs 全站的三组转化率对比

SQP 同时给出品牌与全站的各环节转化率，逐列比较即可定位相对弱势：

| 对比项 | 品牌 < 全站 | 品牌 > 全站 | 结论 |
|---|---|---|---|
| 点击率（点击/曝光） | 主图/价格/评分弱于市场 | 你有外观或价格优势 | 弱势优先修图与定价 |
| 加购率（加购/点击） | 详情页说服力弱 | 卖点表达有效 | 弱势优先修 A+/五点 |
| 购买转化率（购买/加购） | 临门一脚输（价格/运费/促销） | 价格与信任感强 | 弱势优先修价格与促销 |

**用法**：**不要只看品牌自己的绝对值** —— 要与同一行里全站的值对比。全站值就是你所在类目的市场基准。

## 四、SQP → 投放动作映射（本层与投放的衔接）

这一节是本 Skill 存在的意义：把 SQP 的份额诊断翻译成**广告动作**。

| SQP 信号 | 诊断 | 投放动作 |
|---|---|---|
| 曝光份额高 + 点击份额低 | 看得到不点 | **先修主图/价格/评分**；广告**不加价**，可先降预算止血 |
| 点击份额高 + 加购份额低 | 点进来不想买 | 修详情页；维持出价不加，暂时不扩量 |
| 加购份额高 + 购买份额低 | 想买没下单 | 修价格/运费/优惠券；**广告降价或暂停**，等转化修好再放 |
| 曝光份额极低 + 全站搜索量大 + 你的自然排名不差 | 该抢但没抢 | **加价 + 加预算**，优先抢 TOS |
| 四份额均高 + 广告 ACoS 也低 | 统治该词 | **防守**：保持出价，预算保足，别乱动 |
| 自然份额强但广告份额低 | 自然位已够 | **可省广告预算**，把预算挪给弱势词 |
| 广告份额高但自然份额弱 | 靠广告撑 | 广告不能停；同时补自然排名（转化、评论、词频） |
| 广告与自然份额高度重叠 + 总份额不涨 | 广告在蚕食自然 | 收广告预算或降 TOS 加价，看总份额是否维持 |

**与第 8 层（新词分析）的衔接**：SQP 找**份额短板**（结构问题），广告搜索词报告找**新增需求**（增量机会）。先修短板，再放增量 —— 否则新增流量的转化也会漏掉。

## 五、词簇法：把长尾聚成簇看，而不是逐词看

单看一个长尾词，点击量永远达不到统计显著（< 10 次点击），逐词优化等于对着噪声调参。

**做法**：按**词根 / 意图**把长尾词聚成簇，对**簇**做判断。

| 步骤 | 操作 |
|---|---|
| 1. 分词根 | 如 portable blender 簇内：`for smoothies` / `rechargeable` / `cup` / `bottle` |
| 2. 归簇 | 同一词根、同一购买意图的归为一簇 |
| 3. 看三个数 | **簇的自然排名**、**簇的自然流量占比**、**簇的整体订单净增量** |
| 4. 判断 | 整簇在涨 → 加大投入；整簇在跌 → 查是竞品还是季节 |
| 5. 与 SQP 交叉 | 簇内份额断崖处，就是该簇的优化重点 |

**与 SQP 的配合**：SQP 告诉你单词语份额，词簇法解决「单词样本不足」的问题 —— 两者叠加才既有精度又有统计量。

**簇级 KPI（不要逐词考核）**：簇曝光份额、簇自然排名中位数、簇自然订单占比、簇整体订单净增量。

## 六、与现有层次的接入位置

SQP 是本 Skill 诊断链路的**第 0 层**（份额定位），必须在广告层诊断之前跑：

```
第 0 层 SQP 份额漏斗  ← 定位短板在漏斗哪一环（本文件）
    ↓ 短板在转化 → 修 Listing/价格，不要调广告
    ↓ 短板在曝光 → 进入广告层诊断，决定出价与预算
第 1 层 店铺/账户
第 2 层 广告活动
第 3 层 广告组/关键词结构
第 4 层 搜索词
第 5 层 广告位
第 6 层 时段
第 7 层 大促期指标反向解读
第 8 层 新增需求分析
```

**加这一层能防的最大一类错误**：拿转化问题当出价问题，越调越亏。

## 七、输出要求

做 SQP 分析时，输出必须包含：

1. **四份额一览**（品牌 vs 全站可比值的对比）
2. **断崖定位**：短板在曝光 / 点击 / 加购 / 购买 的哪一环，依据是相邻份额落差
3. **归因判断**：这个断崖是 Listing/价格问题，还是广告投放问题
4. **动作**：如果是 Listing/价格问题 → 明确写「**此处不应调广告**」并给出应修项；如果是投放问题 → 给出出价/预算/结构的具体动作
5. **数据边界**：SQP 需要品牌备案；无备案时明确说明该层无法执行

## 八、边界与反模式

| 反模式 | 为什么错 |
|---|---|
| 只看品牌份额，不与全站对比 | 份额高或低都没有意义，必须相对市场 |
| 曝光份额低就加价 | 可能相关性就不对，加价买的是无关流量 |
| 点击份额低就换主图 | 也可能只是价格没竞争力，先分清 |
| 购买份额低就怪广告 | 加购后没买是价格/运费/促销问题，与广告无关 |
| 逐词优化长尾 | 样本不足，必须聚簇 |
| 用 SQP 决定具体 CPC | SQP 给的是份额与漏斗，出价数字仍由可接受 CPC 公式决定（见 metrics.md） |

**SQP 与 ACoS 的关系**：SQP 决定「**该不该在这个词上花钱、该先修什么**」，ACoS/可接受 CPC 决定「**花多少钱**」。顺序不能颠倒。
