# 报告模板

三份模板：日报（异常监控）、周报（优化动作）、月度复盘（目标校准）。**不要每天都做全量诊断**，节奏错了比不做更糟。

---

## 一、日报（只做异常监控，5 分钟看完）

```markdown
# 广告日报 YYYY-MM-DD（站点：US | 币种：USD）

## 异常告警
- [ ] 预算烧穿：<活动名> 在 <时间> 前花完（预算 $X）
- [ ] 花费异常：<活动名> 单日花费 $X，为 7 日均值的 <N> 倍
- [ ] 跑飞词：<搜索词> 今日点击 <N>、0 单，花费 $X
- [ ] 断流：<活动名> 曝光为 0（是否被暂停/预算为 0）
- [ ] 库存告警：<ASIN> 可售天数 < 30（暂停加投）

## 昨日概况
| 指标 | 昨日 | 7 日均值 | 偏差 |
|---|---|---|---|
| 花费 | | | |
| 广告销售额 | | | |
| ACoS | | | |
| 订单数 | | | |

## 今日动作
- （只列止血类：加否定词、暂停明确亏损词）
```

**日报纪律**：不因单日波动调出价；日报只处理「明显异常」，其余留给周报。

## 二、周报（优化动作，主要工作产出）

```markdown
# 广告周报 YYYY-MM-DD ~ YYYY-MM-DD（US | USD）

## 1. 核心指标
| 指标 | 本周 | 上周 | 环比 | 目标 | 状态 |
|---|---|---|---|---|---|
| 广告花费 | | | | — | |
| 广告销售额 | | | | — | |
| ACoS | | | | 25% | |
| 总销售额 | | | | — | |
| TACoS | | | | — | |
| 广告单占比 | | | | — | |

## 2. 分层诊断
- **店铺层**：TACoS 趋势 / 是否蚕食自然位
- **活动层**：预算是否够用、ACoS 是否达标
- **搜索词层**：本周新增浪费词 N 个、可收割词 M 个
- **广告位层**：TOS/PP 的边际效率变化

## 3. 本周动作清单（必须含改前值）
| 优先级 | 对象 | 动作 | 改前 | 改后 | 依据 | 预期影响 |
|---|---|---|---|---|---|---|
| P0 | | | | | | |
| P1 | | | | | | |

## 4. 上周动作复盘
| 动作 | 预期 | 实际 | 结论 |
|---|---|---|---|
| | | | 有效 / 无效 / 待观察 |

## 5. 下周计划
- （只列 3~5 条，聚焦）
```

**关键**：第 4 节「上周动作复盘」是区分专业与业余的地方。没有复盘，优化就是随机游走。

## 三、月度复盘（目标校准）

```markdown
# 广告月度复盘 YYYY-MM（US | USD）

## 1. 结果
- 总销售额 / 广告花费 / TACoS / 净利润
- 广告单占比变化趋势（判断广告健康度的核心）

## 2. 目标校准
- 盈亏平衡 ACoS 是否变化？（成本、FBA 费、佣金、退货率、汇率）
- 目标 ACoS 是否需要重设？

## 3. 结构性结论
- 哪些活动类型（Auto/Broad/Exact/ASIN 定投）是净贡献？
- 预算分配是否该调整？调整方案与依据
- 广告位加价的整体边际效率

## 4. 下月重点
- 最多 3 条

## 5. 需要老板/供应链决策的事
- 定价、库存、新品、断货风险
```

## 四、汇报口径纪律

| 纪律 | 说明 |
|---|---|
| 每个数字带时间窗 | 「ACoS 32%」无效，「近 14 天 ACoS 32%」有效 |
| 带币种与站点 | 跨站点不给单一 ACoS |
| 区分事实与推断 | 推断要写假设 |
| 不藏坏消息 | ACoS 超标就写超标，不要只挑好看的指标 |
| 不承诺精确预测 | 用「预期区间」而不是「一定降到 X%」 |
| 数据不全就标注 | 写明缺哪张报表、影响哪些结论 |

## 五、用脚本生成诊断草稿

```bash
node scripts/ads_opt.mjs calc --price 39.99 --cost 8 --fba 7.5 --first-leg 3 --commission-rate 15 --return-rate 5 --target-margin 15 --cvr 8
node scripts/ads_opt.mjs diagnose --file weekly-search-terms.csv --target-acos 25 --break-even-acos 34
```

脚本产出 P0/P1/P2 候选项 → 人工按学习期/库存/大促状态复核 → 填入周报第 3 节。
