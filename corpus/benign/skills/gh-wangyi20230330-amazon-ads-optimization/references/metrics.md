# 指标口径与核心公式

所有阈值都必须建立在正确的口径上。口径错了，后面所有结论都是错的。

## 一、基础指标

| 指标 | 公式 | 说明 |
|---|---|---|
| ACoS | 广告花费 / **广告销售额** | 只看广告自身效率，不含自然单 |
| ROAS | 广告销售额 / 广告花费 = 1 / ACoS | 与 ACoS 互为倒数，不要重复列 |
| TACoS | 广告花费 / **店铺总销售额（广告+自然）** | 看广告对整店的健康度影响 |
| CTR | 点击 / 曝光 | 广告位吸引力，受主图/价格/相关性影响 |
| CVR | 订单 / 点击 | 转化率，出价能力的核心乘数 |
| CPC | 广告花费 / 点击 | 实际成交价，不是出价 |
| IS（曝光份额） | — | 曝光份额低=被预算或出价卡住 |

**关键区分**：ACoS 高不代表亏，TACoS 涨不代表坏。必须结合目标判断。

## 二、盈亏平衡 ACoS（整个体系的锚）

定义：广告花费最多能占广告销售额多少，这一单才不亏。

```
单位广告前贡献 = 售价
              - 产品成本
              - FBA 配送费
              - 平台佣金（售价 × 佣金率）
              - 头程分摊（每件）
              - 仓储/其他分摊（每件）
              - 退货损耗（售价 × 退货率 × 退货损失率）

盈亏平衡 ACoS = 单位广告前贡献 / 售价
```

口径提醒：
- 分母用的是**广告销售额**，所以盈亏平衡 ACoS 天然是「广告订单口径」的上限。
- **退货率必须扣**：服装/家居等类目退货率 10%~30%，不扣会系统性高估可承受 ACoS。
- 佣金率按类目实际（多数 8%~15%），不要用 15% 一刀切。
- 币种统一后再算，跨境不要混用。

## 三、目标 ACoS（比盈亏平衡线更该用的数）

```
目标 ACoS = (单位广告前贡献 - 目标单件净利) / 售价
```

例：售价 $40，单位广告前贡献 $16（即平衡 ACoS 40%），希望单件净利 $6 → 目标 ACoS = ($16-$6)/$40 = **25%**。

**盈亏平衡线是红线，目标 ACoS 才是日常调优的靶心。** 把 40% 当目标，等于把利润全部让给广告。

## 四、出价天花板（把 ACoS 目标翻译成 CPC）

```
可接受 CPC = 售价 × 转化率 × 目标 ACoS
```

例：售价 $40，CVR 8%，目标 ACoS 25% → 可接受 CPC = 40 × 0.08 × 0.25 = **$0.80**。
当前 CPC $1.10 > $0.80 → 该词结构性亏损，降价或优化转化，不是靠加预算能救的。

**这是最有用的一条**：它把「出价该多少」变成算术题。转化率越高，能承受的 CPC 越高。

## 五、TACoS 的正确用法

```
TACoS = 广告花费 / 总销售额
```

- **推新品/抢排名期**：TACoS 上升是**投资**，看的是自然排名与自然单占比有没有跟着涨。
- **成熟期**：TACoS 持续上升而自然单不涨 = 广告在蚕食自然位，要收。
- 判断信号：**广告订单占比**。若广告单占比上升而总单量不变 → 蚕食；总单量同步上升 → 增量。

| 阶段 | 广告单占比参考 | 关注点 |
|---|---|---|
| 新品期 | 50%~80% | 排名、评论、自然单是否启动 |
| 成长期 | 30%~50% | TACoS 是否随自然单下降 |
| 成熟期 | 15%~30% | 利润、防守竞品 |
| 清库存 | 不限 | 周转天数与总毛利，不看 ACoS |

（占比为常见区间参考，不是硬标准，以本品类与自身趋势为准。）

## 六、多广告位口径

广告位（Top of Search / Product Pages / Rest of Search）的 ACoS 不可直接横向比：
- TOS 流量质量高、CPC 也高，ACoS 天然偏高；
- 判断依据是**该位置的边际效率**：加价后带来的增量订单是否仍满足「可接受 CPC」。
- 加价上限参考：SP 广告位加价可在 0%~900% 区间设置，但**不要因为能设 900% 就设 900%**，按边际数据走。

## 七、常见口径错误（发现就要纠正）

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用「回款率」代替毛利率算平衡线 | 高估可承受 ACoS | 逐项扣：FBA/佣金/头程/退货 |
| 不扣退货率 | 系统性高估 | 按类目退货率折算 |
| 把 ACoS 和 ROAS 当成两个独立指标同时优化 | 自相矛盾 | 二选一，通常用 ACoS |
| 用 7 天数据判断结构 | 学习期噪声 | 结构判断看 14~30 天 |
| 跨站点直接比 ACoS 绝对值 | 结论错 | 比趋势、比 vs 各自目标 |
| 用平均 CPC 估预算 | 忽略位置差异 | 分广告位看 CPC |

## 附：目标 ACoS 的兜底基准（仅在确实算不出时使用）

**优先顺序不变**：先算本品盈亏平衡 ACoS → 再定目标 ACoS。只有在**成本数据缺失、无法算 break-even** 时，才用下表兜底，且**必须向用户标注这是假设值**（官方立场同样是「每个品牌目标不同，第一步应算 break-even ACoS」）。

| 场景 | 参考区间 | 来源（见 [verification.md](verification.md) V10） |
|---|---|---|
| SP 手动（Exact/Broad） | **25%~35%** | 独立实现给出的类目无关基准 |
| SP 自动（Auto） | **35%~45%** | 同上，自动投放转化更粗，容忍度更高 |
| 完全无输入时的默认 | **30%** | 独立实现的兜底默认值 |
| 新品期 | 可放宽至接近盈亏平衡线（示例 ~50%） | 上游 PPC 框架的 Launch 档 |
| 成熟期 | ~30% | 上游 PPC 框架的 Mature 档 |

**注意**：这些是**市场常见基准，不是你的最优值**。算得出 break-even 就必须用你自己的数。

## 附：目标 ACoS 的另一种表达 —— 盈亏平衡 × 策略乘数（独立实现交叉验证）

`目标 ACoS = 盈亏平衡 ACoS × 策略乘数`，与本文第三节的公式**等价**，只是从"利润目标"改从"策略姿态"出发。独立实现给出的起手标定（见 [verification.md](verification.md) V12）：

| 策略 / 姿态 | 乘数 | 示例（BE = 42.6%） |
|---|---|---|
| **launch**（推新品买排名，利润后置） | **1.40 × BE** | 59.6% |
| **dominate**（抢类目份额） | **1.15 × BE** | 49.0% |
| **grow**（要自己养活自己） | **1.10 × BE** | 46.9% |
| maintain（维持） | ≤ 1.0 × BE | ≤ 42.6% |

**两条重要衍生规则**
1. **「砍」的规则跑上限（ceiling）、「加」的规则跑裸 BE。** 即：允许亏损到 ceiling，但只对**真正赚钱**（低于裸 BE）的对象加码 —— 否则你会给一个本来就在亏的词加预算。
2. **目标是产品级的，不是账户级的。** 原文：*A 35% ACoS is excellent on a 55%-margin product and ruinous on a 20%-margin one.* —— 同一个数字在一个品上是胜利、在另一个品上是灾难。**这与本文"不要跨站点直接比 ACoS"是同一条纪律。**

**用法**：先算 BE → 再按本品当前策略选乘数 → 得到目标 ACoS。比"直接拍一个目标值"更有据。
