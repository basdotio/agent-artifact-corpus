# 大促专项复盘（Prime Day / 黑五 / 会员日）

> 来源：阿波罗《送PD复盘Skills｜Prime Day 战况数据复盘：下一轮广告该怎么投？》
> 数据基础：亚马逊美国站服装类目，PD 2026/6/23–6/26 对比活动前 14 天。
> 采编日期：2026-09-21。**本文件补的是「大促复盘」这一层，日常诊断仍走 diagnosis.md。**

## 零、复盘的立场（先纠正目的）

大促复盘的目的**不是总结过去赚了多少**，而是回答：**消费者到底告诉了你什么？**

- ❌ 错误起手式：打开后台看销售额 / ACoS / 花费，然后「恢复日常广告」
- ✅ 正确起手式：先问「这次大促，验证了什么？」，再决定下一轮预算怎么配
- **判断标准**：如果复盘的结论落不到「下一轮预算怎么配置」，那它就只是统计，没有产生经营价值

大促把平时需要两三个月才能积累的样本压进四天 —— 它是**消费者集中表达需求的机会**，不是一次考试。

## 一、三维度九问框架

按这个顺序问，每问都必须有数据答案：

| 层 | 问题 |
|---|---|
| **第一层 整体表现** | ① 广告整体效率提升还是下降？<br>② 流量结构发生了什么变化？ |
| **第二层 流量来源** | ③ 哪些搜索词真正贡献了订单？<br>④ 有多少是**第一次成交的新词**？<br>⑤ 这些新词是偶然，还是长期机会？ |
| **第三层 时间与结构** | ⑥ 哪几个小时最值得投入预算？<br>⑦ 不同匹配方式发生了什么变化？<br>⑧ Auto 有没有发现新机会？<br>⑨ 下一次大促，预算应该怎么分配？ |

## 二、大促期指标的「反向解读」（最容易误判的地方）

**大促期 CTR 下降 + CVR 上升 = 正常现象，不是效率下降。**

实测数据：PD 期间 CTR **-12.3%**，CVR **+6.2%**。
原因：大促期间所有卖家都在抢曝光，消费者每天被大量广告轰炸 → 点击更谨慎；但**真正点进来的人购买意图更强**。

推论：
- 不要因为 CTR 掉就下调出价或改主图 —— 先看 CVR 是否同步上升
- 大促期真正该看的是：**预算有没有流向更高价值的流量**，而不是单个指标的涨跌
- 同理，大促期 ACoS 上升若伴随 CVR 上升，要区分是「竞争推高 CPC」还是「流量变差」

## 三、搜索词层：找「新增需求」，而不是只看 ACoS

### 关键指标：新出单词占比

实测：PD 期间 **233 个出单搜索词，156 个是前 14 天从未成交过的新词 → 占 67%**。

复盘时必算：
```
新出单词占比 = 本次大促新出单词数 / 本次大促全部出单词数
新词效率倍数 = 新词 CVR / 历史词 CVR
```

实测对比：**新词 CVR 是历史词的 2.8 倍，ACoS 仅 6.25%**；三词以上新长尾词平均 CVR 超 87%、ACoS 不到 6%。

### 词长与语义分布

- 词长：6 词以上新词占比**上升**，1~2 词泛搜索占比**下降** → 大促消费者用更具体的方式表达需求
- 语义：新成交词集中在**通用词 / 品牌词 / 尺码词**，材质、颜色等属性词变化不明显 → 消费者是**带着明确购买意图**来，不是来做产品研究

### 结论与动作

- 高转化、低 ACoS 的词，**大多不是流量最大的核心词**，而是需求表达明确的长尾词
- **不要让这些好词继续留在 Auto 里** —— 验证后迁到 Exact，重配预算，形成长期流量入口
- **Auto 的最大价值是持续发现新需求，不是长期贡献订单**；验证完就交给手动放大

## 四、时间结构：预算节奏（本 Skill 对 SP 分时限制的重要补充）

实测：PD 期间 **19:00 是单小时订单最高点**；**17:00–21:00 连续五小时，每小时订单增长均超 100%**。

典型错误：预算平均分到全天 → 上午花完 → 晚上真正成交时广告限流。

**建议解法（SP 原生可做的部分）**：
1. **先调预算节奏，不要第一时间提全天竞价**
2. 把 **40%~50% 的预算集中到 16:00–21:00** 这个高效窗口
3. 同时对这 5 小时**提高竞价 20%~30%**
4. 把该窗口**写入下一次大促的预算 SOP**（固化成流程，不靠临时判断）

> ⚠️ **修正本 Skill 早前的说法**：`diagnosis.md` 第 6 层曾把时段优化简化成「SP 原生没有分时调价，做不了就明说」。这是不完整的 —— **预算分配节奏 + 竞价调整**是 SP 原生就能实现的近似手段，应当先用起来；只有「按小时精确调价」才需要第三方工具或 Ads API 的 budget rules。

**原则：预算管理的对象不只是「今天花了多少钱」，而是「什么时候花、花给谁、为什么这样配」。预算本身不创造价值，配置才创造价值。**

## 五、广告结构：按「承担的任务」配置预算

实测：**Auto Loose Match** 是本次大促表现最好的匹配方式 —— 挖出 **38 个全新出单词**，CVR **+49%**，ACoS **-24%**。
**Phrase Match** 表现相反 —— 吸收大量低意图流量，整体效率下降。

**匹配方式的角色分工**（不要问「哪种更好」，要问「当前阶段该把钱配给谁」）：

| 匹配方式 | 角色 | 什么时候加预算 |
|---|---|---|
| **Auto** | 探索 —— 发现新需求、新搜索词 | 目标是「找机会」时 |
| **Exact** | 放大 —— 承接已验证的高效流量 | 目标变成「放大增长」时 |
| **Broad** | 扩量 —— 覆盖变体与长尾 | 需要铺量时 |
| **Phrase** | 覆盖 —— 兜住中间意图 | ⚠️ 大促期易吸低意图流量，要收 |

阶段对应：**找机会 → 向探索倾斜；放大增长 → 向已验证流量倾斜；进入利润阶段 → 优化结构提高效率，而不是继续无节制扩量。**

**不要因为 Phrase 在大促表现差就全盘否定它** —— 它承担的是覆盖任务，问题在于大促期低意图流量涌入时没有及时加否词。

## 六、复盘后立刻执行的五件事（可直接作为 SOP）

| # | 动作 | 触发条件 |
|---|---|---|
| ① | **加词**：迁移到 Exact，建立长期流量入口 | ACoS < 20% 且出单 ≥ 2 的新搜索词 |
| ② | **建观察名单**：监控大促期间消失的历史出单词，看活动结束后是否恢复 | 历史出单词在大促期 0 单 |
| ③ | **收窄 Phrase**：加否定词，或把高效词迁到 Exact | Phrase 效率下降 |
| ④ | **保留 Auto**：不要因为大促结束就关掉 Auto Loose Match | 无条件 —— 它是后续扩量的来源 |
| ⑤ | **调整预算节奏**：把高效时段写进下一次大促的预算 SOP | 有时段集中证据时 |

> 第 ② 条是本 Skill 原先完全缺失的机制。「**观察名单**」解决的是：历史出单词在大促期消失，可能是竞品动作、自然排名下滑或流量结构变化的早期信号 —— 不建名单就永远看不到。

## 八、边界

- 本文数据来自**服装类目、美国站、单次 PD**。绝对数值（如 67% 新词占比、19:00 峰值）**不可直接套用到其他类目与站点** —— 可复用的是**方法与框架**，不是数字。
- 时段峰值与类目强相关：服装/家居偏晚间，办公/工具类目可能完全不同。必须用**自己站点的逐小时数据**重算。
- 大促期间数据不与日常可比（见 `playbooks.md` 场景 C），但**大促数据内部的横向对比**（新词 vs 老词、高峰 vs 平峰）恰好是平时样本量不足、做不了的。

## 九、大促后的结构重组与验证（补自雨果网实战文，2026-09-21）

> 来源：雨果网《亚马逊大促后广告不敢动、库存不敢补？别凭感觉赌！！》（转载自公众号「十一郎与流氓的跨境江湖」）
> 核心判断：**大促后真正的问题不是销量降了，而是流量结构出现断层。**

### 1. 先认清「销量是租来的」

大促销量由三类流量构成，**共同点是来得快走得也快**：
- 活动流量（秒杀 / BD / LD）
- 低价冲动流量（折扣带来的偶然单）
- 临时关键词爆发流量（大促词、节日词）

**所以大促后不要按峰值销量做决策** —— 要拆结构。

### 2. 流量结构三分类（决定补货与广告力度）

| 结构 | 特征 | 补货 | 广告 |
|---|---|---|---|
| **稳定型** | 主词持续进流 + 长尾词占比提升 + **非活动词占比 > 60%** | 正常节奏，可适度扩量 | 可放量、可加预算 |
| **波动型** | 主词还在但下降 + 长尾词减少 + 活动词占比偏高 | 按正常需求的 **70%~80%**，不追峰值 | 控制预算，以防守为主 |
| **脉冲型** | 流量高度集中活动词 + 新增自然词几乎为零 | **只维持安全库存，禁止大规模补货** | 只保留防守型低价投放 |

### 3. 需求真实性三分类（看活动前 / 峰值 / 回落三条线）

| 类型 | 曲线特征 | 结论 |
|---|---|---|
| **健康增长型** | 活动后仍高于活动前，并有稳定横盘 | 可补货 + 适当扩量 |
| **透支型** | 快速回落到甚至低于活动前原点 | 不建议重仓，保守节奏 |
| **泡沫型** | 只有活动期一根大阳线，无回归结构 | 禁止补货，只清现有库存 |

### 4. ★ 大促后广告的「防守型结构」黄金比例

```
30% 核心词（稳排名）—— 不追爆发，只守住已有位置
50% 长尾词（拉自然流）—— 决定真实转化结构，是未来自然流量来源
20% 防守词（防掉量）—— 防流量断崖，尤其竞品大促后抢流那几天
```

### 5. ★★ 广告目标从「冲排名」改为「验证自然权重」

**判断方法（很实用，我们原先没有）**：做两个动作看结果 ——

| 动作 | 观察 | 结论 |
|---|---|---|
| **关掉广告** | 排名掉了 | **结构不稳定**，自然权重还没接住，仍需广告维持 |
| **降低广告** | 排名与单量仍稳住 | **自然权重已形成**，可以逐步降预算 |

**执行节奏**：**活动结束后第 3 天开始，用 3~5 天逐步降预算**（**不要一次性关停**），观察**自然单占比**与**核心词排名**的变化。
> 若降预算后**自然单占比反而上升** → 链接已经站稳。

### 6. 库存与广告是互相验证的两个系统

| | 判断核心 |
|---|---|
| **库存安全系统**（防断货） | 活动结束后，这个链接还能不能**持续自然吃流量**？ |
| **广告供血系统**（防压货） | 这个链接现在还能不能用广告**有效放大自然权重**？ |

**只看库存** → 按销量峰值备货，因为数据滞后而误判
**只看广告** → 为稳排名继续烧高预算，库存清了、利润没了

**联动规则**：广告能有效带动自然流量增长 → 可补货；广告带不动自然流量、只是纯烧钱 → **不要补货**。
> 一句话：**库存不是看最近卖得好不好，而是看广告是否还能有效放大自然结构。**
