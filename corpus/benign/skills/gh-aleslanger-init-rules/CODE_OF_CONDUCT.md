# Code of conduct

This code applies to issues, pull requests, reviews, and other project discussions in this repository.

## Expected behavior

- Be respectful and constructive, including when you disagree.
- Critique ideas and changes without personal attacks or harassment.
- Respect people's privacy. Do not post private messages, personal data, or secrets without permission.
- Help keep discussions focused on the project and make room for other contributors.

Harassment, discriminatory language, threats, and repeated disruptive behavior are not acceptable.

## Reporting and enforcement

For a concern that can be discussed publicly, open an issue and describe the behavior with links to the relevant discussion. Do not include private information. For a private report, email the maintainer at [aleslanger.dev@gmail.com](mailto:aleslanger.dev@gmail.com). You can also use GitHub's **Report content** feature for abusive content hosted on GitHub.

The repository maintainer may edit or remove comments, close or lock discussions, or restrict participation when needed to uphold this code. Reports will be considered in context; no particular response time or outcome is promised.
