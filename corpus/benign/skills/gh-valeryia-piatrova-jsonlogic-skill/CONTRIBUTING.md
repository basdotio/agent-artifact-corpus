# Contributing to jsonlogic-skill

Thanks for helping improve the jsonlogic skill. This repo is an agent skill: a SKILL.md plus supporting docs, references, and scripts that teach AI coding assistants to work with JsonLogic.

## Ways to contribute

- Report a bug or wrong rule output: open an issue with the rule, the data, and what you expected.
- Add real-world examples: discount, approval, and access-control rules make great additions.
- Improve docs: installing.md and the files under references/.
- Add or fix a JsonLogic library entry in references/libraries.md.
- Fix typos and clarify wording anywhere.

## Pull request process

1. Fork the repo and create a branch from main.
2. Keep changes focused: one idea per PR.
3. If you change SKILL.md behavior, say how you tested it.
4. If you touched skill structure, run scripts/validate_skill.rb.
5. Open the PR with a short description of what changed and why.

## Style notes

- Match the existing tone: plain, direct, no jargon.
- Code examples should be copy-paste runnable where possible.

## Questions

Open an issue. Small questions are welcome.
