# 第24章 债务重组与产权重组：让不良资产"升值"的综合手术

## 核心思想
债务重组是不良处置里**唯一可能实现"价值提升"的综合手段**——用让步（减免/展期）换取更大的总回收。它的核心不是"给债务人减负"，而是**用结构化设计找回价值**：找到关键人、设计附条件豁免、联动关联债权。产权重组则更进一步——把"换钱"升级为"换主体、换结构、换经营方式"。

## 核心框架

### 框架一：债务重组七种方式
| 方式 | 要点 |
|---|---|
| 债务转移 | 经债权人同意；从债务随主债务同走（专属除外）；涉批准登记须办理（如外债变更登记） |
| 债务抵销 | 互负到期债务、种类品质相同可单方抵销（须通知）；不等额部分继续清偿；受让人也可被主张抵销（《合同法》83条） |
| 债务混同 | 债权债务归一人（如企业合并）→ 债务消灭 |
| **债务减免** | 实务常用：对有部分偿债能力但不宜起诉的债务人，减免换取配合与快速回收 |
| 以非现金资产清偿 | 存货/固定资产/知识产权/债权/股权/使用权皆可；涉国资须批准＋评估；防以偿债之名偷漏税 |
| 融资减债 | 增资扩股/发股/发债筹资还债 |
| 修改其他债务条件 | 减息/调利率/延长期限+加计利息/延长期限并减本金——含"以贷还贷（借新还旧）"的定性 |

### 框架二：王牌条款——附条件减债豁免（案例精华）
**双户联动重组实录**：
- 债权A：德辉科技（本金550万，夏华担保＋实控人贾某连带）——判后终本；
- 债权B：博嘉科技（千里马物流＋**德辉科技**担保）——同样终本；
- 关键动作：**找到两笔债务背后同一实际控制人贾某**→提出两户打包重组，核心条款四条：
  1. 公司为甲方、贾某为乙方（个人承债）；
  2. 债权金额适度减免＋分期还款；
  3. **附条件减债豁免**——不按约还款，则**按原合同金额**向原债务人及担保人追偿（豁免只在履约后落袋）；
  4. 签订生效；
- 谈判杠杆：贾某起初不愿为第二户埋单（其仅为第一户担保人）——我方掌握其另开办的多家公司也有债务，**若转让给"那些债权人"将得不偿失**→贾某权衡后接受。
- **When**：任何重组方案——**没有"违约即恢复原额追偿"条款的减免，等于单方面送礼**。

### 框架三：债务重组的价值逻辑（为什么值得做）
- 债权人三得：灵活多样的方案提高达成率（会计上重组收益计入债务人营业外收入→**债务人有配合动力**）；优质抵债/股权变现收益常高于直接收现金；减少诉讼费用支出；
- 债务人：改善资产负债结构＋重组收益；
- 地方政府：稳经济、稳就业——多赢结构是重组成功的政治基础（与第12章三方博弈互为表里）。

### 框架四：重组风险防控三要点
1. **持有与运作能力**：抵债资产/股权的阶段性持有需要专业能力（内部挖潜＋引才＋借外部机构）；
2. **科学评价体系**：基于未来现金流的方案评估具有高不确定性——要建规范流程，不能拍脑袋；
3. **警惕恶意重组**:不公允关联交易掏空企业的案例很多——改善资产负债结构的幌子下要防掏空。

### 框架五：产权重组——从"钱的调度"到"权的重塑"
- 定义：对旧财产关系进行新塑造——①客体范围（什么可以成为财产）②主体的重新塑造（产权代表选择/主体变更）③权利结构（所有权、占有、使用、收益、处分五权边界）④经营方式的重新选择；
- **产权经营方式菜单**：租赁、借贷、联合、兼并、收购、拍卖、股份制、股份合作制；
- 目标体系：终极产权一元化／三级管理责任化／保值增值定量化（"三个四化"要点——适用于国资场景）；
- **审批链是实操第一关**（ST渤化案例）：境内重大重组要过十余道审批（政府批准→国资局/财政部评估立项与确认→土地部门→财政部会计司→证监会要约豁免→外经贸部→工商变更→交易所更名），对比香港只有证监会＋联交所两家——**项目排期必须把审批时间计入**。

### 框架六：资产经营的"放大效应"（重组的价值论）
资产经营通过六种放大效应实现快速增值：**结构放大**（全部资源入局）／**交易放大**（交易规模几何级）／**市场放大**（跨时空交易）／**融资放大**（股本型、直接融资、工具多元、无次数限制）／**时间放大**（回收周期大幅缩短）／**效益放大**（存量+增量+交易一体化增值）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 附条件减债豁免 | 履约后减免生效；违约则恢复原额追偿——重组的"胡萝卜+大棒" |
| 新承债主体 | 引入关联方/第三方承担债务——常与减免、分期组合使用 |
| 实际控制人识别 | 多户债权联动重组的前提——谈判对象是"人"，不是空壳"公司" |
| 以贷还贷定性 | 借新还旧实质=原合同期限等条款的变更（人行复函口径） |
| 产权经营 | 以产权为商品的市场经营活动（租赁/兼并/拍卖/股份制…） |
| 放大效应 | 资产经营的六大增值效应——重组"升值"的理论基础 |

## 思维模型
- **"减免是投资"**：每一次让利都应对应换取某种确定性（还款承诺/个人担保/关联债权打包）——没有对价的减免是亏损。
- **关键人扫描**：每户债权先回答"谁是真正的决策人？他的利益网络在哪里？"——杠杆藏在他的其他公司、其他债务、其他身份里。
- **胡萝卜+大棒条款设计**：给付激励（减免、分期）+违约威慑（恢复原额、加速到期、个人担保）成对出现。
- **联动思维**：同一实控人的多户债权是同一盘棋——单户谈不动的，打包可能就谈动了。
- **审批时差意识**：把国资、税务、外债等审批流程当作项目工期的一部分——报价和资金计划都要预留。

## 反模式
- **无条件减免**：没有恢复追偿条款——债务人拿了好处随时反悔。
- **单户孤军作战**：放着同一实控人的其他债权不用——谈判杠杆白白浪费。
- **对无还款能力者硬推重组**：重组只适用于"有部分偿债能力"的债务人；对彻底空壳应走转让/诉讼路线。
- **忽略审批链**：涉国资的非现金偿债未批未评——交易可能无效。
- **被"重组收益"迷惑**：债务人会计上的营业外收入≠你回收的价值——盯现金流与担保结构。

## 实操示例
**双户重组谈判清单（重建自案例）**：
1. 建立主债务人与关联债权全景图（本案：德辉/博嘉/千里马物流/夏华担保/贾某）；
2. 锁定实际控制人（贾某）及其"软肋网络"（另有多家公司有债务）；
3. 设计条款包：减免幅度（以快速回收线为底）×分期表×附条件豁免×个人连带担保；
4. 谈判节奏：先谈打包（两户一起）→再谈金额与期限→最后落豁免条款；
5. 履约管理：纳入台账"进项"跟踪（第23章），任何一期逾期立即评估"是否触发恢复原额追偿"；
6. 交割闭环：还款完毕→出具豁免确认→台账归档。

## 要点回顾
1. 债务重组七方式：转移/抵销/混同/减免/非现金清偿/融资减债/修改条件。
2. 王牌条款=附条件减债豁免；没有违约威慑的减免不可接受。
3. 多户联动+实控人识别是重组谈判的杠杆放大器。
4. 重组价值逻辑=债权人提率高、债务人会计动力、政府维稳——多赢结构．
5. 三大风险：持有能力/评价体系/恶意重组。
6. 产权重组四内容+经营方式菜单＋审批链现实；放大效应六种是"升值"的理论骨架。
