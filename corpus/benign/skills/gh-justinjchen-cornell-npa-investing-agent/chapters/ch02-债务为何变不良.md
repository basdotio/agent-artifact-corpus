# 第2章 债务为何变不良

## 核心思想
债务不良从来不是单一"经营失败"，而是多重因素的合流——信贷周期、监管环境、治理缺陷、错误认知，最终都汇聚为同一个技术标志：**现金流净值无法满足偿付要求**。对投资者而言，成因分析决定分析路径：资本结构问题看重组，基本面问题假设最坏；而《破产法》第十一章破产保护不是博弈的结束，而是**博弈的开始**。

## 核心框架

### 框架一：企业出险六因素（中国清单）
1. **宽松的信贷供给**：银行从"坐商"变"行商"，主动授信、请企业用款——信贷资源泛滥给企业造成"取之不尽"的错觉；
2. **宽容的监管环境**：金融创新与混业经营下，企业收购牌照、体内自循环，在"一行三会"间左右腾挪；
3. **法治与诚信体系短板**：违约成本低则打击诚信者、鼓励失信者，产生道德风险；
4. **缺乏制衡的公司治理**：家族式结构令"三会一层"表面化——要么"内部人控制"（股权过散无实控人），要么"大股东控制"（隐蔽绝对控股）；
5. **"借钱不用还"的错误思维**：银行强调便利、政府政绩招商、企业幻想"大而不能倒"——三方共谋；
6. **贷款与现金流的错配**：短期借款滚长期投资（造厂房、买设备、并购），期限错配必然爆雷。

- **When**：复盘任何一个出险项目，逐条对照——多数项目同时命中3条以上。
- **How**：先区分"金融供给不足"假说与"流动性过度"事实（见实操示例）。

### 框架二：债务不良四大成因（惠特曼/美国范式）
1. **缺乏资本市场融资通道**：商业模式依赖持续融资的公司一旦被切断（信任危机、评级、监管干预），迅速陷落——案例：德莱塞公司（1990）、贝尔斯登（2008）；
2. **经营恶化**：经济周期、成本上涨、竞争、管制变化、失当战略——通常多因素联合发作（案例：家得宝国际 HPI）；
3. **会计账目恶化**：GAAP 数字"自成体系"，盯市会计（公允价值）会把波动性搬到担保人账上，制造账面巨亏（案例：MBIA）；
4. **大量表外或有负债**：侵权索赔、担保、复杂衍生品的隐性债务，爆发突然、难以预计（案例：USG 石棉索赔，资产健全仍主动申请第十一章以控制价值流失）。

- **When**：拿到任何不良债权/不良企业，先判定成因属于哪一类——它决定你的分析路径（见框架四）。

### 框架三：违约三阶段模型（财务体温计）
用**年经营性现金流净值**与贷款本金、利息比较：

| 阶段 | 条件 | 状态 |
|---|---|---|
| ① 正常还款 | 现金流净值 > 本金 | 健康 |
| ② 勉强还款 | 本金 > 现金流净值 > 利息 | 靠借新还旧/过桥维持，风险敞口已暴露 |
| ③ 无力还款 | 现金流净值 < 利息 | 首次付息失败 → 宣布提前到期 → 违约爆发 |

- **When**：尽调、投后监控、谈判定价。进入②应立即收缩投资、回笼现金；③则为时已晚。

### 框架四：成因 → 分析路径（惠特曼决策规则）
- 成因是**资本结构不健全**（而非业务基本面）：从**重组的可能前景与可行性**入手；
- **业务基本面有疑问**：安全假定=最坏情况（第十一章重整或第七章清算），重点寻找重组后能**全额支付**的证券；
- **侵权/合同索赔导致负债骤增**：同样假设最坏，并聚焦第十一章后仍有偿付能力的部分；
- 债权**有充足抵押品（过度抵押）**：成因分析只有学术价值——只要抵押价值高于破产前债务且不减值，回收基本有保障。

## 关键概念
| 术语 | 定义 |
|---|---|
| 债务不良（惠特曼） | 企业满足当前或未来偿付要求（利息、本金、再融资、保险索赔、侵权索赔）的能力受到或预期受到严重破坏 |
| 流动性 vs 清偿力 | 前者是现金流断点，后者是资产不抵负债；不良投资最常见的误判就是把二者混为一谈 |
| DIP 融资 | debtor-in-possession financing：破产保护期间的存续经营融资，破产博弈的关键变量 |
| 过度抵押 | 抵押品价值超过破产申请前债务价值，债权人回收的一项"护身符" |
| 支点证券（fulcrum security） | 重组中有可能转换为股权的、参与重组的最优先证券 |
| 盯市会计 | 按公允价值记账；波动可严重扭曲报表（MBIA 2007财年每股收益被拽至 -15.22 美元） |
| 表外或有负债 | 或有侵权、造假责任、SPE 债务、衍生品等，破坏性难以预计且突然发生 |
| 期限错配 | 短期资金投长期资产；企业爆雷的工程学根源 |

## 思维模型
- **归因三问**：企业出险，先问"是供给少了还是杠杆过了？是经营问题还是结构问题？是一次性冲击还是模式性缺陷？"——多数中国式爆雷的真相是**流动性过度**，而非供给不足。
- **"借钱不用还"的三个识别信号**：①银行主动上门请用款；②政府配套政策怂恿扩产；③企业以头部地位幻想绑架政府——三者出现任一，风险警戒升级。
- **成因先行原则**：成因类别 → 决定分析框架 → 决定最坏情况假设 → 决定报价底线。
- **会计数字的意义 > 数字本身**：不良/价值投资不关心 GAAP 数字是多少，而关心它意味着什么（惠特曼）。

## 反模式
- **把爆雷归因于"金融支持不够"**：明天系、华信、安邦等案例中，真相恰是流动性过度充裕、杠杆远超还款能力。
- **只看利润表不看现金流表**：净利140亿也可能还不起债——用经营现金流净值做体检。
- **忽视表外或有负债**：它不出现则已，一出现就是致命级（石棉、担保链、衍生品）。
- **对无担保债权不做成因分析**：无担保索偿的回收完全取决于成因与处置路径，跳过这步等于盲投。
- **在第一/第二阶段的错配中加仓**：短期借款滚长期投资的企业，只会加速滑向第三阶段。

## 实操示例
**A企业财务体检（重建自书中数据）**：
- 商场酒店板块：有息负债 1700 亿元（其中短债 850 亿元）；营业收入 400 亿元；净利润 140 亿元；经营性现金流净流入 130 亿元；按 5% 成本估算年利息约 85 亿元。
- 体检结论：经营现金流（130 亿）勉强覆盖利息（85 亿）→ 处于阶段②；但短债 850 亿 ＝ 经营现金流的 6.5 倍 → 已具备阶段③特征。
- 教训：该公司此前两年已出售资产回笼 1100 亿元仍未能脱困——**错配一旦形成，变卖资产只是延缓违约，而非避免违约**。

**HPI（家得宝国际）的恶化链条**：1997年借助收购实现增长（负债/EBITDA 升至 3.2 倍以上）→ 1998 年起遭遇原材料涨价、海外进口竞争 → 前三大客户销售额占比升至 74% 以上 → 毛利从约 24% 一路跌至 17% 附近 → 2006 年11月未能支付有担保次级票据利息 → 申请第十一章预打包破产。"后来很明显的事，在当初做决定时却并不那么显而易见。"

## 要点回顾
1. 成因分中国清单（六因素）与惠特曼范式（四类）两套——互相印证，互为补充。
2. 财务体温计：经营现金流净值 vs 本金/利息，三阶段一测便知。
3. "借钱不用还"的错误思维 + 期限错配 = 中国式爆雷的标准配方。
4. 分析成因不是为了写报告，而是为了选路径：结构问题看重组、基本面问题假设最坏、过度抵押可安心。
5. 破产保护是博弈的开始——把这个假设写进任何一份投资测算。
6. 盯市会计与表外或有负债是两种"账外杀手"：一个制造账面波动，一个制造突然死亡。
