# 第19章 自愿交换与破产法框架：庭外博弈与庭内规则

## 核心思想
自愿交换（庭外重组）的最大敌人是**"不让步问题"**——只要拒绝交换的人能白享信用增级，交换就注定失败；推动交换的唯一方法是**让不参与者处境变差**。而第十一章的全部程序规则（自动冻结、充足保护、计划确认、强行批准、绝对优先）是**一切重组活动的底层操作系统**——无论你在庭外还是庭内谈判。

## 核心框架

### 框架一：自愿交换——为什么经常失败
- 债权人知道两件事：①**他们不会被迫放弃现金偿付的合同权利**（TIA 316(b)＋契约条款）②如果拒绝交换而别人接受了，公司债务负担下降、信用度改善，**自己手里债券的市场价值反而会上升**——这就是 holdout（不让步）的搭便车逻辑；
- 经验事实：试图交换80%以上未偿债务的尝试"往往不会成功"；失败名单不断加长（迈朗能源、科尔柯、路易斯能源、西部联合、第一城市银行、新罕布什尔公共服务等）；
- 关键区分：**债券公众≠股票公众**——股票持有人见到溢价就交换；债券持有人（尤其是二级市场专业投资者）不急于接受，除非看到"不交换的损失"。

### 框架二：推动交换成交的两种设计
1. **修改契约使不交换者次级化**：非现金条款（与现金支付无关的）**50%以上持有人同意**即可修订——让不交换的旧债等级低于新债；
2. **缩短新债到期日**：把交换获得的新债期限定得比旧债短（如新PIK债9年6个月 vs 旧债10年）——用到期时间实现事实上的优先级提升（**合同化优先级＋到期时间，是不良债券的两种优先级形式**）。

### 框架三：类零息债机会（不需要现金的投资者专属）
- **USG案例**：2001年借第十一章控制石棉诉讼成本并保留普通股价值——唯一受损类别是石棉受害者个人索偿；6%无担保票据获全额＋破产后利息＋利息的利息，**等同于购买到期收益率12%的零息债**；
- **MBIA 14%盈余票据**：可视为"类零息债"，大概率全额偿付（含累计利息），即便利息支付暂时延期——当期收益率29.1%、回购收益率39.6%（2013年）、到期收益率29.1%（2033年）；
- **适用对象**：不需要定期现金回收的投资者——"债券上会有很多等同于投资零息债券的好机会"。

### 框架四：破产程序地图（投资必知的路标）
- 章节体系：第七章清盘／第十一章重组（也可用于清盘）／第十五章跨境；第七章备案的预期结果=解除债务责任（727(a)）；
- 启动方式：**自愿**（301，绝大多数）vs **非自愿**（303，极少：3个无担保债权人＋≥12,300美元；保险公司/银行豁免；错误申请的债权人责任大）；
- **挑选法庭**（28 USC 1408：居住地/常住地/主要经营地/主要资产地四种选择）：纽约南区与特拉华为代表"善待债务人"（允许付关键供应商重组前欠款、给债务人更多筹码）；凯马特案的教训：有的法庭会让**2,300家供应商退回收到的付款**——管辖选择即战略选择。

### 框架五：五大程序机制（博弈工具）
| 机制 | 要点 |
|---|---|
| **自动冻结**（362） | 备案即生效：阻止讨债、留置权行使、财产转移；**破产前债务的未付利息停止累计**——时间是债务人的朋友；解除冻结须证明"缺乏足够保护"（362(d)）或财产非必需 |
| **充足保护**（361） | 让担保债权人让渡处置权：额外/替代留置权、现金/定期现金偿付、监管保护、超级优先行政索偿——**担保债权人是破产期间唯一可能继续获得利息的类别** |
| **资产出售**（363） | 正常商业外的交易须通告听证；常用**假马竞标人**（stalking horse）锁定底价：后续竞标须加价5%+、假马可获加顶费（topping fee）、合理费用报销 |
| **待执行合同**（365） | Countryman定义：任一方未履行事项将构成实质性违约的合同；有利的继续/转让、不利的废除；违约合同继续须"补救＋赔偿＋未来保证"三条件；**非住宅租约：210天决定期，拒绝后赔偿上限≈1年租金或剩余租金的15%取大（不超3年）** |
| **废止权**（544/546/547/548） | 撤销破产前私下优待：优先转移（547：90天，内部人1年）／欺诈性转让（548：低于合理价值＋资不抵债，**这是击穿担保链与LBO交易的常用武器**）／未记录或瑕疵留置权的技术性无效 |

### 框架六：计划与确认（1123/1125/1126/1129）
- **披露声明**（1125）：让"虚构的理性投资者"能做出有充分信息支持的判断——含清盘分析与持续经营分析；
- **计划五强制条件**（1123）：明确分类、明确受损与否、规定受损类别处理、同类同处置、实施手段；
- **分类技巧**（1122）："非常接近"的索偿可放不同类别——**只要有一类接受，配合强行批准，计划支持者实际可以保证计划通过**（分类是策略工具）；
- **接受规则**（1126）：每类须 **2/3金额＋1/2人数**同意；无所得类别自动视为反对、无损类别自动视为接受；
- **确认三重门**（1129）：①**最大利益测试**——每个反对者按计划所得 ≥ 第七章模拟清盘所得（支持者要提供模拟清盘分析表）②**强行批准（cram down）**——对反对类别无歧视、公平公正（担保索偿：留置权保留＋现金偿付总额=索偿额＋现值≥财产权益；无担保索偿拒绝时，**后顺位者不得获得任何分配=绝对优先原则**）③**可行性测试**——不得需要第二次、第三次破产。

## 关键概念
| 术语 | 定义 |
|---|---|
| 不让步问题（holdout） | 拒绝交换者搭便车享受信用增级——自愿交换的结构性障碍 |
| DIP | 破产保护债务人——留任经营的原管理层（信托人替代极罕见） |
| 假马竞标人 | 设底价的初始竞标人——获加顶费，后续出价需加价5%+ |
| 充足保护 | 担保债权人让渡抵押物处置权时的对价（利息/替代留置/超级优先索偿） |
| 最大利益测试 | 计划给每个反对者的价值≥第七章清盘价值 |
| 强行批准/绝对优先 | 非全部类别接受时，法院可强批；但反对的无担保类须优先受偿原则保护 |
| 1111(b)投票 | 担保不足的债权人可以全体投票选择被按"全额头寸"对待（更高总额、更少现值弹性） |
| 预打包 | 备案前征集接受（1126(b)）＋承认破产前委员会——省钱＋法律保护双收 |

## 思维模型
- **交换谈判公理**：**"让不参与者受损"**——所有成功交换的设计都指向同一目标；没有这个，报价再高也会失败。
- **冻结=计时器重置**：自动冻结停止利息累计＋DIP融资输血——债务人在庭内获得了"重设时钟"的能力；**债权人评估庭内/庭外路径时，必须把冻结期的复利损失算进去**。
- **分类即策略**：计划分类不是会计技术，是投票数学——理解分类→接受规则→强行批准三者的连锁，就能预判计划通过路径。
- **绝对优先的边界**：绝对优先只约束"强行批准"场景；**各方同意时，低顺位可以拿到钱而高顺位未全额（跳跃分配）**——这正是庭外协商的空间所在。
- **假马机制迁移**：锁定底价＋保护费用＝资产拍卖的入场设计——竞买不良资产包时同样适用（报价保护、排他期、分手费）。

## 反模式
- **轻视holdout收益**：参与交换前必须计算"拒绝并观察"的期望值——否则就是免费送给发行人信用增级。
- **忽视法庭选择的地缘差异**：同一案件在不同辖区结果可能天壤之别（凯马特供应商退款）。
- **不懂冻结的复利账**：把庭内重组当作"慢"——对债务人而言那是利息停摆的庇护所。
- **误读绝对优先**：在协商场景下以为"高顺位必须先全额"——失去换取次级让利的谈判空间。
- **漏算废止权风险**：受让债权前先查：有没有可被547/548撤销的破产前转移？（尤其关联担保、近期资产处置）

## 实操示例
**强行批准（cram down）计算实例（重建自书中示例）**：
- 场景：XYZ公司担保索偿1000万美元，抵押物估值700万美元 → 债权结构=**700万担保＋300万无担保**（506(a)）；
- 强行批准利率：8%/年，计划期5年等额偿付；
- 年偿付额 = 700万×0.08 ÷ (1−1.08⁻⁵) = **1,753,195.2美元/年**；总额8,765,976美元（≥700万条款要求）；
- 现值校验：以8%折现的现值=700万=持有人占债务人财产权益的价值（双重条件同时满足）；
- **变体**：若该类债权有2/3金额同意按1111(b)全体头寸对待——则按**1000万**总额设计偿付（现值仍需≥700万），偿付计划相应加重。
**练习**：把这个计算应用到你在重组谈判中拟提供的"递延现金方案"上——先校核现值条件，再谈年限与利率。

## 要点回顾
1. 自愿交换的结构障碍=holdout；解法=让不参与者受损（次级化/缩短到期）。
2. 类零息债（USG/MBIA式）是不需要现金流的投资者的专属机会。
3. 破产地图：自愿/非自愿、挑法庭、DIP留任、委员会生态。
4. 五大机制：冻结（停息计时器）、充足保护、假马拍卖、待执行合同、废止权。
5. 计划机器：披露→分类→投票（2/3+1/2）→确认（最大利益/强行批准/可行）。
6. cram down计算：担保不足头寸拆分＋现值条件；绝对优先仅在强批时严格适用。
