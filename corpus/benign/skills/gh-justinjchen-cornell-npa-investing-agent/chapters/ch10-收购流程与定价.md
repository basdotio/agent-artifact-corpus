# 第10章 收购流程、定价与交易结构：从邀请函到中标的完整链路

## 核心思想
一次不良资产包收购是一条**标准化流水线**：银行组包封包 → 发《邀请函》 → AMC签保密承诺取档案 → 现场尽调 → 撰写收购方案 → 投标竞价。链路上两个致命环节：**方案的核验**（一处疏忽影响整个报价）与**投标机制的选择**（暗标可能让你多付千万元）。

## 核心框架

### 框架一：收购全流程八步
1. **银行内部启动**：贷款违约后转入资产保全部门；总行按"利润指标＋不良率考核"向分行下发转让限额（不良率低的分行甚至是"必须腾出"的任务）；
2. **选包**："3户及以上"＝3个不同债务人的贷款（同一债务人3笔贷款算1户；**关联企业有时也按1户**看待）；
3. **确定基准日**：全包债权本息计算截止日 → 逐级上报 → 总行审批 → **封包**（户数金额不再变动）；
4. **发出《邀请函》**：市式行文，载明总金额、报名时间方式、注意事项与联系方式；
5. **AMC决策是否参与**：五因素——项目时间是否够、债务人情况、抵质押率高低、抵押物在省内还是省外、债权户数金额与放款时间；
6. **签约取档**：回《邀约确认函》＋《保密承诺》→ 银行发送电子版信贷档案（借款/保证/抵押合同、产权证书、主体资料、财报、诉讼资料）——**这是估值的主要依据**；
7. **现场尽调＋撰写收购方案**；
8. **投标**（现场暗标或网络竞价）。

### 框架二：收购方案撰写三原则（核验清单）
1. **判决书最大**：经过判决的案子已涤除隐藏法律风险——银行资料与判决书不一致的，**以判决书为准**；
2. **明确担保范围**：多笔发放＋最高额抵押时，看清抵押担保对应的是全部贷款还是单笔（如授信3000万分3次各1000万 vs 最高额5000万——范围差之毫厘，估值谬以千里）；
3. **要素齐全**：展期后保证人/抵押人是否重新签名确认（脱保风险）；放款银行与抵押权证登记主体是否一致（主体不一致＝被告异议的抓手）。

### 框架三：估值四因素（报价决策盘）
1. **债权本身的实际价值**（尽调挖掘出的还款来源）；
2. **银行预计的回款值**（出让方的心理锚）；
3. **其他竞标AMC的预计估值**（竞争环境）；
4. **你的投标意愿**（战略与资金约束）。
- **附加判据**：若你的估值显著高于他人，只有两种解释——**你的尽调更细**（掌握了别人没有的重要还款信息，如政府收储补偿款），或者**你估得太乐观**（把债务人还款能力与抵押物想得太美）。

### 框架四：两种定价维度（买卖双方的公式不同）
| 视角 | 定价公式 |
|---|---|
| 银行（卖方） | 预期未来现金流贴现 ＋ 费用开支 |
| 买方（投资方） | 预期投资回报率 － 风险溢价 → 需要**大幅折扣**提供安全边际 |
- 市场事实：中国买受人主体为AMC与民间投资人；美国是对冲基金与私募基金——**交易对手类型决定回报率要求**；
- 周期铁律：危机中抛售→折扣大（不能反映资产真实价值）；复苏初期→价值向上补齐→此时买入减少损失；
- 价格发现前提：**信息充分披露**（贷款资料透明、抵押权证完备确权）。

### 框架五：两种投标机制（规则即策略）
| | 现场投标（主流） | 网络投标（中小银行趋热） |
|---|---|---|
| 规则 | 密封**暗标**，各自报一口价；银行保留底价保密；最高价且高于底价者中标 | 交替加价（如起拍8000万、每次加10万） |
| 风险 | **第一名可能比第二名多付上千万元**（多付也得付） | 价差仅在加价幅度内，无"多付"风险 |
| 程序 | 公证处公证、唱标、拆银行底价封套 | 平台留痕、操作简单（淘宝等） |

## 关键概念
| 术语 | 定义 |
|---|---|
| 保留底价 | 银行设定的保密最低成交价——低于它，最高报价也不成交 |
| 邀约确认函/保密承诺 | 参与尽调的前置文件；签署后获取电子信贷档案 |
| 暗标博弈 | 一口价密封报价机制：报价针对"对手"而非仅针对"资产" |
| 抵质押率 | 贷款本金与抵押物估值的比率——影响参与决策的核心指标 |
| 板结资产 | 收购后因区位/租赁瑕疵难以快速处置、资金被沉淀的资产 |

## 思维模型
- **暗标博弈思维**：你的报价不是回答"资产值多少"，而是回答"比第二名多多少"——先估对手盘，再定量。
- **安全边际铁律**：折扣的本质是对不确定性的补偿——你的不确定性（司法周期/租赁瑕疵/区位）越大，需要的折扣越深。
- **"判决书最大"**：冲突材料里找权威——判决＞银行台账＞口头说明；没有判决的，用要素互印（合同-借据-权证-公告）交叉验证。
- **流水线思维**：把收购当生产流程管理——每一步都有输入输出和质检点（保密承诺→档案完整性检查→现场问题清单→方案数据双核对→报价决策），任何一步跳步都会在后一步加倍付账。

## 反模式
- **方案数字不复核**：一处疏忽（如把抵押金额当回款依据）影响整个报价；数据要反复核对几次。
- **担保范围想当然**：不区分"最高额担保对应全部 vs 单笔贷款"，估值系统性偏差。
- **暗标场景按估值出价**：忽略竞争机制，第一名多付千万的学费。
- **疫情/周期下反向操作**：在恐慌抛售期要求"公允价"（买不到）；在复苏期执意"捡漏"（已无漏可捡）。
- **跨省抵押物轻视**：抵押物分布决定处置成本与周期——远距离资产的管理半径必须计入报价。

## 实操示例
**一次完整收购的作战时间线（重建自书中案例）**：
- 5月13日：银行发出《杭州分行不良资产处置竞价及交易邀请》→ AMC项目经理微信问询+获取债权清单与信贷档案；
- 5月14–16日：案头分析（债权/担保/时效要件），圈定4处抵押物；
- 5月17日：银行组织现场尽调（银行向导+各AMC+评估公司同行），当天跨湖州长兴（商业广场）与绍兴柯桥（沿街店铺）两处；
- 5月19日：赴衢州看最后一处（酒店）——高铁1小时20分＋出租2公里；
- 后续：汇总收购方案 → 数据三核对 → 内部定价会议 → 投标。
**暗标报价决策练习**：设你的成本线为P*、预估第二名报价区间为[Pa, Pb]。你的最优报价＝min(你的估值上限, 略高于Pa的档位)——但要留足"多付容忍度"：多付的部分不能侵蚀你的底线收益。

## 要点回顾
1. 八步流水线：组包封包→邀请函→保密签约→取档→尽调→方案→投标。
2. 参与决策五因素：时间、债务人、抵质押率、抵押物分布、户数金额。
3. 方案三原则：判决书最大、明确担保范围、要素齐全（展期重签/主体一致）。
4. 估值四因素：债权实际价值＋银行回款预期＋他方估值＋你的意愿。
5. 买卖双方定价公式不同——买方需要折扣提供安全边际。
6. 暗标与网络竞价是两种博弈结构——规则决定策略，别用错地图。
