# 第18章 不良资产投资的五大真相（惠特曼核心章）

## 核心思想
五大真相是惠特曼体系的宪法条款：①现金偿付权利**不可剥夺**（除法庭程序或债权人同意）；②**第十一章规则影响所有重组**（包括庭外）；③证券的价值来自**未来现金救济现值**（不论救济来自何处）；④重组**让债权人付出昂贵代价**；⑤债权人**只有合同权利**，没有剩余索取权。"第十一章破产保护不是结局，而是一个开始。"

## 核心框架

### 真相一：没人能剥夺债权人对现金求偿的权利
- 法律根据：1939年《信托契约法》（TIA）第316(b)条——**未经持有人同意，到期及之后获得本息偿付的权利不得受损**；适用门槛：期限>36个月且本金≥1000万美元的公开交易债务；
- 两个次要例外：①75%本金持有人同意可推迟利息支付**不超过3年**（316(a)(2)）；②契约可限制发起诉讼以保护留置资产（316(b)）；
- **衍生结论**：期限短的信用工具在"避免第十一章"的情形下享有同等优先级；进入第十一章后，清偿优先级由**契约与债权人协议**决定，与到期日无关；
- **GMAC实战样本（2008年10月）**：7.375%优先无担保票据，价格62，当期收益率12.5%，到期收益率53.42%；分析三问：①是否保持正常？——估计70%-75%概率应付得了；②是否参与重组？——25%-30%概率换得新证券（重组价值估计60-90美元）；③控股股东（Cerberus持51%）会不会发起自愿交换？——交换价预期80-85美元，但"作为股东不会自杀"，强推交换的威胁可信度低。

### 真相二：第十一章规定影响到所有重组活动
困境公司的重新资本化有**三条路径**：
1. **自愿交换**（庭外）：需逐个争取同意；常因"用市场价值更低的新工具换旧债"的假设站不住脚而失败——除非能向债权人展示"不交换就有损失"；
2. **常规第十一章**：风险与不确定性大；各委员会（活跃的律师/会计师/投行）从自身利益出发；公司承担自己＋对方阵营的全部专业费用；
3. **预先打包（第1126(b)条）**：破产申请前取得同意、备案后延续——**大幅降低不确定性、风险与费用**；适合"收入稳定可预测＋资本结构简单＋或有负债少"的困境企业。
- 本质：一切重组都是**重新资本化**——成功的重新资本化＝减少、推迟或取消现金利息和本金的合同承诺；健康企业的重组（LBO/MBO）则相反，总是**增加**现金责任。

### 真相三：证券的实质特征（价值来自现金救济）
- 投资价值＝**未来现金救济的现值，不论救济来自何处**（推翻约翰·布尔·威廉姆斯1938年的经典定义）；
- 证券分类：预先计划现金承诺**法律可执行**→债务/信贷工具；不可执行→优先股；混合→可转债等；無现金权利的所有权→普通股；
- **现金救济三渠道**：①公司支付（利息/本金/溢价/分红/回购）②市场出售（不止OPMI市场，还含并购市场）③公司控制权（治理价值）；
- **非控制型股东的关键**：重组中取得普通股的被动投资者（银行/保险公司）需要**尽早的退出市场机会**，否则这些证券"没有或仅有很小的价值"；第1145节限制（未付钱且持有一年内的股票，不得取得5%以上并抛售；违规后每周限售15%成交量或1%流通股）；
- Phar-Mor案警示：为保留NOL而限制债权人出售重组股票=扼杀证券价值；DIP在排他期内持有的"水下"证券没有经济价值但有**治理价值**——控制型证券与非控制型是两种商品。

### 真相四：重组给债权人带来昂贵代价
- 债权人将被投行、律师、管理层**层层盘剥**；债务人承担除美国政府外所有债权人的专业费用；
- 学术界"直接成本≈债务账面值+股权市值3.1%"的测算有两大错误：①应用**重组计划确认日**的资产价值（而非破产备案前）；②应看专业费用**占公司现金的百分比**（因为费用是现金支付且优先于申请前债务）；
- 小型第十一章案：不采用预打包（或同等）方式**非常不经济**；
- 计量直接成本时必须计入**四项益处**（对冲项）：①案件期间不付无担保利息②税法利益（破产企业COD不计收入等）③自动冻结④DIP超级优先融资。

### 真相五：债权人只拥有合同上的权利
- 债权人没有剩余索取权——公司正常经营时，妥善公平行使职责的受益人是**所有者**（股东）；
- 债权人只有贷款协议/债券契约中的权利＋法律保护（反欺诈、反欺诈性转让）；
- **资不抵债时董事会职责转向债权人利益**（"资不抵债"的模糊区域是责任诉讼的战场）。

## 关键概念
| 术语 | 定义 |
|---|---|
| TIA 316(b) | 未经同意不得损害到期本息偿付权的法定保护条款 |
| 不让步问题（holdout） | 个别债权人拒绝交换而搭便车享有信用增级——自愿交换的最大障碍 |
| 预先打包（1126(b)） | 破产备案前取得计划同意、备案后延续执行的程序 |
| 重新资本化 | 重组的本质：减少/推迟/取消现金承诺（困境企业）或增加承诺（健康企业LBO） |
| 现金救济三渠道 | 公司支付、市场出售（含并购市场）、控制权/治理价值 |
| 直接成本错误 | 学术界低估费用负担的两大测算错误（时点与口径） |
| 四项对冲益处 | 无担保免息＋税法利益＋自动冻结＋DIP融资 |

## 思维模型
- **"开始而非结束"**：把违约事件当作分析的起点——问"之后会发生什么"（重列？重组？清算？），而不是问"会不会违约"。
- **权利强度扫描**：拿到债权先看三样——契约的现金权利保护（TIA/契约条款）、到期期限、优先级结构——它们决定你在博弈中的底牌。
- **交换谈判的公理**：**必须让不参与者受损**。任何自愿交换方案如果不能让"不交换的处境变差"，注定失败（修改非现金契约条款50%即可；缩短新债到期日可实际提升优先）。
- **利益链条透视**：重组桌上每个人（律师/投行/委员会/管理层）都从"过程"中收费——只有债权人从"结果"中获得回收。别指望有人主动为你加速。
- **证券=现金救济的容器**：评估任何重组中获得的证券，只问一句——**它的现金救济从哪条渠道来？** 三条都不通的，价值为零。

## 反模式
- **用"是否违约"做信贷分析**：不良投资假定违约可能，关键是违约后剧本。
- **接受"市场价值更高"的交换话术**：债权人要的是内在价值与现金权利，不是换个工具的市场标价。
- **为保NOL锁死股东退出**：非控制型证券没有退出通道=没有价值（Phar-Mor教训）。
- **用账面百分比测费用负担**：现金口径才是真实的回收侵蚀度。
- **默认"重组对我有利"**：专业费用、时间成本、税务（OID）会同步侵蚀——先算净利润再上场。

## 实操示例
**GMAC票据决策全流程（重建）**：
1. 底牌确认：优先无担保＋TIA保护（现金权利不可剥夺）；
2. 情景概率化：正常70%-75%（YTM 53.42%）／重组25%-30%（重组价值60-90美元）／清算（尾部）；
3. 对手方剧本推演：Cerberus不会为逼交换而自残（其股东身份决定它不敢轻易走第十一章）；
4. 期望值测算：0.72×正常现金流回报＋0.28×重组价值折现 vs 买入价62；
5. 决策：风险补偿充足（即便重组，60-90的重组价值也远高于62以下的极端假设之外的损失容忍）——**这就是"风险回报比率由价格转变"的实操演绎**。
**对照USG**：6%票据获全额＋"利息的利息"（等价于12%到期收益率零息债）；石棉受害者是唯一受损类别——**看清自己在索偿结构中的位置，先于看清公司基本面**。

## 要点回顾
1. 现金偿付权不可剥夺是整套体系的基石（TIA 316(b)＋契约条款）。
2. 第十一章规则影响所有重组；预打包是困境企业的最优通道（简单结构＋稳定收入）。
3. 价值=未来现金救济现值；三渠道（支付/出售/控制权）决定证券价值形态。
4. 重组费用由债权人阶层实际承担；测算要按现金口径＋四项对冲益处。
5. 债权人只有合同权利；资不抵债时董事职责转向债权人（模糊地带）。
6. "第十一章不是结局，而是开始"——一切分析从违约之后展开。
