# 第33章 盘活重组：租赁、承包、托管与资本运营

## 核心思想
处置不止"卖"一条路，还有"经营"——把资产从"待售品"变成"生息品"。**租赁、承包、托管**是同一组"所有权与经营权分离"工具的三个档位；**资本运营**则是更高维的玩法：经营资产→经营企业→经营资本。核心等式：**全周期价值 = 处置价 + 持有期现金流 + 增值空间**。

## 核心框架

### 框架一：租赁的四种类型（使用权变现工具箱）
| 类型 | 要点 | 处置场景 |
|---|---|---|
| **融资性租赁** | 出租人融资购设备→租给承租人；分期收租；期限3-5年（大设备10年+）；期满多"留购"（名义价取得所有权）；承租人负责维修保险——**实质是信贷** | 设备类资产"以租代售" |
| **服务性租赁** | 短租（月/天/小时）；出租人负责维保；可中途解约；租费低 | 临时性设备 |
| **企业租赁经营** | 整企业出租给个人/集体经营；承租人缴租金+保资产完好；期3-5年；**过渡性强、适用小企业、易接受、安全性高** | 小微困境企业盘活 |
| **经营性租赁** | 融资性以外的一切租赁；可撤销、不完全支付；租金高于融资性；适合更新快的设备 | 办公设备/科技产品 |
- **与第11章呼应**：抵押物尽调中"租赁在抵押前还是抵押后"决定价值——这里给出正面用法：**主动租赁=把不动产的持有期变成现金流期**。

### 框架二：承包经营（责任转移工具）
- **核心内容"两包（保）一挂"**：包上交国家利润＋包资本优化组合完成技术改造＋报酬与效益挂钩；
- "一包"的关键：**包死基数、确保上交、超收多留、欠收自补**——基数确定要参考前三年利润水平/设备完好率与开工率/市场需求；
- **租赁 vs 承包五差异**：①剩余劳动分配形式（租金 vs 利润）②税收适用（个人收入调节税 vs 资金税/工资调节税）③**两权分离程度**（租赁更彻底：经营活动全自主、追加投资归承租者）④适用范围（租赁限于中小企业；承包可大可小、可层层承包）⑤资产增量归属（租赁归承租者，承包终归国家）；
- **承包制的四大局限（今读仍警醒）**：①**扭曲企业法人制度**（绕开法人直接分权，经营者多重人格）②产权未独立化（不能拍卖重组资产、增量归属两难）③所有权约束仍是**行政性约束**④承包基数困境（市场变动下：调基数=强化干预，不调=违约借口）。

### 框架三：托管（代理运营工具）
- 概念：所有权不变，将**经营管理权**委托给专业机构/团队；
- **AMC受托处置业务**（轻资产模式）：不同于买断处置——**不收购资产包**，接受委托代为追索受偿，收服务费，**不对回现金额承诺兜底**；
- **NAMA"收购反委托"**：从银行收购不良后**继续委托银行管理**（并由《收购反委托业务最低服务标准守则》约束）——收购方保留所有权、原机构保留服务收入与客户关系；
- **风险机构托管**（第6章救援工具箱）：只更换三会与财务、派驻外部高管、调转经营方向——"托管"在机构救助中的用法；
- **When**：三种托管场景——资产托管（受托处置）、业务托管（收购反委托）、机构托管（风险化解）。

### 框架四：资本运营（升维玩法）
- **主体**：资本所有者或其授权代理人（**不是经营者**——两者动力机制不同：经营者经营他人资本，追求个人报酬最大化；资本运营涉及整体出售/并购决策，超出经营者权限）；实际主体：国有控股公司（纯控股 vs 混合型）＋AMC（一般以纯控股模式运作）；
- **客体五要素**：资本投入（前提）→资本控制（防流失/道德风险）→资本扩张（参股/并购/联合）→资本流动（向效益最大化方向）→**资本增值（唯一目的，前四者皆为手段）**；
- **三种运营形态**：**实业资本运营**（流动性差、回收慢、收益稳、易操作）／**金融资本运营**（依托金融市场，以工具交易获取价差，不以控制为目的）／**产权资本运营**（整体资产的出售、拍卖、重组、联合——层级最高）；
- **方式菜单**：投资、参股、控股、购买、兼并、重组、托盘、租赁——**购买、兼并、重组是重头戏**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 两权分离梯度 | 租赁>托管>承包（经营权分离的彻底程度） |
| 两包一挂 | 承包制的经典结构（包利润+包资产优化+报酬挂钩） |
| 受托处置 | 不买断、代追索、收服务费、不兜底的轻资产模式 |
| 收购反委托 | 收购不良后委托原机构管理的模式（NAMA式） |
| 资本运营五要素 | 投入/控制/扩张/流动/增值——前四手段、第五目的 |
| 托盘 | 以资金承接维持价格/流动性后择机退出的操作 |

## 思维模型
- **"从清算思维到经营思维"**：拿到资产先问三个价——快速变现价、持有期现金流（租金/经营收益）、增值后价。三者相加对比处置成本，再决定卖还是养。
- **"两权分离刻度盘"**：租赁（彻底）→托管（中等）→承包（有限）——按对资产控制力与专业能力选择档位。
- **"受托处置=不良界的代运营"**：不压资本、赚服务费、不兜底——轻资产机构（如服务商型AMC）的生存模式。
- **"资本运营主体≠经营者"**：决策层级决定谁上桌——重大出售/并购的决策权在所有者或其代理人。
- **"承包基数教训"**：任何委托经营合同都要预设市场变化的调价机制——否则重蹈"调也错、不调也错"的困境。

## 反模式
- **对无经营能力的资产硬做经营**：不是所有抵押物都适合"续建/开发"——先比对处置与经营的全成本。
- **托管不设服务标准**：NAMA有《收购反委托最低服务标准守则》——没有标准约束的托管=责任真空。
- **承租/经营者道德风险失控**：掠夺性经营、超载使用、转租套利——用保证金、抵押担保、监督条款对冲（租赁合同的基本动作）。
- **把资本运营做成本业炒股**：金融资本运营有明确边界（不以控制为目的、依托市场）——越界即变形。
- **忽视行政色彩遗留**：老文本中的"国家/主管部门"语境要替换为现代的股东/监管者框架再使用。

## 实操示例
**一处抵押厂房的四方案比选（结构化决策模板）**：
| 方案 | 3年现金流测算 | 适用条件 |
|---|---|---|
| A 快速变现 | 现价拍卖7折回收 | 市场深度好、无经营能力 |
| B 出租收息 | 年租金≈评估价4%-6%＋3年后处置 | 区位好、易出租、租约可控 |
| C 托管经营 | 服务费+经营分成，不压资本 | 有专业运营方、原经营者配合 |
| D 续建开发 | 投入续建资金、2-3年后出售 | 在建工程/地段稀缺＋团队能力 |
- 决策规则：**B/D与A的差 ≥ 资金成本+经营风险溢价**才选经营路线；否则现金为王。
**受托处置协议要点清单**：委托范围（追索/受偿）＋服务费结构（固定+回款分成）＋**不兜底条款**＋服务标准与报告义务＋权限边界（不得和解/减免的上限）＋退出机制。

## 要点回顾
1. 租赁四类：融资性（信贷变体）/服务性/企业租赁/经营性——把持有期变现金流期。
2. 承包"两包一挂"+五差异+四局限——委托经营的经典制度教材。
3. 托管三场景：资产（受托处置）、业务（收购反委托）、机构（风险救助）。
4. 资本运营：主体=所有者/代理人；五要素（前四手段第五目的）；实业/金融/产权三形态。
5. 全周期价值公式：处置价＋持有期收益＋增值空间——经营路线的判断基准。
6. 轻资产模式（受托处置）与重资产模式（买断）的选择取决于资金与能力的比较优势。
