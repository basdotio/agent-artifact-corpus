# 第23章 投后管理与资产台账：债权生命周期的仪表盘

## 核心思想
投后管理是把收购时的"纸面价值"变成真金白银的日常操作系统。三件核心事：**第一动作不留死角**（主体变更／时效维护／启动诉讼），**台账做驾驶舱**（24列动态管理），**把债务人当问题源头**（谈话机制）。记住两条铁律：**时间是成本**（购入日起利润逐日变薄）、**进项与出项决定策略去留**。

## 核心框架

### 框架一：投后第一动作清单（收到债权后的黄金窗口）
1. **维持时效**：刊登公告＋发送催收通知书＋变更诉讼主体——转让导致时效中断、重新起算；**"发催收通知书"的效力优于"刊登公告"**（《民法典》696条：未通知保证人的，转让对保证人不发生效力——公告方式在新司法解释出台前可能对债务人/担保人无效）；
2. **启动诉讼**：第一时间起诉取得**确权判决**（贷款逾期日起3年内必须起诉；逾期日既可以是合同到期日，也可以是银行宣布的提前还款日）；
3. **主体变更**：法律意义上的诉讼/执行主体变更——只有变更后，法院的新进展才会联系你，而不是原债权人（台账第8列的意义）。

### 框架二：资产台账24列（分组速记）
| 组 | 列 |
|---|---|
| 基础信息 | 序号／债权名称／本金／利息／本息合计／**购入日**（成本计时器） |
| 司法状态 | 诉讼状态（七阶段）／管辖法院／抵押物拍卖进展 |
| 主体变更 | 是否完成债权主体变更 |
| 担保结构 | 保证人／抵押物／抵押物描述／债务人描述／保证人描述 |
| 现金流 | **已回收款项（进项)／已支付费用（出项）** |
| 联系人 | 代理律师／法官或破产管理人／银行经办人 |
| 管理动作 | 债务人谈话／失信限高／管理事项（时间+事件）／待办事项 |
- **用法**：进项>出项→盈利中；进项<出项→考虑调整策略（如从"诉讼回款"切换为"转让回款"）。

### 框架三：诉讼状态七阶段（滚动推进）
未起诉 → 起诉中 → 已立案 → 已判决 → 判决未执行 → 已执行 → 终结本次执行（终本）。
- 每进入一个阶段，及时递交下一阶段所需资料——**尽早进入下一阶段就是尽早回款**。

### 框架四：保证责任三类型（金额算法是估值基础）
| 类型 | 责任范围 | 示例（本金1000万） |
|---|---|---|
| 一般保证 | 约定份额＋对应利息 | 老王对其中500万负责→还500万及对应利息 |
| 最高额保证 | 最高限额内（**不含超限部分利息**） | 老王在最高额500万内→还500万（不担对应利息） |
| 连带保证 | 全部本息 | 老王连带→还1000万及所有利息 |

### 框架五：互保联保——担保圈的四重效应
- **互保**（A为B担保，B为A担保）／**联保**（A→B→C→A闭环）；
- 四重效应：投放前"**搭便车效应**"降低审批约束 → 投放中"**两两抵消效应**"（总量上似乎不存在担保责任）→ 逾期后"**踩踏效应**"互相推诿 → 最终"**多米诺骨牌效应**"风险闪电传导；
- **When**：估值时遇到互保/联保贷款——不是"有担保"，而是"担保圈"；把你的债务人和它的担保网络一起做压力测试。

### 框架六：债务人状态识别（含"换壳"）
- 三状态：经营中／停产／破产——预计还款能力相差很大；
- **换壳识别**：实控人在债务企业外重设新公司，经营一模一样的业务，股东由亲戚/员工/朋友代持——**还款意愿几乎为零的信号**；但换壳也有成本（说服上下游与新企业交易），这是谈判中可以利用的软肋。

### 框架七：管理节奏（谈话／限高／拍卖时机）
- **债务人谈话机制**：尽量促成正式谈话，听债务人的还款想法——书中将其列为重点工作，并对比西欧市场"强制要求债务人先行提供商业计划书"（抓问题源头，而不是只盯抵押物）；
- **失信限高**：申请失信/限高对促成谈判很有帮助（诚信体系互联互通后影响更大）；
- **拍卖时机**：司法拍卖要关注市场行情，不是越早越好；
- **记录规范**："时间＋事件"方式记录——法律程序里时间点把握有时效意义。

## 关键概念
| 术语 | 定义 |
|---|---|
| 确权判决 | 法院确认债权及受偿权利的判决——投后第一目标的载体 |
| 终本 | 终结本次执行——待新财产线索发现可恢复执行的状态 |
| 一般/最高额/连带保证 | 三类保证责任——金额算法不同，直接影响估值 |
| 互保/联保 | 担保圈形态——风险的网络化传导结构 |
| 换壳 | 实控人另起炉灶经营同类业务——逃废债的典型形态 |
| 进项/出项 | 台账现金流两列——策略去留的仪表 |

## 思维模型
- **"时间是成本"**：购入日=成本秒表启动——持有越久利润越薄；所有处置动作都在与秒表赛跑。
- **仪表盘管理**：一次管理24个维度不现实——所以要用台账把"注意力"结构化；每周巡检关键列（时效/状态/现金流/待办）。
- **源头思维**：抵押物是"结果"，债务人是"源头"——谈话机制抓源头；只拍抵押物照片的管理是半程管理。
- **担保圈透视**：看到保证人先画担保网络图——互保联保不是加分项，是风险的传染路径。
- **换壳双面观**：换壳=逃废债信号，但换壳成本（重建上下游信任）是我方谈判的杠杆。

## 反模式
- **不做台账/僵尸台账**：户数一多必然失控——信息断档=动作断档=时效风险。
- **忘记主体变更**：法院只认登记在册的债权人——不变更就等于弃权。
- **迷信公告送达**：公告可能对债务人和保证人无效力——能发催收通知书就别只发公告。
- **把互保当强担保**：担保圈在周期下行时是集体违约的加速器。
- **忽视债务人谈话**：跳过谈话直接拍卖——失去和解与商业计划书的可能，也失去信息。
- **死守单一策略**：进项<出项仍固执诉讼——会用台账的现金流信号及时切换策略。

## 实操示例
**一户债权的投后首月动作清单（重建自书中流程）**：
- 第1天：完成法律主体变更申请；刊登转让＋催收联合公告；向保证人发送催收通知书（保留回执）；
- 第3天：核对台账基础列（本金/利息/购入日/保证类型）并录入；核验最高额保证的范围与期间；
- 第5天：向管辖法院递交起诉资料（判决书最大原则：银行资料与判决冲突以判决为准）；
- 第10天：缴纳诉讼费（逾期按撤诉处理！）并确认立案；
- 第15天：约债务人谈话（记录"时间+事件"）→ 评估还款意愿与换壳嫌疑；
- 第20天：对具备失信限高条件的债务人启动限高申请；
- 第30天：台账全面更新＋现金流盘点（进项0/出项律师费+诉讼费）→ 制定下一季度策略目标。
**检查点**：任何一户，当月内必须完成"时效四件事"：公告、催收、主体变更、起诉/续封。

## 要点回顾
1. 投后第一动作：时效维护（催收通知书＞公告）＋确权判决＋主体变更。
2. 台账24列是驾驶舱：基础/司法/担保/现金流/联系人/动作六组管理。
3. 诉讼七阶段滚动推进；终本可恢复。
4. 保证三类型金额算法：一般（份额+利息）／最高额（限额，无超限利息）／连带（全部本息）。
5. 互保联保四效应：搭便车→两两抵消→踩踏→多米诺。
6. 债务人三状态+换壳识别；谈话机制抓源头；时间是成本。
