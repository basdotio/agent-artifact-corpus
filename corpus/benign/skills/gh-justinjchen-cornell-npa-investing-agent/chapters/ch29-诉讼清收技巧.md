# 第29章 诉讼清收技巧：从确权到执行的完整工艺

## 核心思想
诉讼清收的目标从来不只是"赢官司"，而是两个更深的意图：**把对方拉到谈判桌前**（打破"没人负责"的僵局）＋**把纸面权利变成现金**（执行落地）。三个战场缺一不可：**程序机械**（管辖/时效/文书时限）、**抗辩反击**（对方的四大惯用武器）、**执行落地**（申请要素与"打捞"思维）。

## 核心框架

### 框架一：诉讼程序机械（基本功——每一环都是失权点）
| 要素 | 规则 |
|---|---|
| 管辖 | 约定管辖优先（民诉法34条特殊地域管辖）；**合同转让的，管辖协议对受让人有效**（民诉法解释33条）——对方"约定管辖对受让人无效"的异议可依据驳回 |
| 诉讼时效 | 3年（民法典，自贷款逾期起算；逾期日=合同到期日或宣布提前到期日）；转让公告/催收送达引起中断重算 |
| 罚息 | = 逾期本金 × 罚息利率 × 逾期天数 ÷ 360（罚息利率=贷款利率上浮30%–50%；挪用加收50%–100%） |
| 复利 | = 逾期利息 × 罚息利率 × 逾期天数 ÷ 360 |
| 迟延履行金 | = 逾期本金 × 迟延天数 × 1.75/10000（起算=判决生效日+履行期） |
| 缴费 | 立案后收到通知书次日起**7日内**缴费——逾期按撤诉处理 |
- **起诉资料**：可现场/邮寄/小程序立案（12368查立案窗口）；要素表+证据组合。

### 框架二：常见抗辩与反击（对方四大武器）
1. **"受让人没有诉讼主体资格"** → 反击：三层合法性链证明——①银行→AMC（《金融企业不良资产批量转让管理办法》《金融资产管理公司资产处置管理办法》）②AMC→社会投资者（**公开竞价/招投标**＋《座谈会纪要》第12条：受让人=非AMC的法人、自然人）③签约＋付款凭证；
2. **"已过诉讼时效"（公告催收无效说）** → 反击：**特别法优先**——《十二条司法解释》第10条＋《座谈会纪要》第11条第2款：国有银行/AMC在全国或省级有影响报纸公告催收→**时效中断，对保证合同同等效力**；对抗"公告仅限下落不明"观点的判例（北京一中/二中/高院口径："法律和司法解释另有特别规定的，适用其规定"）；
3. **"出资人/开办单位不应担责"** → 反击两种情形：①非法人企业（无独立财产/自主经营权）→开办者直接清偿；②法人企业被吊销/注销后——**出资不实/抽逃出资**或**无偿接受企业财产**→在接受/出资范围内连带（《执行工作规定》第80、81条；执行阶段可申请**追加被执行人**）；
4. **"管辖异议"（拖延战术）** → 反击：受让人继受实体权利的同时**继受程序权利**；法院可裁定驳回异议。

### 框架三：诉清"拉人上桌"战术（村办企业样本）
案情要点：债务企业吊销、法定代表人去世、厂房被村委会转租给第三人、各方推诿——僵局破法=**把债务人、保证人、村委会一并诉为被告**（村委会作为出资人无偿接受财产）→村委会迫于压力签还款协议。
- 经济合作社类担保人：法院一般不直接判村委会对合作社连带——但**起诉的意义在于逼其出面协调**；
- **When**：一切"主体名存实亡、无人愿意谈"的死局——用诉讼构造谈判对手。

### 框架四：诉讼文书提交时间表（错过即失权）
| 文书 | 时限 |
|---|---|
| 答辩状 | 收到诉状副本起15日内 |
| 上诉状 | 判决书送达起15日内／裁定书送达起10日内 |
| 申诉状 | 判决/裁定生效后2年内 |
| 执行申请（被执行人为公民） | 履行期最后一日起**1年内** |
| 执行申请（被执行人为法人/组织） | 履行期最后一日起**6个月内** |
- 提交方式：直接提交最稳妥；向有管辖权法院（上诉经一审法院或上级；执行向被执行人住所地/财产所在地的一审法院）。

### 框架五：执行落地——申请书要素与"打捞"思维
- 执行申请材料：申请执行书／申请人主体资格／被申请人不履行义务的事实／生效法律文书副本等；
- 申请书写要点：**必须提供能了解的被执行财产状况和线索**＋申请理由/事项/标的＋是否采取过保全；
- **"打捞"思维（集元案例）**：房地产项目债务重组中——抵押瑕疵（缺土地证/出让合同）＋多重抵押（负一层/7层分别抵押）＋**工程款留置权**（510万）＋多方债权人环伺——信达南京办事处选择**协调机制**：让众多债权人从"一味打"转向"共同打捞"，理顺并解开债务链，以投行手段实现套现。
- **When**：多债权人争抢同一抵押物时——单独强执不如**主导协调**（提防拍卖踩踏与价格崩溃）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 罚息/复利/迟延履行金 | 三种加罚工具——判决请求中必须列明（白丢钱的常见项） |
| 特别法优先 | AMC公告催收时效中断依据的司法逻辑 |
| 追加被执行人 | 执行阶段将出资人/开办单位拉入责任圈的程序（第30章详述） |
| 文书时限表 | 答辩/上诉/申诉/执行申请的失权红线 |
| 打捞思维 | 从"打击债务人"升维到"协调债权人矿脉"——债务重组是新兴行业 |
| 留置权优先 | 工程款等法定担保物权在处置分配中的实际优先性 |

## 思维模型
- **"拉上桌"主义**：诉讼是谈判的延伸——起诉状送达的一刻，对方"消失策略"就失效了。
- **"特别法优先"工具箱**：涉及AMC的案子，先翻专项司法解释与座谈会纪要——普通法规则之后适用。
- **时限仪表盘**：把1年/6个月/15日/2年等时限写进台账（第23章），每户逐项打钩。
- **"打捞"哲学**：多债权人场景里，做协调者比做抢跑者赚得多——理顺债务链的人拿走"重组溢价"。
- **财产线索为王**：执行申请书没有财产线索等于半张纸——尽调成果（第9章）在此变现。

## 反模式
- **超期申请执行**：法人6个月/公民1年——过期即失权（比时效更隐蔽的杀手）。
- **漏列罚息/复利/迟延履行金**：判决书没写就不能再主张——三种加罚一分不落。
- **只诉主债务人**：放过出资人/开办单位/保证人——责任链缩水。
- **公告代替催收回执**：虽判例支持公告中断时效，但回执优先（第23章）——双保险。
- **单边强执**：多债权人抢拍——价格踩踏双输；试试"打捞"。
- **忽视管辖异议拖延**：预案不足被拖数月——提前准备33条依据与判例。

## 实操示例
**从确权到执行的全流程时限清单（可直接贴进台账）**：
1. 逾期日起3年内起诉（保留催收中断证据链）；2. 立案后7日内缴费；3. 答辩期15日届满前后准备开庭（传票/证据交换）；4. 判决送达：15日上诉期监控（对方上诉→应对二审）；5. 生效后：申请执行（法人6个月/公民1年红线）＋提供财产线索；6. 执行中：评估→拍卖（或申请以物抵债裁定，第28章）；7. 无可供执行财产→终本→持续监控新财产线索→随时申请恢复执行。
**集元式协调演练**：画出抵押物上的全部权利地图（一抵/二抵/工程款/其他债权人）→排序清偿（工程款留置权实践优先）→召集各方谈判→设计统一处置方案（谁牵头/如何分配/时间表）→以一揽子方案替代单边拍卖。

## 要点回顾
1. 三个战场：程序机械（时限/管辖/加罚）、抗辩反击（四大武器）、执行落地（要素+协调）。
2. 罚息、复利、迟延履行金三公式——请求书必须列全。
3. 公告催收时效中断：特别法优先＋判例支持（对保证合同同等效力）。
4. 出资人责任两情形；执行阶段可追加；村办企业/合作社"一并起诉"破僵局。
5. 文书时限表：15日/10日/2年/1年/6个月——错一环失一权。
6. "打捞"思维：协调多个债权人是比强执更高维的打法。
