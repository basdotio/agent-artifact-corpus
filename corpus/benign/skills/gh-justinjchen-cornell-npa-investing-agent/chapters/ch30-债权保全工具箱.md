# 第30章 债权保全工具箱：撤销权、代位权、实现担保物权

## 核心思想
三把"穿透交易外观"的法律武器：**撤销权**（打掉被转移的财产）、**代位权**（抢回债务人懒得收的钱）、**实现担保物权**（不诉而直拍抵押物）。它们的共同特征是：**绕开债务人的"配合"，直捣财产本身**——对付逃废债与消极履约的两把标尺。

## 核心框架

### 框架一：债权人撤销权（对付"转移财产"）
**四要件（缺一不可）**：
1. **合法有效债权**（既存债权；已由生效判决确定的无须另行举证）——债权须在转让行为**之前**已存在；
2. **无偿转让或明显不合理低价转让**：
   - 无偿之判定：核心看**是否实际支付对价**——约定了价款但未实际履行=无偿；撤销之诉应审查第三人是否实际付款；
   - "明显不合理低价"标准：参照指导价/市场价——**低于70%=一般可视为明显不合理低价**；高于30%=明显不合理高价（高价收购亦可能被撤销）；
   - **股权价值的五种参照**：①以转让发生时点计 ②公司资产价值 ③同期向他人转让的价格 ④净资产价值 ⑤审计报告；
3. **对债权人造成损害**：采**"无资力说"**——行为足以减少一般财产致债权不能完全受偿；恶意**推定原则**：债务人超过清偿资力而为行为→推定恶意；受让人"知道"＝**明知或应知**（可推定）；
4. **除斥期间**：知道或应当知道之日起**1年**／行为发生之日起**5年**——**除斥期间为不变期间**（不适用中止中断），过期权利消灭（与诉讼时效的本质区别）。
- **案例（鑫隆嘉业）**：原股东顾某将公司名下**两间商铺无偿转至自己名下**＋把股权转让给无偿还能力者（金蝉脱壳）→承办团队放弃"诉股东"路线，改用**撤销权之诉**（鑫隆嘉业＋顾某一并诉）→顾某因受让未付对价主动求和→和解结案。
- **经验两点**：①撤销权之诉的债权人对"诉的利益"**应享有优先受偿权**（作者观点——防止非诉债权人搭便车）；②被告范围可加**公司为第三人**（判决可直接确定公司配合股权回转登记的义务）。

### 框架二：债权人代位权（对付"躺着不收钱"）
**五条件**：
1. 债权人对债务人享有**到期债权**；
2. 债务人对次债务人享有**有效到期债权**（已实际抵销消灭的不行）；
3. 债务人**怠于行使**——举证责任在债务人（证明曾以**诉讼或仲裁方式**主张）；"谁主张谁举证"在此倒置；
4. 对债权人造成损害——**推定原则**（无力还债即推定损害）；
5. 非**专属债权**（扶养/抚养/赡养/继承给付请求权、劳动报酬、退休金、养老金、抚恤金、安置费、人寿保险、人身伤害赔偿等不可代位）。
- **次债权数额不确定之争**：作者立场——不应把"数额确定"作为成立要件（否则放纵债务人与次债务人恶意串通）；能证明明确债权债务关系即可；
- **代物清偿未履行案例（国土局案）**：债务人与次债务人约定以土地抵债3400万但未履行——**代物清偿为实践性合同**（以现实受领为生效条件）→原金钱债务未消灭→仍可代位（判决次债务人向债权人支付2100余万）；
- **诉讼启动后的效力**：债务人**不得再处分**被代位债权；次债务人**不得再向债务人清偿**（案例：农行汇金支行案——诉讼中主动清结被认定规避法律，不认可清偿效力）。

### 框架三：实现担保物权（对付"有抵押不还"）
**特别程序全景**：
- **申请人**：抵押权人/质权人/留置权人；其他有权人（抵押人/出质人/被留置债务人或所有权人）；作者主张**建设工程承包人**亦应纳入（合同法286条）；
- **被申请人**：担保人与债务人非同一人时——作者主张**列主债务人为被申请人**（查明事实需要，参照担保法解释128条共同被告思路）；
- **管辖**：级别——一律**基层法院**（196条）；地域——多担保物分散可分别申请（实务通常选其一，受理法院可处理同一债权 разных担保物）；**专属管辖**（排除协议管辖与应诉管辖）；**存在有效仲裁约定则法院无管辖权**；管辖权异议不适用（作者观点）；
- **材料五项**：身份材料／申请书（优先受偿范围＋拍卖变卖请求＋事实理由）／主合同与付款凭证／担保合同与登记证明／实现条件成就的证据；
- **审理**：独任审查（超标的额组庭）／**一审终审**／**30日内审结**——为保全申请的空间很小（申请前先权衡必要性）；
- **执行与异议**：裁定→申请执行（作出裁定的法院或财产所在地法院）；当事人异议15日／利害关系人6个月。

## 关键概念
| 术语 | 定义 |
|---|---|
| 撤销权四要件 | 有效债权＋无偿/低价转让＋损害＋除斥期间 |
| 70%低价线 | 明显不合理低价的司法参照标准 |
| 除斥期间 | 1年/5年不变期间——不可中止中断 |
| 无资力说 | 债务人行为致其丧失清偿能力的损害判断标准 |
| 代位权五条件 | 双向到期＋怠于行使＋损害＋非专属 |
| 实践性合同 | 代物清偿需现实受领才生效——未履行则原债存续 |
| 实现担保物权 | 特别程序：30日审结、一审终审、直接裁定拍卖 |

## 思维模型
- **"穿透外观"三连**：转移财产→撤销；躺着不收钱→代位；抵押在手→直接拍卖——先识别逃废债形态，再选武器。
- **死线意识**：撤销权是**除斥期间**（不可中断）——发现转移行为立即倒排1年期限，不拖延。
- **恶意推定杠杆**：资不抵债情境下债务人恶意可推定、受让人"应知"可推定——把举证压力推回对方。
- **金蝉脱壳的破法**（鑫隆嘉业经验）：盯"股权变化"不如盯"公司资产的去向"——**无偿受让的具体标的是撤销权的最佳抓手**。
- **保全组合拳**：撤销（打回财产）+代位（抢回收款）+追加被执行人（第31章）+另案诉股东（第31章）——连环追击，让逃废债无处落脚。

## 反模式
- **错过除斥期间**：发现转移财产却慢悠悠谈判——1年一到，法律武器失效。
- **搞错攻击对象**：只诉债务人不起诉受让人；股权转让路径不通仍死磕（应转攻无偿受让的财产）。
- **代位权举证顺序颠倒**：要有"我的债权+他对次债务人的债权"双清晰，别只证明自己那份。
- **忽视代物清偿的性质**：误以为"约定抵债=债务消灭"——未履行的实践性合同，原债仍在。
- **保全申请时机误判**：30日审限下申请保全——先评估必要性，做好被驳回准备。

## 实操示例
**逃废债形态 → 武器选择决策树（本工具箱使用法）**：
1. 公司资产被无偿/低价转到股东名下（换壳/金蝉脱壳）→ **撤销权**（盯具体标的：商铺/股权/设备）；
2. 债务人对第三人享有应收款却不起诉不仲裁 → **代位权**（注意专属债权排除）；
3. 抵押物在手、债务人拒不配合 → **实现担保物权**（30天拍上桌，比诉讼快数月）；
4. 被执行人财产在配偶/关联公司名下 → 转入**第31章责任穿透**（追加/揭开面纱）；
5. 组合出击：先撤销回财产→再追加被执行人→执行分配中占位。
**鑫隆嘉业复盘**：尽调先发现"商铺转让+股权变更"双信号（第9章访谈与工商查询）→法律定性为无偿转让→撤销之诉立案（被告=公司+顾某）→顾某求和→和解。**关键动作时间线：从"发现转移"到"提起诉讼"要紧凑——除斥期间不等人。**

## 要点回顾
1. 撤销权四要件：债权在先、无偿/低价（70%线）、损害（无资力说）、除斥期间（1年/5年不可中断）。
2. 代位权五条件＋举证倒置＋诉讼后处分限制；代物清偿未履行不影响代位。
3. 实现担保物权：基层专属、30日、一审终审、直接拍卖——最快的抵押变现通道。
4. 恶意推定与"应知"推定——债权人举证压力的减负器。
5. 组合拳：识别形态→选武器→连环追击。
6. 经验两条：撤销权诉的利益主张优先受偿；被告可加公司为第三人。
