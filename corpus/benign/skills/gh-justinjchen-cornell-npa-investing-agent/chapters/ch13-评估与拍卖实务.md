# 第13章 评估与拍卖实务：值多少与卖多少

## 核心思想
评估解决"**值多少**"，拍卖解决"**卖多少**"——两者之间的差额（评估价到成交价的折价链）正是买方的利润空间。不良资产的评估必须嵌入司法与时间维度：变现折扣、市场深度、权利限制一个都不能少；而 NA MA 的"两步估值走廊"给出了估值的区间思维：**底部是变现价，顶部是长期处置价，报价落在走廊内的某一点**。

## 核心框架

### 框架一：资产评估基础体系
- 定义五要素：专门机构与人员 / 特定目的 / 适用原则与标准 / 法定程序 / 科学方法；
- 对象三分：有形资产（机械设备、房地产等）／无形资产／企业整体资产；
- 评估程序四阶段：**评估准备**（资产清册、资料搜集、工作计划）→ **现场工作**（查明实物、技术鉴定、**现场判定成新率**——现场工作完成的标志）→ **评定估算**（重置成本法/现行市价法；核对订货合同、发票、决算书、现行购置价）→ **自查与报告**（防重复/漏评，估价依据与参数全面复核）；
- 设备鉴别三层：生产系统整体评价（产能、班次、维修、技改、人员水平）→ 单台鉴定（型号/厂家/出厂日期/利用率/大修情况）→ 成新率判断；
- **产权与权利限制特别登记**：设备抵押、担保、租赁情况另行造册——产权受限制的资产估值须单独处理。

### 框架二：不良资产估值的特殊性（工具箱汇总）
1. **非标+流动性差**→ 估值须含折扣与时间成本；
2. **抵押物六层法**（城市→区县→区位→优点→瑕疵→变现，见第11章）；
3. **取小规则**：受偿上限＝min(本金+利息, 最高额抵押金额)；
4. **业态变现梯度**：住宅/厂房易去化 ＞ 商铺/写字楼 ＞ 酒店/在建工程；
5. **压力测试**：二抵与超额抵押项目至少做 -20%/-30% 两档房价下滑测算；
6. **租赁与权利负担**：抵押前出租、查封、多抵押权人、违建瑕疵逐项折价。

### 框架三：NAMA两步估值法（估值走廊）
- 第一步：抵押物按**市场变现价格**估值 × 抬升率 → 估值**底**；
- 第二步：抵押物按**长期处置价格**（市场流动性恢复、住宅市场回暖）估值 × 贴现率 → 估值**顶**；
- 在走廊内向银行报价；**为何不用投资组合模型估值**：银行发放贷款时尽调不充分、贷款文件质量不高、存在未披露法律瑕疵——只能以**特定时点房产价值**估值；
- 示例：本金1亿欧元的贷款，抵押物估值经系数调整后为6000万欧元 → 收购对价即6000万欧元。
- **When**：定价谈判前先自问：我的"底"（清算变现）和"顶"（复苏处置）分别在哪里？差多少？

### 框架四：拍卖实务四阶段
1. **拍卖委托**：委托人须有所有权或处分权；提交身份证明＋权属证明；任意委托（四步：意向→寻找拍卖人→洽谈→签合同）vs 法定委托（公物拍卖、**强制拍卖**——执法部门发《协助执行通知书》即委托要约，附保留价协议、抵押财产清单、贷款合同、抵押合同及双方同意证明）；
2. **公告与展示**：媒体公告（征集/拍卖），标的展示与瑕疵披露——**委托人有说明来源与瑕疵的义务**；
3. **拍卖会策划与组织**：保留价（委托人可确定并要求保密；**委托人不得竞买、不得委托他人代为竞买**）；
4. **结算与交割**：佣金及支付方式、标的交付时间方式（《拍卖法》第44条九要素合同）。
- 司法拍卖的价格链（现行网拍实务，操作前核对最新规定）：起拍价不得低于评估价（或市价）的**70%** → 流拍后二次拍卖降幅不超过前次的**20%** → 两次流拍后可**变卖**。
  - 例：评估1000万 → 一拍起拍700万 → 流拍 → 二拍起拍560万 → 变卖价格再议——**评估价到成交价可缩水40%以上**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 成新率 | 设备有形与无形损耗后的新度指标——现场鉴定阶段的阶段性目标 |
| 重置成本法 | 按现行重置成本扣除损耗估值的经典方法（设备评估主用） |
| 保留价 | 委托人设定的最低可成交价（拍卖人须保密） |
| 强制拍卖 | 法院查扣财产的法定委托拍卖（协助执行通知书形式） |
| 估值走廊 | NAMA两步估值法形成的报价区间（变现底↔长期顶） |
| 折价链 | 评估价→起拍价（约7折）→流拍降价（再8折）→成交的连续折价 |

## 思维模型
- **价格链倒推法**：拿到抵押物先画链——评估价×(成交率折扣)×(流拍概率)×(时间成本)≈你的变现预期；**用链条末端定价，而不是用评估价定价**。
- **走廊谈判术**：与银行谈报价时，先对齐双方的"底"与"顶"（你的底未必是他的底）——走廊重叠区就是成交区。
- **用途决定口径**：司法评估、抵押评估、处置变现评估的口径不同——先问"这份评估报告是给谁用的"。
- **产权限制登记思维**：评估的最后一公里是权利核查（抵押/租赁/查封）——价值对，权利不对，等于零。

## 反模式
- **把评估价当成交价**：忽视折价链与网拍降价机制，报价失锚。
- **忽视权利负担**：抵押前出租、轮候查封、违建——每一项都是真金白银的折价。
- **用投资组合模型估值非标债权**：贷款文件质量不足时，组合模型会系统性高估。
- **拍卖程序瑕疵**：瑕疵未披露、保留价泄露、委托人参与竞买——都可能引发悔拍、撤销与索赔。
- **对难去化业态给高价**：酒店/商铺/办公楼在当前市场深度下必须给足折扣。

## 实操示例
**某抵押物从评估到成交的价格链（模拟）**：
- 评估值：1000万元（住宅，余杭区）；
- 一拍起拍价：700万元（评估价×70%）；若成交，债权人回收700万±；
- 假设一拍流拍 → 二拍起拍价：560万元（降幅20%）；若成交，回收560万；
- 若二拍流拍 → 变卖（可与买家议价，通常低于560万）；
- **买方视角**：若你的目标回收测算建立在"700万成交"上，请三思——网拍市场深度决定真实成交概率；稳妥测算建议按**560-700万的中间偏下**取值，并把2-3年司法周期的时间成本计入。
**NAMA走廊练习**：同处抵押物，变现价560万、长期处置价（3年后市场回暖）900万——报价走廊[560万, 900万]，你出多少？取决于你的资金成本（每年8%＝3年约+26%）与风险偏好——**资金成本越高，报价越靠近走廊底部**。

## 要点回顾
1. 资产评估四阶段：准备→现场（成新率）→估算（重置成本/市价法）→自查报告。
2. 不良估值六工具箱：非标折扣、六层法、取小规则、业态梯度、压力测试、权利负担。
3. NAMA两步估值法：变现底×抬升率 与 长期顶×贴现率 之间报价；文件瑕疵多时不用组合模型。
4. 拍卖四阶段：委托（任意/法定）→公告展示→拍卖会（保留价/禁竞买）→结算交割。
5. 司法网拍折价链：7折起拍→再8折→变卖——评估价到成交价可缩水40%+。
6. 定价心法：用链条末端定价、在走廊重叠区成交、先查权利再谈价值。
