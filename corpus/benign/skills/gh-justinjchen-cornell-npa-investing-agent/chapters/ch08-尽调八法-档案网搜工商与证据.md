# 第8章 尽调八法·上：查阅档案、网络搜索、工商查询、调取证据

## 核心思想
案头尽调四法各有分工：**查阅档案定性（债权效力与时效）、网络搜索画像（主体/涉诉/资产）、工商查询验证（身份与沿革）、调取证据取数（官方底档）**。阅档以"真实、完整、合法、有效"为四原则，网搜以"多域交叉"为方法，工商以"内档为王"，调取以"权限因地而异"为常识——**任何事都不能想当然，唯有实践才能出真知**。

## 核心框架

### 框架一：查阅档案——四大原则与审阅地图
**四原则**：真实性 / 完整性 / 合法性 / 有效性。产出《债权档案信息采集表》＋摘抄重点信息。
**十二类审阅要点（速记版）**：
1. 贷前资料（申请报告、调查报告）→ 看借款用途与形成不良的原因；
2. 债权凭证（借款合同、借据/转账凭证、展期合同）；
3. 担保凭证（保证合同、抵质押合同、他项权证、股东会决议）；
4. **时效资料（催收通知书及回执、公证送达、报纸公告）——重中之中**；
5. 还款资料（还款承诺书、还本付息凭证）；
6. 贷后资料（财务报表、贷后检查、不良原因分析）；
7. 流转资料（历次转让协议、公告、回执）；
8. 主体资料（借款人/担保人资格、背景、实际控制人）；
9–12. 主债权、担保、展期、催收时效的逐项穿透（见框架二）。

### 框架二：三大穿透性核查（阅档的硬功夫）
**① 主债权与借据**
- 合同六查：完备性/原件 → 笔数编号期限用途（是否借新还旧）→ 利率罚息复利合法性 → 管辖约定 → 签章生效要素 → 是否赋强公证；
- 借据五信号（不一致即风险）：金额与合同不符 / 放款日期未印证 / **实际放款明显少于合同金额** / 无借款人签章 / 最高额担保下放款在担保期外或累计超担保额。

**② 保证合同十二问**（节选高频雷区）
- 签订日期晚于借款合同（最高额外）；"借新还旧"两次保证人是否一致（换保风险）；保证方式/期限/范围；最高额期间覆盖；**法人担保须自然人签名（盖私章存疑）**；股东会决议与合同要素互印；多保证人各自对应借款；第三人抵押与保证并存时的责任顺序约定。
- 展期必查：是否所有担保人盖章确认——**未重新确认＝脱保风险**。

**③ 催收与时效七查**（对借款人与保证人分别做）
- 接收对象吻合 / 在到期后2年内首催 / 每次间隔均在2年内 / 内容明确要求还款（承担责任）/ 方式合规（书面、邮寄、公证送达、报纸公告）/ 有无签收 / **超时效后是否有债务人/保证人同意还款的签章（时效复活）**；
- 回执细节：公章样式与合同一致、有接收人签名、催收要素（合同编号、本金）与台账相符。

**逃废债八情形（警铃清单）**：恶意处分财产/设置处置障碍；提供虚假资料；分立合并后新旧企业均不认账；拒签催收；关联企业虚假债权债务/虚假诉讼；关联交易抽逃资金转移资产；股东或法定代表人非正常变更；其他对抗债权人的行为。

### 框架三：网络搜索——三域渠道地图
| 域 | 主力渠道 |
|---|---|
| 企业主体 | 国家企业信用信息公示系统（2014年起全国工商基本信息）、省市级信用网（年检/对外投资/商标）、全国组织机构代码管理中心（可打印扫描件）、信用视界（含信用监控推送、支持部分海外）、必途/悉知（中小企业） |
| 涉诉信息 | 中国裁判文书网（2014.1.1起）、各省高院网站（2014年前文书/开庭公告/执行信息）、**全国法院被执行人查询系统（2007.1.1起）**、失信被执行人名单系统（2013.10.24起）、人民法院报公告查询、北大法宝（早期文书收录全）、无讼案例 |
| 资产信息 | 中国土地市场网（供地计划/出让公告/大额购地）、国家知识产权局专利检索（法律状态/年费） |
- **When**：阅档后第一步就是主体画像；查询结果要留意"数据迟延/技术性已结"等失真情形。

### 框架四：工商查询——内档为王
- 工商档案六类内容：基本法律文件（历次变更执照、章程）、设立文件（批复/验资/审计）、演变情况（沿革/股东变更/高管变动）、合并分立与重大资产处置、资产状况（土地/商标专利/在建工程/分支机构）、重大债权债务与诉讼。
- **六项重点核实**：①基本情况＋内档（历史沿革、年检；**银行账号、股东身份证信息需申请法院调取**——现需承办法官亲自前往）②设立瑕疵（出资不实/不足、违规清算）③抵押债权核对抵押物登记 ④在业企业查重大财产 ⑤注销企业查注销申请人及承债主体 ⑥破产条件企业查程序状态。
- 工具补充：巨潮资讯网（上市公司公告/年报）、上交所、深交所网站。

### 框架五：调取证据——权限地图（因地而异！）
| 对象 | 要点 |
|---|---|
| 工商档案 | 律师凭介绍信/委托书/执业证可查外档；**内档须法官调取** |
| 车辆 | 律师可查（提供姓名+身份证号，不受户籍限制）；执行阶段法官可查封 |
| 房屋 | 北京：律师不受理，须法官；上海：可"以房查人"（含普通人）；珠海：仅"以人查房"＋案件受理证明 |
| 土地使用权 | 县级国土局申请，出具《政府信息公开告知书》（含土地坐落/面积/用途/权证号/抵押查封）；2016年后多地收紧→法官调取 |
| 知识产权 | 中国版权保护中心（著作权）/国家知识产权局（专利）/商标局（商标）；同名结果需现场核实 |
- **绝招案例（曲线救国）**：北京无法调取某公司内档 → 查询该公司**上海分公司的工商档案**获得股东身份信息，锁定其股东资格。教训：**不同地域权限不同，一条路走不通就换一条**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 工商内档 | 工商档案中含股东身份信息、银行账号等敏感材料的内部部分，非律师可查 |
| 赋强公证 | 赋予强制执行效力的公证——可跳过诉讼直接申请执行 |
| 时效复活 | 超过诉讼时效后债务人/保证人在明确催款文件上签章，视为重新确认债务 |
| 脱保 | 展期或变更主合同时未取得保证人重新确认，导致保证责任免除的风险 |
| 借新还旧 | 以新贷偿还旧贷——保证人是否知情与担责密切相关 |
| 数据迟延/技术性已结 | 执行查询系统中地方上报滞后、为考核标注"已结"的失真现象 |

## 思维模型
- **"不一致即风险"扫描法**：尽调不是通读，而是对照——合同vs借据、借据vs台账、抵押登记vs实物、催收要素vs合同编号。任何一处不一致，先当风险处理，再证清白。
- **信息猎手**：阅档时主动收集"信贷员、评估师、审计师、会计师、律师"的姓名与联系方式——他们是你未来的信息网络（书中明言：以利今后收集更多信息）。
- **权限地图思维**：查询行动前先画"谁能查什么"的路线图（律师/法官/普通人 × 各地域），避免无效奔波。
- **曲线救国**：一条查询路径被堵死时，寻找同一信息的**替代载体**（母公司→分公司、正门→侧门）。

## 反模式
- **只查合同不查催收**：诉讼时效是债权价值的第一杀手，催收档案的瑕疵（间隔超2年、无签收）足以让整户债权归零。
- **忽视签章细节**：私章代替签名、公章样式不符、无接收人签名——时效证据的常见致命伤。
- **网搜只看公司**：不搜法定代表人、股东、关联企业、曾用名——漏掉责任穿透的线索（详见第30章）。
- **想当然跑窗口**：不问权限直接去查（如北京律师查房屋）——浪费时间且暴露意图。
- **拿到数据不复核**：同名股东、同名专利不做去伪存真，就会在后续程序中被动挨打。

## 实操示例
**一户债权 30 分钟阅档速检（重建自书中要点）**：
1. 借款合同→借据→台账：编号/金额/日期三方对齐？实际放款是否明显少于合同？（信号：利息前置、砍头息风险）
2. 保证合同：签订日期晚于借款合同吗？是最高额吗？法人担保有自然人签名吗？有股东会决议吗？
3. 展期合同：所有保证人/抵押人重新签章了吗？（没有＝脱保）
4. 催收档案：首催在2年内吗？每次间隔<2年？有签收吗？——逐张列出催收时间轴；
5. 超过时效的：后面有没有签章"复活"？（有＝仍有救）；
6. 快速网搜：公司现状、被执行人记录、失信记录；
7. 输出：时效结论＋脱保结论＋两项待调取证据清单（工商内档/不动产）。
**练习**：把第4步的时间轴画成图——任何两相邻节点间隔>2年，标记红色预警。

## 要点回顾
1. 阅档四原则：真实、完整、合法、有效；产出《债权档案信息采集表》。
2. 三大穿透：借据五信号、保证十二问、催收时效七查——全部指向"债权还能不能打"。
3. 逃废债八情形是警铃清单，见到一条就进入"战斗模式"。
4. 网搜三域：主体、涉诉、资产——渠道各有盲区，交叉验证。
5. 工商查询六项重点：内档、出资、抵押、财产、注销承债、破产状态。
6. 调取证据权限因地而异：工商内档、房屋、土地多须法官；车辆、部分地域的房产律师可查。
7. 曲线救国：主路径堵死时用替代载体获取同一信息。
