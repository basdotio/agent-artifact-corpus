# 第39章 类担保及保障措施：法定担保之外的"创新层"

## 核心思想
《担保法》只有五种担保（抵押/质押/保证/留置/定金）——**权利保障措施远不止于此**。实操中大量"类担保"（差额补足、远期收购、让与担保、债务加入、保证保险、网签控制）被创造出来。用好它们的两条铁律：①**比照适用担保法规则**（想用它规避担保法限制=不可行）；②**尽量写清意思表示**（歧义时法院倾向保护债权人，但确定性才是安全边际）。

## 核心框架

### 框架一：类担保总论（是什么、为什么、注意什么）
- 定义：能起到类似担保效果、但未纳入《担保法》《物权法》范畴的权利保障措施；
- **适用动因（四大真实场景）**：
  1. 上市公司提供连带保证需股东大会程序、时间来不及 → 改用**远期收购**；
  2. 兜底方不愿在征信记录中增加对外担保金额 → 改用**差额支付**；
  3. 已取预售证的在建工程当地不许抵押 → **网签控制**；
  4. 应收账款随时可被清偿、债务人拒不配合监管账户 → **让与担保**（受让债权后通知，成为债权人掌控回款）；
- **三条底线（重要！）**：
  1. **比照适用担保法**：主体资格限制（国家机关/公益事业单位不得作保证人——"463号文"禁止其提供担保函、承诺函）、公司决策程序（对外担保需决议）、担保人抗辩权——**类担保同样适用，起不到规避效果**；
  2. **效力稳定性弱于法定担保**：司法态度尚不完全明朗，传统担保可行时**优先传统担保**；
  3. **保障力度排序**：抵押（优先受偿/破产别除/查封拍卖优先）＞网签控制（仅防再转让抵押，**无优先受偿，破产时与其他债权人平分**）——别把控制型措施当担保用。

### 框架二：债务加入（保障力度最强的"人保"）
- **四概念对比**（债务加入 vs 债务转移 vs 第三人代为履行 vs 连带保证）：
  - 债务加入：原债务不免除＋并存的自己债务＋**无先诉抗辩权、无保证期间限制**——对债权人最有利；
  - 债务转移：需债权人同意、原债务人退出；
  - 第三人代为履行：仅履行行为，第三人不成为债务人；
  - 连带保证：从属性债务＋受保证期间约束。
- **认定规则（最高法判例线）**：
  - 形式："自愿承担"/"承诺还款"/在借款人处签章——**单方承诺即可成立**（债权人未反对即有效）；
  - **"代替"一词有歧义**（可能被解释为代为履行/债务加入/债务转移）——歧义时法院按"双保险更符合债权人利益"倾向债务加入；
  - 责任分担：约定不明→**连带责任/共同还款责任**；
  - **抗辩权随"债的同一性"**：原债务人的诉讼时效抗辩，加入方同样享有——**除非三方共同签署协议**（适用法复〔1997〕4号，新债关系，抗辩被切断）！这是最关键的条款设计点。
- **五条操作建议**：三方共同签署协议／明确"共同债务人+连带责任"／约定加入方追偿权且不得以此抗辩／担保合同同步确认覆盖加入方义务／**取得加入方股东（大）会决议**（举轻以明重，防内部程序抗辩）。

### 框架三：差额补足（最灵活的兜底工具）
- 三类形态：**对债务**（类保证式[一般/连带]、类债务加入式）／**对分红**（保投资方收益——保证无法担保收益权，差额补足是权宜通道）／**对资金归集**（保监管账户余额达标）；
- 四大性质借自保证（从属/单务/无偿/补充）但**"不宜直接视为保证"**（否则套用保证期间、先诉抗辩权的混乱）；
- **条款的两种表述决定命运**：
  - "不能清偿时补足"≈一般保证式→**有先诉抗辩权**（旷日持久）；
  - "未按期足额清偿即补足、无需先起诉/执行"→连带式→**可直接追索**（务必用这种表述！）；
- 效力：法院判例普遍持肯定态度（意思自治）；**但不宜作为唯一保障措施**；
- 追偿权：无法定规定——**必须事先约定**（履行完毕+债务消灭+无过错三条件）。

### 框架四：远期收购与网签控制（速记）
- 远期收购：或有的（触发条件：如债务人未按期还款）or 确定的（期限届满必购）——**要事先签收购协议而非承诺函**，约定条件成就即付价款；
- 网签控制：原理=网签后登记机关一般不允许再转让/再抵押——**只控"再次处分"，不解决"优先受偿"**——谨慎使用。

## 关键概念
| 术语 | 定义 |
|---|---|
| 类担保 | 法定担保之外、起担保效果的权利保障措施 |
| 债务加入 | 第三人以独立债务加入债的关系——无先诉抗辩的保护伞 |
| 债的同一性 | 加入方继承原债务人抗辩权的法理——三方签署可切断 |
| 差额补足三类型 | 对债务/对分红/对资金归集 |
| 连带式差额补足 | "无需先诉"表述——直接追索的写法 |
| 网签控制 | 利用登记系统防再处分的控制措施（无优先受偿） |
| 463号文 | 禁止地方政府/事业单位提供担保函承诺函的联合通知 |

## 思维模型
- **"担保家族光谱"**：法定担保（强、确定）→ 类担保（灵活、需设计）→ 控制型措施（弱、仅防处分）——按保障力度选择，别倒置。
- **"比照适用"定律**：想绕开担保法的限制？法院会让类担保比照担保法走——绕道无效，正面设计才是出路。
- **"歧义归债权人"**（但也别赌）：司法倾向保护债权人，但每一处歧义都是诉讼成本——**把意思表示写死**。
- **"写法的力量"**：差额补足的两种表述（先诉抗辩 vs 直接追索）＝两种命运——条款措辞就是保障力度。
- **"三方签署"仪式**：债务加入/担保确认要想切断抗辩、锁定担保方，就拉三方一起签字。

## 反模式
- **用类担保规避担保法**：主体资格、决策程序照样适用——无效结局。
- **差额补足写成一般保证式**：换来一个旷日持久的先诉抗辩权。
- **债务加入漏三方签署**：原债务的时效瑕疵跟着"同一性"传染给加入方——保护伞漏雨。
- **差额补足单打独斗**：作为唯一保障措施——效力和力度双重不确定。
- **网签冒充抵押**：无优先受偿——破产场景下才发现排队分钱。
- **承诺函代替协议**：远期收购只拿一纸承诺——条件成就时对方拒签正式协议。

## 实操示例
**一套"类担保组合拳"设计（模拟房地产融资场景）**：
1. 主保障：在建工程抵押（若登记可行）；
2. 登记障碍时替代：网签控制（防再处分）＋资金监管账户；
3. 人保层：集团**连带式差额补足**（"未按期足额归还即补足，无需先行处置抵押物"）+ 实控人**债务加入**（三方签署，切断时效抗辩）；
4. 退出层：AMC拟转让时的**远期收购**协议（或有的：触发条件支付价款）；
5. 合规层：核查义务人主体资格/内部决议/征信影响诉求；
6. 文件层：全部意思表示书面化＋担保合同同步确认。

## 要点回顾
1. 类担保障碍场景四例：程序/征信/登记/回款控制。
2. 三底线：比照担保法、优先法定担保、控制≠优先。
3. 债务加入：最有利的"人保"；三方签署切断抗辩是最关键条款。
4. 差额补足：三形态；用"连带式"表述；不宜唯一保障；追偿权事先约定。
5. 远期收购：先签协议不是承诺函；网签控制：防处分不救命。
6. 歧义归债权人（司法倾向）≠ 可以含糊（操作纪律）。
