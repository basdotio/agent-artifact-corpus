# 第1章 不良资产的本质与分类

## 核心思想
"不良资产"不是银行账上静静躺着的一堆坏账，而是一个二十余年间**不断向外扩张的业务宇宙**：从银行不良贷款，到债转股与抵债资产，到非银行/非金融机构不良，再到今天的"大不良"（困境企业、风险机构）。谁先看懂新扩张出来的那一层，谁就拿到了下一个周期的入场券。

## 核心框架

### 框架一：不良资产概念的四次扩展（小不良 → 大不良）
1999年至今，中国对"不良"的认识发生了四次飞跃：

| 层次 | 内容 | 关键标志 |
|---|---|---|
| ① 银行不良贷款 | 次级+可疑+损失三类贷款 | 1998年五级分类；1999年四大AMC成立 |
| ② 债转股+抵债资产 | 贷款转为股权/实物资产 | AMC处置手段延伸 |
| ③ 非银行不良 | 非银金融机构不良 + 非金融机构不良（"非金"） | 2015年非金不良业务管理办法出台 |
| ④ 大不良 | 困境企业、风险机构 | 供给侧改革后困境企业重组、高风险金融机构处置 |

- **When to use**：评估自身业务边界、寻找新增长点时。只在"小不良"里内卷，就会错过"大不良"级别的机会。
- **How**：定期对照四层扫描市场——你现在做的是哪一层？上一层正在发生什么？

### 框架二：贷款五级分类与"一逾两呆"
- 现行口径（1998年起）：正常、关注、**次级、可疑、损失**，后三类合称不良——按"还款能力递减"记忆：本金要承受一定损失 → 部分损失 → 极大损失。
- 旧口径（1998年前）：正常、逾期、呆滞、呆账，"一逾两呆"为不良。
- 补充口径（巴塞尔BCBS）：逾期90天以上即不良；部分优质大行已主动将逾期60天以上计入不良。
- **When**：拿到任何一组贷款数据，先对齐口径。口径不同，"不良"的规模完全不同。

### 框架三：非金不良"真实、有效、洁净"三原则
针对非金融机构不良资产（企业间应收账款等）的认定标准：
- **真实**：资产客观存在、对应基础经济行为真实发生、要素明确具体、可获得可证实；
- **有效**：属于国家法律法规允许转让的范围；
- **洁净**：权属关系无争议，原权利人已履行完毕约定给付义务，无履约纠纷、无优先受偿权、未过诉讼时效。
- **When**：任何"非金不良收购"立项之前。三原则不满足，业务性质可能从"收购不良"滑向"违规提供融资"。

### 框架四：企业违约三阶段模型
企业从正常还款到违约，必经三个阶段（用年经营性现金流净值 vs 本息判断）：
1. **正常还款**：现金流净值 > 贷款本金 → 到期正常兑付；
2. **勉强还款**：本金 > 现金流净值 > 利息 → 靠"借新还旧"或过桥资金维持；
3. **无力还款**：现金流净值 < 利息 → 第一次付息失败，银行宣布贷款提前到期，违约爆发。

- **When**：尽调与投后监控。进入第二阶段就应高度警惕——收缩投资、回笼现金流；滑到第三阶段则为时已晚。

### 框架五：组包与封包
- **不良资产包**：2012年《金融企业不良资产批量转让管理办法》要求10户以上组包、定向转让给AMC；2017年门槛降至**3户及以上**。对应概念为"单（两）户不良资产"。
- **转让基准日**：包内全部债权本息计算的统一截止日；确定基准日即"封包"，此后一般不再调整债权构成。
- **When**：设计转让交易、核对报价构成时。

## 关键概念
| 术语 | 定义 |
|---|---|
| 不良贷款率 | 不良贷款余额 ÷ 贷款余额。"降不良"两招：做小分子（清收/转让）或做大分母（扩大放贷） |
| 拨备覆盖率 | 贷款损失准备 ÷ 不良贷款余额；2018年监管要求由150%下调至120%–150%，越高越稳健 |
| 贷款拨备率（拨贷比） | 贷款损失准备 ÷ 贷款余额；监管要求1.5%–2.5% |
| 经济资本占用 | 覆盖"预计外损失"的资本；抵债资产风险权重随持有时间在100%与1250%之间跳变 |
| 影子银行 | 表外理财、信托贷款、委托贷款、股权质押等；2016年末广义超90万亿元，整治后压降约20万亿元 |
| 债转股 | 债权关系转化为股权关系的操作 |
| 抵债资产 | 以资抵债取得的实物资产；银行须自取得之日起2年内处分（《商业银行法》） |

## 思维模型
- **把银行想成"风险存量"的经营机器**：不良率是分子分母的游戏——看到不良率下降，先分辨是"真处置"还是"分母注水"。
- **所有权转换视角**：不良处置的本质是一连串"权利变形"——债权变股权（债转股）、抵押权变所有权（抵债）、短期利息收益变长期投资收益。
- **会计学链条**：不良资产 ⊇ 不良债权 ⊇ 不良贷款（由资产负债表结构决定）；谈"不良"先对齐口径。
- **"银行手里的房子都是被迫买的"**：抵债资产是银行最不想持有的资产，2年处分期与风险权重跳变制造了低价出手动机——这是买方的机会窗口。

## 反模式
- **把"非金不良收购"做成"融资"**：脱离真实、有效、洁净三原则，实质是放贷，触碰监管红线。
- **只看银行不良、忽视概念扩张**：错过非银（影子银行遗留）、非金融、困境企业三个增量战场。
- **用单一不良率指标下结论**：口径混杂（含/不含关注类、90天/60天规则）会让数据失去可比性。
- **忽视对方的时间约束**：银行的2年抵债处分期、拨备考核压力——这些约束正是买方的谈判筹码。

## 实操示例
**一只银行资产包是怎么诞生的（重建自书中流程）**：
1. 某银行将3户及以上不良贷款组包（2017年后门槛降至3户）；
2. 选定转让基准日（例如某年10月17日），将每户债权本金、利息计算至该日；
3. 封包——此后不再调整包内债权构成；
4. 按监管要求定向转让给AMC，或由AMC再转让给社会投资者。
思考练习：若你是买方，基准日距你实际尽调日已过去6个月——这6个月里的利息、司法进程、资产变化由谁承担？这是报价谈判的第一课（详见第10章）。

**债转股小账本（养猪场案例）**：老王对养猪场持有10万元债权（总投资100万元、年净利50万元）。若转为10%股权，每年分红5万元——2年回本，第3年起为纯收益。债权收益（利息）被置换为股权收益（分红+增值）。

## 要点回顾
1. "不良"是四层递进的宇宙：贷款 → 债转股/抵债 → 非银/非金 → 大不良（困境企业与风险机构）。
2. 规范的贷款分类是"次级+可疑+损失"；记忆锚点：一定损失 → 部分损失 → 极大损失。
3. 1999年四大AMC（华融、长城、东方、信达）成立，是中国不良资产行业的创始元年。
4. 非金不良三原则——真实、有效、洁净，是区分"收购"与"放贷"的生命线。
5. 企业违约必经三阶段；现金流净值跌破利息线，违约即爆发。
6. 3户组包、基准日封包——资产包的"出生证明"。
7. 抵债资产：银行被迫持有，2年处分期与1250%风险权重是理解其定价逻辑的钥匙。
