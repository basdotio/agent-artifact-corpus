# 第31章 责任穿透：追加被执行人、揭开公司面纱与另案诉股东

## 核心思想
有限责任是"双刃剑"——它促进经济发展，也为股东逃债提供租界。债权人的反击是三件穿透武器：**执行内追加**（最快，无需另诉）、**揭开公司面纱**（最重，直击抽逃与混同）、**另案诉股东**（清算责任，覆盖"名存实亡"的死局）。目标只有一个：把空壳公司的债务，落到**活着的主体**身上。

## 核心框架

### 框架一：追加被执行人（《执行追加规定》，2016）
| 被执行人类型 | 可追加主体 | 要点 |
|---|---|---|
| 个人独资企业 | **投资人** | 不能清偿即可追加 |
| 一人有限责任公司 | **股东** | **股东不能证明公司财产独立于自己财产**→连带（举证责任在股东） |
| 合伙企业 | 普通合伙人；未按期足额出资的有限合伙人 | 后者在未缴出资范围内 |
| 企业法人 | 未缴/未足额出资、抽逃出资的**股东、出资人或发起人** | 在未缴/抽逃范围内；**未履行出资义务即转让股权**的，受让人明知或应知→连带（熟人推定） |
| 被注销/吊销/撤销/责令关闭/歇业 | 无偿接受财产的**股东、出资人或主管部门** | 在接受财产范围内；须提供"无偿接受财产"证据（或注销文件中的承诺条款） |
- **案例（广丰喷漆厂）**：担保人被注销，注销文件载明"今后若发生债权债务…由主办单位镇经济中心承担责任"→法院据此**裁定追加镇经济中心**为被执行人→镇府协调下和解；
- **送达难题（鑫达药业）**：一人公司股东下落不明，邮寄退回，法院拒绝公告送达直接驳回——**替代路径：另案起诉股东承担连带责任**（多花时间成本买确定性）；
- **When**：终本案件重启时，**先跑一遍追加表**——执行内程序比另案诉讼快得多。

### 框架二：揭开公司面纱（三种类型）
**① 资本显著不足**——表现为虚假出资、抽逃出资、转移资产。
- 复盘（裕发集团案）：450万"出资"由时代谦和公司汇入→**验资当日即转回**；集团年检报告无该对外投资记录→法院调取银行流水锁定循环转账→认定**抽逃出资**，在450万范围内清偿→集团求和。
- **When**：查出资真伪，**资金流水是照妖镜**（验资户进出、同日往返、关联方过桥）。

**② 人格混同**
- 股东与公司混同：一人公司场景举证倒置（公司法63条）——股东不能证明财产独立的连带（万客来案：股东把公司账户存款转入个人名下逃债）；
- **姊妹公司混同**（认定更严）：表象三查——**人员混同**（"一套人马、多块牌子"）／**业务混同**（交易对手分不清与谁交易）／**财务混同**（账簿账户混同、不当冲账；注意：合并财税报表、分开记账下的集中现金管理≠混同）；实质一查——**财产混同**（归属不明、违背财产分离与资本维持原则）。

**③ 过度控制**
- 定义：控股股东无视子公司独立地位，严密干预并侵犯其资产；
- 案例（荣信达案）：母公司用控股子公司（占95%）的几乎全部资产为自身债务抵押→使子公司丧失偿债能力→**抵押合同被认定无效**（一二审：各方均存在主观恶意+损害他人）。

### 框架三：另案诉股东（清算赔偿责任）
- 依据：《公司法》第183条（解散后15日内清算）＋《公司法解释（二）》第18条："股东怠于清算致公司主要财产/账册/重要文件灭失、无法清算→对公司债务承担**连带清偿责任**"；案由：**股东损害公司债权人利益责任纠纷**；
- **四大攻防焦点**：
  1. **清算程序是否前置**？否定说（作者立场）：清算责任是法定劳务责任，非判断"无法清算"的唯一途径；检索显示**80%判决支持否定说**——可直接起诉；
  2. **"挂名股东"抗辩**？无效——最高法指导案例9号：**全体股东一体为清算义务人**，无论是否参与经营、是否控股；股东内部约定仅约束内部，**对外不得对抗债权人**；
  3. **诉讼时效从何起算**？以"债权人知道或应当知道**公司无法清算**"为准——举证责任倒置（清算义务人须举证债权人早已知晓）；无法清算的事实经庭审才能查明=时效未过；
  4. **责任范围**？分两档——**怠于清算/违法注销致无法清算→完全连带清偿**；仅致财产贬损或恶意处置致损失→**损害范围内**赔偿。

### 框架四：程序攻防（对手的拖延术）
- **送达难**：被追加股东下落不明——公告送达之争（部分法院拒绝）+另案诉讼备选；
- **股东资格确认另案**：股东另案提起"我不是股东"之诉并申请中止本案——应对：向另案法院说明情况提交工商档案；本案中攻击其陈述矛盾；预判部分法官仍会裁定中止的风险（留足时间预算）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 执行内追加 | 不经另诉直接追加被执行人——程序快但证据要求实 |
| 举证倒置（一人公司） | 股东须自证财产独立——否则连带 |
| 抽逃出资 | 出资后以各种方式转出——流水认定 |
| 人格混同三表象 | 人员/业务/财务混同＋财产混同实质 |
| 过度控制 | 控股股东以子公司资产为自身债务担保等滥用行为 |
| 清算义务人 | 有限公司全体股东——法定身份，挂名亦不免 |
| 无法清算 | 财产/账册/文件灭失——触发完全连带责任的事实状态 |

## 思维模型
- **穿透三步搜索**：终本案件标准动作——①跑追加表（执行内，最快）②查面纱证据（流水/混同/过度控制）③评估清算责任另诉（最全但最慢）。按成本递进。
- **资金流照妖镜**：抽逃与混同的证据几乎都藏在银行流水里——申请法院调取账户历史流水是必备动作。
- **举证责任地图**：一人公司财产独立性（股东证）／无法清算知晓时点（清算义务人证）／受让人明知（熟人推定）——绘制后即知哪条路最省力。
- **"挂名不免责"**：指导案例9号是反制"我是挂名股东"剧本的核武器——先亮判例再谈。
- **内部约定不外溢**：股东之间的免责约定对债权人不产生效力——谈判时不要接受"内部解决"话术。

## 反模式
- **毫无证据就申请追加**：法院直接驳回——先取证（流水/注销文件/年报）再动手。
- **只追现股东忘记原股东**：未履行出资即转让股权的，原股东+明知受让人一并追。
- **被"姊妹公司不是一回事"唬住**：人员/业务/财务/财产四查清单逐项对照。
- **忽视注销文件中的"承诺条款"**：白纸黑字的责任承担承诺是最现成的追加依据。
- **对中止审理无预案**：股东资格确认另案一起来就慌乱——证据包（工商档案/任职信息）提前备好。

## 实操示例
**终本案件穿透作业包（可直接套用）**：
1. 查工商：股东变更史/注销状态/年报对外投资（裕发式矛盾点）；
2. 调流水：出资验资户→公司账户→关联方账户（找同日往返与过桥资金）；
3. 对照追加表：勾选适用情形（一人公司?注销?抽逃?）；
4. 证据清单：工商内档＋注销文件＋银行流水＋年检报告；
5. 双轨推进：执行内追加申请＋（并行准备）另案诉股东材料——追加被驳回时无缝切换；
6. 反拖延预案：预判送达/资格确认另案/中止审理三类风险，各备一手。
**裕发案复盘**：突破点在"年检报告与出资记录的矛盾"——集团对外投资7家共1268万却无450万投资记录的比对，引爆了后续的流水调取。

## 要点回顾
1. 追加五情形：独资/一人公司/合伙/未出资抽逃/注销后无偿接受财产。
2. 面纱三类型：资本显著不足（抽逃）／人格混同（三表象+财产实质）／过度控制。
3. 另案诉股东四焦点：非前置（80%判例）／挂名不免责（指导案例9号）／时效从"知晓无法清算"起／责任分两档。
4. 程序攻防：送达难、资格确认另案、中止审理预案。
5. 资金流水是抽逃/混同认定的核心证据——主动申请法院调取。
6. 执行内追加优先、另案诉讼兜底——按成本递进选择武器。
