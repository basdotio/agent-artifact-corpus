# 第38章 担保措施精要：最高额担保与在建工程抵押

## 核心思想
两大高频担保工具的操作地图：**最高额担保**（为"远期、连续、不特定"债权提供担保的唯一成熟法定工具）与**在建工程抵押**（房地产项目核心担保形态）。共同主题：**登记决定效力，地方规则决定可行性，优先权排序决定最终回收**。

## 核心框架

### 框架一：最高额担保——四特征与四大投资场景
- 四特征：为**将来**发生的债权担保／为**连续**发生的债权担保／为**不特定**债权担保／**须有最高限额**约定（形式：最高额保证/抵押/质押）；
- 四大场景（投资业务专用）：
  1. **分期收购同一债务人多笔债权**——担保物不可分割时，第一期即设最高额担保防后几期落空；
  2. 分期发放委托贷款——同上；
  3. **债权尚未发生即预先锁定担保**（远期收购方）——常规从属性担保无法设立，最高额可先行；
  4. 在建工程抵押的地方限制绕行——抵押人提供部分建造资金＋设为共同债务人＋担保范围覆盖共同债务人的全部债务。

### 框架二：设立——合同要点与登记规则
- **效力二分**：担保合同按合同法生效；**担保物权经登记设立/产生对抗效力**；
- 基础关系：《物权法》不限定（超出借款/商品交易范畴存在不确定性但未被禁止）；主体不限制，但**登记机关实践中常仅认银行授信/购销协议且债务人须单一**——**先咨询登记机关再设计**；
- **两特殊条款（缺一险）**：
  - **最高债权额限度**——没有它＝一般抵押＋从属性冲突＝**不成立**；建议明确"最高额指最高**本金**余额"＋担保范围含利息违约金费用（规避"本金最高限额说vs债权最高限额说"之争）；
  - **决算期（债权确定期间）**——登记簿常要求记载；未约定时：担保物权满2年后可请求确定，保证则保证人可随时书面终止。

### 框架三：转让、变更与实现
- **转让规则**：债权**确定前**部分债权转让→最高额抵押权**不转让**（另有约定除外——但登记与司法接受度存疑，审慎）；债权**确定后**→已转为普通担保权，随债权转让；
- **变更**：决算期过长难以确定时，依205条协议变更期间/范围/最高额——须**取得其他担保权人书面认可**＋办变更登记；
- **实现三步**：
  1. **决算六事由**（206条）：约定期间届满／满2年请求／**新的债权不可能发生**（交易终止、基础关系消灭）／**抵押财产被查封扣押**（自**收到法院通知**时起不再增加；知道未通知亦同）／破产或被撤销／其他法定；
  2. **确定效力**：最高额担保权→转普通担保权；担保范围固定（含已到/未到期主债权、利息、违约金、赔偿金）；
  3. **受偿上限与顺位**：实际债权高于最高额→以最高额为限；低于→按实际；**顺位一律按登记先后**——不论各笔债权发生/到期时间、也不论决算先后。

### 框架四：在建工程抵押——六要素与三大冲突
**六要素**：
1. **抵押权人**：《城市房地产抵押管理办法》限"贷款银行"，但**地方已突破至法定金融机构**（北京/广州）——非银行主体能否登记"在具体项目进一步确认"（有判例撤销承建单位工程款抵押登记）；
2. **抵押人**：通常须为债务人本人（防烂尾逻辑），第三人抵押一般不被接受；
3. **抵押物**：一般须"**四证**"（国有土地使用权证/建设用地规划许可证/建设工程规划许可证/建筑工程施工许可证）；部分地方要求**完成投资25%以上**；**不可抵押清单**：有承发包争议的、被罚没查封的、公益性质（学校/医院/幼儿园）的、**已预售部分**；
4. **范围之争**：抵押效力及于"设立时已完工部分"（北京口径）还是"实现时已完工部分"？——**合同约定扩展至新增部分**（登记机关不反对时）值得提倡；
5. **债权行为**：书面合同（用途/进度/证号等指引性内容）；
6. **物权行为**：**登记时设立**——未登记＝无优先受偿权（铁律）。

**三大冲突与衔接**：
- **vs 商品房预售**：各地规则乱（有的只允许已取预售证、有的反之）；**已预售部分必须扣除**（预告登记/备案商品房不属抵押财产）；同意预售≠放弃抵押权之争——须**控制预售回款**（设监管/共管）；
- **vs 现房抵押**：竣工后须办初始登记→**转现房抵押登记**（各地流程不同；有的先注销原登记）——**不及时转办的风险：开发商出售现房致抵押权悬空**；
- **vs 建设工程款优先权**：**工程款优先权优于抵押权**（最高法批复）＋行使期限6个月（自竣工或约定竣工日起）——**尽调必查开发商对承建单位的欠款总额**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 最高限额双重学说 | 本金最高限额说 vs 债权最高限额说——条款设计要防争议 |
| 决算期 | 使不特定债权特定化的日期（债权确定期间） |
| 决算六事由 | 206条规定的债权确定情形（含查封通知/满2年请求） |
| 查封冻结规则 | 抵押权人收到查封通知时起受担保债权额不再增加 |
| 四证 | 在建工程抵押的证照门槛 |
| 预售款项排除 | 已预告登记/备案的预购商品房不属于抵押财产 |
| 工程款优先权 | 优于抵押权＋6个月行使期——房地产抵押的"超级优先权" |

## 思维模型
- **"登记决定命运"**：这两大工具的效力开关都在登记——项目第一步查登记状态与地方口径。
- **"地盘规则核对"**：在建工程抵押的地方规定极碎——先与登记机关确认再设计交易，别拿别省经验套本地。
- **"优先权排序图"**：任何房地产债权尽调都画一张权利排序——工程款（最优先）→抵押权（按登记顺位）→普通债权；漏画一层，回收打折。
- **"主动决算"**：用最高额担保要管理决算触发（查封即冻结、2年可请求）——别让担保悬在"未确定"状态。
- **"边建边担保"的动态度**：在建工程价值随施工变化——用合同把新增部分锁进担保范围，配合进度监控。

## 反模式
- **最高额合同漏限度条款**：直接导致抵押权不成立——最常见的低级重伤。
- **忽视查封通知**：收到通知后新增债权全部脱保。
- **不查工程欠款**：撞上工程款优先权——抵押权让位。
- **预售回款不设防**：同意预售却不控制资金——按揭款被开发商腾挪，抵押物价值挥发。
- **竣工不转现房**：手续拖延期=开发商卖房窗口期——抵押权可能落空。
- **在错误的地方用错误的主体**：非金融机构主体未先确认能否登记——项目半途卡壳。

## 实操示例
**在建工程抵押尽调核查表（八项）**：
①四证齐备？②完成投资比例（当地是否要求≥25%）？③是否已预售/预售证状态？④已预售部分的处理（扣除/回款监管）？⑤工程款欠付总额（工程款优先权风险敞口）？⑥抵押人是否债务人本人？⑦能否办理登记（抵押权人资格/当地口径）？⑧竣工后转现房流程（先注销还是直接转）？
**最高额担保条款清单（六项）**：最高额＝最高本金余额声明／担保范围条款（含利息违约金费用）／决算期约定／已存债权纳入条款（203条转入）／查封通知联系机制／变更与登记配合条款。

## 要点回顾
1. 最高额担保四特征、四场景；两必备特殊条款（最高限额＋决算期）。
2. 转让规则：确定前不随部分债权转、确定后可转；变更须其他担保权人认可。
3. 决算六事由；查封通知即冻结增量；受偿按登记顺位（不论债权先后）。
4. 在建工程抵押六要素：四证/25%/不可抵押清单/范围之争/登记设立。
5. 三大冲突：预售（回款控制）、现房（转办衔接）、工程款（超级优先权+6个月）。
6. 一切以"当地登记机关口径"为最终裁判。
