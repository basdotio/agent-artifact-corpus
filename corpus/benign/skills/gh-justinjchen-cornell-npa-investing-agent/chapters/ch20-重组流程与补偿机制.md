# 第20章 重组流程与补偿机制：偏好拼图与三条通道

## 核心思想
重组的本质是一场**补偿偏好的错配缝合**：银行要现金、基金要股票、供应商要关系、公众持有人要退出价格——方案设计就是把"各方要什么"拼到一张桌上。流程上有**三条通道**：常规第十一章、预打包/提前协商、363资产出售；核心博弈围绕**排他期**与**重组价值悖论**展开。

## 核心框架

### 框架一：参与方需求地图（谁在桌上，各自要什么）
| 参与方 | 核心诉求 | 行为模式 |
|---|---|---|
| 法官/法庭 | 管理案件、处理动议 | 场地选择（shopping）是债权人有限的控制手段 |
| 管理层（DIP） | 保住职位/管控/防御/赔偿 | 排他权是最大武器；很可能动用它保护自身利益 |
| 担保债权人 | **现金补偿**＋抵押物保护 | 充分保护、替代留置、重列即自动通过计划（无需重建票） |
| 贸易债权人 | **继续做生意** | 回收权（45天）＋关键供应商地位；成功重组符合其利益 |
| 普通无担保债权人 | 回收最大化、**类别站位** | 对费用/拖延极度敏感；倾向独立委员会、债务人出资聘顾问 |
| 无控制权秃鹫 | **短期市场价套现** | 按OPMI市场价格计算IRR，"卖个好价钱" |
| 有控制权秃鹫 | **重组后公司的控制权与长期价值** | 如Lampert之于凯马特；重视重组可行性 |
| 专业人士 | 服务费（与时间正相关＋成功费） | 拖延无惩罚、成功费与"案件结束"挂钩 |

### 框架二：补偿偏好矩阵（方案设计的原材料）
| 受益人 | 偏好工具 | 原因 |
|---|---|---|
| 银行/保险 | 现金、现金支付优先级工具 | 监管（资本充足需优质资产）＋经济（90%负债=存款/保单，资产须匹配现金负债） |
| 共同基金 | 不介意普通股 | 几乎没有负债——管理人同意下可全投不分红股票 |
| 贸易债权人/房东/雇员 | 愿意妥协（现金+优先级工具） | 想继续与重组后公司保持关系 |
| 公众/非控制债券持有人 | 套现组合：新信贷工具/优先股/权益/普通股 | 不与重组后公司保持关系；**市场价是重要考量** |
| 初级证券持有人（次级/优先股/普通股） | **要求最大重组价值** | 大价值才能让其分到有价值的东西（也许增值） |

### 框架三：三条通道对比
| 通道 | 机制 | 适用/优势 |
|---|---|---|
| 常规第十一章 | 备案后协商，2/3金额+1/2人数（每类）；可强行批准 | 最普遍（2000-2007大型案73%）；费用高、时间长（平均18个月-3年） |
| 预打包/提前协商 | 破产前协商计划（支持协议）→备案时同步提交（1121(a)＋承认破产前委员会1102(b)(1)＋接受标准1126(b)） | **消除holdout**（达到投票门槛即可强推）；适合小企业（<2亿美元）或简单资本结构；**费用约常规案1/3** |
| 363资产出售 | 通告＋听证＋竞价出售全部/部分资产 | 管理层继续经营至卖完、控制出售过程、可能谈出更好条件；**更快更省**；受363(f)五条件约束 |

### 框架四：排他期与控制权（管理层优势的秒表）
- 排他权：120天提交计划＋60天征求意见；表现良好可延至**备案后18个月**＋再2个月拉票；
- 失控的代价：债权人可提出自己的计划（德士古、惠氏、伊文思产品先例）→ 或终结破产/转第七章；
- 控制权损失清单：放弃独立决策权／超常经营须批准／信息共享／受报告与证词约束；
- 信托人/检察官罕见（近年主要案件仅两起任命检察官），但失控案中非零风险；
- **时间预期**：上市公司第十一章重组平均18个月至3年；失控案时间不可预测——**控制事件时机的ability就是管理层价值**。

### 框架五：重组价值悖论（谈判的核心张力）
- 初级证券要最大重组价值（分得残值）；银行/保险也欢迎较大重组价值（换算更多现金流支付工具）；
- **但重组价值越大→重组后公司的现金支付负担越重→可行性越低**——除非资本市场融资条件改善（信贷＋股权同时改善的概率很低）；
- 结论：估值谈判不是数字游戏，是在"分蛋糕"与"蛋糕能不能存活"之间的平衡。

## 关键概念
| 术语 | 定义 |
|---|---|
| 场地选择（shopping） | 债务人依28 USC 1408挑选备案法院的战略行为 |
| 关键供应商 | 在善良债务人辖区可获破产前欠款全额偿付待遇的供应商 |
| 回收权 | 供应商对备案前45天内交付货物要求收回的权利 |
| 重列（reinstatement） | 担保债权收回原工具＋欠息＋损失补偿——视为接受计划 |
| 提前协商 | 与主要持份人达成锁定/计划支持协议后再备案 |
| 补差费/加顶费 | 假马竞标人的费用保护（协商补偿＋差价百分比） |
| 重组价值 | 重组后公司股权的估值——决定各方分得工具的面值 |

## 思维模型
- **偏好拼图法**：设计任何重组方案前，把各方偏好列成矩阵（现金/股票/关系/套现/控制权），方案=对每格偏好的一次出价。
- **排他期秒表**：管理层的窗口期在走表；债权人反制的时点=排他期终止/表现不佳——投资时把它当作"进程里程碑"监控。
- **363快车道思维**：不打持久战就打快仗——当资产的本质价值在市场（而非持续经营）时，推动363出售优于重组。
- **重组价值双刃剑**：向对方"要价高"短期有利、长期埋雷——测算时同时输出"价值-可行性"曲线。
- **管理层去留的经验法则**：需要换人的（凯马特/家得宝式——战略已死）；不能换人的（纳伯斯/卡万塔式——经营者即价值本身）。

## 反模式
- **给各方塞同一套工具**：无视补偿偏好（给银行发股票、给基金发零息债）——方案必然卡死在投票环节。
- **忽视"关系型债权人"的折扣**：贸易债权人愿妥协的前提是继续合作——破坏关系的方案会失去他们的支持。
- **在失控破产中做确定性时间表**：平均18个月-3年只是统计值，你的案子可能长得多。
- **把重组价值抬到天上**：为了分得多而赞成高估值——重组后公司被偿付负担压死，谁都没好下场。
- **忘记秃鹫双类型**：与无控制权秃鹫谈价格、与有控制权秃鹫谈结构——两种对手，两套打法。

## 实操示例
**一家中型制造企业重组的补偿拼图（模拟设计）**：
1. 银行（担保）：保留留置权＋5年期现金支付优先级票据（满足现金偏好与监管资本）；
2. 共同基金（无担保债券）：60%现金＋40%新普通股（容忍部分股权）；
3. 贸易债权人：正常经营账期＋保留关键供应商身份（换其支持计划）；
4. 公众债券持有人：现金（小部分）＋新股组合，确保退出流动性；
5. 管理层：保留核心团队（其经营能力是重组关键）＋与绩效挂钩的激励计划替代KERP；
6. 股东：老股几乎清零（绝对优先逻辑下）；
7. 关键路径：**争取破产前就达成预打包**——2/3金额＋1/2人数门槛到位，即消除holdout并锁定法院强推。
**时间对账**：常规通道18+个月 vs 预打包数周-数月；费用对比约3:1——把这张账给各方看，是说服他们接受预打包的最有力材料。

## 要点回顾
1. 各方需求地图：法官/管理层/担保/贸易/无担保/两类秃鹫/专业人士——没有抽象"债权人"，只有具体偏好。
2. 补偿偏好矩阵：现金（银行保险）／股票（基金）／关系（贸易）／套现（公众）／最大价值（初级证券）。
3. 三通道：常规、预打包（消除holdout）、363出售（快省）；预打包费用约为常规的1/3。
4. 排他期秒表：120+60天、可延18+2个月；失控则债权人接管剧本。
5. 重组价值悖论：分得多的短期欲望 vs 公司存活的长期约束。
6. 控制权秃鹫时代：Lampert/第三大道/Zell/Danielson——重组即收购。
