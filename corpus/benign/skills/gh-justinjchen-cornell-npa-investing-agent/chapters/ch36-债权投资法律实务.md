# 第36章 债权投资法律实务：债的更新、费用流转与抵债新规

## 核心思想
债权重组中的三个法律枢纽：①**债的更新**定性——决定重组后担保是否存续（要素变更+更新意思=旧债消灭→**担保消灭**）；②**实现债权费用**的流转规则——诉讼费/评估费/律师费各有各的走法；③**以物抵债的司法新态度**——期前是担保、期后是履行，分类适用。理解这三点，重组方案才不会在担保与程序上翻车。

## 核心框架

### 框架一：债的更新（债务重组的司法定性质器）
- 概念：**新债成立→旧债消灭**的契约（罗马法"法锁"观念演化而来；我国民法未设明文，但不禁止约定）。
- **四要件**：①旧债有效存在（诉讼时效届满的债权签更新协议＝债务人放弃抗辩权，可行）②新债有效设立（要因契约：新债不成立，旧债不消灭）③**新旧债要素不同**（社会观念中须为"另一个债务"）④**当事人有更新意思**。
- **非要素变更清单**（这些不构成更新）：仅变更履行期限/场所/给付数量、无担保债权附加担保或利息、有担保债权变无担保、利率变更等"从给付"变更、条件变更——**均不成立更新**。
- **辨析三对**：
  | 对子 | 区别关键 |
  |---|---|
  | 因债权人交替之更新 vs 债权转让 | 更新须**三方合意**；债权转让只需通知 |
  | 因债务人交替之更新 vs 债务承担 | 更新须**明确的更新意思**；外表几乎不可分 |
  | 因内容变更之更新 vs 债的变更 | 是否**要素变更**＋更新意思（内容变更可推定、主体变更须明示） |
- **Why it matters（实操命门）**：一旦构成"债的更新"——**旧债消灭，其上的保证与担保随之消灭**！反之若定性为"债的变更"——担保继续有效。**重组文件起草时必须明确"保留原担保"或对担保人重新确权**。

### 框架二：实现债权费用的法律流转（被忽视的真金白银）
- **费用三类分层处理**：
  1. **诉讼费**：可退还——胜诉后主动向法院申请退费（法院职责）；收购时若有未退诉讼费，合同需约定"转让方收退费后转付受让方"；批量处置的AMC应**主动追讨存量诉讼费**；
  2. **执行中的评估费/拍卖费**：法定**优先扣除**——建议纳入收购标的，但核算对价要考虑被执行人财产价值；对外转让时实际允许的话**不出让**（自行优先受偿）；
  3. **律师代理费（未实际支付）**：属"因实现债权形成的对外债务"——**承包方式优先"一般代理"**并尽量在诉讼前实际支付取得凭证（便于法院认可）；转让时采取**合同权利义务概括转让**，并要求律所事先同意可概括转让。
- **收购决策规则**：未取得生效判决认可的费用→**不纳入收购标的**（不付对价）；已判决确认的→可收购但按偿付能力核价。

### 框架三：以物抵债的司法新动态（第28章升级版）
- 背景：以物抵债被虚假诉讼利用（转移责任财产/规避政策/抢先受偿）→ 司法态度转变，**分类处理**成为统领思路：
  | 类型 | 定性 | 处理规则 |
  |---|---|---|
  | 履行期**前**的以物抵债 | **债的担保** | 未过户不支持过户（流质禁令）；已过户不具物权移转效力（须清算） |
  | 履行期**后**的以物抵债 | **债的履行** | 未过户：视诺成/实践之争（**诺成说渐占上风→可诉请履行**）；已过户：不能反悔主张无效 |
- 江苏高院2014纪要、北京高院房屋买卖纪要、最高法判例研究——**不拘合同名称、探究真实意思**是共同进路；
- **When**：设计或对抗以物抵债方案时，先定位时点，再查当地高院口径。

## 关键概念
| 术语 | 定义 |
|---|---|
| 债的更新 | 新债成立消灭旧债——担保随之消灭的关键定性 |
| 更新意思 | 消灭旧债代以新债的合意（主体变更须明示、内容变更可推定） |
| 要素变更 | 债权人/债务人/给付/发生原因的改变——构成更新的门槛 |
| 实现债权费用 | 诉讼费/评估拍卖费/律师费等——流转与受偿各有规则 |
| 概括转让（律师合同） | 未付律师费随债权转让承接——须律所事先同意 |
| 以物抵债二分法 | 期前=担保；期后=履行——司法分类处理的核心 |

## 思维模型
- **"更新=换命"**：重组谈判中，"要不要构成更新"是一个可以被设计的选择——想保留担保的，用"债的变更"式条款；想彻底重构的，明示更新但同步补齐新担保。
- **"费用也是资产"**：实现债权费用是可流转、可受偿的权利——收购清单与转让清单都要单列"费用科目"，别把它埋在总价里。
- **"时点定乾坤"**（抵债）：同一个"以物抵债"四个字，写在期前与期后，法律命运完全不同——先问时间，再谈方案。
- **"实践说 vs 诺成说"的证据准备**：想调用诺成说（可诉请过户），协议文本要写得像"新债合意"而非"原债履行"。

## 反模式
- **重组后担保裸奔**：方案构成债的更新而忘记重新确权担保——抵质押/保证全部落空（对照第25章"担保消灭警报"）。
- **丢弃可退诉讼费**：批量资产里躺着大量可退未退诉讼费——主动申请。
- **收购未决费用**：把未判决确认的费用纳入对价——白送钱。
- **律师费安排失当**：诉讼后才谈支付/用风险代理却期望法院全额支持——提前设计支付时点与代理方式。
- **期前抵债挤仓**：资不抵债企业用调解书把资产抵给单一债权人——法院会审查其他债权人利益，方案可能被撤销/驳回。

## 实操示例
**重组协议的"担保存续"条款设计（护身模板）**：
①定性条款："本协议系对原合同项下债务的变更（而非更新），原债权债务关系维持同一性"；
②担保维持："各保证人、抵押人确认原担保继续有效，担保范围覆盖经调整后的债务"；
③担保人签章：全体担保人重新签章（防止脱保争议）；
④备选：若谈判需要引入"新债务"结构（如第三方承接），则明确"各方同意构成更新"并**同步签署新担保文件**。
**费用流转清单**：诉讼费（退费跟踪表）／评估拍卖费（纳入标的或自留决策）／律师费（代理方式+付款凭证+概括转让条款）——三张子表随债权档案流转。

## 要点回顾
1. 债的更新四要件与非要素变更清单；主体变更须明示更新意思。
2. 实操命门：更新→旧债消灭→担保消灭；重组文件必须处理担保存续。
3. 费用三分类流转规则：诉讼费退、评估费优先、律师费概括转让。
4. 以物抵债二分法：期前=担保（清算）、期后=履行（诺成化趋势）。
5. 收购未决费用不付对价；转让未决费用充分披露。
6. 一切重组安排先问"存量担保怎么办"。
