# 第9章 尽调八法·下：现场探查、涉诉查询、关系人访谈

## 核心思想
纸面信息永远片面——"总待在办公室是不可能做好不良资产的"。现场探查负责**眼见为实**，涉诉查询负责**画出债务人的司法全貌**，关系人访谈负责**打开人性的信息源**。三法合一，才能从碎片信息拼出真实的债务人画像。

## 核心框架

### 框架一：现场探查——准备、对象与汇总
**前期准备**
- **假定身份**：真实身份会引起警惕——实务中用"租房者"等合理人设（配套设计：手持写有债务人姓名与虚构电话的租房启事）；
- 硬件：录音笔、照相机（留存证据；谈话适时录音防止遗忘）；
- 基本案头工作：带着"宏观指导计划"去现场。

**调查对象一：债务人/保证人经营地**
三种常见情形与对策：
| 情形 | 对策 |
|---|---|
| 不在工商登记地址经营 | 查关联企业（对外投资企业、股东对外投资企业）注册地址逐一核实——"精准来自不断试错" |
| 早已停止经营 | 已吊销/注销：追究股东（开办单位/出资人）连带责任；**登记"开业"实已歇业**：重点核实抵押物使用状态，再定股东责任路线 |
| 根本查不到 | 多为改制后换壳——现场寻找改制前后企业的"同一性"证据 |

**调查对象二：抵押物/抵债物**
- 四项核实：①我方是否持有他项权证**原件** ②他项权证登记与实物**是否等同** ③实际使用状态（谁在用/是否租赁）④是否存在股东或实控人恶意处置、藏匿；
- 方法：现场调查记录（详细描述）＋全量拍照＋价值难定的聘评估机构。

**小组机制**：专职律师（统筹策略）＋专案秘书（记录汇总、维护现场调查明细表、实时共享）＋现场尽调专员（核实）——信息实时更新是团队尽调的生命线。

### 框架二：涉诉查询——安排、范围与分析方法
**安排（按包大小）**
- 小包（十几户）：一人统查；
- 大包（100+户）：两种分组——①按专案小组（1律师+1秘书+尽调员，每组20-30户）②直接把案件分配给律师（每人5-15件）。前者省人力但分析深度不足，后者效率高但依赖律师数量。

**范围：四步圈定关联圈**
1. 画债务人与担保人的**股权结构图**（股东及上一级股东）；
2. 查债务人或担保人的对外投资与持股公司；
3. 查法定代表人、股东（个人）投资或持股公司——按注册地/户籍地圈定范围，去伪存真（防重名）；
4. 汇总关联公司清单并按与债务人的**亲疏程度排序**——决定调查优先级。

**方法渠道**：中国裁判文书网 → 无讼案例（效率高）→ 启信宝APP（移动实时）→ 与承办法官沟通（法院资源的深度利用）。

**分析（最关键一步）**：逐份判决精读——从字里行间判断债务人的经济实力与赖账程度。
查无涉诉的两种可能：①法人有曾用名（通过户籍查询）②工商登记姓名不实（凭身份证号到派出所核实真实姓名）。两者皆无 → 大概率是"正常人"（非老赖）——**正常人只要经济允许，商谈和解的可能性就高**。

### 框架三：关系人访谈——名单、对象与内容
**名单原则**：按与债务人"亲疏关联程度"分类；**被辞退员工＞在职员工**（动机决定信息质量）。

**四类访谈对象**
| 对象 | 挖掘重点 |
|---|---|
| 原始债权人（银行客户经理/保全经理/包项目经理） | 贷款与催收历史、财产线索、主要控制人及其其他财产、追偿价值判断；**对"亮点"信息必须核实**；重要信息要复印件佐证（口头无证据效果）；留联系方式以备追踪 |
| 债务人关系人（评估审计人员/竞争对手/仇人/被辞员工/诉讼对抗人） | ①财产信息 ②涉诉情况（对方的当事人最有价值）③地址（对付"跑路"）④社会关系（勾勒轮廓、锁定下一轮访谈对象）⑤相关人员经济状况（法人/股东/实控人若富裕→追连带责任） |
| 抵押物相关人员（抵押人/抵押权人/承租人/物业/政府经办） | 是否查封、权属、是否出租及剩余租期、**潜在买家及其出价** |
| 其他知情人 | 察言观色、顺时而动——态度反映配合度与了解度 |

## 关键概念
| 术语 | 定义 |
|---|---|
| 假定身份 | 现场核查时的角色设计（如租房者），避免真实身份引起警惕 |
| 现场调查明细表 | 专案秘书维护的动态台账，实时更新共享 |
| 关联圈四步法 | 股权结构图→对外投资→法人股东投资→按亲疏排序 |
| 亲疏排序 | 按与债务人的关系远近确定访谈/调查优先级 |
| "正常人" | 团队术语：非老赖的债务人——有和解可能的对象 |
| 同一性证据 | 证明改制前后企业为同一主体的材料，用于责任追究 |

## 思维模型
- **"百闻不如一见"**：网上能搜到照片和位置，但搜不到"氛围"——城镇/乡村、人流/冷清，这些决定抵押物真实价值。
- **试错即精准**：关联企业一个个跑、线索一条条试——"精准往往来自不断的尝试或者试错"，没有捷径思维。
- **态度读心术**（访谈）：配合程度→了解程度；敌意来源（被辞退/有仇）→信息富矿。
- **判决书是债务人传记**：多份判决串起来，就是一部债务人经济实力的编年史——判词细节比结论重要。
- **信息网络思维**：尽调不是一次性取证，而是建立持续供料的信息网络（信贷员、经办人、法官、关系人的联系方式都要沉淀）。

## 反模式
- **只跑抵押物不看企业**：企业现场（是否停产、周边货运、员工状态）是还款意愿与能力的第一信号。
- **访谈只找"配合的人"**：与债务人关系好的关系人信息价值最低；被辞退员工、竞争对手、仇人往往最有价值。
- **轻信推介"亮点"**：出让方项目经理推介的亮点资产信息多数无材料支撑，必须独立核实。
- **涉诉查询止于债务人本身**：不查股东/关联企业涉诉——漏掉责任穿透和财产锁定的大机会。
- **口头信息不落纸**：有抵押/查封的房产信息务必索取复印件——口头交流没有证据效果。

## 实操示例
**一户偿债能力画像的生成（三法并用）**：
1. 现场：找到企业实际经营地（登记地址已荒芜）→ 观察厂房租赁状态、门口货车进出 → 拍照留存；
2. 涉诉：查询关联圈（四步法圈出3家关联公司）→ 发现其中1家仍有活跃诉讼 → 精读判决 → 判断实控人名下另有资产；
3. 访谈：找到被辞退的财务人员 → 获得实控人实际居住地址与另一处房产线索 → 索取书面线索；
4. 结论：债务企业空壳＋实控人个人有资产 → 处置路线从"清收企业"切换为"责任穿透"（见第30章）。
**检查点**：画像必须回答三个问题——还有没有财产？藏在谁名下？对方是"正常人"还是"老赖"？

## 要点回顾
1. 现场三对象：企业经营地、抵押物、关联企业——假定身份+录音拍照是标配。
2. 抵押物四核实：原件、登记与实物一致、使用状态、恶意处置。
3. 涉诉查询四步圈关联圈，按亲疏排序；判决精读判断实力与赖账程度。
4. 关系人名单按亲疏分类，被辞退员工是富矿；访谈内容聚焦财产、涉诉、地址、社会关系、经济状况。
5. 出让方"亮点"必须独立核实；重要信息索取书面材料。
6. "正常人"判断的意义：和解与强制执行，是两条成本完全不同的路。
