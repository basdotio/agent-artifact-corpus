# 第32章 出清与追责：强制清算、破产清算与刑事责任

## 核心思想
当债务企业成为"植物人"（吊销、空壳、人去楼空）时，常规清收失灵——三件终局武器登场：**强制清算**（逼出"无法清算"裁定，为诉股东铺路）、**破产清算**（压垮实际控制人心理的开关）、**刑事责任**（拒不执行判决裁定罪——"终极法律手段"）。它们的共同价值不止于回款，更在于**给对手施加不可承受的压力**。

## 核心框架

### 框架一：强制清算（从"植物人公司"到诉股东）
- **申请主体**：公司债权人或股东（债权人身份须以历次转让的合法公告链自证）；
- **申请事由**（公司法180/183）：章程期限届满或约定事由出现／股东（大）会决议解散／**被吊销、责令关闭、被撤销**／司法解散——出现解散事由15日内未组清算组即符合强制清算条件；
- **管辖**：地域——被申请人住所地；注册地与**实际营业地**不一致时，以**实际营业地**为准（便于送达/执行；北京高院解答口径）；级别——按公司登记机关级别（县区→基层；地市以上→中院）；
- **不适用诉讼时效**：清算责任是法定行为责任（非债权请求权）——"植物人公司"再多也不怕过期；
- **保全**：受理后可依申请对公司财产采取保全（防隐匿转移）；
- **无法清算的出路**（核心价值）：账册/文件灭失、人员下落不明→法院以**"无法清算"为由裁定终结**——裁定明确载明**债权人可依《公司法解释（二）》第18条另诉股东、董事、实际控制人**！
  - 案例（华东装饰公司）：股东（华东空调＋李某＋刘某）相互推诿、账册公章失踪→强制清算终结裁定→获得诉股东基础；
- **是否为诉股东前置程序**？**不是**——多数案件直接诉股东（强制清算耗时费力，建议直接诉讼，或双轨并行）。

### 框架二：破产清算（一记重锤）
- **申请主体**：债务人／债权人／清算义务人（企业已解散未清算且资不抵债）；
- **受理**：债务人住所地法院管辖；债权人申请只需提交"不能清偿到期债务"证据——债务人若辩称有清偿能力，**举证责任在债务人**；受理前需通知债务人并给其异议期（异议期满10日内裁定；**该通知程序不适用公告送达**——找不到人也照裁定，效率友好）；
- **清偿顺序**（破产费用优先拨付后）：①职工工资与劳动保险费用 ②所欠税款 ③破产债权（不足则按比例）；
- **破产债权三条件**：破产宣告前成立＋不享有优先受偿权＋依破产程序行使（未到期债权视为到期、减去未到期利息）；
- **优先权两道护身符**：
  - **有财产担保债权**：抵押权（按登记先后顺位；抵押物灭失→降为普通债权）／留置权（可留置变卖优先受偿）；担保物不足清偿部分转普通债权；须**及时申报**否则丧失优先权；争议期间清算组可提存变价；
  - **抵销权**：对破产企业负债的债权人可主张抵销——但**关联方恶意抵销是重灾区**（虚构债权、转移资产）；司法解释限定：受理前6个月内、符合40条第(2)(3)项情形的抵销，管理人可在受理后3个月内起诉主张**抵销无效**。
- **费用垫付现实**：无破产财产时——诉讼费、管理费均由**申请人垫付**（管理费金额协商确定）；
- **When**：空壳企业"开业"幌子下资不抵债——申请破产清算给实际控制人最强压力（尤其对有社会声誉顾虑的老板）。

### 框架三：刑事责任（终极压力工具）
**拒不执行判决、裁定罪（刑法313条）**：
- **追诉升级**（2015年司法解释）：由单一公诉→**公诉＋自诉并行**！公安不立案→拿**不予立案通知书**→直接向法院提起**刑事自诉**（材料：不予立案通知书＋主体/委托材料＋刑事自诉状＋证据）；
- **管辖**：执行法院所在地法院（在哪执行就在哪自诉）；
- **申请依据**：须存在**生效判决或裁定**——**不含民事调解书**（最高法研究室答复：调解书拒不执行不构成本罪；但可申请强制执行）；
- **起算时点**（三说之争）：判决生效说／执行立案说／**执行文书送达说（作者主张）**——执行通知送达后才产生申报财产义务与明确的主观故意；
- **构成两要件**：①有能力执行而拒不执行 ②**情节严重**；
- **"情节严重"清单**（全国人大解释＋《解释》第2条八项）：隐藏、转移、故意毁损财产、无偿或明显不合理低价转让财产；拒不/虚假报告财产、违反限高令经罚款拘留仍拒不执行；伪造毁灭证据/妨害作证；拒不迁出房屋退出土地；**虚假诉讼、虚假仲裁、虚假和解妨害执行**；冲击执行现场；侮辱殴打执行人员；毁损执行材料车辆；致债权人重大损失等；
- **案例（庆隆葡萄园）**：债务人（夫妻店）藏匿被查封车辆→以拒执罪追究→**刑事压力下主动还款**；
- **其他罪名工具箱**（本章结尾举要）：虚假诉讼罪等——针对具体违法行为选择罪名。

## 关键概念
| 术语 | 定义 |
|---|---|
| 无法清算裁定 | 强制清算的"结业证书"——诉股东的直接依据 |
| 实际营业地管辖 | 注册地与营业地分离时的管辖确认原则 |
| 破产费用优先拨付 | 管理费/诉讼费/共同利益费用先于一切清偿 |
| 抵销权限制 | 关联方6个月内恶意抵销可被管理人起诉无效 |
| 拒执罪自诉 | 2015年后公安不立案可直诉法院的新通道 |
| 执行文书送达说 | 拒执罪起算的主流实务观点（作者立场） |
| 情节严重清单 | 拒执罪定罪的门槛（人大解释+司法解释八项） |

## 思维模型
- **"植物人激活术"**：吊销公司→强制清算→"无法清算"裁定→诉股东——一条把死资产盘活的程序流水线。
- **"压力阶梯"**：民事（诉/追加）→行政（失信限高）→刑事（拒执罪）——每一级都是谈判的筹码；多数案件在"刑事立案"表态时即可和解。
- **送达经济学**：破产受理通知不公告、强制清算按实际营业地——制度本身在帮债权人绕开"找不到人"的泥潭；善用程序细节提速。
- **"调解书陷阱"**：拿了调解书≠拿到拒执罪武器——能判则判（判决>调解书），为终局手段留弹药。
- **恶意抵销雷达**：破产程序中关联方突然主张抵销——立即核查6个月窗口并可申请管理人提起诉讼。

## 反模式
- **死磕空壳不换武器**：对吊销企业反复申请恢复执行——应该转强制清算/破产轨道。
- **忘记申报优先债权**：有抵押却漏报——优先权与债权双失。
- **以调解书提拒执自诉**：法院不予受理——提前锁定判决/裁定文书。
- **跳过公安程序直接自诉**：没有"不予立案通知书"，自诉通道打不开。
- **让对方谈判拖过除斥期**：拒执罪有追诉时效概念（刑罚相关）——证据固定后尽快行动。

## 实操示例
**"植物人公司"处置流水线（重建自三章案例）**：
1. 尽调确认：吊销+停业+股东在世且有实力（华东空调式）→预估诉股东可行性；
2. 证据准备：历次转让公告链（主体资格）＋股东不能提供账册的庭审记录；
3. 发起强制清算（或直接另案诉股东——多数案件更优）；
4. 取得"无法清算"终结裁定→诉股东连带（第31章四焦点武器随身）；
5. 并行施压：对存续股东申请限高/失信；如发现转移财产/藏匿查封物→评估拒执罪（固定"有能力+情节严重"证据：隐匿车辆、虚假报告财产等）；
6. 谈判登顶：以"刑事自诉材料已备齐"作为谈判桌上的最后一张牌——**目的仍是回收，而非真要把人送进去**。

## 要点回顾
1. 强制清算三价值：逼出无法清算裁定、财产保全、诉讼时效豁免；非诉股东前置。
2. 破产清算三要点：清偿顺序（工资→税→普通）、优先权申报纪律、关联抵销限制。
3. 拒执罪四件套：自诉通道/执行法院管辖/判决裁定依据/执行送达起算。
4. 情节严重清单八项——隐藏转移财产是首罪状。
5. 费用垫付现实：空壳破产的费用要申请人先掏——计入项目成本。
6. 压力阶梯：一切程序手段的终点是谈判桌上的回款。
