# 第12章 处置全景：六条路径与三方博弈的纳什均衡

## 核心思想
一笔不良资产从银行出表，有**六条路径**（自行清收、核销、出售、证券化、政府救助、成立AMC承接）；而进入处置环节后，一切复杂性的根源在于**三方利益结构**——AMC要效益、政府要稳定、企业要重生。理解三方策略矩阵，就能理解为什么有些案子几个月清收完毕，有些案子拖成"W型处置"。

## 核心框架

### 框架一：风险传导链（为什么要快速处置）
单体银行挤兑/无法偿付同业负债 → 风险蔓延同业 → 银行业信用中介功能收缩、流动性冻结 → 传导至实体部门 → 政府救助（财政担保/注资）→ 财政薄弱国家引发主权风险 → **金融风险、实体风险、主权风险交织螺旋下坠**。结论：金融风险处置不能期待"延期"和"经济复苏自然会好"，必须前瞻、快速、果断。
- 银行不良积累的六重后果：影响盈利→侵蚀拨备资本→**倾向延期暴露风险（继续输血）**→减少新增信贷→声誉受损→市场信心流失。

### 框架二：银行侧处置六路径对比
| 路径 | 核心要点 |
|---|---|
| ① 自行清收 | 十种方式：诉讼、破产清算、预重整、破产重整、拍卖抵押物、法庭调解（六种经法院）；催收、庭外和解、债转股、债务重组（四种自行）。**银行权限窄**：本金减记、以资抵债几乎不可行，债转股须经AIC。预重整＝先协商一致再提法院裁定（防少数债权人拖累） |
| ② 核销 | 账销案存权在；要有内外部证据；财政部《呆账核销管理办法》严防道德风险；中国"应核尽核"（不良率低+拨备充足）vs 欧盟若干国家"审慎核销" |
| ③ 出售 | 依赖市场建设与合理定价；中国买受人=AMC+民间投资人（vs 美国对冲/私募基金）；危机时恐慌折价、复苏期价值补齐；信息披露充分则价格发现充分 |
| ④ 证券化 | 优先/夹层/次级分层出售；可设回购条款与超额收益条款；简单分层ABS透明可控；多层嵌套CDO被禁 |
| ⑤ 政府救助 | 担保（"口惠而实不至"风险）、注资（TARP模式：限薪+缩表+债权人先自救）、存款保险（FDIC式；中国2015年实施、最高50万赔付） |
| ⑥ 成立AMC | 国有vs私营（NAMA之初公私混合后纯国有；西班牙SAREB私人控股）；一家vs多家（KAMCO/SECURUM一家；中国四家——体量大+互相竞争）；权限差异（马来西亚Danaharta可司法外扣押） |
- **AMC的七重目标**：清理银行表／最大化回收／维护金融稳定／调节信贷错配／支持企业降杠杆／建设市场教育投资者／减少信息不对称——**多目标导致考核复杂：商业利润与社会责任难以同时计量**。

### 框架三：三方博弈矩阵（坏账公司 / 政府 / 债务企业）
| 主体 | 最优策略 | 次优策略 | 最劣策略 |
|---|---|---|---|
| AMC | 立即起诉/充分竞价 | 先调解、调解不成起诉/不完全充分竞价 | 无法起诉/指定主体受让、不竞价 |
| 政府 | 先主导调解 | 发函冻本停息、设受让人门槛/国资受让 | AMC直接起诉/充分竞价、企业倒闭 |
| 债务企业 | AMC不起诉、指定第三方低价承接 | 政府居间调解达价 | 直接起诉竞价、核心资产被拍、全额本息（含罚息复利迟延履行金） |
- **纳什均衡与社会最优**：三方的"最优"互相踩踏（AMC起诉＝企业最劣；企业低价承接＝AMC最劣）。从**社会总效用**出发，均衡解是"**调解不成再起诉 / 不完全充分竞价**"——作者称"这个结论初看有悖常识"：它低于充分竞争的市场理念，但避免了"企业死亡（税收就业消失）"与"国资流失＋逃废债激励"两个极端。
- **When**：每笔重大处置开始前，把三方诉求各写一行，预判对方的策略位次——你就会明白为什么"一户债权处置会受多个作用力"。

### 框架四：处置速度的战略选择
- 经济长期低迷 → 快速处置（止损）；
- 预期经济回暖、资产价格将升 → 慢下来"根雕"（管理提升价值）——**快处置与慢管理之争，本质是宏观周期判断**。
- I型处置（简单直行）vs W型处置（多因素纠缠：纳什大户/著名商标/稳岗企业/出口先进，政府介入后司法措施审慎）——**企业社会属性越强，处置越接近W型**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 预重整 | 债务人与债权人先行协商重整方案，再提交法院裁定——缩短流程且对异议债权人有强制力 |
| 账销案存 | 核销仅从账面移出，追索权保留，回款冲减损失 |
| 超额收益条款 | 证券化中超过预期回现部分的收益分成安排 |
| 冻本停息 | 政府函件要求金融机构停止计息、不得抽贷、不得起诉的干预方式 |
| W型处置 | 受政府、企业、社会多重因素纠缠的复杂处置路径（对应I型直线处置) |
| 社会最优均衡 | "调解优先＋司法兜底"的处置节奏——三方综合效用最大化点 |

## 思维模型
- **策略位次镜**：碰到僵局时问——对方把我放在了哪个位次？我把对方放在了哪个位次？差距就是谈判空间。
- **坏账公司的花店比喻**（另一版）：银行是大棚、不良是鲜花、AMC是花店——但政府可能要求你"不能打折卖花"，企业希望你"低价把花还给我"——三方拉扯决定门市价格。
- **"不能期待延期"原则**：金融风险处置的前瞻性——等到经济自发复苏时，损失已经翻倍。
- **考核矛盾意识**：AMC利润考核与社会责任的冲突是结构性矛盾，不是执行力问题——分析其行为时先看它的考核表。

## 反模式
- **单边最优陷阱**：AMC只求起诉竞价最大化——短期回收高，但企业死亡引发政府对抗、区域市场恶化（后续包拿不到）。
- **政府过度干预**：冻本停息/设受让人门槛——看似保住企业，实则把成本转嫁中央财政，并激励逃废债（"不以为耻、反以为荣、开班授课"）。
- **忽视周期做处置节奏**：经济下行期死守资产等回暖、上行期急售——两头挨打。
- **把多目标当单目标**：用纯商业ROI评估承担救助使命的AMC行为，会系统性误读其策略。

## 实操示例
**用矩阵推演一单：某县域纳税大户企业的1.2亿元不良债权**
1. 三方诉求：AMC要回收（成本8折）、政府要保税收就业（施压冻本停息）、企业想低价了断（出资0.5亿回购债权）；
2. 位次推演：AMC的最优（起诉拍卖厂房）＝企业最劣、政府次劣 → 三方将陷入对抗；
3. 均衡设计：先接受"调解"路径——AMC提出：企业实控人追加个人担保＋出售非主业资产＋3年分期（参考NAMA商业计划书11项动作，见第6章）→ 回收目标8折→企业存续→政府接受；
4. 兜底条款：调解失败即启动诉讼，不给无限期拖延——用"确定性时间表"锁定政府与企业的承诺；
5. 结果校验：社会效用最大（企业不死、税务不断、AMC回收达标）——这就是"调解不成起诉/不完全充分竞价"的实战版。

## 要点回顾
1. 六条路径：自行清收（10方式）、核销、出售、证券化、政府救助、成立AMC。
2. 银行权限窄（减记/抵债难、债转股须AIC）——解释了为何出售成为主流。
3. AMC七重目标：商业利润仅是其一，考核复杂性是结构性的。
4. 三方矩阵的纳什均衡＝"调解不成再起诉"——社会最优而非单方最优。
5. 处置速度取决于宏观周期判断：低迷快处、回暖慢养。
6. I型/W型：企业社会属性越强，处置路径越复杂。
