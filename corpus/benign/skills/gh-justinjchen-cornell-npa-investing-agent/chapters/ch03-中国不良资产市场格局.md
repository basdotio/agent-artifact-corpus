# 第3章 中国不良资产市场格局：四阶段演进与新变局

## 核心思想
中国不良资产市场是**政策与市场双轮驱动**的四阶段演进产物：政策性剥离（1999–2006）→ 商业化转型（2007–2016）→ 规范发展（2017至今）。读懂市场的钥匙是四个仪表：**供给、需求、基础设施、交易方式**——每一次行业变局，都是这四块拼图中的一块在变化。

## 核心框架

### 框架一：行业四阶段演进
| 阶段 | 时间 | 标志 |
|---|---|---|
| ① 政策性时期 | 1999–2006 | 两次大规模剥离：1999年对口剥离约1.4万亿元（工、农、中、建、国开行→四大AMC）；2004–2005年招拍挂剥离约1.1万亿元（工、中、建、交行）。银行不良率1998年攀升至33%的"技术性破产"边缘被拉回 |
| ② 商业化时期 | 2007–2016 | 政策性任务完成，接管问题金融机构股权，收齐银行、保险、证券、基金、信托、期货等全牌照，陆续股改上市 |
| ③ 规范发展时期 | 2017至今 | "三大攻坚战"与回归主责主业：以不良资产为资源，对**不良资产、困境企业、高风险机构**多维开发 |
| ④ 新变局 | 2021年起 | 个贷批转开闸、第五家全国AMC、外资入场、银登中心试点——大不良时代 |

- **When**：解读任何行业新闻/政策，先定位它作用于哪个阶段逻辑。
- **How**：注意AMC定位变化——20年前：政策性、财政兜底、行政命令、国有独资；今天：市场化、财政隐性背书、绩效考核、国有控股。

### 框架二：市场四要素仪表盘
1. **供给端**：银行每年处置不良约3万亿元量级（2020年银行业处置3.02万亿元、年末不良余额3.5万亿元、不良率1.92%）；增量来源依次为——个贷不良（试点开闸，估算约1万亿元级）、非银（影子银行遗留）、非金不良、困境企业与风险机构；
2. **需求端**：五大全国性AMC＋每省两家地方AMC＋银行系AIC＋外资（橡树等）＋民营投资人——多层次、多所有制格局成型；
3. **基础设施**：长期依赖现场投标/淘宝/产权交易所"千人千面"；2021年银登中心试点撮合交易，是统一市场的雏形；
4. **交易方式**：批量转让（3户及以上组包定向转让AMC）为主，单户对公与个贷批转试点扩围中。

### 框架三：2021年新变局五件事（制度供给清单）
1. **个贷批转开闸**：银保监办便函〔2021〕26号，试点单户对公不良转让、个人不良贷款批量转让——万亿级供给释放；
2. **统一交易设施**：银登中心试点居间撮合（首批开户：中信、民生、平安银行，四大AMC＋银河、国厚等）；首单个贷包为平安银行20户、本金618.66万元；
3. **第五家全国AMC**：中国银河资产管理有限责任公司（控股股东为中央汇金，区别于四大的财政部控股）；
4. **外资入场**：橡树资本全资子公司获北京市不良资产批量收购牌照；
5. **地方AMC"二孩"**：每省可设两家区域性AMC。

### 框架四：三大结构性矛盾（行业课题）
- **个贷无法二次批转 vs 盘活存量**：26号文仍禁止AMC收购个贷后对外再次转让——1万亿个贷、约200万户，而AMC前台合计约5760人，人均须管理约347户，倒逼"放水养鱼"式分期方案（3–8年分期）而非一次性催收；
- **交易活跃 vs 无统一基础设施**：撮合平台渐有垄断之势，手续费抬升，买卖双方缺乏替代平台；
- **收购不良 vs 机构出险**：对治理失效的中小金融机构，单纯收包已不足以解决问题，需向事前注资、改造治理结构延伸（如山东AMC受让某银行1438.90亿元不良＋增资入股的组合操作）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 批量转让 | 金融企业对3户及以上不良资产组包、定向转让给AMC |
| 单户对公转让 | 2021年试点：单户对公不良可直接转让（突破组包门槛） |
| 地方AMC | 省级区域性资产管理公司，每省原则上可达两家（"二孩"） |
| 银行系AIC | 金融资产投资公司，市场化债转股的主力实施机构之一 |
| 银登中心 | 银行业信贷资产登记流转中心：登记、托管、流转、结算＋撮合 |
| 影子银行遗留 | 表外理财、信托贷款等整治后沉淀的存量风险（估算不良0.85–2.5万亿元） |
| 金融基础设施 | 六类：登记托管、清算结算、交易设施、交易报告库、支付系统、征信系统 |

## 思维模型
- **AMC是逆周期生意**：经济下行＋信贷收缩＝资产的"原料"供给高峰。行业景气度与经济周期反向。
- **"供给—需求—设施—价格"四格扫描**：判断一个市场机会，先看四要素中哪格在松动（2021年的松动点在"供给（个贷）"与"设施（银登）"）。
- **政策即变量**：重大政策文件（26号文、批量转让办法、地方AMC备案）直接改变市场参数，把政策当作定价模型的输入。
- **从"收包"到"治机构"**：理解行业功能升级——AMC的使命从买坏账延伸到救助机构、修复功能、减少不良再生成。

## 反模式
- **用对公思维做个人不良**：个贷单户金额小、债务人还款能力未根本丧失，需分期/和解策略，不能套用对公清收。
- **押注单一交易平台**：现场投标、淘宝、交易所、银登中心并存，"千人千面"是常态而非过渡。
- **只收购、不治本**：对治理失效机构只收存量不良，风险会再生成。
- **忽视隐性规律**：地方干预强的区域，处置周期长、"I型处置变W型处置"（见第12章三方博弈）。

## 实操示例
**首单个人不良贷款资产包的"算术题"（2021年，平安银行经银登中心挂牌）**：
- 资产包：债权20户，本金合计618.66万元 → 户均本金约31万元；
- 承接方约束：AMC收购后不得二次转让；全国AMC前台约5760人，面对估算200万户个贷不良 → 人均347户；
- 推论：靠人力催收不可行 → "3–8年分期、放水养鱼"才是规模化出路——政策设计与商业可行性的交点。
**启示**：拿到新品类业务时，先做"单位经济模型"（人力×户数÷回收率），再谈战略。

## 要点回顾
1. 四阶段：政策性（1999–2006）→ 商业化（2007–2016）→ 规范发展（2017至今）→ 新变局（2021起）。
2. 两次剥离共约2.5万亿元不良资产，换来银行体系重生与国企三年脱困。
3. 债转股（580户/3951亿元）使企业资产负债率从73%降至50%以下，80%企业扭亏。
4. 市场四要素：供给、需求、基础设施、交易方式——用它们扫描每一次变局。
5. 个贷开闸、银登中心、银河公司、外资入场、地方AMC扩容是2021年的五块拼图。
6. 三大矛盾揭示行业下一程：个贷模式创新、统一市场建设、机构救助深水区。
