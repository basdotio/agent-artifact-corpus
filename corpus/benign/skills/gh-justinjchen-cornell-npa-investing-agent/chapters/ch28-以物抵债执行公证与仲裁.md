# 第28章 以物抵债、执行公证与仲裁

## 核心思想
三条"绕开常规诉讼"的路径：**以物抵债**（债权换物权——四个达成时点=四条效力轨道）、**执行公证**（债权人手握"放弃抗辩"承诺，跳过诉讼直达执行）、**仲裁**（定制司法：快捷、专业、保密）。每条路径的核心问题都是同一个：**我的权利凭证能不能直接变成执行依据？**

## 核心框架

### 框架一：以物抵债——四个时点的效力矩阵
学理名称：**代物清偿**（受领他种给付以代替原定给付，消灭原债）。
| 时点 | 效力规则 |
|---|---|
| 清偿期届**前** | 有**流质（抵）契约**嫌疑（物权法186/211禁止）→ 实务观点：协议本身有效，但**不能对抗其他债权人**；须履行**清算**：折价/拍卖/变卖，**多退少补** |
| 清偿期届**后** | 协议有效；但**未办物权转移前**，债务人反悔或不配合→法院**不判确权**，债权人只能主张违约责任；已办完物权转移后一方反悔→法院一般驳回其无效之诉（除非可撤销情形） |
| 审判中（调解书） | 以物抵债调解书**只是债的确认**（≠分割共有物类文书）→ 物权变动仍需**交付/登记** |
| 执行中 | 仅签和解协议=裸奔（不能排除其他法院强制执行）；**必须申请法院出具"以物抵债裁定"**（物权法28条＋司法解释一第7条：裁定直接产生物权变动）——裁定前法院须核实其他债权人、合理评估；案外人异议属实可撤销 |
- **强制以物抵债四条件**（不必被执行人同意）：①无金钱给付能力 ②财产无法拍卖变卖 ③已经评估、拍卖程序 ④申请执行人**单方同意**——一经送达申请执行人即生效；
- **土地抵债特则**：以出让方式取得的国有土地使用权及地上房屋抵债——**必须办理权属变更登记**，仅有裁定不产生变动效力（且须双方书面协议＋评估作价防暗箱）。

### 框架二：以物抵债案例——"以用抵债"的想象力
- 案情：债务企业已吊销、涉诉10余条、失信名单；转向保证人**永兴建筑工程公司**（村办集体企业）——核心资产=30年土地租赁协议的**剩余16年使用权**（120亩、紧邻北京六环）；
- 方案：以"剩余期限土地使用权"抵偿债务（严格说是"以**用**抵债"）→ 签署和解协议 → 公司运作**成功转租给两家企业** → 债权圆满解决；
- **启示**：抵债标的可以是"权利的剩余期限"（租赁权/经营权/收费权）——不要只盯所有权。

### 框架三：执行公证（赋强公证）——最简便的处置路径
- **两大要件**：①明确的债权债务关系 ②**债务人书面承诺自愿接受强制执行、放弃抗辩**（没有这个承诺就不成立）；
- **可赋强范围**：借款/借用/无担保租赁合同、赊欠货款文书、借据欠单、还款（物）协议、赡费/补偿金类、其他适格文书；**担保合同**亦可赋强（第三人担保人须向公证机构提出申请）；**担保函（保函）**纳入（保函+债权人接受=保证合同成立）；
- **执行证书之争**：作者观点——**执行证书不应作为申请执行的依据**（五理由：立法无据/否定公证效力/弱化职能/损害债权人/签发程序掣肘）——公证书本身即执行依据；
- **可诉性三情形**：①债务人起诉→**不受理**（违背承诺）②债权人超过申请执行期限后起诉→**不受理**（自负其责）③债权人**主动放弃申请执行而起诉**→**应予受理**（处分自有权利，且可防范公证书被裁定不执行的风险）。

### 框架四：仲裁——定制化的争议解决
- **四大优势**：便捷快速（快速立案/审理/裁决，直接换取执行文书）／专业公正自主（自选仲裁员与程序，适合专业性强的处置案件）／节省人力物力／**保密**（不公开审理，程序与结果不披露）；
- **仲裁条款效力**：补充协议继承主协议仲裁条款（案例：五方补充协议虽未约定争议解决，但作为主协议不可分割的补充，仲裁条款及于新加入的保证人）；**无效六情形**：超范围、无/限制行为能力人订立、胁迫订立、口头形式、约定不明且补充不成、**选的仲裁机构不存在**；
- **流程五步**：申请（有效仲裁协议＋申请书＋证据）→ 5日内受理通知 → 预交仲裁费 → 组庭审理（可调解/和解）→ 出裁决书/调解书；
- **保全两条**：仲裁前（向财产地/住所地法院）／仲裁中（通过仲裁机构提交法院）——涉外仲裁提交**中级人民法院**；
- **救济两途**：撤销裁决（六理由：无协议/超范围/程序违法/证据伪造/对方隐瞒证据/仲裁员索贿舞弊枉法）／不予执行（同类理由清单）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 代物清偿 | 以物抵债的学理名称 |
| 流质契约禁止 | 债务履行期届满前约定"还不上就归债权人"的禁止规则——期前抵债须清算 |
| 以物抵债裁定 | 执行中法院出具的物权变动文书——"协议 vs 裁定"是效力分水岭 |
| 赋强公证 | 赋予强制执行效力的债权文书公证——核心是"放弃抗辩"承诺 |
| 执行证书 | 公证机构在违约后出具的文书——作者主张非执行必要条件 |
| 仲裁条款独立性 | 补充协议继承主合同仲裁条款（保证人加入亦受约束） |

## 思维模型
- **"时点即轨道"**：以物抵债签在哪个时点，就走哪条效力轨道——谈判时先定位"我们在哪条轨道上"。
- **"裁定＞协议"**：执行中任何"协议"都可能被其他债权人掀桌子——拿到法院裁定才是真安全。
- **"放弃抗辩"定价**：赋强公证的价值全在债务人那句"自愿接受强制执行、放弃抗辩"——这是能省掉整个诉讼程序的钥匙条款。
- **"剩余权利也有价值"**：抵债标的从所有权扩展到**剩余期限的使用权/经营权**——想象力就是回收率。
- **"私有化司法"**：仲裁=当事人的定制程序（选人、选程序、保密）——当案件专业性强或需要低调处理时，它的溢价就是条款的溢价。

## 反模式
- **期前抵债不清算**：忘了折价与多退少补义务——协议效力存疑且得罪其他债权人。
- **拿和解协议当产权证**：执行中只签协议不申请裁定——白白暴露于其他法院的查封。
- **以为调解书=过户**：审判中调解书仅是债的确认——不去办交付/登记，物权没动。
- **土地抵债不办登记**：裁定在手也未变动——必须完成权属变更登记。
- **仲裁条款约定粗糙**：机构名称不全、"选择性约定"——条款无效白签。
- **只申请执行证书误事**：陷入签发程序的掣肘（作者观点：公证书即依据，别被执行证书卡住）。

## 实操示例
**"还款协议＋赋强公证"组合拳（重建自执行公证案例）**：
1. 引入新债务人（田某）与承债公司（天马），与公司（债权人）签《还款协议书》；
2. 核心条款三件套：①三方同意办理赋强公证 ②新债务人承诺按约定分期还款，否则债权人可申请执行证书并凭公证书+执行证书直接申请强制执行 ③**自愿放弃抗辩权、自愿接受强制执行**；
3. 担保跟进：保证人单独向公证机构提出接受强制执行的申请（锁定担保合同的赋强效力）；
4. 违约管理：任何一期逾期→立即评估"申请执行 vs 放弃执行改诉"（记得三情形可诉性规则）；
5. 执行衔接：向有管辖权法院申请强制执行，无需诉讼——时间即金钱。
**对照**：若对方抗拒放弃抗辩→退回常规诉讼或仲裁（第29章），别在无承诺的协议上浪费时间。

## 要点回顾
1. 以物抵债四时点四轨道：期前（清算）/期内（违约救济）/调解书（债确认）/执行（裁定=物权变动）。
2. 强制抵债四条件；土地抵债必须变更登记；标的可延伸至"剩余期限使用权"。
3. 赋强公证两要件；范围含担保合同与保函；执行证书非必要性（作者观点）。
4. 公证书可诉性三情形：债务人诉不受理/超期诉不受理/放弃执行而诉应受理。
5. 仲裁优势四；无效六情形；流程五步；保全与救济各两条。
6. 仲裁保密性是处置类案件的隐性价值——尤其涉及债务人声誉与商业机密时。
