# 第11章 资产包收购实战：某银行杭州分行资产包全解析

## 核心思想
这是一次完整的收购演习：**4处抵押物、4种典型场景**（县区商业广场 / 抵押前出租的沿街店铺 / 实控人自住住宅 / 二抵酒店），串联起不良资产估值最常用的五件工具：抵押物六层分析法、抵押前出租判断、抵押顺位规则、抵押金额与本金取小规则、估值四因素决策。

## 案例背景
- 2021年5月，某大型AMC收到某银行杭州分行（实为浙江省一级分行）资产包邀约：数十户不良债权，合计金额数千万元级，含次级与可疑类；担保方式以"抵（质）押+保证"及保证为主；
- 抵押物共4处，分布于湖州长兴、绍兴柯桥（两处）、杭州余杭、衢州柯城；
- 债务人A为*ST上市公司（借壳上市后激进扩张、资金链崩盘）；保证人含一家著名桥梁设计公司（已破产、已分配部分款项）、A的全资子公司、子公司的全资子公司、A的实际控制人。

## 核心框架

### 框架一：抵押物分析六层法
对每一处抵押物，按以下顺序层层递进（脑内分析即可，不必画图）：
**城市经济发达程度 → 区县经济发达程度 → 抵押物区位 → 抵押物优点 → 抵押物瑕疵 → 抵押物变现能力**
- 长兴县商业广场：县域经济百强第30名（电池产业之都）→ 但现场空置率高（无统一规划、缺大流量品牌）→ 变现能力中等偏弱；
- 柯桥区沿街店铺：绍兴主城区、轻纺城所在地 → 车水马龙人流好，承租人为连锁医院（现金流优质长期租户）→ **但"抵押前出租"为重大瑕疵**；
- 余杭区住宅：杭州城市能级高（特大城区）→ 小区配套完善 → 实控人夫妻自住（腾退有道德摩擦）→ 变现尚可；
- 衢州酒店：四省通衢、政府广场边、挂四星 → 但酒店是难去化业态 → 变现能力弱。
- **When**：时间有限时，先互联网预判，再决定是否现场——大面积金额占比小的抵押物可免跑（本案第一处即"估值可忽略"级别）。

### 框架二：抵押前出租（银行抵押权的重大瑕疵）
- 定义：抵押物在抵押给银行**之前**已出租给第三方；
- **三大不利后果**：①租赁存续期内承租人可继续使用，债权人无权干涉；②拍卖须**带租挂拍**，降低买受人意愿（买了不能马上用）；③承租人若已付清多年租金，银行拿不到后续年份租金（一年一付才有意义）；
- 对策判断：**抵押后出租不可对抗银行抵押优先权**（相对可控）；抵押前＋长租约＋大额预付＝价值大打折扣。
- **When**：现场尽调租赁情况必须问清"租赁合同签署时间 vs 抵押登记时间"。

### 框架三：抵押顺位与清偿规则
- 一抵（第一顺位）优先于二抵（第二顺位）受偿；一抵可能在不同银行间形成，也可能同一银行内部叠加（银行风险敞口因此放大）；
- **测算示例**：房屋评估1000万元——银行A一抵放600万；银行B二抵放余值400万×60%＝240万。房价跌到700万：B的240万只能收回100万；跌到600万：B颗粒无收。**二抵的回收对房价变动极度敏感（高β资产）**。

### 框架四：抵押金额与贷款本金"取小"规则
拍卖款清偿金额 = **min（贷款本金＋利息，最高额抵押金额）**：
- 情形1：本金1000万＋最高额抵押1500万，拍得2000万 → 银行拿**本金＋利息**（不是1500万）；
- 情形2：本金1500万＋最高额抵押1000万，拍得2000万 → 银行只能拿**最高额抵押金额1000万**（不是本息全额）。
- **When**：对二抵/超额抵押项目估值时，先确定"取小规则"下的实际受偿上限。

### 框架五：估值四因素（报价决策）
债权实际价值（尽调挖掘）＋银行预计回款（对方锚定）＋其他AMC估值（竞争面）＋你的投标意愿（战略面）。
- 本案作者的决策：大部分抵押物位置偏僻或存在租赁瑕疵、整体变现偏弱、短期难处置（**板结资产**风险）→ **理性报价（宁可不中）**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 抵押前出租 | 租赁先于抵押登记——承租人使用权优先于银行抵押权 |
| 带租挂拍 | 拍卖公告注明"带租约"，买受人须接受既有租约 |
| 抵押顺位 | 一抵/二抵的法定清偿顺序；二抵回收对资产价格的敏感度远高于一抵 |
| 最高额抵押 | 在最高债权额限度内担保连续发生债权的抵押——注意"取小"规则 |
| 板结资产 | 收购后难以快速处置、占用资本的资产（区位偏僻/租赁瑕疵是主因） |
| *ST退市预警 | 上市公司连续被出具无法表示/否定意见审计报告将触发退市——重大价值毁灭信号 |

## 思维模型
- **"六层漏斗"**：城市→区县→区位→优点→瑕疵→变现——迅速把无限信息收敛为一个变现判断。
- **租赁优先权扫描**：任何商业地产抵押物，第一个问题永远是"租给谁、租到何时、租金怎么付、租赁vs抵押谁是先手"。
- **高β警惕**：二抵、超额抵押、非标业态（酒店/在建工程）的回收对市场价高度敏感——要求更深的折扣或直接放弃。
- **保证人结构分析**：本案保证人4层（破产设计公司【已分配款】/全资子公司/孙公司/实控人）——**担保圈的价值要逐层评估，实控人个人担保才是终极抓手**。
- **不中标也是决策**：当尽调发现整体变现偏弱时，理性报价＝用纪律换安全边际。

## 反模式
- **为小抵押物耗大成本**：金额占比可忽略的抵押物不必亲赴现场（网上核实即可）。
- **忽视"抵押前出租"**：只看位置好、租户好，忽视租赁先手——尽调现场遗漏、估值高估。
- **把抵押金额当回款上限**：无视"取小"规则与顺位，估值系统性出错。
- **高估难去化业态**：商铺、办公楼、酒店（网购与远程办公冲击下供大于求）——去化难易度：住宅/厂房 ＞ 商铺/写字楼。
- **对*ST与破产保证人抱幻想**：退市预警＋无法表示意见的审计报告＝价值毁灭的明确信号，保证人破产则担保价值按其清偿率（常常很低）折价。

## 实操示例
**二抵回收敏感性测算（本案柯桥店铺场景）**：
- 抵押物：一抵金额A₁＋对应本金P₁；二抵金额A₂＋对应本金P₂；
- 拍卖所得V的分配：先偿一抵（min(P₁+利息, A₁)），余额偿二抵（min(P₂+利息, A₂, 余额)）；
- 设V下跌10%：一抵仍可能全额覆盖，二抵回收率可能从60%直接跌到20%-30%——**二抵资产的估值必须做房价下滑的压力测试**（建议至少-20%/-30%两档）。
**保证人追加回收测算**：破产保证人已通过管理人分配划付部分款项 → 直接冲减本息；对子/孙公司保证人（大概率空壳）按接近0估值；对实控人个人担保，横向调查其名下资产后再给值（访谈与涉诉线索见第9章）。

## 要点回顾
1. 六层分析法快速收敛抵押物判断：城市→区县→区位→优点→瑕疵→变现。
2. 抵押前出租是重大瑕疵：带租挂拍＋租金旁落＋腾退困难三连击。
3. 顺位与取小规则决定实际受偿上限，二抵项目必须做价格压力测试。
4. 估值四因素＝实际价值＋银行预期＋他方估值＋你的意愿。
5. 保证人结构分层估值，实控人担保是终极抓手；破产保证人按清偿率折价。
6. 理性报价的纪律：板结资产宁可放弃——不中标也是一种胜利。
