# 第4章 参与主体全景：生态圈里的角色、约束与诉求

## 核心思想
不良资产生态圈 = **供给方（银行）＋加工方（AMC/AIC）＋终端投资者（外资/民营）＋服务商（律所/评估/拍卖/配资/清收）＋司法与政府环境**。每类角色都有自己的约束条件和诉求——看清生态，本质是看清：你的对手盘是谁、你的队友是谁、每一方的"不能"在哪里。

## 核心框架

### 框架一：供给方——银行体系
- 顶层结构：中央银行（人民银行，最后贷款人）→ 政策性银行 → 商业银行（国有大行/股份行/城商行/农商行/信用社/村镇银行）。
- **不良的生成机制——踩踏效应**：企业第一次利息违约→征信进入"瑕疵级"→各家银行争先抽贷→资金链加速枯竭→不良最终爆发。"银行风控事后如惊弓之鸟，不在事前把控风险，自己把贷款催成了不良资产。"
- **When**：预判资产包的供给节奏与谈判地位——踩踏中期的银行最急于出包。

### 框架二：加工方——AMC 家族图谱
| 类别 | 成员与要点 |
|---|---|
| 四大全国性AMC | 华融（工行对口）、长城（农行）、东方（中行）、信达（建行）；1999年成立，财政部控股 |
| 第五家全国性AMC | 银河公司（2021年开业，中央汇金控股，"鲇鱼效应"）；注册资本100亿元以上 |
| 人民银行旗下 | 汇达公司：处置央行历史遗留资产，参与救助（如锦州银行） |
| 省级AMC | 2012年"一孩政策"（每省一家，注册资本100亿）→ 2013年门槛降至10亿 → 2016年"二孩政策"（每省可增一家）；**限制：只能参与本省批量转让、购入资产须债务重组处置、不得对外转让**；长期存在"监管真空"（无金融许可证） |
| 银行系AIC | 2017年起五大行设立（工银/农银/中银/建信/交银投资）；注册资本100亿元；专司市场化债转股及配套业务 |
| 外资持牌 | 橡树资本（北京）2020年注册，首家外资AMC（详见框架三） |

- **关键区分（AMC vs AIC）**：AMC是独立于银行的机构——**银行体系外**的风险隔离；AIC是商业银行集团内部子公司——**银行体系内**的风险隔离。银行不得直接将债权转为股权，须通过AIC实施。
- **AIC债转股白名单/黑名单**（《金融资产投资公司管理办法（试行）》2018）：优先——周期波动可逆转企业、高负债成长型（战新产业）、产能过剩行业关键企业；禁止——僵尸企业、失信企业、债权债务不清企业、助长过剩产能企业、金融业企业。

### 框架三：终端投资者
- **外资机构**：2001年入场（摩根士丹利首单108亿元资产包），2020年中美经贸协议再开放（省级牌照起步）；代表：橡树资本（管理规模约1200亿美元）。
  - 劣势：对国内司法环境、各级政府相对陌生；
  - 优势：**投行化思维做整体开发**（而非只做诉讼与公开转让）；
  - 注意：外资资金成本并不低——特殊资产板块预期回报10%以上，估值模型与国内不适配，"谈得多、成得少"。
- **民营投资人**：一级市场（从AMC受让）与二级市场（受让后再转让）的活跃主体，贴近区域、手段灵活。

### 框架四：服务商生态
AMC展业依赖七类服务商：**律师事务所、资产评估公司、拍卖机构、配资公司、报刊（公告）、信息供应商、合作清收机构**。
- 律所的法律分析报告是收购定价的关键输入，四查：①债权是否成立 ②抵押登记是否存瑕疵 ③保证担保是否无效 ④诉讼时效是否过期——重大法律漏洞直接影响估值。
- **When**：搭建交易团队、编制尽调预算时。

### 框架五：司法与政府环境
- **法院**：四级（基层/中/高/最高）＋专门法院（金融法院等）；与不良资产相关的三个部门：立案庭（窗口）、民二庭（金融纠纷审理）、执行局（强制执行）。
- **破产管理人**：律所/会计师事务所担任，程序中心角色；清偿顺序实践：工资、税款、工程款往往优先于抵押权 → 优先债权（最高额抵押范围内）→ 普通债权（清偿率常为0–10%）。**报酬博弈**：管理人报酬比例可协商，且"要先谈好报酬才能领取分配款"——急于回款的债权人易被抬价。
- **各级政府**：分管副职、金融办、帮扶办高频互动；政府目标是保税收、保就业、稳区域金融——这既是AMC的帮手，也可能成为处置的约束（见第12章三方博弈）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 踩踏效应 | 银行集体抽贷加速企业资金链断裂的自我实现机制 |
| 影子风险隔离 | AIC（体系内）vs AMC（体系外）的制度设计差异 |
| 服务商 | 律所、评估、拍卖、配资、报刊、信息、清收等第三方机构 |
| 破产管理人 | 法院指定、接管破产事务的专业中介（律所/会所） |
| 限高 | 限制失信被执行人高消费——失信名单制度（累计发布超1443万人次，限制购飞机票2682万人次级） |
| 帮扶专班 | 地方政府针对重点债务企业的协调机制 |

## 思维模型
- **生态位思维**：拿到一个项目先画生态图——钱从谁那里来（供给）、经过谁的手（加工/服务）、最终回款依靠谁（法院/政府/债务人）。
- **债务人"感冒"模型**：不能还款≠永远不能还——区分"感冒"（流动性困难，可康复）与"癌症"（经营模式死亡）；但"恶意逃废债"是另一物种，须全力追偿。
- **看待债务人的三层次**（石佳华）：①不歧视（创业规律是90%失败、10%成功）②动态（现在不能还不代表将来不能还；子女保证人有强还款意愿）③辩证（对转移财产的恶意逃废债者，动用一切法律武器）。
- **谈判时序心理学**：无论管理人报酬还是债权受让谈判——暴露"着急"的一方，把定价权交给了对方。

## 反模式
- **把AIC当AMC用**：ASIC不能替代AMC的跨体系风险隔离功能；银行不得直接债转股。
- **低估地方AMC约束**：不得对外转让、须债务重组处置——直接影响你与其合作（或收购其资产）的方式。
- **歧视一切失信债务人**：把可康复的"感冒患者"当成"老赖"处理，会错失重组价值。
- **忽略服务商成本与时序**：尽调、公告、诉讼、拍卖、管理人报酬合计可能吃掉可观回收——测算时全部计入。
- **期待外资推高价格**：外资受回报率约束（10%+要求），其报价未必高于国内买家。

## 实操示例
**金融借款诉讼12步标准流程（重建自书中清单）**：
1. 原告起诉并申请财产保全（本息+孳息）；2. 立案窗口审查受理；3. 送达受理通知与缴费通知；4. 收到案号，7日内缴费（逾期按撤诉处理）；5. 法院排期开庭、寄送传票；6. 开庭：身份核验、诉请、质证辩论、总结陈述；7. 判决；8. 胜诉后申请强制执行；9. 被告15日内可上诉；10. 或当庭和解（法院出具调解书）；11. 执行局查询财产→评估→网络拍卖（价高者得）；12. 回款分配（最高额抵押范围内优先抵押权人，剩余按比例），无财产则"终结本次执行"，发现新财产可恢复执行。
**练习**：把这12步映射到时间轴与现金流表——哪几步最耗时间？哪一步对回收率影响最大？（答案提示：执行局的财产查控与拍卖定价。）

**破产清偿顺序小算盘**：假设清算财产1亿元——工资/税款/工程款先走（实践中常优先于抵押权）；抵押债权在最高额抵押范围内清偿；剩余给普通债权（通常0–10%）。**推论**：做报价时，先确定自己是哪一层清偿顺位，再谈折扣率。

## 要点回顾
1. 生态圈五环：银行（供给）→ AMC/AIC（加工）→ 投资者（承接）→ 服务商（配套）→ 法院/政府（环境）。
2. 踩踏效应解释了不良资产"突然爆发"的机制——也解释了银行的谈判心态。
3. AMC与AIC：体系外隔离与体系内隔离，不可混用；AIC债转股有白名单与黑名单。
4. 省级AMC是"戴着镣铐的玩家"：区域限制＋不得转售＋必须债务重组。
5. 外资有投行思维但受回报率硬约束——不是天然的"高价买家"。
6. 破产管理人报酬谈判、清偿顺序：回款的每一环都有摩擦成本。
