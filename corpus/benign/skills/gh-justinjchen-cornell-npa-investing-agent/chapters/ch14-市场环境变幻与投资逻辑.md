# 第14章 不断变换的金融市场环境：三大力量与信用风险大转移

## 核心思想
1990年以来，**金融创新、新法律（BAPCPA）、2008年金融危机**三起大事重塑了不良资产投资环境。最深刻的变化是"信用风险大转移"：风险从受监管的商业银行，转移到了监管更少的非银机构手中——这让信用周期的波动比过去更大、更暴烈，也让不良资产投资的机会与陷阱同步放大。

## 核心框架

### 框架一：三大驱动力
1. **金融创新**：结构化工具（SIV、CLO、CDS）把贷款转化为证券，商业银行从"金融中介"退化为"承销商和分销商"——不再愿意承担信用风险；
2. **新的法律法规**：2005年《防止滥用破产和消费者保护法案》（BAPCPA）改写破产游戏规则（见框架四）；
3. **2007-2008金融市场崩溃**：资本市场冻结，所有依赖再融资的企业暴露于生死线。
- 量化参照：1980年代初，1美元困境公司担保贷款只卖约40美分；到1990年代初和2008危机前，同样贷款要付85–90美分——**周期决定价格，价格反映周期**。

### 框架二：信用风险大转移（脱媒全景）
| 渠道 | 要点 |
|---|---|
| 债券替代银行贷款 | 银行贷款占信用债市场：26.2%（1985）→21.5%（1990）→9.8%（2005年末）；企业债券升至56.9% |
| 垃圾债券（高收益债） | 通常无担保、契约限制少；144A豁免发行；1989年占非金融企业未偿债券20%；持有人=共同基金/养老/保险/CDO/对冲基金 |
| 夹层融资 | 小企业专属：私募发行、流动性差、持有到期、无担保、排序低于银行贷款 |
| 银团贷款市场 | 领头银行角色从"银行代表"变为"投行"（发行人=客户，借款人=投资者）；LIBOR+利差定价；循环贷款vs定期贷款；**加杠杆贷款定义**：评级BB/B及以下或利差≥125基点；一级市场从1989年<5000亿→2007年峰值2.25万亿美元 |
- **关键数据**：非银机构持有约**70%**的已发行杠杆贷款（几乎全是加杠杆贷款）；2006年非银持有**56%**的偿付问题贷款，而银行只有**16%**——**银行把最差信用甩给了非银**，这也是危机的燃料。

### 框架三：2008崩溃——资本市场通道=呼吸机
- 运营中的企业很少真正"还债"，而是靠**再融资续作**债务；扩张中的企业靠赚钱能力加杠杆——一切的前提是资本市场的门开着；
- 危机中门被关上：**好公司**（福特信贷、GE、高盛、摩根大通、美林、摩根士丹利）与**困境公司**（AIG、贝尔斯登、CIT、花旗、两房、GMAC、雷曼、华盛顿互惠）同列困境名单；
- **"熊市掠袭者"（做空者）五武器**：①报升规则取消（2007年纽交所）②期权市场（买看跌+卖看涨，低成本建仓）③**买CDS＋做空正股**（CDS涨→隐含违约概率升→股价跌的自我实现循环）④指数做空⑤互联网与商业电视传播传闻——针对需要持续融资、客户可低成本撤离的企业，威力巨大。
- **盯市会计（FASB 133/157）的双面性**：对"交易组合"是合适的（市价=最佳出售指标）；对**持有到期的正常贷款组合是误用**——市价波动不等于经济损害，被市场参与者误读为巨亏信号（MBIA案例）。

### 框架四：BAPCPA——破产规则的关键改动（影响重组成本）
- 排他性权利期：提交重组计划（POR）≤18个月、征求支持≤20个月（旧法120/180天且常无限延长——曾有案件排他期长达七八年）；
- 待执行合同与租约：接受非住宅租约时限210天；之后拒绝的，出租方可获两年租金补偿；
- 关键雇员保留计划（KERPs）受限（10倍/25%规则）——企业转而用"经理人激励计划"绕过限制；
- 欺诈性转让回溯期：1年→**2年**；定义扩大到低于合理价值的转让；
- 供应商15天货物召回 → 延长至45天（+20天缓冲）；
- 新增**第十五章跨境破产**（替代旧第304节）；
- 总体效果：**第十一章行政成本高企 → 预先打包（pre-packaged）/提前协商重组大行其道**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 脱媒 | 信用融资从银行转向资本市场（债券/银团贷款）的过程 |
| 加杠杆贷款 | 评级BB/B及以下或利差≥125基点的贷款（LPC/S&P口径） |
| 熊市掠袭者 | 通过做空、CDS、传播信息迫使弱势发行人崩盘的做空力量 |
| 盯市会计 | 按模型/市价记录金融工具价值（FASB 133/157）——制造账面波动 |
| 绝对优先原则 | 破产分配的价值按优先级顺序分配，除非债权人同意（Rule of Absolute Priority） |
| 排他性权利期 | 债务人独家提交与征求重组计划支持的期限（BAPCPA设为18/20个月） |
| 预先打包重组 | 破产申请前已就重组方案征得债权人支持的程序——BAPCPA时代的效率工具 |

## 思维模型
- **"风险转移≠风险消失"**：风险离开了银行资产负债表，进入了杠杆更高、监管更少的机构——系统性风险不降反升。分析任何市场结构变化时，先问"风险最终落在谁的身上"。
- **资本市场通道＝呼吸机**：判定企业脆弱性，不看它今天的利润表，看它**明天是否需要再融资**——需要，就是潜在的不良标的。
- **盯市错杀机会**：当市场价格反映的是会计波动而非经济损害时（MBIA式），就是不良投资者的猎场——"在评估这些证券未来表现时，可以完全忽略市场价格"（前提：不质押、不被迫出售）。
- **自我实现循环识别**：CDS涨→股价跌→评级降→客户逃→真的违约——识别谁在循环中被裹挟，谁被错杀。
- **法律变化即成本变化**：排他期收紧、KERP受限，让庭外谈判与预先打包成为主流——重组谈判的"时点游戏"规则已变。

## 反模式
- **用盯市价格评估持有到期的正常贷款**：把波动当损失，把机会当风险。
- **忽视通道依赖**：只看资产质量不看再融资需求——2008年的"好公司"照样溺亡。
- **把危机只当风险**：作者在危机中推荐的三只证券（MBIA盈余票据49%价位/收益率39.9%、GMAC 7.375%、森林城3%）判断"保持正常概率70%–90%"——危机是错误定价的批发市场。
- **无视BAPCPA后的成本结构**：还用旧时代的"拖"字诀做重组谈判——新规下拖不动。

## 实操示例
**MBIA 14%盈余票据的投资决策树（重建自书中案例）**：
1. 现状：价格约为票面**49%**，到期收益率**39.9%**（2013年1月15日回购日）；
2. 关键判断：MBIA在2007-2008年初注资约28亿美元后**资本充足**；回购日后票息=3个月LIBOR+11.26% → **有理由相信公司会尽力回购**；
3. 路径A（保持正常，概率70%–90%）：忽略市场价格，回报率37%–38%（低于到期收益率是再投资假设所致）；
4. 路径B（参与重组）：信用工具大概率转换为"获得充足融资的重组公司"的普通股，还可能享受**经营净亏损的税收冲抵优惠**；
5. 清算场景的终极问题："清算产生的现金是否足以偿付到期或回购时的贷款？"——是，则即使清盘，本金有望保全。
**决策要点**：先分"正常/重组/清算"三种情景，各自给概率与回收值，再算期望回报——而不是盯着市价波动做判断。

## 要点回顾
1. 三力量：金融创新、BAPCPA、2008危机——共同重塑不良资产市场。
2. 大转移：银行贷款份额一路降至9.8%；非银持有70%杠杆贷款、56%问题贷款——风险搬家，波动放大。
3. 2008的教训：资本市场通道一断，"好公司"与"坏公司"同列名单；做空者五武器让脆弱者加速坠落。
4. 盯市会计：交易组合适用、持有到期组合误用——后者是错误定价的主要来源。
5. BAPCPA要点：18/20个月排他期、2年欺诈回溯、45天货物召回、跨境第15章——重组成本与节奏的底层参数。
6. 危机中的行动纲领：分辨"市场价格波动"与"经济实质损害"，在70%–90%的正常概率上布局。
