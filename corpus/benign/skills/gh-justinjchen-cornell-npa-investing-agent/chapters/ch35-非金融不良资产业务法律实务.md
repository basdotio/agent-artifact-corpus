# 第35章 非金融不良资产业务法律实务

## 核心思想
非金业务的基础资产分三类——**债权类（债权）、实物类（物权）、股权类（股权）**，三类财产权利各有法律特点和风险地图。核心功课：**先按资产类型识别风险，再匹配处置模式**。非金与金融不良的最大区别：**标准化程度低、信用度低、成因复杂**——尽调的"真实、有效、洁净"三原则不是口号，是命门。

## 核心框架

### 框架一：债权类资产的六大一般风险（受让方视角）
| 风险 | 机制与对策 |
|---|---|
| ① 债权不存在 | 基础关系虚构/未发生——**虚构债权骗融资是核心风险点**；最高法近期判例：基础债权不真实不得对抗善意第三人（但争议仍存） |
| ② 效力瑕疵 | 合同无效（合同法52条）/被撤销（54条）/被解除/超诉讼时效（3年，转自然之债）——收购前逐项核查 |
| ③ 履约瑕疵 | 双务合同中转让方义务未履行完毕→债务人主张**同时履行/先履行抗辩权**——洁净性=转让方义务全部履行完毕 |
| ④ 可被抵销 | 债务人可向受让人主张抵销（先到期/同时到期的债权）——**收购前要求转让方与债务人共同确认金额并放弃抵销权** |
| ⑤ 转让瑕疵 | 可转让性（法定/约定禁止限制）+ 对内效力（合同约定时点）vs 对外效力（**通知送达债务人时点**）——非金业务不适用AMC公告特权，须稳妥送达 |
| ⑥ 一物二卖 | 债权无公示效力——**借鉴保理经验：中登网应收账款转让登记**，为债权转让附加公示效力 |
- **买卖合同债权的特殊风险**：货物交付与价款分批进行→金额可能不等于合同额（**核查运输/仓单/发票凭证**）；瑕疵担保责任等。

### 框架二：实物类资产的风险地图
- **权属四查**：担保物权负担（未经担保权人同意不得转让）／**买卖不破租赁**（租赁在先则转让不破租约）／共有财产（处分需2/3份额或全体共有人同意）／限制转让（受让人资格限制）；
- **转让规则**：不动产**登记生效**；动产**交付生效**；特殊动产（船舶/航空器/机动车）**未经登记不得对抗善意第三人**；
- **动产三种特殊交付**（AMC常遇）：简易交付（受让人已占有）／**占有改定**（约定由转让人继续占有）／**指示交付**（转让返还请求权）——AMC收购设备类动产通常不实际占有——**风险：实际占有人擅自处分+善意第三人取得**——必须做实管理工作；
- **善意取得三条件**（救急工具）：善意＋合理价格（**留存评估作价依据**，防"对价不合理被撤销"）＋登记/交付完成。

### 框架三：股权类资产的风险地图
- **权属**：股东名册为权属凭证；工商登记虽非生效要件但**不得对抗善意第三人**——以工商登记股东为准；**代持**情形须让隐名股东书面确认；
- **认缴出资陷阱**（2013年公司法修订后）：认缴未缴足=股东对公司的债务——**随股权一并受让**——收购前必查实缴情况并调整对价；
- **转让限制**：公司章程禁限转核查；股东对外转让须**过半数同意+其他股东优先购买权**——取得内部决策文件＋放弃优先购买权书面文件；
- **善意取得**：股权准用善意取得（最高法近期裁判倾向）；上市公司/外商投资/国有企业股权另需审批与国资程序（AMC自身为国有控股，一并适用国资程序）。

### 框架四：非金收购的特别风控动作（汇总清单）
1. 三原则内核：**真实**（基础行为真实发生）、**有效**（可转让）、**洁净**（无瑕疵负担）——尽调指向与设计增强；
2. **强确权**：转让方与债务人共同确认金额＋放弃抗辩与抵销的书面文件；
3. **公示化**：应收账款转让登记（中登网）；
4. **增强保障**：追加担保/债务加入（见第39章）弥补非金债权保障薄的先天不足；
5. **送达纪律**：转让通知切实送达债务人（非公告特权场景）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 自然之债 | 超过诉讼时效的债权——未灭失但丧失胜诉保护 |
| 同时履行/先履行抗辩权 | 双务合同中以对方未履行为由的拒付权 |
| 占有改定/指示交付 | 动产不实际转移占有的两种交付方式（AMC收购设备常遇） |
| 买卖不破租赁 | 租赁在先，物权转让不影响租赁关系 |
| 认缴出资义务 | 未缴足注册资本随股权转让——受让人的隐性债务 |
| 应收账款转让登记 | 中登网登记为债权转让附加公示效力（保理经验） |

## 思维模型
- **"三性体检"**：任何非金项目先过三关——真实吗（基础行为）？有效吗（可转让）？洁净吗（无瑕疵）？三问不打折。
- **"按权利类型配风险滤镜"**：债权看抗辩/抵销/时效；物权看权属/租赁/共有；股权看实缴/优先购买/代持——不同滤镜不同重点。
- **"占有≠无害"**：动产不占有（占有改定/指示交付）就要用协议+登记+巡查把控制权补回来。
- **"对价要留痕"**：折扣是行业常态，但要让"合理价格"可证明——评估作价文件是善意取得的护身符。
- **"非金补强法则"**：非金债权天生的保障薄弱——每个非金项目默认搭配一道增强（担保/债务加入/登记）。

## 反模式
- **轻信非金债权的真实性**：非金融机构信用度低、凭证残缺——虚构债权是核心风险，财务凭证与基础合同链必须闭环。
- **忽视认缴出资**：受让股权才发现未缴足——隐性债务吃掉全部收益。
- **漏办动产控制**：占有改定后不管不问——实际占有人处分+善意第三人取得。
- **抵销权裸奔交易**：不要求放弃抵销——执行阶段被抵销暗器击中。
- **照搬金融不良的公告特权**：非金转让通知必须稳妥送达——公告不是万能钥匙。

## 实操示例
**一个非金债权收购的标准作业包**：
1. 基础合同链核查（合同-发票-运输单-对账单-验收单——形成闭环证据链）；
2. 债务确认：转让方与债务人签署《债权金额确认书》＋《放弃抗辩及抵销权承诺》；
3. 可转让性核查（合同有无禁止转让条款/是否最高额抵押主债权）；
4. 转让通知：EMS＋签收回执（公证送达备选）；
5. 公示：中登网办理应收账款转让登记；
6. 增强：要求债务人追加实控人担保或提供抵质押（视谈判地位）；
7. 留痕：评估作价报告入档（防"不合理对价被撤销"）。

## 要点回顾
1. 三类资产三套风险地图：债权（不存在/瑕疵/履约/抵销/转让/二卖）、实物（权属/转让/善意取得）、股权（权属/实缴/优先购买）。
2. 债权受让六大风险的通用对策：确权、放弃抗辩、登记公示、稳妥送达。
3. 动产不实际占有的控制术：协议+登记+巡检。
4. 认缴出资与优先购买权是股权收购的两颗暗雷。
5. 非金收购默认配"增强"：担保/债务加入/登记。
6. 三原则是生死线：真实、有效、洁净。
