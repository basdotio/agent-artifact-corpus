# 第21章 估值分析与风险观：从"会不会违约"到"违约后值多少"

## 核心思想
不良资产投资的估值**不从"会不会违约"开始，而从"假设违约后、资本结构中每个信贷工具能得到什么"开始**。估值有两个引擎——严格持续经营与资源转换；而围绕估值的博弈（谁要高估值、谁要低估值）本质是**分配之战**。风险也不是一维的：七种限定语、四类结构风险、估值在破产全程的核心地位——逐项识别，才能保住回收。

## 核心框架

### 框架一：估值双引擎
**引擎一：严格持续经营（Going Concern）**
- 定义：企业持续投身同样日常业务、留在相同行业、管理与融资照旧——"比较少见"；
- 收益的严格定义：**在花费现金的过程中创造财富**——而且"收益不具备持续经营价值，除非企业能在现金不足时获得资本市场融资"（与第14章的"呼吸机"呼应）；
- **EBITDA调整实务**：净收入→加回利息（去资本结构影响）→加回税费→加回折旧摊销（非现金）；再剔除**非经常性/非营运项目**；
- **折旧vs资本支出陷阱**（三案例）：Texas Instruments（Capex中位数>折旧→EBIT高估收益）／Intel（两者接近→EBIT适用）／Micron（Capex≪折旧→EBIT低估收益）；
- **困境企业特殊风险**：此类企业可能**推迟必要资本支出来维持流动性**——只看报表EBITDA会系统性高估收益；正确量度=**EBITDA − 所需资本支出**；
- 分析师还必须估算**未来5年的现金缺口需融资多少**；重组费用（关厂/裁员/出售业务）要判断哪些是一次性、哪些影响未来收益。

**引擎二：资源转换（Resource Conversion）**
- 活动清单：剥离、并购、所有权与控制权转移（MBO/IPO）、资产收购融资、债务再融资；
- 证据：道琼斯成分股5年的资源转换调查（并购/剥离/回购等大量发生）——**纯严格持续经营是少数派**；
- 含义：估值不能只算经营现金流，要算资产换个用途/换个主人后能值多少。

### 框架二：估值在破产程序中的角色（全流程核心变量）
估值决定：充分保护（361）／解除冻结（362）／资产使用出售与现金抵押（363）／担保索偿拆分（506）／1111(b)追索与无追索选择／优先转移的偿付能力分析（547）／欺诈性转让（548/544）／货物收回（546）／计划可行性与公平公正（1129(b)(2)）／最佳利益测试与模拟清盘（1129(a)(7)）。
- **抵押物估值双标准**（506(a)）：债务人**自用**→重置价值；**处置**→处置价值；
- **估值之争的本质**：一方出高值、一方出低值，各有证据——"估值争议的结果很难预测"。

### 框架三：估值博弈论（谁想要高、谁想要低）
- **低级类别**（老股东/初级次级债务人）：要**高估值**——才能"参与"重组分得一杯羹；
- **控股股东/管理层**：也可能要高估值或拖延——借估值争议**拖延计划批准**、保住控制权；
- **高级类别**：倾向**低估值**——债务人更容易继续经营、计划更容易实施；
- **补偿形式→可行性法则**：发行越高级的证券（现金支付工具）越多，重组可行性越低；发行越多的**所有者权益（不带强制现金义务）**，可行性越高；例外：现金工具能换来更有利的融资渠道。反例：**航空业若干公司因债权人对现金工具的要求，重组后资本结构不可行，很快二次破产**。

### 框架四：风险的两个梯队
**第一梯队：七种限定语**——投资风险（资本永久性损失）、信用风险（是否违约）、操作风险、评级风险、通胀风险、市场风险（OPMI波动）、**重组风险**（如何重新资本化、每类债权人拿多少）。价值投资者"不用'风险'这个词，除非加上限定语"。
**第二梯队：不良投资四类结构风险**
| 风险 | 机制 | 投资者动作 |
|---|---|---|
| ① 优先级改变 | **公平降级**（510(c)：须从事不公平活动＋损害他人/自获优势＋不违反破产法——Mobile Steel三要求；罕见但致命）；**实质合并**（子母公司资产负债合并；检查表：运营独立性/账目可分性；三种司法测试） | 尽调四问：原持有人是否被降级？转让是否会受影响？是否内部人/控制主体？贷款人何时获得控制？（安然诉斯普林菲尔德：降级"个人能力"可随转让让渡，但出售不行） |
| ② 估值风险 | 抵押物估值标准之争；**价值折损三因**（买方继续使用磨损/经济恶化/未受保护）；举证责任在债务人；保护不足时507(b)给行政费用优先权 | 核对你拿到的是"充分保护"还是"口头保证" |
| ③ 重组风险 | 提交计划前的补偿不确定性——你预期得到的和最终得到的可能不同 | 用概率分布而非点估计做测算 |
| ④ 其他风险 | **关键供应商支付**（凯马特：2,330家供应商获付约3亿美元，资金来自新增DIP超级优先融资——实质是对无担保债权人的让步）；**担保权益瑕疵**（担保协议＋完善备案；UCC融资报告名称错误可让担保变无担保！） | 买入索偿前跑一遍"担保四验"：协议、备案、名称、优先顺序 |

### 框架五：投资信息检查清单（第10章尾部汇总）
- 结构化次级（控股公司/受监管子公司）／实质性合并可能性／正常贷款企业的违约事件／修订契约／消极承诺条款／公平课税条款；
- 信息源：《每日破产回顾》（Daily Bankruptcy Review）等；想更深入可聘私人调查机构或设法获取公司所得税申报表（公开市场投资者通常拿不到）。

## 关键概念
| 术语 | 定义 |
|---|---|
| EBITDA−Capex | 更准确的困境企业收益量度（剔除折旧与真实资本需求差异） |
| 资源转换 | 通过换用途/换所有权（并购、MBO、IPO、再融资）创造财富 |
| 公平降级 | 510(c)下将索偿降为次级——针对不公平行为的极端救济 |
| 实质合并 | 把不同法律主体的资产/负债合并对待——改变回收的"原子弹级"救济 |
| 关键供应商支付 | 备案后全额偿付特定供应商的历史欠款——损害其他无担保人的利益 |
| 完善担保权益 | 通过UCC备案对第三人产生效力的步骤——名称错误=担保失效 |
| 重组价值博弈 | 低级类别要抬估值、高级类别要压估值——分配之战 |

## 思维模型
- **"违约后估值"思维**：起点不是概率预测，而是**情景下的分配计算**——先假设违约，再逐层分钱。
- **Capex滤镜**：看任何困境企业的EBITDA都先过一层"资本支出真实性"滤镜——推迟维修/更新的企业透支的是未来。
- **估值即分配**：估值的每一分变化都会落到某一类债权人的口袋——谈判时永远问"这个估值数字改变了谁的回收"。
- **可行性-补偿曲线**：设计重组对价时，沿"现金义务→权益"的滑杆调节可行性——现金越多越易谈成、越难存活。
- **降级尾巴扫描**：买任何控制型贷款人/内部人背景的索偿前，先查它的"公平降级尾巴"。
- **担保四验**：协议→备案→名称→顺位——四验不过，担保索偿就是普通索偿。

## 反模式
- **直接用GAAP净收入或未调整EBITDA估值**：忽略capex缺口与一次性项目。
- **买忽视担保瑕疵的债权**：UCC名称错一个字母，回收天壤之别。
- **给重组后公司塞满现金工具**：为拿"高级别"补偿而牺牲可行性——航空公司的二次破产教科书。
- **把最低类别的高估值提案当利好**：低级证券持有人与管理层抬高估值往往是为**拖延或重新分配**，不是价值创造。
- **忽视实质合并的前置布局**：集团内担保链密集的债权，回收取决于合并测试的走向。

## 实操示例
**一家困境制造企业的估值与分配演练（模拟）**：
- 情景A（严格持续经营）：EBITDA 5000万 − 必要Capex 3000万 = 可持续收益2000万；按6倍≈企业价值12亿；
- 情景B（资源转换）：核心厂区处置价值8亿＋品牌/渠道出售2亿 = 10亿；
- 分配演算：担保银行（抵押物重置价值5亿）全额受偿5亿；优先级无担保（3亿）回收率约（10−5）×70%…按绝对优先逐层推；
- **估值区间[10亿,12亿]即谈判走廊**：低级类别拉向12亿、高级压向10亿；
- 补偿设计校验：若给银行全部现金票据，可行性测算的固定偿付覆盖率<1.1 → 换成"现金+新股"组合，覆盖率>1.5——**用滑杆调可行性**。
**风险清单同步过一遍**：担保四验✓；公平降级（原持有人为控股股东关联方→高风险，要求价格折让）；实质合并（集团内交叉担保→概率高，按合并后口径重算）；关键供应商（已获批3亿支付→对应减少分配池）。

## 要点回顾
1. 估值起点：违约后、资本结构工具逐层分配——不是违约概率预测。
2. 双引擎：严格持续经营（EBITDA−Capex）＋资源转换（换用途换主人）。
3. 抵押物估值双标准（自用=重置价；处置=处置价）；估值战本质是分配战。
4. 四类结构风险：公平降级、实质合并、估值折损、担保瑕疵＋供应商支付。
5. 补偿形式决定可行性：现金义务越多越危险；权益越多越稳。
6. 尽调清单：结构化次级、实质合并、违约事件、消极承诺、担保四验。
