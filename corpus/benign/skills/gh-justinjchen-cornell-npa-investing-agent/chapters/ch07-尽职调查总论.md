# 第7章 尽职调查总论：尽调三目的、两大阶段与报告体系

## 核心思想
尽职调查是不良资产收购定价的"地基"——它的产出不是一堆资料，而是一个**可报价的判断**。所有尽调动作服务于三个目的：发现潜在价值、核实出让方披露信息、确定购买价格与处置路径。而真正的功力差距，不在投资前（前奏曲），在投资后的深度挖掘——"生命不息，尽调不止"。

## 核心框架

### 框架一：尽调三目的（行动导航仪）
1. **发现潜在价值**：根据资产包规模与结构确定尽调期限（数日到半年不等），重点挖掘潜在价值资产；
2. **核实披露信息＋设置保护条款**：以独立判断核实出让方信息准确性，并在交易结构中设置限制性条款预防风险；
3. **确定购买价格＋初步确立处置意向**：这是终极目的——确定价格，并想清楚收购后怎么处置。
- **When**：任何一次尽调启动前，先明确本次尽调服务于哪个目的；每个调查动作都应能回答"它帮哪个目的"。

### 框架二：尽调对象的两个维度
**维度一：资产包本身**
| 对象 | 核查要点 |
|---|---|
| 借款人 | 工商、房产、土地、税务、对外投资、负债、现场经营、报表文件 |
| 担保人 | 担保金额/范围/方式的合同约定＋同借款人一样的全面调查 |
| 抵押人/抵押物 | 按类别调查（房产/土地/设备/其他产权） |
| 本息 | 债权本金与利息（计算至基准日） |
| 诉讼状态 | **未诉**：核实转让有效性（主体/方式合规）＋诉讼时效；**已诉**：核实执行时效（是否中止/中断） |

**维度二：资产包所在市场**
- 区域经济环境（反映债务人还债能力）→ 司法环境（清收速度＋对债务人的威慑）→ 是否有合作伙伴 → 资产退出活跃度。
- **When**：同等债权条件、不同区域的两只包，报价差异的根源常在维度二。

### 框架三：尽调类型矩阵
**按范围：全面 vs 抽样**
- 全面调查触发条件：包内笔数/户数不多；**抵押类贷款或抵押物一律全面调查**；次级类资产全面调查；
- 企贷抽样规则：按剩余本金排序或设界限（如500万元以上全查）；样本覆盖本金不低于80%、最好90%以上；单户多笔/关联贷款按整体纳入；**有抵押物的一律重点**；**抵债资产一律尽调**；
- 个贷抽样规则：按项目（同一开发商/车商）划分；覆盖本金>80%（过于分散可适度调低）；**虚假个贷按项目全查**（本金较大、范围易定），真实个贷（小额分散）可用预留电话做电话访谈评估。
- **When**：收到《邀请函》后设计尽调方案——时间和人力有限时，抽样规则决定你的安全边界。

**按阶段：投资前 vs 投资后**
- 投资前（概括性、粗放性、抽样性）七项：来源渠道/标的额/抵押物初步评估/司法环境/价格/投资能力/退出市场环境；
- 投资后（深度挖掘）——真正拉开差距：审阅档案并访谈经办人 → 勘察实物与抵押物（在建工程欠费、被租占、抵押登记效力、多抵押权人、最高额抵押范围、可撤销情形）→ 工商调档 → 破产程序查询（登记、清算方案、财务数据）→ 重大财产（土地房产/车辆/分支机构）→ 诉讼执行状态（立案/审理/执行/查封冻结/以物抵债/和解恢复/终结）→ 社保缴纳 → 公路收费权质押 → 商标专利……
- **When**："投资前的尽调只能算前奏曲，投资后的尽调才是揭开债务人面纱的利器。"

### 框架四：尽调输出物体系
| 文书 | 出具方 | 核心内容 |
|---|---|---|
| 《法律意见书》 | 律所律师（分户出具） | ①调查过程 ②主债权+担保+抵押+转让四查 ③债务人与保证人（工商/财务/经营/财产线索）④抵押物（登记/查封/实勘/估值）⑤代理起诉判决执行 ⑥结论（时效/追偿价值/建议） |
| 《尽职调查报告》 | 尽调小组（在律师意见书基础上综合） | ①调查期间范围程序 ②债权整体概况（分布/形态/诉讼状况/地域）③资产包特点（抵押/债务人/保证人）④整体价值判断（附件列重点逐项）⑤难点与风险收益点 ⑥**整体处置预案＋处置费用与时间预测**（作为收购价格参数）⑦结论 |

- **关键**：处置预案、费用和时间的预测，是收购报价的重要参数——不会做处置预案的尽调报告，等于没写完。

## 关键概念
| 术语 | 定义 |
|---|---|
| 尽调简洁版定义 | 尽调方利用专门工具和指导手段对项目所涉债务人及关联企业进行的资产情况调查 |
| 抵债资产必查原则 | 银行依法行使债权/担保物权受偿的实物资产，一律纳入尽调 |
| 虚假个贷 | 打包在个贷资产包中、以个人名义作幌的企业贷款——按项目全查 |
| 双重尽调原则 | 现场尽调执行双人同行（本书作者实践惯例） |
| 执行时效 | 已诉债权需要关注的时间线（中止、中断情形） |

## 思维模型
- **尽调三问**：每个调查动作过一遍——发现了价值吗？验证了披露吗？能帮助定价吗？三问皆否的动作，砍掉。
- **碎片→系统**：尽调的本质是把碎片化信息（金额、效力、担保、财产、背景、障碍）编织成有逻辑的定价判断；信息有时效、地域、真伪、不确定四重干扰——交叉验证是唯一解。
- **"前奏曲与正曲"**：投资前尽调定生死（要不要买），投资后尽调定盈亏（能挖多深）。
- **抽样安全边际**：抽样的不是"省事"，而是用80–90%本金覆盖率换取尽调效率；抵押物与抵债资产不参与抽样妥协。

## 反模式
- **只做投资前尽调**：把尽调当成买入前的"一次性门票"，收购后不再挖掘——错失最大价值来源。
- **抽样漏掉必查项**：抵押物、抵债资产列入抽样范围是致命错误。
- **报告写成一堆资料**：没有价值判断、没有风险点、没有处置预案与费用时间预测——无法支撑报价。
- **忽视市场维度**：只看债权本身不看区域司法环境、退出活跃度——同样的债权在两地的回收率可以差一倍。

## 实操示例
**一次完整的收购前尽调设计（重建自书中方法）**：
1. 收到银行《邀请函》与债权清单 → 决策是否参与（时间/债务人/抵质押率/抵押物分布/户数/金额）；
2. 签署《邀约确认函》＋《保密承诺》→ 获取电子版信贷档案（借款/保证/抵押合同、产权证、主体资料、财务报表、诉讼资料）；
3. 制定尽调方案：抵押物100%全查；其余按剩余本金从大到小抽样，目标覆盖本金≥85%；抵债资产全查；个贷按项目分组＋电话访谈；
4. 现场尽调（双人）＋工商调档＋法院执行查询＋破产查询；
5. 汇总律师《法律意见书》，形成《尽职调查报告》——含**逐户估值附件 + 处置预案 + 费用时间预测**；
6. 输出内部报价建议 → 进入投标环节（见第10章）。
**检查点**：第6步的报价建议能否用第3步的抽样覆盖率自证稳健？若重点户（前20%金额）未100%覆盖，报价即为空中楼阁。

## 要点回顾
1. 尽调三目的：发现价值、核实披露、定价定预案——一切动作向目的对齐。
2. 对象双维度：包内（借款人/担保人/抵押物/本息/诉讼状态）＋包外（区域经济/司法环境/合作方/退出活跃度）。
3. 抽样铁律：抵押物一律重点、抵债资产必查、覆盖率80–90%目标、"500万以上全查"式界限法。
4. 投资后尽调是深水区：档案访谈、实物勘察、工商调档、破产与执行查询、社保商标等冷门线索。
5. 输出物：律师《法律意见书》（六大项、分户）＋小组《尽职调查报告》（含处置预案与费用时间预测）。
6. "生命不息，尽调不止"——尽调不是阶段，是习惯。
