# 第17章 交易费用、承担方与关键事项：破产博弈的成本账

## 核心思想
破产是一场**由债务人现金买单的博弈**——律师和财务顾问的费用优先于无担保索偿、现金即期支付、极少拖延。这意味着：**专业费用实质上是无担保债权人的回收值在燃烧**。理解谁付钱、付多少、为何拖延，是估算回收率的必修课；再叠加管理层的留任博弈与税务陷阱，构成了不良资产投资的"隐性成本清单"。

## 核心框架

### 框架一：专业费用机制（谁付、凭什么、付多少）
- **付款人**：债务人；**法律依据**：第503(b)(4)条认可行政费用合法；**第507(2)条**——行政费用优先于其他无担保索偿；
- **委员会结构**：第1102节授权美国信托人组建债权人委员会（无担保债权委员会＋必要时股权持有人委员会）——资本结构越复杂，委员会越多，费用越高；
- **收费模式差异**：
  - 律师：**按时间计费**（总费用与案件时长强相关）；
  - 财务顾问：月费＋奖金式费用（重组费/完成费/奖励金/交易费）——**与时间无关，与"交易完成或案件结束"挂钩**（不论最终结果好坏）；
- **统计数据（48起案件）**：普通第十一章案平均专业费用约 律师981万美元＋财务顾问787万美元（律师占比55%/财务顾问45%）；**预打包/提前协商案**约 律师222万＋财务顾问179万——**破产前的谈判可以直接把费用砍掉75%**；
- 结案时间：BAPCPA把排他期投票上限定在20个月，与常规案件平均结案时间相仿——但实践中"其他各方引入方案"仍会拉长战线。

### 框架二：谁真正承担费用（回收率杀手）
- 费用以现金即期支付→**直接减少债务人资金**→最终来自无担保与担保不足债权人的回收值；
- **小型重组（经验值＜3亿美元）**：现金费用可能直接掏空债务人，无担保债权人**颗粒无收**；
- **大型破产**：自动冻结与DIP融资的超级优先级条款可以暂缓现金流出，费用影响被部分抵消；
- 残酷结论：**无论哪种情况，费用都来自无担保和未获充分保障的债权人的那部分利益**。

### 框架三：管理层留任与抗御（第十一章里的"软性优势"）
- 实践中罢免管理层/任命信托人**极少发生**——管理层留任经营（超出一般业务的活动受法庭监督）；
- 排他权（本可18个月）让管理层控制公司节奏，**对债权人形成不对称杠杆**（发起抗御、争取补偿、限制新证券发行）；
- KERP（关键雇员保留计划）在BAPCPA后被限制，但**改用"激励计划"即可绕开第503节限制**（凯马特离职经理人赔偿是著名案例）；
- 加速重组的理由：费用随时长膨胀；拖延的倾向"总是向增加专业人士费用方向发展"——小公司尤甚，因为费用直接吃掉债权人回收。

### 框架四：税务四大坑（债务重组的隐藏成本）
| 坑 | 机制 | 投资者应对 |
|---|---|---|
| **COD收入**（债务免除） | 债务被豁免=企业确认收入；IRC 108(b)要求以减免税收抵免属性抵消（NOL等顺序递减） | 评估债务交换比例时把税负最小化作为变量 |
| **OID**（首发折扣） | 1990年修法后重组交换产生的OID需缴税——**最有害**：最高税率、纳税时点不可控、缴税时没有现金收益 | 计算持有期应税收入，避免"无中生有的应税收入" |
| **NOL限制** | 以股抵债豁免被取消，重组后公司利用经营净亏损受限 | 重组后公司的税收价值重估 |
| **证券界定** | 债务工具是否属"应税证券"：**经验法则——原始期限≥10年的债务工具一般按应税证券处理** | 交易结构设计时核对期限 |

## 关键概念
| 术语 | 定义 |
|---|---|
| 行政费用优先权 | 第507(2)条：破产行政费用（含专业费用）优先于无担保索偿支付 |
| 债权人委员会 | 第1102节授权设立的官方委员会——代表债权人谈判与监督 |
| 预打包便宜 | 预打包/提前协商案的破产专业费用仅为常规案的两三成 |
| 排他权杠杆 | 债务人（实为管理层）独家提出重组计划的权利——对债权人的不对称优势 |
| COD/OID | 债务免除收入/首发折扣——重组税务的两大经常性陷阱 |
| 重组价值3亿美元线 | 低于此线的企业，专业费用可能掏空破产财产——投资小案需极端保守 |

## 思维模型
- **费用意识（Fee Drag）**：给任何重组案做回收测算时，先扣一层"专业费用池"——小案按财产占比可能高于10%，大案也要按百万美元级预提。
- **"拖延的激励链"**：律师按小时计费＋案件越复杂委员会越多＋管理层借排他权拖时间——**各方都有拖的动力，只有债权人着急**。反过来利用：**你的谈判筹码之一是"加速方案"（预打包能省钱，双方都有动力）**。
- **预打包经济学**：破产前谈成方案=省下75%的专业费用——这是"庭外博弈优于庭内"的量化依据（对应第19章"自愿交换"）。
- **管理层补偿再定价**：把KERP/激励计划/遣散费看作一个"管理层抽租率"，从回收预期中扣除。
- **税后回收思维**：不良债务的税后收益才是真收益——OID/COD会静默削掉可观回报。

## 反模式
- **只看偿付率不看费用池**：忽略费用的小案回收模型系统性高估。
- **忽略税务结构**：把税务当会计细节——OID税可在没有现金收入时产生现金税负。
- **与拖延共谋**：接受慢节奏谈判而不推预打包——把回收值交给计时表。
- **不做管理层激励审查**：不审查KERP/激励计划就谈重组——才发现钱已经在"保留团队"里花掉。

## 实操示例
**一笔中型破产债权的回收快算（模拟）**：
- 破产财产可分配值约2亿美元（重组价值<3亿美元线）；
- 预估专业费用池：律师+顾问按常规案中位数合计约1500万美元→占可分配值7.5%；
- 若案件拖到36个月（vs 18个月）：律师费近似翻倍→费用池升至约2500-3000万美元；
- 无担保债权（假设占债务结构50%）分得的回收值因费用增加而下降（约5个百分点）；
- **决策**：优先推动预打包方案（费用池可压缩至约500万美元级）——向对方展示"费用节省的分成"作为谈判甜点。
**对照**：同样的债权，在常规流程下净回收率可能比预打包低3-5个百分点——这就是**程序选择权本身的价值**。

## 要点回顾
1. 专业费用优先于无担保索偿、现金即期——**实质是无担保债权人在买单**。
2. 律师55%/顾问45%；律师按时间、顾问按奖金结构——激励方向不同。
3. 预打包/提前协商案的费用约为常规案的两三成——程序选择有真金白银的价值。
4. 管理层：留任＋排他权＝不对称杠杆；KERP被限但激励计划可绕开。
5. 税务四大坑：COD、OID（最有害）、NOL受限、≥10年期限的证券界定。
6. 小型破产（<3亿美元）投资：费用敏感度极高，回收测算必须极端保守。
