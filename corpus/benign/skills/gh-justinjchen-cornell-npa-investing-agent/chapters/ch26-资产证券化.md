# 第26章 资产证券化：把"不流动的现金流"变成可流通的证券

## 核心思想
证券化的本质是**资产信用融资**——偿付来源锁定在特定的资产池现金流上，**与发起人的信用无关**（"真实出售"＋SPV隔离）。对不良资产而言，它的悖论是：素材本身"不稳定"，靠**组合、预测与分层**制造出相对稳定的现金流结构。华尔街的名言："只要能产生稳定现金流的资产，我们就能把它证券化。"

## 核心框架

### 框架一：定义与本质
- 中国口径（《信贷资产证券化试点管理办法》）：从不良贷款中抽取部分组成资产池，出售给SPV；SPV通过**信用增级**定价发售，成为可流通证券，持有人享受未来现金流所有权；
- 三点本质：①对**特定资产池现金流**的权利（不是对经营实体的权利要求）②权益偿付来源锁定、客观③**信用等级只取决于资产池，与发起人无关**。

### 框架二：基础资产四大类
| 类别 | 示例 |
|---|---|
| 金融机构信贷资产 | 住房/汽车/消费/商业地产按揭、企业贷款、**不良贷款**、公积金贷款、信用卡应收 |
| 企业债权 | 保理应收款、企业应收款、小额贷款、委托贷款、信托收益权 |
| 企业收益权 | 租赁收益权、市政水电气与基础设施收费权、路桥/经营场所/票款/PPP收益权 |
| 不动产资产 | 商业/工业地产、保障房、养老/医疗地产——公私募REITs产品 |
- **负面清单五条**（不得入池）：①政府及平台公司为债务人的资产（PPP除外）②未开发/未完工不动产（保障房除外）③矿产与土地出让收益权④准物权（提单/仓单/产权证——需处置才产生现金）⑤无关联资产组合（异质资产混装）。

### 框架三：基础资产实质要件五条
1. **构成独立财产权**：法律上清晰界定、无抵押质押等限制、权利实现不依赖其他财产；
2. **权属清晰**：获取与存续无条件无限制；
3. **可合法有效转让**（"真实出售"）——三类禁止转让：具有人身属性的债权／当事人约定不得转让／**最高额抵押担保的主合同债权**；
4. **标准化、同质性高**：格式化合同、付款期限稳定可预测；
5. **债务人分散**：集中度低，无单一大债务人风险。

### 框架四：不良ABS的发行条件（五条）
1. **未来可预期稳定现金回流**——不良虽已违约，但可通过催收/诉讼/拍卖/重组回收；
2. **现金回流分布在整个存续期**（合同期限不再可信——要逐项目预判时间，用多项目组合平滑）；
3. **行业与地区足够分散**（不把鸡蛋放一个篮子）;
4. **规模化效应**（达不到规模，证券化费用吃光收益）；
5. **合同条款标准化、高质量**——国防/军工、国家安全敏感债权不得入池。

### 框架五：交易流程四步与参与主体
**四步**：①发起人组建资产池 → ②设立SPV、原始权益人向SPV**转让基础资产** → ③SPV设计交易结构、进行**结构化信用增级** → ④SPV发行证券、投资者认购，募集资金支付转让款。
**主体图谱（首单"2008建元重整资产证券化"实配）**：发起机构=建设银行；发行人/受托=中诚信托；主承销=中金公司；资金保管=工商银行；资产服务顾问=某AMC；登记=中债登；评级=联合资信。

### 框架六：分层装载与增信设计
- 标准结构：**优先级／夹层／次级**（按风险偏好定价）；不良ABS的次级通常由发起人自留（自担首损）；
- 附加条款：**回购条款**（回现不达预期时交易对手可要求银行赎回）＋**超额收益条款**（上行时按比例分成——"利润的二次分配"）；
- 边界：**简单分层（一次）是透明可控的**；2008年危机式的二次、三次嵌套CDO在国内现阶段监管不允许。

## 关键概念
| 术语 | 定义 |
|---|---|
| ABS | 资产支持证券——以资产池现金流为支持的可流通证券 |
| SPV | 特殊目的载体——实现资产隔离与"真实出售"的法律容器 |
| 真实出售 | 资产从发起人表内/信用中切割出去——证券信用与发起人脱钩 |
| 分层/次级自留 | 优先-夹层-次级的风险切割；发起人留次级=风险共担信号 |
| 超额收益条款 | 回现超预期时发起人与投资人的分成机制 |
| 资产负面清单 | 五类不得入池资产（政府平台/未完工/矿权地权/准物权/无关联组合） |

## 思维模型
- **"稳定的悖论"**：素材越不稳定，越依赖组合设计与预测能力——不良ABS功夫在**资产池工程**，不在包装。
- **信用切割**：SPV隔离=把"谁发的"与"拿什么还"分开——凡涉及风险隔离的交易结构都可借用这个思维（如救助中的新设主体）。
- **分层装载迁移**：把确定性（优先）与可能性（次级/超额分成）分层出售——任何复杂重组方案都可沿用（参照中钢"留债+可转债"）。
- **规模阈值意识**：证券化有高额固定费用——不到规模不上桌，小资产包直接走转让/诉讼更划算。

## 反模式
- **把不可预测现金流硬包装成"稳定"**：脱离回收预测的产品设计=埋雷。
- **忽视可转让性瑕疵**：约定不得转让、最高额抵押主债权等混入池——"真实出售"失败，法律基础坍塌。
- **集中度失控**：单一行业/地区/债务人过重——池子一出事就是系统性事件。
- **越界结构化**：国内做多层嵌套CDO——监管红线。
- **忘算费用账**：小池子证券化——发行费/评级费/服务费吃掉全部超额收益。

## 实操示例
**首单建元复盘（数据说话）**：
- 资产池：基准日（2007.6.20）未偿本息合计113.5亿元；借款人656户、合同1000笔；覆盖10家一级分行、17个行业；
- 发行：2008.1.24簿记，优先级21.5亿元当日认购达规模；
- 兑付：2009.9.23应次级投资人要求终止信托——累计兑付优先级本金21.5亿＋利息9,106万＋次级本金4.83亿。
**设计清单（自家项目对照）**：①回收预测模型有吗（逐项目时间表）②行业/地域集中度多少③转让限制清了吗（三类禁止）④规模够覆盖费用吗⑤次級自留与激励对齐了吗⑥回购/超额分成条款谈了吗——六问皆过，方可进入SPV设立。

## 要点回顾
1. 证券化=资产信用融资；信用等级取决于资产池，与发起人无关。
2. 四大类基础资产＋负面清单五条＋实质要件五条（含三类禁止转让债权）。
3. 不良ABS五条件：可预期回流/分布存续期/分散/规模化/合同标准化。
4. 四步流程：组池→SPV转让→增信设计→发行支付；主体分工明确。
5. 分层（优先/夹层/次级）＋回购/超额分成条款；多层嵌套CDO被禁。
6. 建元样本：113.5亿池→21.5亿优先级→圆满兑付——中国不良ABS的起点。
