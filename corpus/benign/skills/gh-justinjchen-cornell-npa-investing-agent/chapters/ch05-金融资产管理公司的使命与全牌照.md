# 第5章 金融资产管理公司：使命与全牌照

## 核心思想
AMC 是银行体系之外的"风险加工厂"：**以不良资产为资源、以全牌照金融工具为手段**，兼具政策性与商业性的二元属性。它存在的深层意义，是充当信贷资源配置的"存量优化器"——把呆滞在淘汰企业身上的信贷资源释放出来，重新导向有前景的企业。

## 核心框架

### 框架一：历史使命三步走
| 阶段 | 使命 | 标志 |
|---|---|---|
| 政策性（1999–2006） | 对口剥离四大行不良、政策性债转股助国企脱困 | 完成约2.5万亿元处置任务 |
| 商业化（2007–2016） | 股改、引战、上市＋收齐金融牌照 | 转型综合金融服务商 |
| 规范发展（2017至今） | 回归主责主业，"大不良"多维开发 | 拆解为主责主业服务 |

- **When**：理解AMC任何行为（报价风格、合作模式、人事）时，先判断它处于哪种使命逻辑中。

### 框架二：货币政策传导的"存量优化闭环"（石佳华）
银行负责**信贷增量**（放贷给企业），AMC负责**信贷存量的优化**：
1. AMC 向银行支付收购对价 → 银行收回逾期贷款 → 资金重新贷给有前景的中小微企业；
2. AMC 向债务人催收/处置 → 债务人偿付或抵押物拍卖 → 资金回流 AMC；
3. 净效应：信贷资源从淘汰企业转移到有前景的企业——**资产公司是货币政策传导机制中被忽视的一股能量**。
- **When**：向监管/政府/内部论证AMC业务价值时，用这个闭环讲清宏观角色。

### 框架三：全牌照工具箱（以长城公司为样本）
- 子公司矩阵：银行（长城华西）、证券（长城国瑞）、保险（长生人寿）、信托（长城新盛）、金融租赁、投资基金、国际控股、咨询、置业；
- 分公司网络：32家省级分公司，覆盖京津冀、长三角、大湾区、东北、长江经济带等国家战略区域；
- **"资源×工具"公式**：不良资产是资源，全牌照是手段——每一项精细业务都需要多种工具组合：
  - 贷款重组/展期 → 贷款工具；追加抵押/增信 → 银行工具；以资抵债/续建 → 地产工具；债转股 → 股权工具；行业整合/保荐上市 → 证券工具；资产置换 → 跨条线协同。

### 框架四：分（子）公司协同的辩证关系
子公司"依附母公司"的四个问题：①失去独立拓客能力；②只是在集团总利润内部划转，不产生增量；③远离市场、缺乏话语权，内部协同需求都无法满足；④无竞争则积极性下降。
- **结论**（作者观点）：子公司应成为市场中与同类机构同台竞技的**独立主体**，唯有如此，主业需要时才能真正发挥作用。
- **When**：评估AMC系金融机构/子公司合作价值时，看其市场化程度而非牌照本身。

### 框架五：负债结构决定业务风格（对NAMA的对照）
| | 国内AMC | 爱尔兰NAMA |
|---|---|---|
| 资金来源 | 以银行借款为主（信达借款占总负债42%、华融49%） | 发行债券（95%高级债+5%次级债） |
| 资金性质 | 储户存款（零风险偏好，不能损失） | 投资人资金（风险收益对称，可承担损失） |
| 期限适配 | 1年期短期借款 vs 3年处置周期 → 不适配"根雕"式增值资产 | 1年期可展期+5.264%次级债，损失可由债减记吸收 |

- **When**：分析AMC行为约束、判断其能否持有"慢资产"时——**负债结构就是AMC的DNA**。

## 关键概念
| 术语 | 定义 |
|---|---|
| 体系外风险隔离 | AMC独立于银行体系（对应AIC的体系内隔离） |
| 财政隐性背书 | 国有控股背景下市场对AMC的隐性信用预期 |
| 并表管理 | 按持股比例将子公司纳入集团统一监控（风险集中度从集团口径考核） |
| 二元属性 | 政策性（化解风险、救助实体）＋商业性（利润考核）并存 |
| 存量优化 | AMC 将信贷资源从淘汰企业转移至有前景企业的宏观功能 |
| 逆周期 | 经济下行、不良供给增加时业务扩张的行业属性 |

## 思维模型
- **花店模型**（石佳华）：银行是种花的大棚，不良贷款是鲜花，AMC是城里的花店——从银行采购"鲜花"，经过修剪、包装，或打捆或单支出售给投资人。**价差决定收益**，但采购价、修剪手艺（重组能力）、售卖渠道（投资人网络）同样决定成败。
- **资源×工具矩阵**：判断一个AMC/项目的竞争力 = 资源获取能力 × 工具运用能力；只有资源没有工具，眼看盈利机会流失；只有工具没有资源，是无米之炊。
- **负债—资产匹配原则**：短负债不能配长资产（1年借款配3年处置周期＝在错误的时间被迫卖出）；判断一家AMC的报价行为，先看它的资金期限结构。
- **"政策+商业"双账本**：AMC做每笔业务时同时记两本账——社会责任账（稳就业、保主体、化风险）与经济账（回收率、IRR）；两者冲突时的取舍，构成了中国式不良资产投资最微妙的部分。

## 反模式
- **转型离开不良资产主业**：转型成保险公司、第三方资管、银行或小贷公司的路子都走不通——离开不良资产，AMC就失去了制度特点与比较优势。
- **子公司过度依赖母公司供客**：利润只是内部划转，市场竞争力退化。
- **短债长投**：用1年期银行借款持有需要3年以上培育的资产——环境稍有变化就陷入被动。
- **只讲牌照不讲协同**：牌照组合不会自动产生效益，协同机制（客户共享、信息互通、联合展业）才是价值来源。

## 实操示例
**"买包—修剪—出售"的闭环算账（花店模型实操版）**：
- 采购：以3折从银行受让本金10亿元的资产包，支付3亿元；
- 修剪（工具组合）：对其中2亿元债权实施债转股（证券/股权工具）；对3亿元抵押物权配合子公司续建后处置（地产工具）；其余5亿元诉讼清收（法律工具）；
- 出售/回收：假设综合回收6亿元 → 毛利约3亿元，扣除资金成本（按5%/年×3年×3亿元≈0.45亿元）、服务商费用（约0.6亿元）→ 净收益约1.95亿元；
- **敏感性**：处置周期从3年拉到5年 → 资金成本增至0.75亿元且回收打折 → 净收益可能腰斩。**结论：负债成本与处置周期是净收益的两个最大杠杆。**

**负债结构对报价的影响（NAMA对照实验）**：同一资产包，A用1年期授信报价、B用5年期金融债报价——B可以承受"持有等待市场回暖"的期权价值，A则被迫尽快处置。**报价差异本质是资金期限差异**。这也解释了为何"有耐心"的资本总能在周期底部拿到更好的资产。

## 要点回顾
1. AMC使命三段论：政策性剥离 → 商业化转型 → 规范发展与"大不良"。
2. 存量优化闭环：AMC是货币政策传导中被忽视的一环——信贷资源再配置的搬运工。
3. 全牌照的本质：不良资产是资源、工具是手段；工具箱决定处置的"手艺上限"。
4. 子公司必须市场化独立——协同不是内部划转，而是能力互补。
5. 负债结构（短债vs长债）决定AMC的行为与报价——理解资金，就理解了报价。
6. 二元属性（政策+商业）是中国式AMC与NAMA/KAMCO等纯商业坏账公司的最大区别。
