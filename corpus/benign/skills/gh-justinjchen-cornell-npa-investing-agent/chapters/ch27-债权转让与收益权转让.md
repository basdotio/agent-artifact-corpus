# 第27章 债权转让与收益权转让

## 核心思想
债权转让是不良资产的**二级市场引擎**——"卖给谁"决定"卖多少"，**15类买方地图**就是定价地图；收益权转让是82号文时代的"准转让"——只转收益不转债权，**操作简易（无需通知债务人、无需变更登记）但风险内嵌**（追索不完整、无破产隔离），便宜必须便宜在明处。

## 核心框架

### 框架一：供应方地图（谁在卖）
| 供应方 | 要点 |
|---|---|
| 银行等金融机构 | 社会投资者难直接购买——通常**借道AMC"过桥/借通道"**；国有银行偶经产权交易所挂牌 |
| AMC | 四大（华融/长城/东方/信达）＋地方AMC；"4+2"格局（每省可设两家）；地方AMC获准"对外转让"且受让主体不受地域限制 |
| 政府指定国企 | 汇达（央行系）、建银投资（证券业）、广州金控（收购原广州银行不良）、广永国资（协议受让东方广州办数百户包）——维稳与掌控区域资产双重动机 |
| 社会投资者 | 外资（摩根士丹利/花旗首轮吃大包分拆转售）、民间投资人（"二手包/三手包"来源） |
| 其他 | 拟改制国企剥离、小贷/典当/担保等融资类企业的坏账 |

### 框架二：买方地图15类（定价的第一性工具）
| 类型 | 买家 | 愿意溢价的原因 |
|---|---|---|
| 信息优势型 | ①掌握债务人**隐匿财产**的人 ②知道**案件内幕**的人（刑案终结/判决有利/纠纷症结已解） ③掌握**政府信息**的人（征地拆迁/规划调整） | 只有他知道的东西值钱——信息差即溢价 |
| 功能型 | ④政府机构（维稳/员工群访）⑤**有专业技能**的人（法律/财务/投行/包装——"能把永昌公司改造为旅游农庄"）⑥有**人脉**的人（涉政/涉法/涉地方关系资产） | 能解决别人解决不了的执行难题 |
| 关联型 | ⑦债务人的债务人（抵销/代位对冲）⑧**债务人的关联人**（担保人/股东/高管/亲朋/共有权人）⑨债务人的"**仇人**"（竞争对手/被辞员工——报复性查封）⑩其他债权人（首封者扩大战果/抵押权人保处置权/最大债权人"大包围"） | 动机五花八门：回购消除老赖记录/掩盖骗贷黑幕/抢先查封/逼迫让步/**避税**/**洗钱**/行使优先购买权 |
| 资本型 | ⑪扩大资产规模的企业（上市"讲故事"/美化报表）⑫资金充裕的投资主体（土豪/中间商/周期套利者/大资金分包商） | 囤资产、赚差价、等复苏 |
| 策略型 | ⑬**预先安插处置障碍的人**（买相邻债权卡位，为更大交易占议价权）⑭与银行**利益交换**的人（全价受让＋反委托清收，换优惠贷款——暗箱个案） | 买卖的不是债权，是布局 |
- **用法**：转让前把15类逐一过一遍——**你的资产对谁"特别值钱"？** 找到信息优势型/功能型买家往往比公开挂牌多卖十几个点。

### 框架三：交易模式与流程
**五种模式**：产权交易所挂牌（几大产交所/淘宝，周期约两个月）／拍卖（入库机构中摇珠确定，大标的联合拍卖）／竞价（密封报价、当众拆封、价高者得）／竞标（保底价＋多维评分：注册资本/团队经验/声誉）／协议转让（民间债权人或收益权转让）。
**七步流程**：①要约或要约邀请（意向函）→ ②谈判及阅档（保密协议＋个别保证金）→ ③竞买或协议（成交确认书）→ ④签约（债权转让协议）→ ⑤付款（分期需补充协议：首期/进度/滞纳金/违约）→ ⑥**债权转让通知**（争取债务人回执；银行/AMC可省级报刊公告；民间债权人还需**公证送达**）→ ⑦资料交收（主从债权原件尽收）。

### 框架四：转让实务经验（风险清单）
1. **优先购买权**：涉国企债权转让须通知出资方/国资委是否行使优先购买权——未通知→轻则拖延（债务人趁机转移财产）重则**转让无效**；买家应查验通知凭证；
2. **协议效力三查**：优先购买权程序（国企债务人）／转让方程序合规（尽调/评估/定价/监管要求）／**历次转让的通知链条**（多次流转每一环都要有通知）；
3. **主体设计**：联合体购买（紧密=出资比例共担；松散=包内项目拆分）——避免内部竞争、对抗外部竞价；
4. **时间预期**：从国有银行/AMC买入至少**3个月**（立项/尽调/评估/上会/拍卖）＋国企优先权程序再＋1个月；期间要防核心财产流失；
5. **竞争排除（灰度技巧）**：节假日公告／信息详略安排／中介操盘／混搭组包令对手左右为难／异地挂牌——书中如实披露的行业"暗面"，了解它才能防御它。

### 框架五：收益权转让（82号文框架）
- 制度：银监办发〔2016〕82号——**信托计划为受让银行信贷资产收益权的唯一渠道**；两环节：①设立信托计划（优先/劣后级）②信托计划受让不良资产收益权；
- **首单样本（江苏银行）**：原始金额4.245亿元、实际转让2.54亿元（**5.98折**，高于已发四单不良ABS）；9户/次级类/江苏；投资者含地方AMC；2016.9.6经银登中心备案完成；
- 收益权四类型：以债权/股权/SPV份额/未来收入为基础资产；
- **性质之争**：收益权能说／用益物权说／**将来债权说（作者主张）**——收益权依赖基础资产产生现金流，本质是将来债权给付请求权。
- **与债权转让的核心区别（内外效力对照）**：
  - 收益权转让：无须通知债务人、无须办理抵押变更登记、操作简易；**对内效力（法律地位取代/从权利转移/文件交付/瑕疵担保）与对外效力（通知生效/表见让与）均不适用**——债权主体未变；
  - 债权转让（卖断）：无追索权出售、彻底脱钩；折扣率与资信挂钩；二重让与规则——**全部转让优于部分转让；已通知优先于未通知**。

### 框架六：收益权的四风险与防范
| 风险 | 机制 |
|---|---|
| 从属性风险 | 基础资产仍在出让方名下可被处分；无登记公示制度→受让方可能"落空" |
| 追索权不完整 | 只能追转让方的转付义务——**够不着债务人和担保人** |
| 现金流不确定 | 基础资产风险直接传导为转付金额不足 |
| 无破产隔离 | 出让方破产清算时基础资产被视为其自有财产 |
- **防范二式**：设定**回购义务**＋设定**担保权利**（针对现金流与权属两大不确定性）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 借通道/过桥 | 社会投资者商请AMC出面受让再转售的通行路径 |
| 二手包/三手包 | 投资者之间再次转让的资产包——二级市场流通层 |
| 大包围 | 最大债权人收购全部债权掌控谈判与分配主动权 |
| 转让通知链条 | 多次转让中每一环的通知完备性——链条断裂即效力瑕疵 |
| 表见让与 | 转让通知后即使让与无效，债务人对受让人的履行仍有效 |
| 将来债权 | 收益权的性质定位——依赖基础资产现金流的给付请求权 |
| 回购+担保双保险 | 收益权转让的实务增信设计 |

## 思维模型
- **"买方地图即定价地图"**：同一笔债权对不同买家价值差异巨大——先匹配"谁特别需要它"，再定价。
- **动机透视**：了解买家的真实动机（受偿/掩护/避税/布局/报仇）——既能预判他出价的上限，也能防范交易反被利用。
- **通知即权利**：转让通知是外部效力的开关（受让人的胜诉权系于此）；民间债权再加公证送达——"能拿回执拿回执，拿不到就公证"。
- **权利残缺定价**：收益权比债权便宜是结构性原因——把"追索不完整+无破产隔离"折进价格，再谈回购与担保。
- **时间预算思维**：国资转让3-4个月起步——把时间当成本列进交易计划（参照第23章"时间是成本"）。

## 反模式
- **忽视优先购买权**：涉国企债权不查通知程序——转让可被抗辩甚至无效。
- **公告代替一切**：只登报不取回执、多层转让漏通知——效力链条处处是雷。
- **不懂收益权的边界**：受让收益权后径直向债务人追债——**无权限**，只能追转让方的转付义务。
- **以"简易"低估收益权风险**：没要回购义务/担保安排就签约——风险裸奔。
- **盲目公开挂牌**：资产对某些特殊买家"特别值钱"却走过场式竞价——卖价白白流失。

## 实操示例
**一笔债权转让的作战清单（重建自流程要点）**：
1. 匹配买家：按15类地图列出候选（本案有区政府规划调整信息→优先接触"政府信息者"与政府系买家）；
2. 查两事：国企债务人？→先做优先购买权通知；历次转让记录？→逐环核对通知凭证；
3. 模式选择：国有性质走竞价/竞标；民间协议——设定保密与保证金；
4. 签约与付款：分期方案配补充协议（滞纳金+违约条款）；
5. 通知三件套：债务人回执（力争）→省级报刊公告（银行/AMC）→公证送达（民间）；
6. 资料交收：合同、借据、判决书、他项权证原件逐一对照清单；
7. 台账更新：主体变更＋转让节点入"事件记录"（第23章）。
**收益权场景对照**：改走信托计划通道——核查82号文适用性→设计优先/劣后结构→确认无须通知债务人→**同时谈判回购义务与担保条款**→银登中心备案登记。

## 要点回顾
1. 供应方五类；买方15类地图（信息优势/功能/关联/资本/策略）——定价先定买家。
2. 五种交易模式＋七步流程；通知三件套（回执/公告/公证送达）。
3. 优先购买权、通知链条、联合体、时间预算、竞争排除——转让实务五大考点。
4. 收益权转让：信托唯一渠道、首单5.98折、四类型、将来债权说。
5. 收益权四风险（从属/追索不完整/现金流/无破产隔离）＋回购担保双保险。
6. 债权转让内外效力：地位取代、从权利转移、瑕疵担保、表见让与——收益权统统不适用。
