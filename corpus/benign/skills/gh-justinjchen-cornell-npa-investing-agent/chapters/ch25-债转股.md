# 第25章 债转股：最深刻的债务重组

## 核心思想
债转股是工具箱中**变动最激烈**的一招：把借贷关系根本性地改写为股权关系。它既可能"变现"也可能"升值"，但同样是双刃剑——**只在"企业能恢复生机"且"转股回收率高于破产清算"时才成立**。中钢模式揭示了高级玩法：**"留债＋可转债＋有条件债转股"的分层结构**。

## 核心框架

### 框架一：中钢模式解剖（央企首单市场化债转股）
- 背景：钢铁矿业央企（65家二级单位、2家上市公司、4万员工），2014年大宗寒冬违约；
- 制度窗口：国发〔2016〕54号（降杠杆）＋《关于市场化银行债权转股权的指导意见》；
- 结构：对本息总额**600多亿元**整体重组——**留债近300亿＋转股近300亿**（各家银行留债/转股比例不同，**取决于中钢在各行的抵押资产情况**）；
- **可转债通道**：新设控股平台向债权人发行可转债，用于置换"非留债部分"对应债权；**条件满足后逐步行使转股权**——给转股加了"渐进阀门"；
- 协调面：6家主席行＋44家金融机构＋发改委/央行/财政部/银监/国资委支持——**多方博弈的工程化解决**。

### 框架二：债转股的实质变化（两面看）
- 对债务人：引入新股东——若转股金额大于原资本额，相当于引入相对/绝对控股投资者；**治理权应交付新股东**；股本融资成本理应高于债务融资（回报率＞利率）；
- 对债权人：**放弃债权固定收益（利息）＋放弃抵押担保追索权** → 换股权收益；回报取决于企业经营能否根本改善、股东权利能否落实——**把握不当会陷入"既不是债权人，又不像股东"的尴尬**。

### 框架三：形式与对象（做什么、对谁做）
- 公司制企业三形式：①不改变注册资本、只做股东变更（原股东以股权转让折抵债务）②增加注册资本（债权→投资）③企业改制时以债权出资；
- 上市公司可行，但增资须证监会审核；
- 对象企业：债务人或保证人企业、或其持股/控股企业（须为有限责任公司或股份公司）；
- 实施主体：**银行不得直接持股**——通过向实施机构（AMC/AIC等）转让债权后由其转股。

### 框架四：可转股权的三类型（依据溯源）
1. **合同之债**（两条件：债权人已履行合同义务＋不违反法律/行政法规/国务院决定/章程禁止性规定）；
2. **生效裁判确认的债权**（判决/裁定）；
3. **和解协议确定的债权**（经法院批准的重整计划/认可的和解协议）。
- 两个以上债权人→**转股前必须先分割债权**；涉及批准的依法报批。

### 框架五：三大程序（合规三关）
1. **评估**：依法设立的评估机构评估，**作价出资金额不得高于债权评估值**；股东（大）会决议确认作价；
2. **验资**：验资机构出具证明（债权基本情况/评估情况/完成情况/批准情况四项）；
3. **工商变更**：注册资本与实收资本变更登记——资料清单至少7项（债转股合同、股东会决议、作价确认决议、验资报告、修改后章程、主体资格证明、承诺书/裁判文书/和解文书）。

### 框架六：对象选择铁律（债转股成败的第一道闸）
- 残酷现实："**容易扭亏为盈的企业，银行或AMC不会轻易转让给你**"——"债转股并非适合所有企业"；
- 适用画像：**经营仍有好转可能，只是财务负担过重**——甩掉一部分包袱后经营状况可能实质性好转；
- **双阈值判据**：①企业具备现金流产生能力（丧失造血能力的企业，杠杆再低也无意义）②**转股回收率高于破产清算回收率**——否则转股没有意义；
- 四个禁止（《意见》反面清单）：僵尸企业／恶意逃废债企业／债权债务复杂不明晰企业／助长过剩产能与库存的企业；
- 失败后果：企业未如预期好转→原债权人（現股东）承担更多债务——**转股不是终点，是风险的换装**。

### 框架七：风险防范条款（转股前必须设计）
- **担保消灭警报**：转股后原保证人、抵押人、质押人的法律关系**自行消灭**——旧担保不复存在；
- 替代保障设计：对未转股部分（留债）的担保保留＋对新股东权利的治理条款＋退出安排（回购/对赌/优先清算——视谈判地位）；
- 治理承诺：债权人变股东后，"债转股意义的发挥取决于公司治理和经营效率有没有明显提高"——要的是股权多元化与机制改善，不是账面重分类。

## 关键概念
| 术语 | 定义 |
|---|---|
| 留债＋可转债＋有条件转股 | 中钢模式：把确定性（留债）与可能性（转股）分层装载 |
| 可转债通道 | 以新平台发行可转债置换债权，条件成熟再转股——渐进阀门 |
| 债权出资 | 以债权作为非货币财产出资——须评估、验资、登记 |
| 转股前债权分割 | 多债权人的债转股前置要求——先分清楚，再转 |
| 回收率双阈值 | 转股必要性=造血能力＋回收率>清算率 |
| 担保消灭 | 债转股导致原从属性担保关系终止——必须补充新保障 |

## 思维模型
- **分层装载**："全部转"是赌博，"全不转"是僵局——留债（求确定）+可转债（留期权）+转股（博升值的组合才是工程化解法。
- **造血优先**：债转股投的是"恢复中的造血能力"——看现金流产生能力，不看资产负债表的账面重组。
- **"容易的不给你"定律**：好到能轻易翻身的资产不会流到你手里——所以真正的功课在**甄选与治理改造能力**（人无我有）。
- **担保换装思维**：转股一瞬间，旧法律武器全失效——在签字之前把新武器（治理权、退出条款、对赌机制）装上。
- **双向阈值清单**：立项前答两题——它靠自己能活吗？转股的期望回收是否真的高于清算？

## 反模式
- **给僵尸企业转股**：违背《意见》红线——转股只是延缓死亡，还把债权人变成陪葬股东。
- **忘记担保消灭**：转股后才发现抵押/保证已不复存在——设计阶段必须换装新保障。
- **跳过评估/验资/登记**：程序瑕疵可致转股无效——照《办法》清单逐项闭环。
- **只重分类不治理**：把"债转股"当会计操作——没有治理改善和经营者替换，股权就是废纸。
- **一刀切转股比例**：不复盘抵押结构（中钢按各行抵押资产确定留债/转股比例）——结构设计粗糙。

## 实操示例
**中钢式分层结构推演（教学简化）**：
1. 对600亿本息做现金流切分：按企业可持续现金流覆盖能力定"留债"规模（约300亿，正常或展期条件）；
2. 剩余部分（约300亿）不直接转股，而是置换为**新平台可转债**——票息从低、转股条件挂钩经营指标（如盈利恢复、上市平台市值）；
3. 条件满足→逐步转股；不满足→债权形态延续（比直接转股保留更多权利）；
4. 抵押差异处理：各行留债/转股比例按抵押资产覆盖情况差异化设计；
5. 配套：债委会协调机制＋多部委政策支持＋治理层重组（董事席位、经营监督）。
**自家项目checklist**：目标企业真的适合吗（造血/双阈值）→ 谁能实施（AMC/AIC通道）→ 债权类型合规吗（合同/裁判/和解）→ 评估验资登记三关过了吗→ 担保换装条款写了吗→ 治理与退出安排呢？

## 要点回顾
1. 中钢模式：留债＋可转债＋有条件债转股——分层装载的央企范本。
2. 债转股的实质：债权人放弃利息与担保，换股权收益——"两边不像"是最大陷阱。
3. 三形式、三债权类型、三程序（评估/验资/工商变更）。
4. 对象选择双阈值：造血能力＋回收率高于清算率；四类企业禁止。
5. 担保消灭是转股的第一风险——签字前换装新保障。
6. 债转股的成功在治理——重分类是起点，经营改善才是价值。
