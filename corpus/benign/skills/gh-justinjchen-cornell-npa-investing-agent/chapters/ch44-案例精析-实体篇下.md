# 第44章 案例精析·实体篇（下）：合同效力与担保争议十案

## 核心思想
十个围绕"转让合同效力与担保责任"的判例，构成受让人最需要的**防御手册**：会议纪要的适用边界、无效之诉的攻防、限制追偿条款、越权担保、配偶声明、保证期间、以贷还贷、工程款优先权、复利罚息、代位执行——每一条都是收购尽调与诉讼预案的检查点。

## 核心框架

### 案16：农商行是否属《会议纪要》适用范围
- 会议纪要适用对象为**国有银行与AMC**间的特定转让；**农商行（农村商业银行）**等主体的转让是否适用存在争议——受让人需按主体性质判断纪要规则的适用性（关系到优先购买权、利息规则等的适用）。

### 案17：转让合同无效之界定（受让人的"选择权"）
- 界定三方面：①申请人是否具备提起无效之诉的主体资格（国有债务人企业的相关权利）②是否符合**法定无效事由**③主张**全部无效还是部分无效**；
- **受让人策略**（本案精髓）：根据所受让债权的实际或可能盈亏——**亏了主张无效（退回），盈了维护有效**——"根据盈亏情况提起全部或部分无效"。

### 案18："限制追偿条款"效力之界定
- 背景：AMC转让时约定受让人**放弃向国有银行、各级政府、国家机构追偿**的条款；
- 规则：**该类条款有效**——受让人受约束，权利人可依据其抗辩；**但有效不等于受让人完全丧失救济**（对非列举主体仍可追偿、对债务人本体仍可执行）；
- **When**：二级市场收购前逐字读"限制追偿条款"——估值时把这条减项算进去。

### 案19：越权签订担保合同效力之界定
- 争议：法定代表人/实际控制人越权对外担保；
- 规则：司法实践将**《公司法》第16条界定为"管理性强制性规定"而非"效力性强制性规定"**——但违反之**不当然认定担保有效**（学理与司法仍有分歧区）；
- **When**：接受公司担保时——必须验**股东（大）会/董事会决议**（第39章操作建议的判例注脚）。

### 案20："保证人配偶声明"效力之界定
- 场景：夫妻一方对外担保，是否夫妻共同承担；
- 三焦点：声明效力／瑕疵时效力认定／无效或无声明时夫妻共同债务的认定路径；
- **When**：自然人保证的尽调——核查配偶知情与共债认定（婚姻法及其解释的适用）。

### 案21：保证期间届满后保证人责任之承担
- 规则（批复精神）：保证期间届满后保证人在催款通知书上签字——**原则上不承担保证责任**；**但催款通知书内容具体明确**（载明保证金额、期间、方式等要素）且保证人签收→**构成对保证债务的重新确认**；
- **When**：向已过保证期间的保证人发函——**把要素写全**（回执=复活证据）。

### 案22："以贷还贷"中保证人责任之承担
- 规则（本案结论）：新贷旧贷为**同一保证人**时——**无论保证人是否知道或应当知道**以贷还贷，均需承担保证责任；不同保证人的规则另有分层；
- **When**：审查借新还旧档案——先看两头保证人是否同一。

### 案23："建筑工程款"之优先受偿
- 依据：合同法286条——**建设工程款优先受偿权**（优于抵押权，最高法批复确认）；
- 冲突场景：发包人无法还贷时——承包人与抵押权人争夺同一工程；
- **When**：房地产抵押估值必查工程款欠付（第38章衔接）；受偿顺序：工程款（+6个月行使期）＞抵押权＞普通债权。

### 案24："复利罚息"专属债权之适用
- 依据：《人民币利率管理规定》第3条——人民银行是利率主管机关；**计收复利罚息是金融机构（含AMC这类非银行金融机构）的专属债权**；
- 争议点：银行借款合同约定的复利罚息**能否随债权转让给非金融机构受让人**——法院判决不一；
- **When**：受让人评估利息主张范围时——预判当地对"复利罚息转让"的口径（潜在减少项或争议项）。

### 案25：代位执行制度之适用
- 场景：债务人无财产，但对第三人享有到期债权且怠于主张（甚至隐匿/恶意处理）；
- 依据：执行规定第七部分"对被执行人到期债权的执行"——**第三人（次债务人）在法定期间内未提出有效异议**即可能被直接执行（代位执行）；
- **When**：终本案件再次排查——"对外债权"是最常被忽略的财产线索（第9章涉诉圈定的用途兑现）。

## 关键概念
| 术语 | 定义 |
|---|---|
| 禁止无效之诉主体 | 国有债务企业相关权利人的无效诉权——受让人预判工具 |
| 盈亏无效选择 | 受让人依盈亏主张全部/部分无效的策略 |
| 限制追偿条款 | 有效条款——收购估值的减项与救济边界的边界 |
| 管理性强制规定 | 公司法16条的定性——越权担保不当然无效 |
| 保证债务重新确认 | 要素齐全的催款通知+签收=保证复活 |
| 复利罚息专属 | 金融机构专属债权——转让效力存争议 |
| 代位执行 | 对债务人到期债权的执行——终本复活通道 |

## 思维模型
- **"条款即减项"**：限制追偿条款、复利罚息争议——都是估值模型里的价格调整项，谈判前逐条过。
- **"写全要素"**：向保证人发函要写清金额/期间/方式——一句话决定保证能否复活。
- **"同一性判断"**：以贷还贷看保证人是否同一；清算看主体是否同一——判决里"同一"二字定六案。
- **"异议期博弈"**（代位执行）：第三人异议是闸门——研究异议期的适用与应对。
- **"盈亏双面"**：转让无效之诉是柄双刃剑——只有算清盈亏才决定砍向哪边。

## 反模式
- **不读限制追偿条款**：接手后才发现不能向国有银行追偿——估值失算。
- **接受无决议担保**：越权担保效力存疑——公司担保必验决议。
- **保证函要素缺失**：向已过期间保证人发函不写要素——复活失败。
- **抵押估值漏工程款**：工程款优先权截胡——回收测算失真。
- **忽略复利罚息争议**：把罚息复利按全额估值——当地口径不符则回收缩水。
- **忘记代位执行**：终本后只盯债务人自己——放着对第三人的到期债权沉睡。

## 实操示例
**受让人防御清单（案16-25合成）**：
①主体核验（案16：转让人性质→纪要适用性）；
②条款审计（案17盈亏策略/案18限制追偿/案19决议/案24复利罚息）；
③保证审查（案20配偶/案21期间要素/案22以贷还贷同一性）；
④财产排查（案23工程款/案25代位执行）；
⑤诉讼预案逐项配置。
**一句话记忆**：**"主体、条款、保证、财产"四栏过账——十个判例全部落在这四栏内。**

## 要点回顾
1. 会议纪要适用看主体；无效之诉看盈亏；限制追偿条款有效但要读全。
2. 越权担保（管理性规定）、配偶声明、保证期间复活（要素齐全）——公司/自然人担保三件套。
3. 以贷还贷同一保证人必担责；工程款优先于抵押权；复利罚息转让存争议。
4. 代位执行是终本复活的隐藏通道。
5. 四栏过账法：主体、条款、保证、财产。
