## 二、报价决策盘（暗标场景）

| 变量 | 取值 |
|---|---|
| 你的成本线 | P*（资金成本×时间+费用） |
| 你的估值上限 | 三情景概率化后的期望值×安全折扣 |
| 对手盘估计 | [Pa,Pb]区间 |
| 定价规则 | min(估值上限, 略高于Pa)；多付容忍度不侵蚀底线收益 |
| 心理检验 | 报价是否回答"比第二名多多少"而非"资产值多少" |

## 五、处置路径选择树

| 场景 | 首选路径 |

## 七、担保与类担保：写法对照

| 想要的效力 | 正确写法 | 错误写法 |
|---|---|---|
| 连带式直接追索 | "未能按期足额清偿即补足/承担，无需先行追索" | "不能履行时……"（一般保证式） |
| 保留原担保 | "变更非更新"+担保人重新签章 | 直接签"新债务"（更新→担保消灭） |
| 最强人保 | 债务加入（三方签署） | 单方承诺（抗辩随原债传染） |
| 资金控制 | 让与担保（清算型）+通知 | 流质型（无效） |
| 兜底灵活化 | 差额补足（连带式） | 硬上连带保证（征信/程序障碍） |

## 八、破产博弈速查（美式框架迁移）

| 问题 | 答案 |
|---|---|
| 谈判基准假设 | 最差=第十一章（博弈开始） |
| 交换成功前提 | 让不参与者受损（次级化/缩短到期） |
| 债权人权利底线 | TIA 316(b)/合同现金权利不可剥夺 |
| 费用谁出 | 债务财产→实质由无担保债权人承担 |
| 计划通过 | 每类2/3金额+1/2人数；绝对优先只在cram down严格适用 |
| 快通道 | 预打包（费用约常规1/3）/363出售 |
| 安全垫标准 | 正常情景≥25%；重组情景IRR>30% |

## 九、谈判心理学：五个开关

1. **时间是成本**：购入日起利润逐日变薄（对你也对对手）
2. **暴露着急=交出定价权**（管理人报酬/受让谈判均适用）
3. **换壳成本**：债务人重建上下游信任的成本是你的谈判杠杆
4. **刑事表态**：材料备齐的"表态"常足以促成和解（不用真起诉）
5. **社会最优位**：调解优先+司法兜底——让政府和企业都有台阶

## 十、估值走廊计算器（NAMA式）

```
底价 = 市场变现价 × 抬升率
顶价 = 长期处置价 × 贴现率
报价 ∈ [底价, 顶价]，靠哪端取决于：
  ├─ 你的资金成本（越高→越靠底）
  ├─ 风险偏好（不确定性大→越靠底）
  └─ 竞争强度（对手少→可压更低）
```

## 十一、四栏过账法（受让人防御清单）

**主体** → 转让人性质/纪要适用性/优先购买权 | **条款** → 限制追偿/复利罚息/盈亏无效策略 | **保证** → 决议/配偶/期间要素/以贷还贷 | **财产** → 工程款/代位执行/轮候查封

## 十二、机构救助六阶梯（介入程度递增）

政府担保 → 保障基金 → 托管（外脑） → 剥离不良 → 注资（财务性/控股） → 承接债务式重组（零对价+隐性负债）
