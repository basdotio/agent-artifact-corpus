# 设计师个人网站风格原型库

把“我想要一个好看的个人网站”变成一个**有依据的风格决定**，再落到具体版式、字体、配色和动效。

数据来源：RicoUI（@ricouii）收藏的 180 个设计师 / 创意开发者网站，2026-10-18 实测抓取，174 个有效。原型由人工看图归类，技术与配色特征由 DOM 和截图自动提取。

## 11 种原型

| 原型 | 中文 | 一句话 | 占比 |
|---|---|---|---|
| `poster-type` | 巨型字体海报型 | 首屏被超大名字 / 标语占满，海报式构图 | 21% |
| `work-grid` | 作品优先型 | 首屏就是作品图墙或项目索引 | 13% |
| `saas-landing` | 商业落地页型 | 服务、客户 logo、预约 CTA，面向转化 | 9% |
| `immersive-3d` | 沉浸式 3D 型 | 全屏 WebGL 场景、电影感光影 | 9% |
| `minimal-text` | 极简文字型 | 小字号单栏自述，靠文字和细节 | 9% |
| `statement-hero` | 一句话宣言型 | 一句中大号宣言 + 少量作品图，专业克制 | 8% |
| `bento-cards` | Bento 卡片型 | 圆角卡片拼成仪表盘式网格 | 7% |
| `editorial-serif` | 编辑杂志型 | 衬线大标题、杂志版式 | 7% |
| `illustrated-world` | 插画世界型 | 插画 / 纸艺构成可探索场景 | 6% |
| `skeuo-desktop` | 拟物桌面型 | 桌面、操作系统、实物道具隐喻 | 6% |
| `experimental-art` | 实验艺术型 | 故障、像素、CRT、反常规导航 | 5% |

每种原型的完整说明在 `references/archetypes/<原型>.md`。

## 工作流程

1. **摸清三件事**（从上下文推断，缺了再问，最多问一轮）：
   - **身份与目标**：产品设计师求职、自由职业接单、工作室获客、创意开发者炫技、插画师展示……
   - **手里的作品**：有没有高质量图 / 视频？数量多少？是否以界面、品牌、插画、3D、代码为主？
   - **性格与约束**：想要安静还是张扬；能写代码还是只用 Framer / Webflow；有多少时间。
2. **选原型**：按 `references/decision-guide.md` 选 1 个主原型，必要时加 1 个次原型做点缀。给出 2–3 个候选和取舍理由，不要只扔一个答案。
3. **读原型文档**：打开对应的 `references/archetypes/<原型>.md`，按其中的版式骨架、字体、配色、动效规范设计。
4. **找参考站**：用 `scripts/find_refs.py` 按原型 / 明暗 / 动效 / 搭建方式 / 身份筛选。每个候选原型配 1–2 个，合计 3–5 个，说明每个看什么。**推荐前先打开链接确认仍在线、没有改版**——数据是 2026-10-18 的一次快照。
   ```bash
   python3 scripts/find_refs.py --archetype editorial-serif --theme light
   python3 scripts/find_refs.py --role product-designer --motion static,low
   ```
5. **产出**：按用户需要输出其一——设计 brief、线框 + 设计 token、或直接写代码（单页 HTML / Next.js / Framer 结构说明）。首页之外的案例详情页、涉密（NDA）作品的呈现方式见 `references/case-study.md`。写代码时遵守下面的“通用底线”。

## 跨原型的共性（来自 174 站统计）

- **浅色 + 近乎单色是主流**：62% 浅色底，64% 几乎无彩色；强调色通常只有一个，且只用在 1–3 处。
- **平滑滚动在动效型原型里很普遍**：整体 28% 用 Lenis，海报型 61%、商业型 44%；但极简型几乎不用（7%）。动效型原型可以先加 Lenis；安静型原型不要加。任何情况下 `prefers-reduced-motion` 时都要关掉。
- **动效分层**：静态 18%、轻 32%、中 30%、重 20%。重动效集中在海报型、编辑型和 3D 型；极简型 60% 完全静态。
- **约 1/3 有自定义光标**，多见于海报型（19/36）和编辑型（6/12）。
- **字体高度集中在无衬线**：Inter、Geist、Neue Montreal 最常见；想要辨识度，用衬线或压缩体做标题是最便宜的差异化。
- **搭建方式**：60% 手写代码，17% Framer，13% Webflow。Framer 在拟物型（36%）和商业型（31%）里占比最高。
- **进站门 / 加载动画少而集中**：只出现在 3D、插画和实验类站上，其余原型基本不用，不要滥加。

## 通用底线（所有原型）

- **移动端**：标题用 `clamp()` 随视口缩放，不写死桌面 px；断点至少覆盖 390 / 768 / 1280；多栏和网格在 < 768px 重排为单列，并重新考虑内容顺序；390px 宽不得横向滚动。
- **可访问性**：正文对比度 ≥ 4.5:1；所有可点元素键盘可达并有 `:focus-visible` 样式；拟物 / 场景型导航必须另有普通文字导航；图片和 canvas 提供文字替代。
- **减少动效**：`prefers-reduced-motion: reduce` 时关闭入场动画、视差、平滑滚动、自动播放视频和光标跟随，内容直接可见。
- **性能**：首屏图片用 WebP / AVIF + 响应式尺寸；3D / 重动效原型提供静态兜底，并显示加载进度。

## 数据结论与编辑判断

- 各原型文档里的**百分比、中位数、强调色、字体名、代表站**来自抓取数据（每个原型都混有个人站和工作室，样本量 9–36，只能看趋势）。
- `decision-guide.md` 的**首选 / 备选**是编辑判断：依据访客场景（谁来看、看多久），不是“数据里最多的就是最好的”。两者冲突时向用户说明。
- 数据有抓取噪声：少数字体名是内部代号（如 "P"、"X"、`__Plus_Jakarta_Sans_…`），`find_refs.py` 会标成 `?`。

## 原创性守则

- 参考的是**模式**，不是站点本身：不要照搬别人的文案、插画、照片、3D 资产或独特的品牌元素。
- 推荐参考站时给链接，让用户自己去看，不要把别人的作品图放进用户的站里。
- 对外引用这份数据时，注明来源是 RicoUI 的清单。

## 文件

- `references/decision-guide.md`：选型决策表（身份 × 作品 × 性格 → 原型），含条件冲突时的处理
- `references/case-study.md`：案例详情页结构与 NDA 作品呈现
- `references/archetypes/*.md`：11 种原型的详细规范
- `assets/sites.json`：174 个站的精简特征（原型、技术栈、配色、字体、动效）
- `scripts/find_refs.py`：参考站检索
