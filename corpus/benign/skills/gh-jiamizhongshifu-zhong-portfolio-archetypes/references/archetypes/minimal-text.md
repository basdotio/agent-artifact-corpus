# minimal-text · 极简文字型

小字号单栏自述 + 一串链接，大量留白，几乎没有图。靠文字的语气、排版精度和一两个藏起来的细节取胜。
15 / 174（9%）。

## 适合 / 不适合

- **适合**：设计工程师、产品设计师、写作者、作品涉密或数量少的人；时间少（几天能上线）。
- **不适合**：视觉作品是核心卖点的插画 / 品牌设计师——会浪费作品。

## 版式骨架

```
┌───────────────────────────────────────────┐
│                                           │
│        Name                                │ ← 内容列宽 480–640px，居中或偏左
│        一段 2–4 句的自述，带内联链接        │
│        Currently: …   Previously: …       │
│                                           │
│        Writing / Projects                 │ ← 列表：标题 + 年份 / 阅读量
│        2026  Title ……………………… 12.4k        │
│        2025  Title ……………………… 8.1k         │
│                                           │
│        email · X · GitHub · LinkedIn      │
└───────────────────────────────────────────┘
```

- 首屏标题中位 **20px**，80% 是小号——没有“大标题”这回事。
- 页面很短（中位 1.5 屏）。
- 变体：等宽终端风（#13 用彩色语法高亮写自述）、左侧栏导航（#73、#86）、表格索引（#149）。

## 字体

- `Inter`、`Geist`、`Inter Tight`、`Bricolage Grotesque`；等宽可选 `Berkeley Mono`（付费）/ `JetBrains Mono`、`Departure Mono`（免费）。
- 字号 14–17px，行高 1.5–1.6，正文色比纯黑浅一档（`#3a3a3a` / `rgba(0,0,0,.72)`），次要信息再浅一档。

## 配色

- 87% 浅色、93% 近单色。唯一的颜色通常来自**链接下划线、一个小 emoji 或内联小图**。
- 例：#85 rauno.me 一个荧光黄圆 `#fdfd1a`；#19 自述里内联人物小照片。

## 动效

- 60% 完全静态。动效只出现在**一个细节**上，而且要精：
  1. **内联小图**：自述文字里直接嵌 emoji 尺寸的照片 / 图标（#19），或链接悬停时浮出预览。
  2. **文字逐行淡入**：首屏段落按行 `opacity + translateY(4px)`，总时长 < 600ms。
  3. **一个可玩的小交互**：#85 rauno.me 首屏的荧光黄圆 + 十字准星；#13 末尾闪烁的文本光标。
  4. **深浅色切换**做得细：切换时用 `view-transition` 做圆形扩散。

## 技术栈

- Next.js 40%、自写 73%。也是最适合 Astro / 纯 HTML 的原型。内容放 Markdown，便于写作。

## 反模式

- 极简变成简陋：没有字号层级、行宽过长（> 80 字符）、链接不可辨认。
- 自述写成简历罗列，没有个性。这类站**文案就是设计**，要写得像人说话。
- 为了“有点东西”硬塞粒子背景，破坏整体安静感。
