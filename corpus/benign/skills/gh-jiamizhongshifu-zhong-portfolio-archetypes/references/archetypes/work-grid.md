# work-grid · 作品优先型

首屏直接是作品：图墙、拼贴、散落的缩略图或项目索引表。界面退到后面，让作品说话。
23 / 174（13%）。

## 适合 / 不适合

- **适合**：插画师、摄影师、动效设计师、作品图质量高且数量多（≥ 8 个）的设计师。
- **不适合**：作品少、作品涉密、作品是不好截图的复杂系统。

## 版式骨架

三种常见变体：

```
A. 规整网格               B. 散落拼贴               C. 索引表
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│ name      about  │   │ name   ·  about  │   │ name        info │
│ ▢ ▢ ▢ ▢          │   │   ▢      ▢       │   │ 01 Project  2026 │
│ ▢ ▢ ▢ ▢          │   │ ▢     NAME   ▢   │   │ 02 Project  2025 │
│ ▢ ▢ ▢ ▢          │   │      ▢     ▢     │   │ 03 Project  2025 │ ← 悬停出预览图
└──────────────────┘   └──────────────────┘   └──────────────────┘
#33 #135 #147          #101 #66 #150          #105 #149(类)
```

- 首屏文字很小（中位 **25px**），61% 标题属于小号——名字只是署名。
- 页面不长（中位 3.8 屏）：作品本身就在首屏，往下是更多作品或分类。

## 字体

- 87% 无衬线、13% 等宽。名字和导航用小号 `Inter`、`Host Grotesk`、`Geist Mono` 就够；不要和作品抢。

## 配色

- 61% 浅色、30% 深色，52% 近单色、43% 低饱和——**界面越中性，作品越突出**。
- 深色底适合摄影与动效作品（#150、#154、#142），浅色底适合插画与平面。

## 动效

- 动效偏轻：低 39%、静态 30%。重点不在页面动，而在**作品自己动**。
- 招牌手法：
  1. **悬停预览**：索引表悬停某行，在光标旁浮出缩略图或视频（跟随光标，带缓动）。
  2. **悬停放大 / 去色**：网格中其他项降低不透明度，当前项放大 1.03。
  3. **视频缩略图**：动效作品用静音循环 `<video>`，进入视口才播放（`IntersectionObserver`）。
  4. **拖拽画布**：拼贴型可整体拖动浏览（#66 "click to zoom in, or drag to rearrange"）。

## 技术栈

- 自写 48%、Cargo 13%、Framer 13%、Webflow 9%、Wix 9%。**Cargo** 是这类站的老牌选择，插画 / 摄影师零代码可用。
- 图片务必做响应式（`srcset` / `next/image`）和懒加载，否则首屏极慢。

## 反模式

- 作品图尺寸、比例、调色不统一，网格看起来像素材库。先统一裁切比例或给每张图同样的底色。
- 只有图没有上下文：至少给项目名、类型、年份。
- 首屏一次加载 30 张原图。
