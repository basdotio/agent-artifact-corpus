# statement-hero · 一句话宣言型

首屏一句中大号无衬线宣言（我是谁 / 我做什么），下面是少量精选作品。干净、专业、可信，是求职作品集的安全牌。
14 / 174（8%），其中 8 个个人站、5 个工作室、1 个公司——下面的统计含工作室样本。

## 适合 / 不适合

- **适合**：产品 / UX 设计师求职、资深设计师、品牌化程度不高的工作室。
- **不适合**：想要强烈个人风格、希望被记住的人——容易显得“没特点”，需要靠作品和细节撑。

## 版式骨架

```
┌───────────────────────────────────────────┐
│ name                    work about contact│
│                                           │
│ 一句宣言，2–4 行，48–96px，句首或关键词      │
│ 可以换颜色 / 换衬线斜体做重点                │
│ 小字：Currently at X · Previously Y        │
│                                           │
│ ┌─────────┐ ┌─────────┐                   │ ← 2–4 个精选案例，大卡片
│ │ case 01 │ │ case 02 │                   │
└───────────────────────────────────────────┘
```

- 首屏标题中位 **67px**，36% 中号、36% 大号；**0 个**全大写——这一类用句子大小写说话。
- 页面中等偏长（中位 7.7 屏），案例往下展开。

## 字体

- 无衬线 79%：`Neue Montreal`、`Söhne`、`Suisse Intl`、`Helvetica`。免费替代 `Inter`（大字号开启 `opsz` 光学尺寸轴）、`Geist`、`Satoshi`、`Switzer`。
- 宣言句字重 400–500，行高 1.05–1.15，字距 -0.02 到 -0.03em。
- 小技巧：句中一个词换成衬线斜体（`Instrument Serif`），立刻有设计感；也可以像 #61 那样把后半句变灰来分出层次。

## 配色

- **93% 浅色**、79% 近单色。白底 / 浅灰底 + 黑字；重点词用灰色或一个强调色区分（#61 后半句变灰）。

## 动效

- 分布平均（静态 29%、中 29%）。Lenis 36%、three.js 36%（常是首屏一个 3D 小物件，如 #53 的黑色 3D 雕塑、#115 的彩色 3D 物体）。
- 招牌手法：
  1. **宣言逐词浮现**：按词 stagger 淡入。
  2. **首屏一个 3D 小物件**：自转或随光标转动，给干净页面一个视觉锚点。
  3. **案例卡片悬停**：图片轻微放大 + 光标变成 "View" 圆标。

## 补记忆点

这一原型自带“容易没特点”的短板。在不破坏克制感的前提下，只加**一个**记忆点（详见 `decision-guide.md`“条件冲突时”）：
- 宣言里一个衬线斜体关键词，带一条手绘感下划线；
- 页脚或角落一个“活的”小组件：本地时间 / 与访客的时区重叠、当前在做的项目；
- 一个精致的光标交互：悬停案例时出现 "View" 圆标；
- 首屏一个可转动的 3D 小物件（需要 three.js）。

## 技术栈

- 自写 71%、Framer 14%。Next.js + MDX 写案例最方便；Framer 也能很快做出来。

## 反模式

- 宣言写成空话（“I design delightful experiences”）。写具体：给谁、做了什么、结果如何。
- 首屏之后案例全是同样大小的缩略图——精选 2–4 个大案例比 12 个小卡片有力。
