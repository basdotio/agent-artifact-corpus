# experimental-art · 实验艺术型

故障、抖动、像素、CRT、生成艺术、非常规导航——故意打破网页惯例，网站是一件数字艺术作品。
9 / 174（5%），样本最少但辨识度最高。

## 适合 / 不适合

- **适合**：艺术指导、生成艺术 / 创意编程者、音乐 / 文化类工作室、想参加奖项的创意开发者。
- **不适合**：任何需要“被快速理解”的场景：求职、接单、B2B。若要用，务必保证名字、作品入口和联系方式一眼可见。

## 版式骨架

没有固定骨架，但数据里反复出现这几种结构：

```
A. 拼贴爆炸（#1）         B. 单一生成画面（#169）   C. 复古屏幕（#65）
多层图片 / 文字 / 色块      全屏 canvas 线条 / 点阵     CRT 弧面 + 扫描线
互相遮挡，信息密度极高     角落极小导航               像素大字 + 噪点
```

- 页面短（中位 1 屏），像一个可交互的画面而非文档。

## 字体

- 定制 / 展示字体为主：`Octave`（#1）、`ABC Oracle`（#2）、像素体（#65 "22.09.2000"）、`Persona` 风格（#36）。
- 免费替代：像素 `Silkscreen`、`VT323`、`Departure Mono`；怪诞展示 `Rubik Glitch`、`Bungee`、`Major Mono Display`。

## 配色

- 67% 深色，67% 近单色——实验感多来自**纹理和运动**而不是颜色。
- 常见组合：黑底 + 一个信号红 `#d00000` / `#bb0b0a`（#1、#36）；黑底 + CRT 琥珀黄 `#ebd348`（#65）；纯黑白（#30、#169）。

## 动效

- 三档平均（低 / 中 / 高各 33%），three.js 56%，p5.js 也出现了（#2）。
- 招牌手法：
  1. **故障 / 切片**：图片按条切片错位（#30 竖条切片人像）。
  2. **生成式线条**：Joy Division 式叠加波形线（#169），用 canvas 2D 即可。
  3. **CRT 效果**：曲面变形 + 扫描线 + 噪点 + 暗角（WebGL 片元着色器或 CSS 叠层）。
  4. **抖动（dither）/ 点阵**：Bayer 矩阵把图像变成 1-bit 像素。
  5. **反常规导航**：沿路径排布的文字（#30 环绕文字带）、节点图（#67）。

## 技术栈

- 自写 89%，Astro 33%（静态外壳 + 一个重 canvas 岛）。p5.js / three.js / 原生 canvas。

## 反模式

- 只有效果没有观点：实验要服务于你的身份（音乐、文化、技术立场），否则就是 Shadertoy 拼盘。
- 完全不可访问：没有文字替代、闪烁频率过高（> 3 次/秒有光敏风险）。
- 移动端直接崩溃。
