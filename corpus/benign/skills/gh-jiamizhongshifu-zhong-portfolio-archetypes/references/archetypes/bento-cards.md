# bento-cards · Bento 卡片型

圆角卡片 / 小组件拼成仪表盘式网格，像 iOS 主屏或个人名片集：头像、简介、所在地、工具栈、作品、社交，各占一格。
12 / 174（7%）。

## 适合 / 不适合

- **适合**：产品设计师、创意开发者、多面手（设计 + 写作 + 副业项目）；信息种类多但每样都不长。
- **不适合**：只有 1–2 类作品的人（格子会空）；追求强烈艺术感的品牌设计师。

## 版式骨架

```
┌───────────────────────────────────────────┐
│ ┌──────────┐ ┌─────┐ ┌─────────────────┐  │
│ │ 头像+简介 │ │地点 │ │   精选作品大卡   │  │
│ │          │ │时钟 │ │                 │  │
│ ├──────┬───┴─┴─────┤                 │  │
│ │ 工具 │  客户 logo │                 │  │
│ ├──────┴──────┬────┴─────────────────┤  │
│ │ 最近文章     │ 社交 / newsletter     │  │
│ └─────────────┴──────────────────────┘  │
└───────────────────────────────────────────┘
```

- CSS Grid，12 列或 4 列基础单元，卡片跨 1–2 格；圆角 16–24px，间距 8–16px。
- 首屏标题中位 **32px**，100% 无衬线。

## 字体

- `Geist`（3 例，最常见）、`Inter`、`Satoshi`、`Nohemi`、`Suisse Intl`。卡片内用 13–15px 小字 + 一个 24–32px 标题。

## 配色

- 67% 浅色、33% 深色，83% 近单色。
- 浅色版：浅灰底 `#f2f2f2` + 白卡片 + 极淡阴影；深色版：`#0f0f10` 底 + `#1a1a1c` 卡片 + 1px 边框 `rgba(255,255,255,.08)`。
- 颜色交给卡片里的内容（作品图、App 图标、贴纸）。

## 动效

- 偏轻：静态 42%、低 33%。
- 招牌手法：
  1. **卡片悬停微抬升**：`translateY(-2px)` + 阴影加深，或 3D 倾斜（`perspective` + 光标位置）。
  2. **活的小组件**：实时时钟 / 本地时间、天气、正在听的歌、GitHub 贡献格子（#95）。
  3. **贴纸 / 可拖拽元素**：在卡片上贴可拖动的贴纸（#175 墨镜和笑脸贴纸）。
  4. **入场 stagger**：卡片按网格顺序缩放淡入。

## 技术栈

- 自写 58%、Framer / Webflow 各 17%。CSS Grid 足够，不需要动效库。

## 反模式

- 每格内容都一样重，没有主角。让 1 张卡（精选作品或自我介绍）明显更大。
- 为了填格子放无意义的装饰卡。
- 移动端只是把网格缩小——要重排成单列并调整顺序。
