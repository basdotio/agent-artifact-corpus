# skeuo-desktop · 拟物桌面型

把网站做成一个界面隐喻：操作系统桌面、文件夹、便签、笔记本电脑、唱片机、硬件面板、桌上的实物。访客通过“使用”它来浏览你。
11 / 174（6%）。

## 适合 / 不适合

- **适合**：设计工程师、交互设计师、Framer 开发者——拟物交互本身就是能力证明。
- **不适合**：作品需要大面积展示的视觉设计师；赶时间的人（细节量大）。

## 字体

- 跟随隐喻：Windows XP 用 `Tahoma`（#59），复古 Mac 用 `Chicago`（#64），现代 macOS 用 `Inter` / `SF`；文本感用打字机等宽 `iA Writer Quattro`（#22），名字可用手写体（#54 `Historia Sky Script`）。
- 免费替代：`Inter`、`DM Sans`；像素体 `Silkscreen`、`Pixelify Sans`、`Departure Mono`；打字机 `iA Writer`（开源）、`Courier Prime`。

## 配色

- 64% 浅色，配色来自物件本身。现代版：浅灰桌面 + 真实物件阴影；复古版：XP 蓝 `#547de7`、像素紫 `#5757e9`（#64）。
- 数据中的强调色：`#538ecc`、`#547de7`、`#5757e9`、便签黄 `#fbf9d5`。

## 动效

- 动效库用得少（只有 three.js 9%），但**交互细节密度最高**：React 64%（状态多）。
- 招牌手法：
  1. **可拖拽窗口 / 物件**：`pointer` 事件 + 惯性，层级点击置顶。
  2. **开机 / 登录流程**：#59 XP 登录页 "To begin, click on Mitch Ivin to log in"。
  3. **真实物理感**：物件阴影随拖动变化、放下时轻微回弹（spring）。
  4. **声音反馈**：点击、开窗、唱片机音效（#62）。
  5. **便签 / 手写注释**：#22 "Hey, glad you're here…" 手写便签引导访客。

## 技术栈

- React 64%、Framer 36%（Framer 很适合做可拖拽物件）。复杂窗口管理用 React 状态 + `framer-motion` 的 `drag`。

## 反模式

- 隐喻只是贴图，什么都点不了——这一原型的价值全在“能用”。
- 移动端照搬桌面窗口，手指拖不动。为移动端设计一个简化入口（列表或卡片）。
- 复刻真实系统的商标 / 图标太像，有侵权风险。#59 这类致敬要做出自己的变体。
