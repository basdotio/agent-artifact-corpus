# editorial-serif · 编辑杂志型

衬线大标题、杂志式版面、克制的配色和精致的图文关系。优雅、有文化感，像一本设计年鉴。
12 / 174（7%）。

## 适合 / 不适合

- **适合**：品牌设计师、艺术指导、时尚 / 生活方式 / 文化领域的设计师与工作室、写作型设计师。
- **不适合**：科技 / 开发者气质的个人品牌（衬线会显得不搭）；作品图质量一般的人（杂志版式会放大图片的缺点）。

## 版式骨架

```
┌───────────────────────────────────────────┐
│ EST. 2015 · CITY          AUTUMN 2026     │ ← 刊头式小字：年份、地点、季节
│                                           │
│        Nik  Klemenc                       │ ← 衬线大名字，可居中、可满宽
│        ─────────                          │
│  小字栏         大图 / 作品               │ ← 不对称两栏、细分隔线
│  (摘要)                                   │
│                                           │
│ 01 ─ Project title ─────── 2026           │
└───────────────────────────────────────────┘
```

- 首屏标题中位 **64px**，42% 达到 120px+（#89 VIC ROJO、#141 REGINA MUSI 满宽）。
- 页面长（中位 9.4 屏），像翻杂志一样一页页展开。

## 字体

- 标题衬线 42%（名字识别为无衬线的多是自定义衬线文件，实际比例更高）。数据中的衬线：`Newsreader`、`Martina Plantijn`、`Crimson Pro`、`Larken`、`Reckless`。
- 免费替代：`Instrument Serif`、`Newsreader`、`Fraunces`、`Playfair Display`、`Cormorant`；正文配干净无衬线（`Inter`、`Suisse` 类）或同族衬线。
- 斜体是灵魂：名字或关键词用斜体（#120 橙色斜体名字、#139 斜体大写）。
- 刊头小字：大写 + 开字距 0.1em + 10–12px。

## 配色

- 83% 浅色，75% 近单色。底色常是**纸张色**而非纯白：`#f4efe6`、`#ede6da`、米色、浅灰绿。
- 一个文化感强调色：墨绿 `#134343`、`#1f2702`（#139 橄榄绿底配荧光黄绿字）、陶土橙（#120）、深绿（#141）。

## 动效

- 高 33%、低 33%，两极分化：要么非常安静，要么做精致的滚动叙事。GSAP 33%、Lenis 25%，6 / 12 有自定义光标。
- 招牌手法：
  1. **图片遮罩揭示**：图片从 `clip-path: inset(100% 0 0 0)` 展开到 0。
  2. **标题行遮罩上移**：每行在 `overflow: hidden` 容器里从下方升起。
  3. **视差图文**：图片与文字以不同速度滚动。
  4. **文字跟随光标的圆形 "View" 按钮**。

## 技术栈

- 自写 58%、Framer / Webflow 各 17%、Tilda 8%。

## 反模式

- 衬线和无衬线混用超过 2 种字族。
- 用纯白 `#fff` 底 + 纯黑字——失去纸张感。
- 只有标题像杂志，作品区退化成普通网格。
