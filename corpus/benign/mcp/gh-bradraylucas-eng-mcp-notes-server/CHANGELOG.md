# Changelog

## 1.0.0 — 2026-10-13
- Initial open-source release (MIT): notes server with create_note, list_notes, search_notes tools; local JSON storage with atomic saves; input validation; client config examples; dependency-free smoke test.
- Released as the free companion to the paid "MCP Server Starter Templates" pack on Gumroad (bradray2.gumroad.com), which adds a read-only SQLite lookup server, a web-summary server skeleton, a testing checklist, and security notes.
