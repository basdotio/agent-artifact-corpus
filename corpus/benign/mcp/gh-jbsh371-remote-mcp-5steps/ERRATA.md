# 정오표

책이 나간 뒤에 발견된 잘못과, 시간이 지나 어긋나게 된 곳을 여기 모읍니다.

**막히셨을 때 여기부터 보세요.** 이 책에는 라이브러리 버전과 플랫폼 화면에 따라 달라지는 곳이 있습니다. 그런 곳은 시간이 지나면 책에 적힌 것과 달라집니다. 책대로 했는데 안 되면 여러분이 잘못하신 게 아닐 수 있습니다.

브라우저에서 `Ctrl+F`를 누르고 단계 이름이나 오류 메시지로 찾아보세요.

## 적는 방식

| 항목 | 뜻 |
|---|---|
| 자리 | 어느 장의 어느 대목인가 |
| 무엇이 틀렸나 | 책에 적힌 것 |
| 무엇이 맞나 | 지금 맞는 것 |
| 언제 | 확인한 날짜 |
| 왜 | 오탈자인지, 시간이 지나 달라진 것인지 |

**오탈자와 낡은 것을 구분해 적습니다.** 오탈자는 처음부터 틀린 것이고, 낡은 것은 그때는 맞았는데 지금 달라진 것입니다. 뒤의 것은 여러분이 쓰시는 버전이 책과 다를 때만 해당합니다.

- 무엇을 하셨고 무엇이 나왔나 (오류 메시지를 그대로)
