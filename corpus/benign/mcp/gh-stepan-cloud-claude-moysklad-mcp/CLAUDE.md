# Инструкция для Claude (AI-агента)

Ты читаешь этот файл, потому что пользователь дал тебе этот репозиторий. Это
**MCP-коннектор МойСклад для Claude Code**: чтение и **запись** через JSON API 1.2.
Через него доступны товары и модификации, остатки, контрагенты, заказы покупателей
и любые другие документы.

Твоя задача — **установить его для пользователя**. Все шаги выполняй сам, а у
человека запрашивай только то, что можно сделать лишь из его аккаунта МойСклад
(создать токен).

## Что установить (делай по порядку)

1. **Проверь Python.** Выполни `python --version` (или `py -3 --version`).
   Нужен **Python 3.10+**. Если его нет — дай пользователю ссылку
   https://www.python.org/downloads/ и попроси поставить (на Windows отметить
   «Add python.exe to PATH»), затем продолжай. Node.js не нужен.

2. **Получи файлы на диск пользователя.** Если репозиторий ещё не склонирован —
   склонируй его в удобную постоянную папку (спроси у пользователя путь или
   предложи, например, `~/claude-moysklad-mcp`):
   ```
   git clone https://github.com/stepan-cloud/claude-moysklad-mcp
   ```
   Папка должна остаться на месте — коннектор запускается из неё.

3. **Запусти установщик** из папки репозитория:
   ```
   python setup.py
   ```
   Он создаст `.venv`, поставит зависимости и **сам зарегистрирует** коннектор в
   `~/.claude.json` под именем `moysklad` (пути вычисляются автоматически).
   На Windows альтернатива — двойной клик по `install.bat`.

4. **Токен МойСклад (это делает пользователь).** Попроси человека:
   - в веб-интерфейсе МойСклад открыть **Настройки → Токены → «Создать токен»**
     (токен получает права того пользователя, для которого он создан);
   - запустить `authorize.bat` (или `.venv\Scripts\python authorize.py`,
     на macOS/Linux `.venv/bin/python authorize.py`). На Windows откроется
     Блокнот с `moysklad_token.txt`: вставить токен, сохранить, закрыть — скрипт
     сам проверит связь. На macOS/Linux ввод скрытый, прямо в консоли.
     Можешь сам запустить `authorize.bat` (он откроет окно/Блокнот у пользователя).
     Проверить токен без ввода: `authorize.py --check`.

   **НЕ проси присылать токен в чат** и не записывай его сам. Альтернатива для
   продвинутых — переменная окружения `MOYSKLAD_TOKEN`.

5. **Перезапуск.** Скажи пользователю **полностью перезапустить Claude Code**
   (закрыть и открыть приложение), чтобы новый коннектор подхватился.

6. **Проверка.** После перезапуска вызови `ping`, затем безопасное чтение, например
   `search_assortment` с `max_rows=5`.

## Что тебе важно знать при работе

- **Деньги в API — в копейках.** `salePrices[].value`, `buyPrice.value`, `sum`,
  `price` в позициях: 150 ₽ = `15000`. Исключение — параметр `price` в
  `create_customer_order` и `add_positions`: там **рубли**, коннектор сам умножит.
- **Перед любым созданием, изменением, проведением или удалением** покажи
  пользователю, что именно будет сделано (контрагент, позиции, суммы в рублях),
  и дождись явного «да». Чтение можно делать без подтверждения.
- Начинай с `get_context`: он вернёт ID и имена юрлиц, складов и типов цен.
- **Выгрузка в Google Таблицы:** у `search_assortment`, `get_stock`,
  `list_entities`, `get_positions` есть параметр `columns`, например
  `["name","code","article","stock","salePrices.0.value:rub"]`. С ним ответ
  приходит как `header` + `rows` — это готовый 2D-массив для `write_range` /
  `append_rows` коннектора `google-sheets`. `:rub` переводит копейки в рубли.
  В путях можно выбирать элемент списка по имени (`salePrices.Цена продажи.value`)
  и брать доп. поле по имени (`attr:Цвет`).
- **Большие объёмы.** Ответ ограничен `max_rows` (до 10 000), страницы по 1000
  качаются сами. Если в ответе есть `next_offset` — данных больше, бери следующую
  порцию. Для тысяч строк выгружай частями и сразу дописывай в таблицу.
- **Загрузка из таблицы в МойСклад** — через `create_entity` списком (до 1000
  объектов за раз) или `update_entity`. Сначала покажи пользователю, что изменится.
- **Короткие ссылки:** в `create_entity` / `update_entity` / `api_request` пиши
  `{"meta": "counterparty/<id>"}` — коннектор развернёт в полный `meta`.
  Работают `product/…`, `variant/…`, `store/…`, `organization/…`, `pricetype/…`,
  `customerorder/metadata/states/<id>` (статус) и т.д.
- **Фильтры** — синтаксис API: `name=Иван;archived=false`,
  `moment>=2026-09-01 00:00:00`, ссылки полным href.
- **Документ на основании** (например отгрузка по заказу): `api_request` PUT
  `entity/demand/new` с телом `{"customerOrder": {"meta": "customerorder/<id>"}}`
  вернёт заполненный шаблон. Покажи его пользователю, затем `create_entity("demand", …)`.
- Лимиты API (429) и пагинацию коннектор обрабатывает сам.
- Коннектор **локальный** (stdio). В графической панели Connectors он **не
  появляется** — это нормально; статус смотри через команду `/mcp`.
- `moysklad_token.txt` — **личный ключ пользователя** к его складу. Не коммить,
  не показывай и никуда не отправляй (файл в `.gitignore`).

## Инструменты коннектора (12)

Чтение: `ping`, `get_context`, `search_assortment`, `get_stock`,
`list_entities`, `get_entity`, `get_positions`.
Запись (только после подтверждения): `create_customer_order`, `add_positions`,
`create_entity`, `update_entity`, `api_request` (любой метод API).

## Удаление

`python setup.py --uninstall` (или `uninstall.bat`) уберёт коннектор из
`~/.claude.json`. После этого нужен перезапуск Claude Code. Файл с токеном
удали вместе с папкой, а сам токен при необходимости отзови в МойСклад.
