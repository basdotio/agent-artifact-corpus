MCP 工具描述编辑

play_fishing 工具描述

                        

                        

                            
Claude 每次调用钓鱼工具时看到的说明。写指令教程、行为限制、角色设定均可。

                            
                        

                    

                    

                        

                            
                            
new_fishing_game 工具描述

                        

                        

                            
Claude 调用重开一局时看到的说明。

                            
                            

                                

                                    提示

                                    这两个工具是 Claude 唯一能调用的 MCP 接口。所有游戏操作都通过 play_fishing 的 command 参数传入。


                                    你可以在描述里写：

                                    · 指令教程（教 Claude 怎么用）

                                    · 行为限制（"只能钓稀有鱼""不准卖传说鱼"）

                                    · 角色设定（"你是一个贪心的渔夫"）

                                    · 策略提示（"先攒钱解锁高级钓点"）
