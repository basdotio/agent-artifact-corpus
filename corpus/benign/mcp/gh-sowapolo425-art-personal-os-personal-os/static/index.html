1. 连接你的 Agent
在支持本地 MCP 的 Agent 中添加 Personal OS。启动参数与资料库路径保持一致，面板和 Agent 就能使用同一份资料。
Codex、Claude Code、ZCode、WorkBuddy 的具体设置，请查看项目接入指南；品牌兼容状态以实际验证为准。
2. 用对话积累资料
/capture 只记录原文
/deep 深聊并记录
/discuss 只讨论，不写入
/review 基于证据复盘
这些是 Agent 的交互规则；真正调用工具后才会保存。
3. 在面板里确认草稿
你的经历、想法与 AI 推断需要区分。打开待确认草稿，核对内容和证据，再批准或拒绝。
面板每 30 秒刷新；Agent 写入新资料后也可以点击刷新。
4. 保管好你的资料
使用备份管理下载完整备份，包含隐藏的历史与草稿。恢复会创建新的资料库，不会覆盖当前内容。
本地文件为明文。使用云端模型时，Agent 读取的内容仍可能发给对应服务。
