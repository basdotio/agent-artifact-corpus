# Contributing to ReachDirect-MCP

First off, thank you for considering contributing to ReachDirect-MCP! It's people like you that make open-source such a great community.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
* Use the GitHub issue search — check if the issue has already been reported.
* Check if the issue has been fixed — try to reproduce it using the latest `main` branch.

### Suggesting Enhancements
* Open a new issue to discuss the enhancement before starting work.
* Provide a clear and detailed explanation of the feature.

### Pull Requests
* Fill in the required template.
* Do not include issue numbers in the PR title.
* Include screenshots and animated GIFs in your pull request whenever possible.
* End files with a newline.
