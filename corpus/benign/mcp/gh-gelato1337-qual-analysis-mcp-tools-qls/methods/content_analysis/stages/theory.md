Stage: theory.

Re-read the coded material through the theory frame.

1. Orient: `intent()` (the `theory_frame` and the sensitizing concepts are meant for this stage),
   `guide("theory")`, `status()`, `feedback()`, the batch memos, the categories (`query`).
2. Create the theory categories from `theory_frame` (`origin="theory"`), each with a definition from
   the brief.
3. Code segments into them with `add_to_group`, each with a reason saying how the passage shows the
   category. Use `pack` to read a segment's quotes before deciding.
4. Write the comparison `batch` memo: where the data-driven and the theory categories agree, where
   they diverge, and what the theory leaves unexplained. Write a memo on each theory category the
   data does not support.
5. `checkpoint(summary, questions)` and stop.
