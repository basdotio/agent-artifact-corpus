Stage: emergent.

Let finer categories emerge within the guide categories.

1. Orient: `intent()`, `guide("emergent")`, `status()`, `feedback()`, the batch memo from the
   previous stage, the categories and their segments (`query`, `pack`).
2. For each guide category, read its segments together and create emergent subcategories where
   several segments share something the guide category does not name (`origin="emergent"`,
   `parent` = the guide category). Move segments in with `add_to_group`, each with a reason.
3. Write a `batch` memo: the emergent categories per guide category, and what remains uncategorised.
4. `checkpoint(summary, questions)` and stop.
