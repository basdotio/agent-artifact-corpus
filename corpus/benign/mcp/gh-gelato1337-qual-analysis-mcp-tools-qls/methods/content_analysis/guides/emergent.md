# Emergent categories

Within each guide category, read all its segments together (`query`, `pack`) and ask: what kinds
of thing are being said here? Where several segments share something the guide category does not
name, that is an emergent category.

- Create it with `add_category`, `origin="emergent"`, `parent` = the guide category it refines, and
  a definition.
- Move segments into it with `add_to_group`, each with a reason. A segment stays in its guide
  category too: emergent categories refine, they do not replace.
- An emergent category needs at least two segments, from more than one interview if possible. One
  striking segment is a memo, not a category.
- Name it in the informants' terms where you can. Do not use theory words yet.
- Segments that fit no emergent category are fine. Write a short memo on what the remainder of each
  guide category contains.
