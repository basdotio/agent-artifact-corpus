# Case description and path

One memo per interview: `memo(about=[source], kind="summary", level="interview")`. The interview
level is reserved for this case description; notes from earlier stages are `note`-level memos.

Build it from that case's coded segments (`query`, `pack`), ordered by `period`. Write it in two parts:

1. **The case's story.** How the firm's development unfolded over the period, in the order it
   happened: the main phases, the events and turning points that separate them, and what the
   informant says drove each upturn and downturn. Cite segment ids.
2. **The path.** A short year-by-year (or phase-by-phase) list: period, what changed, the
   categories involved, direction. Where the brief gives stage models, say which stage each phase
   resembles, and say plainly where the case does not follow the stages.

Stay with this one case. Do not compare with other cases here; that is the synthesis.

## The synthesis (after all cases)

One `corpus` memo about the intent, citing the batch memos (and naming the case memos in the text): answer each research question across the
cases. What is shared, what differs, and why. Keep the cases visible: a pattern seen in one case is
said to be in one case.
