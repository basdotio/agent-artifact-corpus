# Setting up the coding frame

The coding frame is in `intent()` under `coding_frame`. Create one category per entry with
`add_category`, `origin="guide"`.

- Use the label as given. Write the definition so that a coder who has not read the brief can
  decide what belongs: what the category covers, and what it does not (with the neighbouring
  category to use instead).
- If the frame is two-dimensional (for example internal/external × accelerating/decelerating),
  make one category per cell, not one per dimension: each passage is then coded into a cell.
- Do not add, merge or rename categories. If the frame seems to miss something, write a `method`
  memo about the intent and raise it at the checkpoint.
- Do not create theory categories yet: they come in a later stage.
